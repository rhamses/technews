contentHtml: "<div><p>The most capable agents have something simple in common: they are given their own computer to work with.</p><p>Coding agents work this way. You give them a filesystem, a shell, tools, packages, and the ability to run code. They inspect the environment, make changes, test their work, and keep going. The computer gives the model a familiar way to act on the world. At Cloudflare, we’re working hard to provide the right primitives on which to build the most capable agents.</p><p><strong>Today we’re introducing an early preview of <a href=\"https://github.com/cloudflare/workspace\" target=\"_blank\"><u>@cloudflare/computer</u></a>.</strong> The @cloudflare/computer package provides an agent runtime where the details and mechanics of what code runs in an isolate, a container sandbox, or a web browser are handled by the platform. Each agent gets a computer, the runtime optimizes for efficiency, and scalability. </p><p>We believe that in order to meet the growing demand for compute required by agentic systems we need to look to solutions beyond traditional containerization.&#160;</p><h2>Changing how agents are built</h2><p>We’ve seen a subtle evolution of this story over the past six months. At the start of the year, spinning up a container and running an agent inside of it was the norm. In recent months, we’ve seen a rapid move for agent harnesses to provide sandboxed code execution via tools. This separates the hands (the sandbox where work is done) from the brain (the agent loop).</p><figure><p><img src=\"https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01KZ0QHGR1F725Y45HAYQ7EP4V.png&w=715&h=292&f=webp&fit=cover&position=center\" srcset=\"https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01KZ0QHGR1F725Y45HAYQ7EP4V.png&w=640&h=261&f=webp&fit=cover&position=center 640w, https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01KZ0QHGR1F725Y45HAYQ7EP4V.png&w=715&h=292&f=webp&fit=cover&position=center 715w, https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01KZ0QHGR1F725Y45HAYQ7EP4V.png&w=750&h=306&f=webp&fit=cover&position=center 750w, https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01KZ0QHGR1F725Y45HAYQ7EP4V.png&w=828&h=338&f=webp&fit=cover&position=center 828w, https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01KZ0QHGR1F725Y45HAYQ7EP4V.png&w=1080&h=441&f=webp&fit=cover&position=center 1080w, https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01KZ0QHGR1F725Y45HAYQ7EP4V.png&w=1280&h=523&f=webp&fit=cover&position=center 1280w, https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01KZ0QHGR1F725Y45HAYQ7EP4V.png&w=1430&h=584&f=webp&fit=cover&position=center 1430w\" alt=\"BLOG-3464_image6.png\"></p></figure><p>No matter where the harness runs, giving every agent a container presents a challenge —&#160;across all the clouds, all the hyperscalers, there’s nowhere near enough compute in the world for every company to give each of their users’ agents their own containerized compute environment. This will not scale to hundreds of millions, then billions, of concurrent agents. This is why there is desperate, panicked industry demand for CPU compute, not just GPU compute.</p><p>We’ve been working on this problem for a long time at Cloudflare, creating a more efficient compute primitive: isolates. We made that out-of-consensus bet almost 10 years ago when we <a href=\"https://blog.cloudflare.com/introducing-cloudflare-workers/\" target=\"_blank\"><u>introduced Cloudflare Workers</u></a>. We made it again when we <a href=\"https://blog.cloudflare.com/introducing-workers-durable-objects/\" target=\"_blank\"><u>introduced Durable Objects</u></a> almost six years ago. We made this bet because isolates are infinitely horizontally scalable. They spin up and tear down incredibly quickly. They can <a href=\"https://developers.cloudflare.com/durable-objects/examples/websocket-hibernation-server/\" target=\"_blank\"><u>hibernate</u></a> when the agent is idle, <a href=\"https://blog.cloudflare.com/sqlite-in-durable-objects/\" target=\"_blank\"><u>store the agent’s own state</u></a>, and even <a href=\"https://blog.cloudflare.com/dynamic-workers/\" target=\"_blank\"><u>spin up their own isolates</u></a> to run untrusted code. Isolates are the best way to scale horizontally, and horizontal scale is what agents demand.</p><figure><p><img src=\"https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01KZ0QHG8112R261JGEK5515Y7.png&w=715&h=683&f=webp&fit=cover&position=center\" srcset=\"https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01KZ0QHG8112R261JGEK5515Y7.png&w=640&h=611&f=webp&fit=cover&position=center 640w, https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01KZ0QHG8112R261JGEK5515Y7.png&w=715&h=683&f=webp&fit=cover&position=center 715w, https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01KZ0QHG8112R261JGEK5515Y7.png&w=750&h=716&f=webp&fit=cover&position=center 750w, https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01KZ0QHG8112R261JGEK5515Y7.png&w=828&h=791&f=webp&fit=cover&position=center 828w, https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01KZ0QHG8112R261JGEK5515Y7.png&w=1080&h=1032&f=webp&fit=cover&position=center 1080w, https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01KZ0QHG8112R261JGEK5515Y7.png&w=1280&h=1223&f=webp&fit=cover&position=center 1280w, https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01KZ0QHG8112R261JGEK5515Y7.png&w=1430&h=1366&f=webp&fit=cover&position=center 1430w\" alt=\"BLOG-3464_image3.png\"></p></figure><p>Last year, we <a href=\"https://blog.cloudflare.com/containers-are-available-in-public-beta-for-simple-global-and-programmable/\" target=\"_blank\"><u>gave isolates the ability to spin up their own container sandboxes</u></a>. From day one, Cloudflare’s architecture has been designed to run the agent harness in the isolate (in a Durable Object) and call an attached container on-demand as a tool. This allows you to utilize heavier compute primitives only when required, optimizing performance and cost. Durable Objects scale infinitely horizontally, and the attached container lets it scale vertically to perform any task. This is how we build agents ourselves, and we’re seeing customers build incredible things this way too.</p><figure><p><img src=\"https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01KZ0QHGJWE4D64HEZPZ1PMCAN.png&w=715&h=352&f=webp&fit=cover&position=center\" srcset=\"https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01KZ0QHGJWE4D64HEZPZ1PMCAN.png&w=640&h=315&f=webp&fit=cover&position=center 640w, https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01KZ0QHGJWE4D64HEZPZ1PMCAN.png&w=715&h=352&f=webp&fit=cover&position=center 715w, https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01KZ0QHGJWE4D64HEZPZ1PMCAN.png&w=750&h=369&f=webp&fit=cover&position=center 750w, https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01KZ0QHGJWE4D64HEZPZ1PMCAN.png&w=828&h=408&f=webp&fit=cover&position=center 828w, https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01KZ0QHGJWE4D64HEZPZ1PMCAN.png&w=1080&h=532&f=webp&fit=cover&position=center 1080w, https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01KZ0QHGJWE4D64HEZPZ1PMCAN.png&w=1280&h=630&f=webp&fit=cover&position=center 1280w, https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01KZ0QHGJWE4D64HEZPZ1PMCAN.png&w=1430&h=704&f=webp&fit=cover&position=center 1430w\" alt=\"BLOG-3464_image8.png\"></p></figure><p>But when we look at this need to have multiple underlying compute primitives to build agents (isolates and containers) and the need for our customers and developers to combine them themselves in userspace, we think we can do better. We think that we can provide a simpler abstraction.</p><p>That’s why we’re starting this experiment by shipping @cloudflare/computer as an open-source library, to learn with our customers who are pushing the bounds of running agents at scale.</p><h2>A shared filesystem across isolates and containers</h2><p>The @cloudflare/computer package starts with a simple premise: what if we give an agent a primed filesystem, declaratively defined, containing everything required for the task at hand and a selection of execution environments to operate on those files, each with their own pros and cons regarding speed, capability and cost?</p><p>It turns out that agents today are surprisingly capable of selecting the right environment for the task at hand. A job that only needs to manipulate files, process data, or manage a git repository can run inside an isolate. A command that needs Linux, <code>npm</code>, or a native binary can run inside a container. Both work against the same files that are kept in sync with the source filesystem.</p><figure><p><img src=\"https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01KZ0QHGH4NAWXAMWKSJ5JDMQY.png&w=715&h=645&f=webp&fit=cover&position=center\" srcset=\"https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01KZ0QHGH4NAWXAMWKSJ5JDMQY.png&w=640&h=577&f=webp&fit=cover&position=center 640w, https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01KZ0QHGH4NAWXAMWKSJ5JDMQY.png&w=715&h=645&f=webp&fit=cover&position=center 715w, https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01KZ0QHGH4NAWXAMWKSJ5JDMQY.png&w=750&h=677&f=webp&fit=cover&position=center 750w, https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01KZ0QHGH4NAWXAMWKSJ5JDMQY.png&w=828&h=747&f=webp&fit=cover&position=center 828w, https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01KZ0QHGH4NAWXAMWKSJ5JDMQY.png&w=1080&h=974&f=webp&fit=cover&position=center 1080w, https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01KZ0QHGH4NAWXAMWKSJ5JDMQY.png&w=1280&h=1155&f=webp&fit=cover&position=center 1280w, https://blog.cloudflare.com/_image?href=https%3A%2F%2Fblog.cloudflare.com%2F_emdash%2Fapi%2Fmedia%2Ffile%2F01KZ0QHGH4NAWXAMWKSJ5JDMQY.png&w=1430&h=1290&f=webp&fit=cover&position=center 1430w\" alt=\"BLOG-3464_image2.png\"></p></figure><p>The @cloudflare/computer package provides a durable filesystem that you can use with git repositories, storage buckets or any files you choose. It provides tools that let you read, write and edit files using <a href=\"https://blog.cloudflare.com/code-mode/\" target=\"_blank\"><u>Code Mode</u></a> or bash commands.
