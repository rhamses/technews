upgrade any <code>@astrojs/*</code> integrations and adapters you have installed, too!</p>\n<h2 id=\"persistent-ui-in-view-transitions\">Persistent UI in View Transitions</h2>\n<p>Our first release of the <code>&lt;ViewTransition /&gt;</code> router brought smooth transitions between pages but still caused any stateful islands or elements to be re-rendered.</p>\n<p>In 2.10, we’ve added a new <code>transition:persist</code> directive to the API to address this.</p>\n<p>With this directive, you can keep the state of DOM elements and islands from the old page when transitioning to the new page. <a target=\"_blank\" href=\"https://stackblitz.com/edit/github-stfdbe-ikkp2e?file=src%2Fpages%2Findex.astro\">Here’s a demo</a> of it in action.</p>\n<p>For example, to keep a video playing across page navigation, add <code>transition:persist</code> to the element:</p>\n<div><figure><pre><code><div><p><span>&lt;</span><span>video</span><span> </span><span>controls</span><span>=</span><span>\"\"</span><span> </span><span>autoplay</span><span>=</span><span>\"\"</span><span> </span><span>transition:persist</span><span>&gt;</span></p></div><div><p><span><span>  </span></span><span>&lt;</span><span>source</span></p></div><div><p><span>    </span><span>src</span><span>=</span><span>\"https://ia804502.us.archive.org/33/items/GoldenGa1939_3/GoldenGa1939_3_512kb.mp4\"</span></p></div><div><p><span>    </span><span>type</span><span>=</span><span>\"video/mp4\"</span></p></div><div><p><span><span>  </span></span><span>/&gt;</span></p></div><div><p><span>&lt;/</span><span>video</span><span>&gt;</span></p></div></code></pre></figure></div>\n<p>This <code>&lt;video&gt;</code> element, with its current state, will be moved over to the next page (if the video also exists on that page).</p>\n<p>Likewise, this feature works with any client-side framework component island.
