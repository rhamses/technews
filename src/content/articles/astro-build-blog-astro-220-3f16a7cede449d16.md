Included in this release are:</p>\n<ul>\n<li><strong><a target=\"_blank\" href=\"https://astro.build/blog/astro-220/#cdn-support\">CDN support for assets</a></strong>: You can now deploy your assets to an external CDN, and Astro will load them from there.</li>\n<li><strong><a target=\"_blank\" href=\"https://astro.build/blog/astro-220/#image-schema-api-change\">image() schema helper API change</a></strong>: (experimental) The <code>image()</code> helper has been moved to be inline with the schema definition.</li>\n</ul>\n<p>Additionally, Astro 2.2 includes <strong>8 patch changes</strong> and was released alongside <strong>8 integrations</strong> with patch releases.</p>\n<p>Run <code>npm i astro@latest</code> to upgrade to the latest version.</p>\n<h2 id=\"cdn-support\">CDN support</h2>\n<p>In 2.2 you can now configure Astro to point to a CDN in order to load your assets. In your Astro config:</p>\n<div><figure><pre><code><div><p><span>import</span><span> { </span><span>defineConfig</span><span> } </span><span>from</span><span> </span><span>\"astro/config\"</span></p></div><div><p><span>export</span><span> </span><span>default</span><span> </span><span>defineConfig</span><span>({</span></p></div><div><p><span>  </span><span>build</span><span>: {</span></p></div><div><p><span>    </span><span>assetsPrefix</span><span>: </span><span>\"https://cdn.example.com\"</span><span>,</span></p></div><div><p><span><span>  </span></span><span>},</span></p></div><div><p><span>})</span></p></div></code></pre></figure></div>\n<p>The links for any assets, scripts, and stylesheets after running <code>astro build</code> will be prefixed with the configured URL. This applies to both SSG and SSR modes.</p>\n<div><figure><pre><code><div><p><span>&lt;</span><span>link</span><span> </span><span>rel</span><span>=</span><span>\"stylesheet\"</span><span> </span><span>href</span><span>=</span><span>\"https://cdn.example.com/_astro/global.css\"</span><span> /&gt;</span></p></div></code></pre></figure></div>\n<p>The assets are still built to your <code>dist/</code> folder, like always.
