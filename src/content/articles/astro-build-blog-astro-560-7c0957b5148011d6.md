the perfect balance between speed and resource usage with Astro’s new prefetch eagerness controls. With the experimental <a target=\"_blank\" href=\"https://docs.astro.build/en/reference/experimental-flags/client-prerender/\"><code>clientPrerender</code></a> flag enabled, you can use the <code>eagerness</code> option on <code>prefetch()</code> to suggest to the browser how eagerly it should prefetch/prerender link targets.</p>\n<p>This new option, which aligns with the browser’s <a target=\"_blank\" href=\"https://developer.mozilla.org/en-US/docs/Web/HTML/Element/script/type/speculationrules\">Speculation Rules API</a>, gives you fine-grained control over how aggressively the browser should prefetch or prerender your links:</p>\n<div><figure><pre><code><div><p><span>---</span></p></div><div><p><span>---</span></p></div><div><p><span>&lt;</span><span>script</span><span>&gt;</span></p></div><div><p><span>// Control prefetching eagerness</span></p></div><div><p><span>import</span><span> { </span><span>prefetch</span><span> } </span><span>from</span><span> </span><span>'astro:prefetch'</span><span>;</span></p></div><div><p><span>// Let's be strategic about this resource-intensive page</span></p></div><div><p><span>prefetch</span><span>(</span><span>'/data-heavy-dashboard'</span><span>, { </span><span>eagerness</span><span>: </span><span>'conservative'</span><span> });</span></p></div><div><p><span>// This page is critical to the user journey, load it ASAP!</span></p></div><div><p><span>prefetch</span><span>(</span><span>'/product-details'</span><span>);
