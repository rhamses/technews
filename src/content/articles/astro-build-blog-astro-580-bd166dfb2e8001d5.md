Alternatively, upgrade manually by running the upgrade command for your package manager:</p>\n<div><figure><pre><code><div><p><span># Recommended:</span></p></div><div><p><span>npx</span><span> </span><span>@astrojs/upgrade</span></p></div><div><p><span># Manual:</span></p></div><div><p><span>npm</span><span> </span><span>install</span><span> </span><span>astro@latest</span></p></div><div><p><span>pnpm</span><span> </span><span>upgrade</span><span> </span><span>astro</span><span> </span><span>--latest</span></p></div><div><p><span>yarn</span><span> </span><span>upgrade</span><span> </span><span>astro</span><span> </span><span>--latest</span></p></div></code></pre></figure></div>\n<h2 id=\"updated-minimum-nodejs-version-to-18208\">Updated minimum Node.js version to 18.20.8</h2>\n<p>Node.js 18 has now reached end-of-life and will no longer receive security updates or support. Therefore, Astro 5.8 now requires v20.3.0, v22.0.0 or higher. (v19 and v21 are not supported.) To help users upgrade, Astro will temporarily continue to support Node.js 18.20.8, which is the final LTS release of Node.js 18.</p>\n<p>We will drop support for Node.js 18 entirely in a future release, so we recommend upgrading to Node.js 22 as soon as possible. See Astro’s <a target=\"_blank\" href=\"https://docs.astro.build/en/upgrade-astro/#nodejs-support-and-upgrade-policies\">Node.js support policy</a> for more details about how and when we upgrade the minimum Maintenance LTS version.</p>\n<p>You can check your current Node.js version by running:</p>\n<div><figure><pre><code><div><p><span>node</span><span> </span><span>-v</span></p></div></code></pre></figure></div>\n<p>You will need to update both your local development environment and any CI/CD environments to use Node.js 18.20.8 or one of the supported versions. You can check the docs for your <a target=\"_blank\" href=\"https://docs.astro.build/en/guides/deploy/\">deployment platform</a> to see how to set the Node.js version. This might involve choosing an option in a dashboard, setting an environment variable, or adding a configuration file to your project. Many platforms will respect the <code>NODE_VERSION</code> environment variable or a <a target=\"_blank\" href=\"https://github.com/nvm-sh/nvm#nvmrc\"><code>.nvmrc</code></a> file.</p>\n<p>For example, to set the Node.js version to 22, you can create a <code>.nvmrc</code> file in your project root with the following content:</p>\n<div><figure><pre><code><div><p><span>22</span></p></div></code></pre></figure></div>\n<p>See the <a target=\"_blank\" href=\"https://github.com/nvm-sh/nvm#nvmrc\">nvm docs</a> for more details on how to use <code>.nvmrc</code> files.</p>\n<h2 id=\"bug-fixes\">Bug fixes</h2>\n<p>As always, we’ve been working hard on fixing issues since the <a target=\"_blank\" href=\"https://astro.build/blog/astro-570\">5.7 release</a>.
