alpha</h2>\n<p>Work on the next major version of Astro has begun. The first Astro 7 alpha includes two big changes:</p>\n<h3 id=\"vite-8-support\">Vite 8 support</h3>\n<p>Astro 7 upgrades to <a target=\"_blank\" href=\"https://vite.dev/blog/announcing-vite8\">Vite 8</a>, the latest major version of the build tool that powers Astro. This is a breaking change for Astro integrations and plugins that depend on Vite internals, but most Astro users should be able to upgrade without any changes to their project code.</p>\n<h3 id=\"stable-rust-compiler\">Stable Rust compiler</h3>\n<p>The Rust-based Astro compiler, previously available as an experimental flag (<code>experimental.rustCompiler</code>), is now the default and only compiler in Astro 7. The Rust compiler delivers significantly faster build times compared to the previous Go-based compiler. The <code>experimental.rustCompiler</code> flag is no longer needed and can be removed from your config.</p>\n<h3 id=\"try-it-out\">Try it out</h3>\n<p>The Astro 7 alpha is available for early testing:</p>\n<div><figure><pre><code><div><p><span>npm</span><span> </span><span>install</span><span> </span><span>astro@alpha</span></p></div></code></pre></figure></div>\n<p>We’d love to hear your feedback! Please report any issues you encounter on <a target=\"_blank\" href=\"https://github.com/withastro/astro/issues\">GitHub</a>.</p>\n<h2 id=\"other-improvements\">Other improvements</h2>\n<ul>\n<li><strong><code>allowedHosts</code> for preview servers</strong>: Astro’s <a target=\"_blank\" href=\"https://docs.astro.build/en/reference/configuration-reference/#serverallowedhosts\"><code>server.allowedHosts</code></a> option is now passed down to adapter preview servers, letting you control which hostnames are accepted when running <code>astro preview</code> behind a reverse proxy or with custom local domains. If you’re an adapter author, <code>allowedHosts</code> is now available on the <code>options</code> object passed to your preview entrypoint. See the <a target=\"_blank\" href=\"https://docs.astro.build/en/reference/adapter-reference/#previewserver\">adapter reference</a> for details.</li>\n<li><strong><code>\"jsx\"</code> option for <code>compressHTML</code></strong>: The <code>compressHTML</code> option now accepts a <code>\"jsx\"</code> value that strips whitespace using JSX rules, so whitespace behaves the same way across <code>.astro</code> and <code>.tsx</code> files. Multi-line indented text is collapsed into a single line with spaces between words, while whitespace inside <code>&lt;pre&gt;</code> tags is preserved.</li>\n</ul>\n<p>For a complete list of bug fixes
