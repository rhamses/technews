Cloudinary is a hosting platform for media assets that allows you to transform and optimize media types.</p>\n<p>Content collections are Astro’s answer to organized, managed, type-safe content. Now with Astro’s content layer, you can bring in all different types of content and data from external sources during the build. See the <a target=\"_blank\" href=\"https://astro.cloudinary.dev/installation\">Cloudinary loader configuration guide</a> for details.</p>\n<p>Then import and use the loader inside of your <code>src/content/config.ts</code> configuration file:</p>\n<div><figure><pre><code><div><p><span>import</span><span> { </span><span>defineCollection</span><span> } </span><span>from</span><span> </span><span>'astro:content'</span></p></div><div><p><span>import</span><span> { </span><span>cldAssetsLoader</span><span> } </span><span>from</span><span> </span><span>'astro-cloudinary/loaders'</span></p></div><div><p><span>const</span><span> </span><span>samples</span><span> = </span><span>defineCollection</span><span>({</span></p></div><div><p><span>  </span><span>loader</span><span>: </span><span>cldAssetsLoader</span><span>({</span></p></div><div><p><span>    </span><span>limit</span><span>: </span><span>4</span><span>,</span></p></div><div><p><span>    </span><span>folder</span><span>: </span><span>'samples/food'</span></p></div><div><p><span><span>  </span></span><span>})</span></p></div><div><p><span>})</span></p></div><div><p><span>export</span><span> </span><span>const</span><span> </span><span>collections</span><span> = { </span><span>assets</span><span> }</span></p></div></code></pre></figure></div>\n<p>And that’s it! From here, you can query and use collections the same way you would for local collections.
