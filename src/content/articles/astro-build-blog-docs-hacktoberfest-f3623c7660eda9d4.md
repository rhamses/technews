contentHtml: "<article>\n<p>Welcome to Astro Docs Week! All week, our docs maintainers are taking over <a target=\"_blank\" href=\"https://twitter.com/astrodotbuild\">Astro’s Twitter account</a>. We’ll be sharing docs updates and fun from the community, so make sure you’re following us!</p>\n<p>To kick things off, let’s take a moment to talk about Astro Docs and Hacktoberfest. We love to celebrate Astro’s amazing open-source contributors. Here’s how Hacktoberfest helped us do that.</p>\n<img src=\"https://astro.build/_image?href=%2F_astro%2Fcontributors.rvvGfhX3.webp&w=1536&h=606&f=webp\" srcset=\"https://astro.build/_image?href=%2F_astro%2Fcontributors.rvvGfhX3.webp&w=768&h=303&f=webp 768w, https://astro.build/_image?href=%2F_astro%2Fcontributors.rvvGfhX3.webp&w=1500&h=592&f=webp 1500w\" alt=\"Avatars for the many, many contributors to Astro docs\">\n<p><a target=\"_blank\" href=\"https://docs.astro.build/\">Astro’s documentation website</a> is open source and driven by our community. Our <a target=\"_blank\" href=\"https://github.com/withastro/docs/graphs/contributors\">270+ contributors</a> make it easier for you to use Astro every day and we couldn’t do it without them! So this year, we wanted to use Hacktoberfest as a chance to recognize the work they do.</p>\n<p><a target=\"_blank\" href=\"https://hacktoberfest.com/\">Hacktoberfest</a> is an annual event run by Digital Ocean to encourage open-source participation. Every October, people who sign up can see their PRs rewarded with a t-shirt — or have a tree planted in their name! For the first time, this year’s edition welcomed <a target=\"_blank\" href=\"https://hacktoberfest.com/about/#low-or-non-code\">low or non-code contributions</a>. How could we say no to a forest of docs contributions?</p>\n<h2 id=\"planting-the-seed\">Planting the seed</h2>\n<p>For us, contributions come in all shapes and sizes. From typo fixes and CSS tweaks, to bigger documentation improvements. But that’s not all! Astro’s Docs are available in 10 languages thanks to our tireless translators. That’s where we decided to focus our efforts this month.</p>\n<p>In line with Hacktoberfest’s low-code focus, we wanted to encourage new translations. But <strong>we can’t merge translations without reviews from our multilingual community.</strong> It might not be obvious, but a good PR review is as valuable as the PR itself. To recognize this, we made it possible to <a target=\"_blank\" href=\"https://github.com/withastro/docs/blob/main/.github/hacktoberfest.md\">get Hacktoberfest credit for reviewing PRs</a>. Then we let folks know our plans on <a target=\"_blank\" href=\"https://astro.build/chat/\">Discord</a> and <a target=\"_blank\" href=\"https://twitter.com/astrodotbuild/status/1576221838950412289\">Twitter</a>, sat back, and waited…</p>\n<h2 id=\"so-how-did-it-go\">So, how did it go?</h2>\n<p>Drum roll please… Astro’s docs merged <strong>more than 130 PRs from 58 unique contributors</strong> as part of this year’s Hacktoberfest! This includes <strong>41 first-time contributors</strong> to the docs repo. 🎉</p>\n<p>As we had hoped, more than half of these PRs were translation-related. And, along the way:</p>\n<ul>\n<li>Someone sped up our CI tests.</li>\n<li>Our awesome Spanish team battled against incoming PRs to maintain “translation inbox zero.” (In fact, they’re likely translating this blog post as you read this!)</li>\n<li>Deploy guides for Deno Deploy and GitHub Pages got a once over.</li>\n<li>A new contributor submitted an epic, seven-page Russian translation.</li>\n<li>A bug in our docs Discord bot got squashed.</li>\n<li>Our community made improvements across all our languages.</li>\n<li>One contributor submitted <em>seven</em> translation reviews.</li>\n<li>And did typos get fixed? You bet!</li>\n</ul>\n<p>Thank you so much to everyone who took part! We welcomed new contributors, but were just as happy to see our existing contributors join in the fun, too. We hope you all enjoyed participating in Hacktoberfest as much as we did.</p>\n<h2 id=\"hacktoberfest-is-over-but-open-source-is-for-life\">Hacktoberfest is over, but Open Source is for life</h2>\n<p>Are you interested in getting involved with Astro’s Docs? You can always find us in <a target=\"_blank\" href=\"https://github.com/withastro/docs\">the docs repo on GitHub</a> or in <a target=\"_blank\" href=\"https://astro.build/chat/\">the <code>#docs</code> channel on Discord</a>. Can’t wait to meet you and merge your PR!</p></article>"
