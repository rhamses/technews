contentHtml: "<article><p>Two weeks ago, we <a target=\"_blank\" href=\"https://www.netlify.com/blog/astro-ssr\">announced experimental support for server-side rendering (SSR) with Netlify</a> as our launch partner on <a target=\"_blank\" href=\"https://docs.netlify.com/functions/overview/\">Netlify Functions</a>. Today, we’re announcing support for SSR on Netlify’s new <a target=\"_blank\" href=\"https://www.netlify.com/products/#netlify-edge-functions\">Edge Functions</a> platform. Edge Functions went live today and Astro has day 1 support.</p>\n<p>With SSR and Astro, you can:</p>\n<ul>\n<li>Build large, CMS-backed sites that are difficult to scale with SSG (static-site generation).</li>\n<li>Build apps that need authentication or persistent state, such as E-commerce backends.</li>\n<li>Use a simplified HTML-like syntax with sprinkles of JavaScript, only when you need it.</li>\n</ul>\n<p>With <strong>edge rendering</strong> you bring SSR closer to your users, getting those first bytes to the browser, faster. Combined with serving static assets at the edge, this gives you optimal network performance. Astro is committed to making performant content sites easy to achieve, and Netlify’s new Edge Functions platform is an ideal place to deploy your Astro SSR applications today.</p>\n<p>To get started, install the Netlify adapter:</p>\n<div><figure><pre><code><div><p><span>npm</span><span> </span><span>install</span><span> </span><span>@astrojs/netlify</span></p></div></code></pre></figure></div>\n<p>And then add the adapter in your <code>astro.config.mjs</code> file:</p>\n<div><figure><pre><code><div><p><span>import</span><span> { </span><span>defineConfig</span><span> } </span><span>from</span><span> </span><span>\"astro/config\"</span></p></div><div><p><span>import</span><span> </span><span>netlify</span><span> </span><span>from</span><span> </span><span>\"@astrojs/netlify/edge-functions\"</span></p></div><div><p><span>export</span><span> </span><span>default</span><span> </span><span>defineConfig</span><span>({</span></p></div><div><p><span>  </span><span>adapter</span><span>: </span><span>netlify</span><span>(),</span></p></div><div><p><span>})</span></p></div></code></pre></figure></div>\n<h2 id=\"migrating-from-netlify-functions\">Migrating from Netlify Functions</h2>\n<p>Astro is already available on Netlify Functions, a Node.js based serverless runtime. With Edge Functions you can get even better performance, and we’ve tried to make it as easy as possible to switch.</p>\n<h3 id=\"compatibility\">Compatibility</h3>\n<p>Netlify Edge Functions run on top of <a target=\"_blank\" href=\"https://deno.land/\">Deno</a>, but <em>most</em> Astro applications do not need to change code to deploy to the new environment. The Netlify adapter takes care of compiling and bundling your source so that it can run on Deno.</p>\n<p>If you are using dependencies that depend on Node.js’ built-in modules, it’s possible that you cannot move off of Netlify Functions. If so, Netlify Functions is still a great platform for most use-cases and provides a standard Node.js runtime for Node package support.</p>\n<p>If you use the <code>&lt;Markdown /&gt;</code> component, it cannot presently run in non-Node environments. A possible alternative in the meantime is using <code>.md</code> pages.</p>\n<h3 id=\"migration\">Migration</h3>\n<p>First, upgrade to the latest <code>@astrojs/netlify</code> like so:</p>\n<div><figure><pre><code><div><p><span>npm</span><span> </span><span>install</span><span> </span><span>@astrojs/netlify@latest</span></p></div></code></pre></figure></div>\n<p>Then, update your <code>astro.config.mjs</code> to import the edge functions adapter:</p>\n<div><figure><pre><code><div><p><span>import</span><span> { </span><span>defineConfig</span><span> } </span><span>from</span><span> </span><span>'astro/config'</span><span>;</span></p></div><div><p><span> </span><span>import</span><span> </span><span>netlify</span><span> </span><span>from</span><span> </span><span>'@astrojs/netlify/functions'</span><span>;</span></p></div><div><p><span> </span><span>import</span><span> </span><span>netlify</span><span> </span><span>from</span><span> </span><span>'@astrojs/netlify/edge-functions'</span><span>;</span></p></div><div><p><span>export</span><span> </span><span>default</span><span> </span><span>defineConfig</span><span>({</span></p></div><div><p><span>  </span><span>adapter</span><span>: </span><span>netlify</span><span>()</span></p></div><div><p><span>});</span></p></div></code></pre></figure></div>\n<p>And that should be it! The next time you build, it will generate an SSR build compatible with Edge Functions, which can then be deployed with <code>netlify deploy --build</code>.</p>\n<h2 id=\"partnerships\">Partnerships</h2>\n<p>Netlify was Astro’s launch partner for SSR. Even within the short time since that announcement we have seen tremendous support from other hosting platforms with adapters either already been built or in the works.</p>\n<p>If you’d like to build an adapter for another platform, swing by our <a target=\"_blank\" href=\"https://discord.com/channels/830184174198718474/852168748353060875\">Discord channel</a> and we’d be happy to help you along!</p></article>"
