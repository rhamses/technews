For example, the following Markdown:</p>\n<div><figure><pre><code><div><p><span>## Get started</span></p></div></code></pre></figure></div>\n<p>will generate HTML a bit like this:</p>\n<div><figure><pre><code><div><p><span>&lt;</span><span>h2</span><span> </span><span>id</span><span>=</span><span>\"get-started\"</span><span>&gt;Get started&lt;/</span><span>h2</span><span>&gt;</span></p></div><div><p><span>&lt;</span><span>a</span><span> </span><span>href</span><span>=</span><span>\"#get-started\"</span><span>&gt;Section titled “Get started”&lt;/</span><span>a</span><span>&gt;</span></p></div></code></pre></figure></div>\n<p>This ensures that headings in the document structure are not cluttered by anchor links and that the links themselves still have a clear label available for assistive technology.\nWe’ve been using this approach in the Astro docs for some time now and are excited to make it available to all sites built with Starlight!</p>\n<h2 id=\"tailwind-v4-support\">Tailwind v4 support</h2>\n<p>Starlight has supported authoring styles with Tailwind CSS since shortly after our first release via a custom Tailwind plugin. We’ve now updated our support for compatibility with Tailwind v4!</p>\n<p>Tailwind v4 comes with some big changes. Support is now provided via a Vite plugin and configuration has moved to a CSS file instead of a JS module. Starlight’s Tailwind compatibility styles must now be imported directly in your CSS and customized using the <code>@theme</code> directive:</p>\n<div><figure><pre><code><div><p><span>/* Include the \"starlight\" layer alongside Tailwind’s default layers. */</span></p></div><div><p><span>@layer</span><span> base, </span><span>, theme, components, utilities;</span></p></div><div><p><span>/* Import Starlight’s compatibility styles. */</span></p></div><div><p><span>@import</span><span> </span><span>'@astrojs/starlight-tailwind'</span><span>;</span></p></div><div><p><span>@import</span><span> </span><span>'tailwindcss/theme.css'</span><span> layer(theme);</span></p></div><div><p><span>@import</span><span> </span><span>'tailwindcss/utilities.css'</span><span> layer(utilities);</span></p></div><div><p><span>@theme</span><span> {</span></p></div><div><p><span>  </span><span>/* Configure Starlight theme variables. */</span></p></div><div><p><span>}</span></p></div></code></pre></figure></div>\n<p>For detailed guidance on updating see the <a target=\"_blank\" href=\"https://github.com/withastro/starlight/blob/main/packages/tailwind/CHANGELOG.md\"><code>@astrojs/starlight-tailwind</code> changelog</a>. You might also want to keep the <a target=\"_blank\" href=\"https://tailwindcss.com/docs/upgrade-guide\">official Tailwind v4 upgrade guide</a> and <a target=\"_blank\" href=\"https://starlight.astro.build/guides/css-and-tailwind/#tailwind-css\">Starlight’s Tailwind set-up guide</a> handy.</p>\n<h2 id=\"css-cascade-layers\">CSS cascade layers</h2>\n<p>It’s important that Starlight users can easily customize their sites.
