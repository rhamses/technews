included support for generating sidebar navigation links from directories of content since day one.\nThis release brings new flexibility to how this works.</p>\n<p>Previously, autogeneration always created a labeled group in the sidebar for the specified directory.\nWith v0.39, Starlight’s autogenerated links can be slotted alongside any other link types.</p>\n<p>If you have existing autogenerated link groups in your sidebar, update them by wrapping the config in an <code>items</code> </span></span><span>},</span></p></div><div><p><span><span>  </span></span><span>],</span></p></div><div><p><span>  </span><span>// ...</span></p></div><div><p><span>}),</span></p></div></code></pre></figure></div>\n<h2 id=\"styling-improvements\">Styling improvements</h2>\n<p>Modern CSS makes everyone’s lives easier by the day, and with this release we’re putting it to good use.</p>\n<ul>\n<li>We’ve improved spacing of nested lists in your content thanks to the magic of <code>:has()</code>. (Check out <a target=\"_blank\" href=\"https://github.com/withastro/starlight/blob/ec70630cbbe43bb5b026ddabfe7224759c798a4b/packages/starlight/style/markdown.css#L34-L60\">the full selector</a> — it’s a doozy.)</li>\n<li>When users expand or collapse a sidebar group, causing overflow, the Starlight sidebar is now more stable. We banished layout shift with a simple <code>scrollbar-gutter: stable</code>.</li>\n</ul>\n<h2 id=\"better-multilingual-sites\">Better multilingual sites</h2>\n<p>Starlight’s internationalization story has been key from the outset, and we’re always looking to push it forward.\nThis release brings:</p>\n<ul>\n<li>Improved multilingual SEO with <code>x-default</code> meta links to pages in the site’s default locale. These alternate links are <a target=\"_blank\" href=\"https://developers.google.com/search/docs/specialty/international/localized-versions#xdefault\">used by search engines</a> as a signal of which language to fall back to if no other is available.</li>\n<li>Better text layout in Chinese and Japanese documentation thanks to the <code>text-autospace</code> CSS property. This <a target=\"_blank\" href=\"https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/text-autospace\">newer CSS property</a> makes text more legible by automatically applying spacing between CJK and non-CJK characters.</li>\n<li>We’ve updated <code>i18next</code>, the underlying library powering Starlight’s localization APIs, from v23 to v26.</li>\n</ul>\n<p>The Astro core team
