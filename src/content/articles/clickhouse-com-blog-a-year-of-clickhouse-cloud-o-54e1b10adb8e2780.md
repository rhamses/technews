This connector allows customers to seamlessly load files from Azure Blob Storage into ClickHouse Cloud. It supports two modes of ingestion: <strong>one-time loads</strong> and <strong>continuous ingestion</strong> as new files are added to the storage containers.</p>\n<p><a target=\"_blank\" href=\"https://clickhouse.com/cloud/clickpipes/azure-blob-storage-connector\">You can sign up for the private preview here.</a></p>\n<p>This connector is built to support enterprise-grade workloads with the following capabilities:</p>\n<ol>\n<li><strong>Built for reliability</strong> – Under the hood, it leverages the native <code><a target=\"_blank\" href=\"https://clickhouse.com/docs/sql-reference/table-functions/azureBlobStorageCluster\">azureBlogStorageCluster</a></code> table function in ClickHouse, but enhances it with improved reliability and a fully managed experience. Loading billions (or even trillions) of rows from object storage can be error-prone due to transient network issues—retries aren’t trivial, and handling duplicates is tricky. The connector handles retries automatically and ensures <strong>exactly-once ingestion</strong>, so you don’t have to worry about data consistency or partial loads.</li>\n<li><strong>Secure by design</strong> – It supports ingestion from private buckets, with authentication through connection string, which includes account name and key, or can be specified using the storage account URL. You can also use our Shared Access Signature (SAS) within the connection string for time-limited access without sharing your storage account key.</li>\n<li><strong>Optimized for performance</strong> – The connector dynamically tunes ingestion based on your workload and the size of your ClickHouse instance—for example, by adjusting ingestion parallelism, tuning ClickHouse-specific settings, and more.</li>\n<li><strong>Fully managed experience</strong> – The connector is fully integrated into the ClickHouse Cloud experience. It offers high availability, built-in metrics and monitoring, including throughput, detailed logs for error diagnosis and debugging, in-place pipe editing (e.g., adding columns), and more.</li>\n</ol>\n<p><strong>Note:</strong> Continuous ingestion may have some caveats, such as limits on the number of files in the bucket.
