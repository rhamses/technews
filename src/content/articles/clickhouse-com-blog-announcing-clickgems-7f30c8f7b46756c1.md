contentHtml: "<article><div><p>A few months ago, the Ruby Central team, inspired by our work on <a target=\"_blank\" href=\"https://clickpy.clickhouse.com/\">ClickPy</a>, asked if we could load public RubyGems download stats into a public ClickHouse instance. The goal was to make it easier for the open-source community to analyze the data. <a target=\"_blank\" href=\"https://clickhouse.com/blog/announcing-ruby-gem-analytics-powered-by-clickhouse\">We were glad to help</a>, supporting open source projects has always been a priority for us, and we enjoy working with large, real-world datasets that show what ClickHouse can do.</p>\n<p>After bringing the dataset into our <a target=\"_blank\" href=\"https://sql.clickhouse.com/?query_id=HVMKR3JXFT4DA8NMAPGXKM\">SQL Playground</a>, we decided to go a step further and build a dedicated analytics site for the RubyGems community.</p>\n<p>Today, we're introducing <a target=\"_blank\" href=\"https://clickgems.clickhouse.com/\">ClickGems</a>, a new platform that provides analytics for RubyGems. It lets you explore download statistics for more than 200,000 gems, covering data from 2017 to today and totaling over 200 billion downloads.</p>\n<h2 id=\"what-is-clickgems\"></h2>\n<p>ClickGems is a website designed to empower Ruby developers with in-depth analytics for their favorite Ruby gems.</p>\n<p><span><img alt=\"clickgems-1.png\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2Fclickgems_1_7d1b56c822.png&w=2048&q=75\"></span></p>\n<p>ClickGems follows the same purpose as ClickPy, so we decided to reuse the same code base. For now, development lives in a <a target=\"_blank\" href=\"https://github.com/ClickHouse/clickpy/tree/clickgems\">dedicated branch</a> of the ClickPy GitHub repository, though we may fork it later if it makes sense.</p>\n<p>If you've used ClickPy before, ClickGems will feel familiar. The design and features are the same. The landing page shows global statistics such as recent releases for popular gems and top repositories.</p>\n<p>From there, you can click on any gem to open its detail page. Each gem page includes charts and metrics such as downloads over time or downloads by country.</p>\n<p><span><img alt=\"clickgems-2.png\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2Fclickgems_2_0bf618d631.png&w=2048&q=75\"></span></p>\n<h2 id=\"how-we-build-visualizations\"></h2>\n<p>Each visualization is powered by a SQL query, which you can view by clicking the link icon in the top-right corner. This opens the SQL Playground, where you can see the query and run it against the raw data. You can use this as a base to build your own visualizations.</p>\n<p>To ensure fast execution, we use Materialized Views in ClickHouse to pre-aggregate data as it's ingested. For more details on how we set up these Materialized Views to speed up queries for ClickGems, see our <a target=\"_blank\" href=\"https://clickhouse.com/blog/announcing-ruby-gem-analytics-powered-by-clickhouse#materialized-views\">previous blog post</a> on bringing RubyGems data into ClickHouse.</p>\n<p><span><img alt=\"CleanShot 2025-10-02 at 21.16.22@2x.png\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2FClean_Shot_2025_10_02_at_21_16_22_2x_fd970c0daa.png&w=2048&q=75\"></span></p>\n<p>While building ClickGems, we had the chance to work with <a target=\"_blank\" href=\"https://www.metabase.com/\">Metabase</a>, which offers the ability to host and embed charts anywhere. Thanks to their support, we were able to add this functionality to both ClickGems and ClickPy.</p>\n<p>Now, from any gem or package page, you can export a chart and embed it directly into your website, documentation, blog post, or project page. This makes it easy to share usage trends and showcase the impact of your favorite libraries.</p>\n<p><span><img alt=\"clickgems-gif.gif\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2Fclickgems_gif_03e56b5954.gif&w=2048&q=75\"></span></p>\n<h2 id=\"how-we-power-clickgems\"></h2>\n<p>ClickGems and ClickPy, along with other public demos like our SQL Playground and AgentHouse, are all powered by the same ClickHouse Cloud deployment.</p>\n<p>This unified infrastructure allows us to manage large volumes of data and use cases while keeping the infrastructure and maintenance cost fairly low. ClickHouse ability to ingest large volumes while handling large numbers of parallel queries makes it possible.</p>\n<p>We also decided to leverage <a target=\"_blank\" href=\"https://clickhouse.com/blog/introducing-warehouses-compute-compute-separation-in-clickhouse-cloud\">compute-compute separation</a> within our ClickHouse Cloud in order to dedicate resources to ClickPy and ClickGems website. This architectural decision ensures that peak usage on one service, such as a surge in ClickGems queries, does not affect the performance or availability of other services like ClickPy or our other public demos. This guarantees a smooth and consistent experience for all our users across all our analytics platforms.</p>\n<p>Below is a high-level overview of the deployment.</p>\n<p><span><img alt=\"clickgems-diagram.jpg\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2Fclickgems_diagram_c7822f23bd.jpg&w=2048&q=75\"></span></p>\n<h2 id=\"try-clickgems\"></h2>\n<p>This is exciting to see three organizations, ClickHouse, Ruby Central and Metabase come together to offer a fully fledged analytical application to the open-source community!</p>\n<p>We invite you to go today to <a target=\"_blank\" href=\"https://clickgems.clickhouse.com/\">ClickGems</a> and see how your favorite gems are doing. We'd also love your feedback and contributions, feel free to open an <a target=\"_blank\" href=\"https://github.com/ClickHouse/clickpy/issues\">issue</a> in the ClickPy GitHub repository if you have questions, suggestions, or ideas.</p></div></article>"
