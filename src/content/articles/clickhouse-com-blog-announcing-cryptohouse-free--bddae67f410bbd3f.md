This requires the use of a -Merge function when querying e.g. here.</li>\n<li><strong>Use date filters on main tables</strong> - The Materialized Views aggregate by day. For more granular analysis, refer to the base tables e.g., transactions. These tables contain every event and are, as a result, hundreds of billions of rows. When querying these rows, always apply a date filter to avoid exceeding a month's timespan.</li>\n</ul>\n<h2 id=\"if-users-want-more\"></h2>\n<p>While we have attempted to be as generous as possible with quotas, we expect some users will want to run queries requiring more computational power than CryptoHouse offers.
