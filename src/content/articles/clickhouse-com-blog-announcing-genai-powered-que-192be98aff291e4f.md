contentHtml: "<article><div>\n<p>\nWe are pleased to announce the general availability of GenAI-powered query suggestions in the ClickHouse Cloud query console. Users of ClickHouse Cloud can now write queries as natural language questions and leave the query console to convert these to SQL queries based on the context of the available tables.\n</p><p>Generative AI and Large Language Models (LLM) are a hot topic of late. Many of us will have used services, such as ChatGPT, to make our daily working practices more efficient. The emergence of these technologies has no less impacted the work of a data analyst, engineer, or database administrator. While the ability for LLMs to write SQL has been known for some time, services such as ChatGPT can be imprecise and prone to generate less than correct queries unless provided with context. By integrating ChatGPT APIs directly into Cloud’s SQL console, we are to provide the tables and their respective schemas as context to any query - thus improving the accuracy and usefulness of responses.</p>\n<p>Users of all levels of SQL experience can benefit from this feature. As well as lowering the barrier for non-technical users to write queries against ClickHouse, experienced SQL experts can improve their productivity and utilize the query assistant to provide the basis for complex questions or just syntax they can’t quite remember :)</p>\n<p>An an example, consider the following table schema from our commonly used <a target=\"_blank\" href=\"https://clickhouse.com/docs/en/getting-started/example-datasets/uk-price-paid\">UK house price paid dataset</a>:</p>\n<div><pre><code><span><span>CREATE TABLE</span> default.uk_price_paid ( </span>\n<span>  `price` UInt32, </span>\n<span>  `<span>date</span>` <span>Date</span>, </span>\n<span>  `postcode1` LowCardinality(String), </span>\n<span>  `postcode2` LowCardinality(String), </span>\n<span>  `type` Enum8(<span>'other'</span> <span>=</span> <span>0</span>, <span>'terraced'</span> <span>=</span> <span>1</span>, <span>'semi-detached'</span> <span>=</span> <span>2</span>, <span>'detached'</span> <span>=</span> <span>3</span>, <span>'flat'</span> <span>=</span> <span>4</span>), </span>\n<span>  `is_new` UInt8, </span>\n<span>  `duration` Enum8(<span>'unknown'</span> <span>=</span> <span>0</span>, <span>'freehold'</span> <span>=</span> <span>1</span>, <span>'leasehold'</span> <span>=</span> <span>2</span>), </span>\n<span>  `addr1` String, </span>\n<span>  `addr2` String, </span>\n<span>  `street` LowCardinality(String), </span>\n<span>  `locality` LowCardinality(String), </span>\n<span>  `town` LowCardinality(String), </span>\n<span>  `district` LowCardinality(String), </span>\n<span>  `county` LowCardinality(String) </span>\n<span>) ENGINE <span>=</span> MergeTree()</span>\n<span><span>ORDER</span> <span>BY</span> (postcode1, postcode2, addr1, addr2)</span></code></pre></div>\n<p>Let’s say we want to run a year-by-year analysis of transaction volume and value on this table.
