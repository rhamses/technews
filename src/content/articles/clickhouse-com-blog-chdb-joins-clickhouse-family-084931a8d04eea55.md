contentHtml: "<article><div><p>Today, we are pleased to announce that <a target=\"_blank\" href=\"https://doc.chdb.io/#/\">chDB</a>, an embedded SQL OLAP engine powered by ClickHouse, is now part of ClickHouse. chDB’s creator and main contributor, Auxten, <a target=\"_blank\" href=\"https://auxten.com/chdb-is-joining-clickhouse\">is joining forces with us</a> to focus on evolving chDB and integrating it even more closely with the ClickHouse ecosystem.</p>\n<h2 id=\"what-is-chdb-and-how-did-we-get-here\"></h2>\n<p>ClickHouse is best known as a scalable analytics database that uses a client-server architecture, but we’ve actually always had ClickHouse Local, a CLI tool that contains ClickHouse.</p>\n<p>People <a target=\"_blank\" href=\"https://news.ycombinator.com/item?id=34265206\">became aware of ClickHouse Local at the beginning of 2023</a> and they loved it, but we also got feedback that they wanted to be able to integrate ClickHouse Local with the other tools they were using both in their data pipelines and for data analysis.</p>\n<p>Around this same time, Auxten had started working on chDB with the goal of being able to use ClickHouse as an “out of the box” Python module.</p>\n<p>You can use chDB to do in-memory analysis of data that lives locally or remotely in all the formats and sources supported by ClickHouse. You can also choose to persist data in a local ClickHouse instance and chDB uses the same storage format as ClickHouse Local, which means their databases are interchangeable. The diagram below shows how chDB works in comparison to other ClickHouse variants.</p>\n<p><span><img alt=\"chDB Image 4 updated 2.png\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2Fch_DB_Image_4_updated_2_6fd7ed2265.png&w=2048&q=75\"></span></p>\n<p>We were really impressed with chDB and contacted Auxten to tell him that we loved his work and wanted to help promote it. This resulted in Alexey mentioning chDB in the <a target=\"_blank\" href=\"https://www.youtube.com/live/TI1kONfON18?si=OhCU6_R58iByNXVQ&t=1872\">23.7 release call</a>, as well as a subsequent <a target=\"_blank\" href=\"https://clickhouse.com/blog/welcome-chdb-to-clickhouse\">introductory blog post about chDB</a> in August 2023. A few weeks later Auxten wrote <a target=\"_blank\" href=\"https://clickhouse.com/blog/chdb-embedded-clickhouse-rocket-engine-on-a-bicycle\">chDB - A Rocket Engine on a Bicycle</a>, in which he went through chDB’s design decisions and implementation details</p>\n<p>In the months since then, <a target=\"_blank\" href=\"https://clickpy.clickhouse.com/dashboard/chdb\">we’ve seen more interest in chDB</a>, have been working closely with Auxten, and gradually saw an opportunity to take our collaboration to the next level.</p>\n<h2 id=\"what-does-the-news-mean-if-i-m-a-chdb-user\"></h2>\n<p>If you’re an existing user of chDB, this is great news for you. Auxten will now be working full-time on chDB rather than only in his spare time. This means we’ll be able to fix bugs/issues more quickly as well as adding new features and integrations.</p>\n<p>chDB will soon be integrated into ClickHouse’s continuous integration pipeline, which will allow us to have chDB closely follow the release schedule of ClickHouse.</p>\n<p>We’ll be moving the chdB documentation to live alongside the ClickHouse documentation and will make chDB more prominent in our getting started guides.</p>\n<p>We’ll also be looking at ways that we can better integrate chDB with the rest of the data engineering ecosystem, so let us know if you have any opinions about where we should start!</p>\n<h2 id=\"what-happens-next\"></h2>\n<p>Our goal is to create a seamless experience whether you’re analyzing Parquet files on your laptop, creating data pipelines with other tools in the Python ecosystem, or building a real-time data warehouse to serve data products to your users.</p>\n<p>We want to get to the point where it takes minimal effort to switch between the different flavors of ClickHouse.</p>\n<p>We don’t know exactly what this will look like and we’d like your help figuring this out. Below are some of the things at the top of our todo list for what to do next:</p>\n<ol>\n<li>Better performance, especially on Pandas DataFrame and Arrow Buffer</li>\n<li>Keep up with latest ClickHouse release</li>\n<li>Better integration with more programming languages and data sources</li>\n</ol>\n<p>But maybe you have better ideas! We’d love to hear your thoughts on the <a target=\"_blank\" href=\"https://github.com/orgs/chdb-io/discussions\">chDB Github Discussions</a>.</p>\n<h2 id=\"get-started-with-chdb-today\"></h2>\n<p>In the meantime, if you’re not yet familiar with chDB, we thought we’d include a little example to whet your appetite. chDB is <a target=\"_blank\" href=\"https://pypi.org/project/chdb/\">published on PyPi</a> and can be installed with the pip package manager. We’ll also install Pandas and pyarrow as we'll be using those too:</p>\n<div><pre><code><span>pip install chdb pandas pyarrow</span></code></pre></div>\n<p>Once that’s installed we can open a Python REPL, Jupyter notebook, or similar and import the following module:</p>\n<div><pre><code><span><span>import</span> chdb</span></code></pre></div>\n<p>Let’s now look at how to query the Hugging Face <a target=\"_blank\" href=\"https://huggingface.co/datasets/vivym/midjourney-messages\">midjourney-messages</a> dataset, which contains metadata about images generated by the Mid Journey Generative AI service over several months in 2023. This dataset contains 55 million rows spread over 55 Parquet files.</p>\n<p>The following query returns the count of images as well as the minimum/maximum size, width, and <span>18928</span></span>\n<span><span>max</span>(height): <span>16128</span></span>\n<span><span>max</span>(size):   <span>24498571</span></span>\n<span><span>min</span>(width):  <span>32</span></span>\n<span><span>min</span>(height): <span>56</span></span>\n<span><span>min</span>(size):   <span>312</span></span></code></pre></div>\n<p>If we want to persist the data from those We look forward to learning what you do with this compact yet powerful way to use ClickHouse in your local projects!</p>\n<p>Read more about the history of chDB, and the creator Auxten's perspective, <a target=\"_blank\" href=\"https://auxten.com/chdb-is-joining-clickhouse\">in his post</a>.</p></div></article>"
