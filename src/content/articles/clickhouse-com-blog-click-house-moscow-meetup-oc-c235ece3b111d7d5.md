There are a lot of new features to discuss in the 21.10 version of ClickHouse, along with many more new features coming up on the roadmap.</p>\n<p>There were over 200 attendees in person for the Meetup and 3,853 viewers online, and we want to thank everyone who attended live. You can watch the recording of the Meetup on YouTube <a target=\"_blank\" href=\"https://www.youtube.com/watch?v=W6h3_xykd2Y\">here</a>.</p>\n<p>Alexey Milovidov, Chief Technology Officer, welcomed and updated the community on ClickHouse Inc.'s latest news. Maksim Kita, Sr. Software Engineer at ClickHouse, started with a discussion on the new User Defined Functions (UDFs) available in 21.10. UDFs can be defined as lambda expressions using the CREATE FUNCTION command. For example:</p>\n<div><pre><code><span>CREATE FUNCTION a_plus_b AS (a, b) -&gt; a + b</span></code></pre></div>\n<p>In addition to UDFs, there are two new table engines - Executable and ExecutablePool - that can stream records via stdin and stdout through custom scripts written in whatever language you prefer. For details, be sure to check out our <a target=\"_blank\" href=\"https://clickhouse.com/learn/lessons/whatsnew-clickhouse-21.10/\">new training lesson on What's New in ClickHouse 21.10</a>.</p>\n<p>You can now encrypt your data stored on S3, HDFS, external disks, or on a local disk. ClickHouse developers Vitaly Baranov and Artur Filatenkov discussed the details and benefits of encrypting your data at rest in ClickHouse. Vitaly presented the new full disk encryption feature and Arthur presented column-level encryption.</p>\n<p><span><img alt=\"disk-encryption-performance.jpeg\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2Fdisk_encryption_performance_80c4b61183.jpeg&w=2048&q=75\"></span></p>\n<p><span><img alt=\"arthur-filatenkov.jpeg\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2Farthur_filatenkov_e06321b4f3.jpeg&w=2048&q=75\"></span></p>\n<p>Alexey then spent 40 minutes discussing some of the amazing new features on the ClickHouse roadmap, including:</p>\n<ul>\n<li>ClickHouse Keeper: a new C++ coordination system for ClickHouse designed as an alternative to ZooKeeper</li>\n<li>Support for working with semi-structured data, including JSON objects with arbitrary nested objects</li>\n<li>Asynchronous insert mode - now you can insert data without batching!</li>\n</ul>\n<p>After the talk, Alexey took questions from users on:</p>\n<ul>\n<li>How to parse User-Agent in ClickHouse</li>\n<li>Is it true that ClickHouse developers have a ClickHouse tattoo</li>\n</ul>\n<p><span><img alt=\"yaml-configuration.jpeg\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2Fyaml_configuration_8521694388.jpeg&w=2048&q=75\"></span></p>\n<ul>\n<li>If you are excited about ClickHouse, be sure to join us on <a target=\"_blank\" href=\"https://t.me/clickhouse_en\">Telegram</a></li>\n<li>We also have a community Slack workspace be sure to join <a target=\"_blank\" href=\"https://clickhousedb.slack.com/\">here</a>.</li>\n<li>If you are new to ClickHouse and want to see it in action, check out our <a target=\"_blank\" href=\"https://clickhouse.com/learn/lessons/gettingstarted/\">Getting Started lesson</a>.</li>\n</ul></div></article>"
