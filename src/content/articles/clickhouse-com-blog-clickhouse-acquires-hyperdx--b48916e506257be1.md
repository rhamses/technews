By integrating HyperDX's powerful UI and session replay capabilities with ClickHouse’s industry-leading database performance, we’re taking open-source observability to the next level.</p>\n<h2 id=\"observability-is-a-data-problem\"></h2>\n<p><a target=\"_blank\" href=\"https://clickhouse.com/resources/engineering/what-is-observability\">Observability</a> is fundamentally a data problem. The size of the dataset dictates how difficult and expensive it will be to build an observability platform. That’s why the choice of database is one of the most important decisions when starting an observability company or building an observability platform in-house.</p>\n<p>This is also why ClickHouse has been the backbone of observability platforms for years, powering logging, metrics, and tracing solutions at companies like <a target=\"_blank\" href=\"https://clickhouse.com/videos/monitorama-pdx-2024-distributed-tracing-all-the-warning-signs-were-out-there\">eBay</a> and <a target=\"_blank\" href=\"https://www.youtube.com/watch?v=HRh5setqGCU\">Netflix</a> or at observability startups like <a target=\"_blank\" href=\"https://sentry.engineering/blog/introducing-snuba-sentrys-new-search-infrastructure\">Sentry</a> and <a target=\"_blank\" href=\"https://clickhouse.com/blog/ibm-instance-monitoring-clickhouse-performance\">Instana</a>. ClickHouse's disruptive storage efficiency literally flattens the cost curve, delivering 10x savings over traditional solutions, while blazing-fast query performance ensures engineers aren’t waiting on slow tooling to debug production issues. We wrote about this trend first in <a target=\"_blank\" href=\"https://clickhouse.com/blog/the-state-of-sql-based-observability\">\"The State of SQL-Based Observability\"</a> and since then, it continued to gain steam in conversations with our customers and partners.</p>\n<p>However, a database alone doesn’t make an observability solution. Engineers need turnkey data ingestion and visualization, alerting, and other DevOps tooling that “just works”. Until now, ClickHouse has relied on <a target=\"_blank\" href=\"https://clickhouse.com/blog/clickhouse-and-open-telemtry\">OpenTelemetry for data collection</a> and an <a target=\"_blank\" href=\"https://clickhouse.com/blog/clickhouse-grafana-plugin-4-0\">integration with Grafana for visualization</a>—an approach that helped our own observability team move from an established SaaS solution to an internally-built <a target=\"_blank\" href=\"https://clickhouse.com/blog/building-a-logging-platform-with-clickhouse-and-saving-millions-over-datadog#performance-and-cost\">LogHouse</a> achieving a staggering 200x cost reduction in the process.</p>\n<p>While this stack is still valid and delivers value (especially if a user has more than one observability store), we saw room for improvement, particularly in streamlining workflows, leveraging ClickHouse unique capabilities, and adding session replay, something existing open-source tools we looked at didn’t provide.</p>\n<blockquote>\n<p>\"ClickHouse’s analytics capabilities and open ecosystem make it a powerful technology for observability. However, the end-user experience lacked some of the comprehensive features of more established solutions. HyperDX is very exciting, bringing together an enhanced query experience with a more intuitive UI for exploratory observability workflows.\"</p>\n<p>Viktor Eriksson, Lovable</p>\n</blockquote>\n<h2 id=\"why-hyperdx\"></h2>\n<p>That’s when we found HyperDX—an open-source observability layer purpose-built on ClickHouse. HyperDX open-sourced their V2 UI in late 2024, and after testing it internally, we knew this was the missing piece. The setup was seamless, and our developers immediately saw the benefits. More importantly, we realized that our users deserved the same experience.</p>\n<p>After speaking with the HyperDX team, it was clear we shared the same vision:</p>\n<ol>\n<li><strong>Standards-Based Data Collection</strong> – Both ClickHouse and HyperDX are committed to OpenTelemetry, with ClickHouse now maintaining the ClickHouse OpenTelemetry exporter.</li>\n<li><strong>Open-Source First</strong> – A robust observability stack should be available to everyone, with cloud offerings providing a simple, cost-effective operational experience.</li>\n<li><strong>Flexible Data Access</strong> – Users should have direct access to their observability data, with multiple ways to analyze it, and we remain deeply invested in Grafana as the best cross-data-source observability UI on the market.</li>\n<li><strong>Blazing Fast Performance</strong> – Query terabytes in seconds, making real-time troubleshooting seamless.</li>\n</ol>\n<p><span><img alt=\"output.gif\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2Foutput_3efd2b01cf.gif&w=2048&q=75\"></span></p>\n<h2 id=\"what-s-next\"></h2>\n<p>This acquisition is an acceleration, not a disruption.
