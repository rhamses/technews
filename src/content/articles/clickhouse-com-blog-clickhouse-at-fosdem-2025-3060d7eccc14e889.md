contentHtml: "<article><div><p>This year, ClickHouse made a strong showing at FOSDEM 2025, with several team members traveling to Belgium and multiple talks covering everything from powerful new JSON data types to the challenges of fuzzing databases. If you weren’t able to attend (or just want a recap), here’s what went down in Brussels.</p>\n<h2 id=\"what-is-fosdem\"></h2>\n<p>For those unfamiliar, <strong>FOSDEM</strong> (Free and Open Source Developers' European Meeting) is one of the biggest open-source conferences in the world. Every year, thousands of developers, engineers, and open-source enthusiasts gather in Brussels to share knowledge, showcase projects, and engage in deep technical discussions. It's a place where open-source software meets innovation, and where deep-dive technical talks are the norm.</p>\n<p>And this year, ClickHouse was <strong>well represented</strong>.</p>\n<h2 id=\"the-clickhouse-talks\"></h2>\n<h3 id=\"how-we-built-a-new-powerful-json-data-type-for-clickhouse\"></h3>\n<p>JSON support is a hot topic for ClickHouse users, and at FOSDEM, we shared details about the <strong>new JSON data type</strong> we built. This talk covered <strong>why</strong> we introduced it, how it <strong>differs from traditional JSON handling</strong>, and what kind of performance benefits users can expect. If you're working with semi-structured data at scale, this was a must-watch.</p>\n<p><strong>Speaker:</strong> Robert Schulze</p>\n<p><strong>Abstract:</strong> JSON has become the lingua franca for handling semi-structured and unstructured data in modern data systems. Whether it’s in logging and observability scenarios, real-time data streaming, mobile app storage, or machine learning pipelines, JSON’s flexible structure makes it the go-to format for capturing and transmitting data across distributed systems.</p>\n<p>At ClickHouse, we’ve long recognized the importance of seamless JSON support. But as simple as JSON seems, leveraging it effectively at scale presents unique challenges. In this talk we will discuss how we built a new powerful JSON data type for ClickHouse with true column-oriented storage, support for dynamically changing data structure and ability to query individual JSON paths really fast.</p>\n<p>Links related to the topic:</p>\n<ul>\n<li><a target=\"_blank\" href=\"https://github.com/ClickHouse/ClickHouse/issues/54864\">RFC: Semistructured Columns #54864</a></li>\n<li><a target=\"_blank\" href=\"https://github.com/ClickHouse/ClickHouse/pull/58047\">Implement Variant data type #58047</a></li>\n<li><a target=\"_blank\" href=\"https://github.com/ClickHouse/ClickHouse/pull/63058\">Implement Dynamic data type #63058</a></li>\n<li><a target=\"_blank\" href=\"https://github.com/ClickHouse/ClickHouse/pull/66444\">Implement new JSON data type. #66444</a></li>\n</ul>\n<h3 id=\"fuzzing-databases-is-difficult\"></h3>\n<p>Database reliability and security are always important priorities, and fuzz testing is one way to uncover hidden bugs. But as it turns out, <strong>fuzzing databases is hard</strong>. This talk dove into the complexities of fuzz testing, why traditional approaches don't always work well for databases, and what strategies can improve effectiveness. If you’re interested in database internals or security, this one was for you.</p>\n<p><strong>Speaker:</strong> Pedro Ferreira</p>\n<p><strong>Abstract:</strong> After fuzzing databases for the last 3 years, I learned that simple design decisions on a fuzzer impact on the issues it can ever find. In this talk I would to address some of those decisions. As an example, I would to discuss about the design of BuzzHouse, a new database fuzzer to test ClickHouse.</p>\n<p>Links related to the topic:\n<a target=\"_blank\" href=\"https://github.com/ClickHouse/ClickHouse/pull/71085\">First iteration of Buzzhouse #71085\n</a></p>\n<h3 id=\"rdns-map-the-internet-in-your-hands\"></h3>\n<p>Reverse DNS (rDNS) is an often-overlooked but powerful tool for understanding the structure of the internet. This talk explored how we can <strong>map out rDNS data</strong> at scale and why it's useful for network monitoring, security research, and even performance optimization.</p>\n<p><strong>Speaker:</strong> Alexey Milovidov</p>\n<p><strong>Abstract:</strong> I've created an rDNS map, available at <a target=\"_blank\" href=\"https://reversedns.space/\">https://reversedns.space/</a>, and I want to tell you how. It was not hard to do, but there was a lot of unusual and amusing stuff in the process.</p>\n<p>Of course, no ClickHouse event is complete without some time with the community. After a full day of talks, we gathered with our community members for dinner and drinks in Brussels. It was a chance to meet users, discuss database internals, and share ideas over great food and drinks. If you were there, thanks for joining us! If not, we hope to see you at the next one.</p>\n<p>In the meantime, feel free to join us on <a target=\"_blank\" href=\"https://clickhouse.com/slack\">Slack</a> or give the <a target=\"_blank\" href=\"https://github.com/ClickHouse/clickhouse\">ClickHouse repository</a> a star.</p>\n<h2 id=\"some-photos\"></h2>\n<p><span><img alt=\"FOSDEM_Robert.png\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2FFOSDEM_Robert_7ae18824d8.png&w=2048&q=75\"></span></p>\n<p><span><img alt=\"FOSDEM_Pedro.png\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2FFOSDEM_Pedro_281eabed62.png&w=2048&q=75\"></span></p>\n<p><span><img alt=\"FOSDEM_Alexey.png\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2FFOSDEM_Alexey_f71f4433fb.png&w=2048&q=75\"></span></p>\n<p><span><img alt=\"FOSDEM_Room_Full.png\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2FFOSDEM_Room_Full_42d27aab9b.png&w=2048&q=75\"></span></p>\n<p><span><img alt=\"FOSDEM_Dinner_Venue.jpg\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2FFOSDEM_Dinner_Venue_2d60dbbefb.jpg&w=2048&q=75\"></span></p>\n<p><span><img alt=\"FOSDEM_Dinner_Full.jpg\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2FFOSDEM_Dinner_Full_bbae49afa6.jpg&w=2048&q=75\"></span></p></div></article>"
