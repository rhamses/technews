contentHtml: "<div><p>ClickHouse's compatibility with third-party business intelligence tools and data visualization platforms is crucial for deriving insights from the stored data. Tools like Superset, Metabase, and Grafana can connect natively to ClickHouse and help users create fast and meaningful dashboards and reports, leveraging ClickHouse’s unbeatable performance and versatility.</p>\n<p>However, some of our users deploy tools that do not yet provide a native ClickHouse connector. Often, these tools are also proprietary solutions and don’t offer easy ways for us to contribute a native integration. To address this requirement, we are thrilled today to announce that compatibility can be achieved leveraging the <a target=\"_blank\" href=\"https://clickhouse.com/docs/en/interfaces/mysql\">MySQL interface for ClickHouse</a>, now available in ClickHouse Cloud. As of the time of writing this, compatibility allows our users to use Looker Studio and Tableau online with ClickHouse with support for Amazon QuickSight under active development.</p>\n<h2 id=\"a-concrete-example-with-clickhouse-cloud-and-google-looker-studio\"></h2>\n<p>We designed an opt-in experience for the MySQL interface in ClickHouse Cloud in order to limit the network exposure of Cloud services by default. Using the connection string screen, you can now access the MySQL tab and decide to enable the MySQL interface for your service.</p>\n<p><span><img alt=\"mysql_protocol_enable.png\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2Fmysql_protocol_enable_918aa8a730.png&w=2048&q=75\"></span></p>\n<p>Once enabled, your ClickHouse Service will expose port 3306 and prompt you with your MySQL connection string that includes your unique MySQL username. The password will be the same as the service's default user password.</p>\n<p>With these settings, you can now go to your <a target=\"_blank\" href=\"https://lookerstudio.google.com/\">Looker Studio</a> interface,declare a new MySQL Data Source, and provide the provided credentials.</p>\n<p><span><img alt=\"looker_mysql.png\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2Flooker_mysql_53e2568b78.png&w=2048&q=75\"></span></p>\n<p>In the Looker Studio UI, you’ll need to check the \"Enable SSL\" option. ClickHouse Cloud's SSL certificate is signed by LetsEncrypt. You can download this root cert <a target=\"_blank\" href=\"https://letsencrypt.org/certs/isrgrootx1.pem\">here</a> and upload it in Looker Studio.</p>\n<p><span><img alt=\"enable_ssl_mysql.png\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2Fenable_ssl_mysql_42acf992ac.png&w=2048&q=75\"></span></p>\n<p>That’s it! In a few steps, you now have a working connection in place between Looker Studio and ClickHouse Cloud that is using the MySQL interface. Alternatively, you can also leverage this interface to accelerate the migration of your custom applications built for MySQL to ClickHouse Cloud for faster analytics capabilities at scale.</p>\n<p><span><img alt=\"hackernews_looker.png\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2Fhackernews_looker_5ab1e4313d.png&w=2048&q=75\"></span></p>\n<h2 id=\"what-s-next\"></h2>\n<p>We tested this feature extensively with Google Looker Studio and Tableau online and improved the overall compatibility of the MySQL interface in ClickHouse by addressing <a target=\"_blank\" href=\"https://github.com/ClickHouse/ClickHouse/issues?q=is%3Aissue+%22MySQL%22+author%3Aslvrtrn+\">numerous issues</a> (shoutout to Serge Klochkov and Robert Schulze for the great work!). For a detailed description of the work done and efforts made by Serge and the team, see <a target=\"_blank\" href=\"https://clickhouse.com/blog/mysql-support-in-clickhouse-the-journey\">here</a>. We’ll be continuing this evaluation and continuous improvement on different platforms, prioritized based on user feedback. As of now, we are already exploring Microsoft PowerBI and Amazon QuickSight.</p>\n<p>As always, user feedback is extremely valuable. If you experience limitations with this functionality for a specific tool or platform or you’d like to see support for another tool, please don’t hesitate to reach out to us (<a target=\"_blank\" href=\"https://clickhouse.com/company/contact\">contact form</a>, <a target=\"_blank\" href=\"https://github.com/ClickHouse/ClickHouse/issues/new/choose\">new issue</a>).</p></div><p><a target=\"_blank\" href=\"https://clickhouse.cloud/signUp?loc=blog-cta-footer&utm_source=clickhouse&utm_medium=web&utm_campaign=blog\">Get started</a> with ClickHouse Cloud today and receive $300 in credits.
