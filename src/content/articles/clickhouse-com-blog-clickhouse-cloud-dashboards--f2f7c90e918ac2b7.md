Internally at ClickHouse, we use ClickHouse Cloud as our data warehouse, but many team members, particularly in non-technical roles, didn't want to write SQL or even see SQL code to view data. To address this, we deployed <a target=\"_blank\" href=\"https://superset.apache.org/\">Superset</a> on top of our ClickHouse Cloud service and created dashboards for the team's consumption.</p>\n<p>The core issues were clear: many users aren't comfortable writing SQL and expect dashboard-based data access. Additionally, our SQL console made it impossible to view results from multiple queries side-by-side.</p>\n<h2 id=\"how-dashboards-work\"></h2>\n<p>At their foundation, dashboards are visual representations of <code>SELECT</code> queries, we designed our dashboards feature with this principle at its core. We also added helper elements like spacer bars and text boxes to help users organize and annotate their dashboards.</p>\n<p>Using ClickHouse Query Parameters, dashboards can be made interactive.
