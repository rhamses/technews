We’ve spent a fair bit of time recently with the documentation, not only improving existing but building out <a target=\"_blank\" href=\"https://clickhouse.com/docs\">an entire new collection of content</a> to help developers, admins, architects and analysts gain the knowledge they need to successfully use ClickHouse.</p>\n<p>Here is what you will find in this new version of the docs:</p>\n<ul>\n<li>A redesigned <strong><a target=\"_blank\" href=\"https://clickhouse.com/docs/en/quick-start/\">Quick Start</a></strong> and <strong><a target=\"_blank\" href=\"https://clickhouse.com/docs/en/tutorial\">Tutorial</a></strong> to get up and running quickly</li>\n<li>A new <strong><a target=\"_blank\" href=\"https://clickhouse.com/docs/en/connect-a-ui\">Connect a UI</a></strong> section with guides on how to connect popular UI/BI tools to ClickHouse like Grafana, Metabase, Superset, and Tableau</li>\n<li>A new <strong><a target=\"_blank\" href=\"https://clickhouse.com/docs/en/integrations\">Integrations</a></strong> section of guides on how to connect ClickHouse to external systems like Kafka, AWS S3, PostgreSQL, MySQL, Airbyte and much more</li>\n<li>We are particularly excited about the new <strong><a target=\"_blank\" href=\"https://clickhouse.com/docs/en/guides\">User Guides</a></strong> section filled with articles, tutorials and how-to guides covering all sorts of fundamental and advanced ClickHouse topics. We want users to understand important topics like how to choose a primary key, configure the new ClickHouse Keeper, improve query performance, and lots of other helpful tips and tricks.</li>\n<li>The historical docs can be found in the new <strong><a target=\"_blank\" href=\"https://clickhouse.com/docs/category/reference\">Reference</a></strong> section, where you will find all the technical details like a complete ClickHouse SQL reference, an explanation of the various ClickHouse data types, instructions on how to build ClickHouse from the source code, and much more.</li>\n</ul>\n<p>Have you ever wanted to contribute to an open-source project? Documentation is often a great place to get started.</p>\n<p>According to the <a target=\"_blank\" href=\"https://opensourcesurvey.org/2017/\">Github Open Source Survey</a>:</p>\n<blockquote>\n<p>Incomplete or outdated documentation is a pervasive problem, observed by 93% of respondents, yet 60% of contributors say they rarely or never contribute to documentation.</p>\n</blockquote>\n<p>We strongly encourage users of ClickHouse and providers of integrated platforms to contribute new articles and user guides. We chose a user-friendly Creative Commons license for the new docs to allow for contributions and non-commercial use. (Note: that changes and contributions to the historical docs will continue in the <a target=\"_blank\" href=\"https://github.com/ClickHouse/ClickHouse/tree/master/docs\">ClickHouse/ClickHouse</a> repo.)</p>\n<p>You are all welcome to join us on the journey of documenting!</p></div></article>"
