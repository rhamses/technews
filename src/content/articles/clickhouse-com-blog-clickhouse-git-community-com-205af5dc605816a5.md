For the first few posts, we will focus on an analysis of the ClickHouse repository using the <code>git-import</code> tool distributed with ClickHouse.</p>\n<h2 id=\"introduction\"></h2>\n<p>In this post, we’d like to give some insights back to our community. The <a target=\"_blank\" href=\"https://ghe.clickhouse.tech/\">Github archive</a> dataset has been the foundation for examples and demos for some time. While a great resource, it doesn’t track the details of repositories at a code level, e.g., commits and changes to lines of code, but instead focuses on issues, stars, PRs, and events. Meanwhile, Git insights (via pulse) are interesting but incomplete…and exploring ClickHouse is substantially more fun.</p>\n<p>Fortunately, a tool is distributed with ClickHouse that solves this very issue: the <code>git-import</code> tool.</p>\n<pre><p>\nClickHouse % clickhouse-git-import -h\nA tool to extract information from Git repository for analytics.\nIt dumps the data for the following tables:\n- commits - commits with statistics;\n- file_changes - files changed in every commit with the info about the change and statistics;\n- line_changes - every changed line in every changed file in every commit with full info about the line and the information about previous change of this line.\nThe largest and the most important table is \"line_changes\".\nRun this tool inside your git repository. It will create .tsv files that can be loaded into ClickHouse (or into other DBMS if you dare).\n</p>\n</pre>\n<p>For the ClickHouse repository, this generates files of the following sizes in a few minutes as of November 8th, 2022:</p>\n<ul>\n<li><code>commits.tsv</code> - 7.8M - 266,051 rows</li>\n<li><code>file_changes.tsv</code> - 53M - 266,051 rows</li>\n<li><code>line_changes.tsv</code> - 2.7G - 7,535,157 rows</li>\n</ul>\n<p>You can generate this data for any repository on Github (see linux <a target=\"_blank\" href=\"https://clickhouse.com/docs/en/getting-started/example-datasets/github#downloading-and-inserting-the-data\">here</a>) and analyze your own projects using the questions below for inspiration. If you don’t have time to generate the data yourself, we’ve loaded our own data into <a target=\"_blank\" href=\"https://sql.clickhouse.com/?query_id=DCQPNPAIMAQXRLHYURLKVJ\">play.clickhouse.com</a> (note the database is <code>git_clickhouse</code>) so our community can play with the example queries.</p>\n<h2 id=\"questions-answered\"></h2>\n<p>The tool handily proposes some possible questions for you to answer. We’ve answered these, in addition to some others of interest, for the ClickHouse repository. You can find the complete list of questions and their current answers <a target=\"_blank\" href=\"https://clickhouse.com/docs/en/getting-started/example-datasets/github\">here</a>.  Please share your own insights for both ClickHouse and other repositories, and feel free to contribute queries and improvements!</p>\n<p>Note that some of the questions are quite broad and open to interpretation, so we welcome alternatives. The data is also intended for high-level analytical purposes. It can be imprecise for a few reasons (e.g., dirty and broken commit histories), making some more exact queries particularly challenging. This shouldn’t impact any high-level analysis, however.</p>\n<p>In future posts, we’ll dig into some specific queries and highlight a range of ClickHouse functionality. For now, we’d like to present the opportunity to solve one of the tools suggested questions for which the current answer feels like it could be improved….</p>\n<h2 id=\"a-challenge\"></h2>\n<p>The most challenging query posed by the tool is probably the reconstruction of the git blame command. Our documentation has an <a target=\"_blank\" href=\"https://clickhouse.com/docs/en/getting-started/example-datasets/github/#git-blame\">approximate solution</a> appropriate for high-level analysis, but we hope you can improve this.</p>\n<p>We leave this to the reader to solve - with a t-shirt for the first to present their answer - tweet us at @ClickHouse, send us an email at  <a target=\"_blank\" href=\"mailto:community@clickhouse.com\">community@clickhouse.com</a> with the title “git blame solution” or just raise a PR on the <a target=\"_blank\" href=\"https://github.com/ClickHouse/ClickHouse/blob/master/docs/en/getting-started/example-datasets/github.md\">doc page</a>.</p>\n<p>A few tips:</p>\n<ul>\n<li>When comparing your query result with <code>git-blame</code>, make sure you check out the same commit for which this dataset was generated up to - if using play, check the latest commit <a target=\"_blank\" href=\"https://sql.clickhouse.com/?query_id=7ARCDLHQCESYBP3INDPTVO\">here</a>.
