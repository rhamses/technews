contentHtml: "<article><div><p>We’re excited to announce a new integration between ClickHouse and Microsoft OneLake -  Microsoft Fabric’s unified data lake - powered by the OneLake <a target=\"_blank\" href=\"https://learn.microsoft.com/en-us/fabric/onelake/table-apis/iceberg-table-apis-overview\">Tables APIs</a> and <a target=\"_blank\" href=\"https://iceberg.apache.org/\">Apache Iceberg</a>.</p>\n<p>This integration will debut as a beta feature in ClickHouse 25.11 (November release) and will be available shortly after in ClickHouse Cloud.</p>\n<p>With this new integration, ClickHouse now supports direct querying of Iceberg tables in OneLake, eliminating friction and unlocking unified, fast analytics across multiple sources.</p>\n<h2 id=\"building-a-unified-analytics-and-ai-platform\"></h2>\n<p>A common challenge for organizations and in particular data teams is being able to use all of their data, regardless of where it’s stored for analytics, GenAI and AI agents. Discovery, governance and access controls are critical to successfully delivering on these projects. Making sure they work with all data assets in various data lakes, data warehouses and operational stores is very difficult.</p>\n<p>Microsoft OneLake enables organizations to unify their data into a common store, cataloging and securing it in a single place. They can use <a target=\"_blank\" href=\"https://learn.microsoft.com/en-us/fabric/onelake/onelake-shortcuts\">OneLake Shortcuts</a> to connect external stores like <a target=\"_blank\" href=\"https://learn.microsoft.com/en-us/fabric/onelake/create-s3-shortcut\">Amazon S3</a> or <a target=\"_blank\" href=\"https://learn.microsoft.com/en-us/fabric/onelake/create-gcs-shortcut\">Google Cloud Storage</a> to OneLake, moving data only when it is queried. They can also continuously replicate data from popular databases using native <a target=\"_blank\" href=\"https://learn.microsoft.com/en-us/fabric/mirroring/overview\">zero-copy mirroring</a> or build their own with <a target=\"_blank\" href=\"https://learn.microsoft.com/en-us/fabric/mirroring/open-mirroring\">Open Mirroring</a>. All of this data is cataloged in the <a target=\"_blank\" href=\"https://learn.microsoft.com/en-us/fabric/governance/onelake-catalog-overview\">OneLake catalog</a> and secured using <a target=\"_blank\" href=\"https://learn.microsoft.com/en-us/fabric/onelake/security/get-started-security\">OneLake Security</a> so it can be safely accessed from Microsoft Fabric, <a target=\"_blank\" href=\"https://azure.microsoft.com/en-us/products/ai-foundry\">Azure AI Foundry</a> and many popular 3rd party engines like ClickHouse.</p>\n<p>OneLake’s Iceberg-compatible <a target=\"_blank\" href=\"https://learn.microsoft.com/en-us/fabric/onelake/table-apis/iceberg-table-apis-overview\">Tables APIs</a> make it possible for ClickHouse to discover and query data in OneLake with minimal configuration. The ease of use and ecosystem interoperability enable a unified analytical platform that combines flexibility and control to empower users to build and deliver analytics and AI projects quickly with all of their data - enterprise, operational, logs, and 3rd party.</p>\n<h2 id=\"how-does-the-integration-work\"></h2>\n<p>To use this new integration, you only need two components:</p>\n<ul>\n<li>A ClickHouse instance (even <a target=\"_blank\" href=\"https://clickhouse.com/docs/operations/utilities/clickhouse-local\">ClickHouse local</a> will suffice)</li>\n<li>A <a target=\"_blank\" href=\"https://www.microsoft.com/en-us/microsoft-fabric/getting-started\">Microsoft Fabric account</a></li>\n</ul>\n<p>Tables can be written into OneLake using Fabric managed engines like <a target=\"_blank\" href=\"https://learn.microsoft.com/en-us/fabric/data-engineering/runtime\">Spark</a> or <a target=\"_blank\" href=\"https://learn.microsoft.com/en-us/fabric/data-warehouse/\">Data Warehouse</a> or your tool of choice. You can write tables in either Delta Lake or Apache Iceberg format. OneLake’s format virtualization will automatically convert between formats and keep both in sync at all times, making it easy to bring your engine of choice without converting or migrating your data.</p>\n<p>OneLake also exposes an Iceberg REST catalog via OneLake Table APIs, which ClickHouse uses as an interface to discover and query the underlying Iceberg tables directly.</p>\n<p><span><img alt=\"onelake_image1.png\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2Fonelake_image1_01d3a18aa2.png&w=2048&q=75\"></span></p>\n<p>For security, ClickHouse uses Microsoft Entra ID (formerly Azure Active Directory) to authenticate the user identity with the OneLake Table APIs, ensuring secure and controlled access to data stored in OneLake. Additionally, the same access token received from Entra will be used to allow users the ability to read data from OneLake. Access permissions are managed in Entra as <a target=\"_blank\" href=\"https://learn.microsoft.com/en-us/entra/identity-platform/app-objects-and-service-principals?tabs=browser\">Service Principals</a> or through Fabric <a target=\"_blank\" href=\"https://learn.microsoft.com/en-us/fabric/data-engineering/lakehouse-sharing\">workspace-level permissions</a>.</p>\n<h2 id=\"getting-started-with-clickhouse-and-onelake\"></h2>\n<p>Getting started with ClickHouse and OneLake is simple. You can deploy ClickHouse on <a target=\"_blank\" href=\"https://clickhouse.com/partners/azure\">Azure</a> or directly from the <a target=\"_blank\" href=\"https://marketplace.microsoft.com/en-us/product/saas/clickhouse.clickhouse_cloud?tab=overview\">Azure Marketplace</a>, ensuring you’re using version 25.11. Once your service is deployed, you’ll be able to enable the OneLake integration and run the following queries to access your Iceberg tables directly. Read more in the <a target=\"_blank\" href=\"https://clickhouse.com/docs/use-cases/data-lake/onelake-catalog\">ClickHouse documentation for OneLake</a>.</p>\n<h2
