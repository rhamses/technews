Have a listen <a target=\"_blank\" href=\"https://clickhouse.com/company/events/getting-started-with-clickhouse/\">here</a> and send it to your friends that don’t know ClickHouse yet!</p>\n<h2 id=\"clickhouse-v22-3\"></h2>\n<p>On March 17, we released ClickHouse 22.3 LTS with lots of new features (especially one that we are very excited about). It is also a Long Term Support (LTS) release, so you can use it for the next year and we’ll keep the bug fixes coming. If you’re not planning to upgrade your ClickHouse monthly with the newest available version you should be on an LTS release!</p>\n<p>What’s in 22.3:</p>\n<ol>\n<li>\n<p><a target=\"_blank\" href=\"https://presentations.clickhouse.com/release_22.3/\">JSON</a> is a new data type that allows you to ingest any JSON documents directly into a column. Under the hood, ClickHouse will create dynamic subcolumns to store the data, so access is still fast.</p>\n<p>Historically, when storing JSON documents in ClickHouse you would create table columns for each field. This works well if you know beforehand what your data is going to look like. But with JSON this is often not the case, especially if it is logs from different applications and services, for example. To get this kind of “semi-structured” data into ClickHouse, it was often necessary to develop <a target=\"_blank\" href=\"https://eng.uber.com/logging/\">sophisticated data schemas</a> involving arrays and materialized columns.</p>\n<p>No longer! Now it can all just go into one column of type JSON. It’s a really powerful feature and we’re very excited about it, so give it a go and let us know what you think.</p>\n</li>\n<li>\n<p><strong>ARM</strong> builds are now available <a target=\"_blank\" href=\"https://hub.docker.com/r/clickhouse/clickhouse-server/tags\">as Docker images</a>! For example, you can run ClickHouse on macOS using Docker with <code>docker run clickhouse/clickhouse-server</code>. All functional tests are now passing for ARM builds in our CI. In addition you can now obtain deb, rpm, apk, and binary packages.</p>\n</li>\n<li>\n<p><strong><a target=\"_blank\" href=\"https://clickhouse.com/docs/en/engines/table-engines/mergetree-family/mergetree/#table_engine-mergetree-s3\">S3 disks</a></strong> as storage for ClickHouse are now fully tested as well. You can configure using S3 for storage in the <code>&lt;storage_configuration&gt;</code> section of the ClickHouse configuration file. Note: There are still some performance issues that we are working on.</p>\n</li>\n<li>\n<p>The <strong><a target=\"_blank\" href=\"https://github.com/ClickHouse/ClickHouse/pull/34946\">Hive table function</a></strong> allows you to read data from Apache Hive tables directly and combine it with data in ClickHouse. Or insert the data into ClickHouse using <code>INSERT INTO clickhouse_table SELECT * FROM hive(...)</code>.</p>\n</li>\n</ol>\n<p>For more details including live demos have a look at the release webinar recording <a target=\"_blank\" href=\"https://www.youtube.com/watch?v=GzeANZzPras\">here</a>. To insert it into a JSON column ClickHouse, you can run something like:</p>\n<div><pre><code><span>CREATE TABLE logs (message JSON) ENGINE = MergeTree ORDER BY tuple()</span>\n<span>INSERT INTO logs SELECT json FROM file(log.json.gz', JSONAsString)</span></code></pre></div>\n<p>Note how we use the <code>JSONAsString</code> format to prevent ClickHouse treating each JSON field as its own column (and even with the new JSON data type, if your data is structured and the fields are known, you should still consider doing that).</p>\n<p>Note also that we cannot sort the MergeTree table by anything in the data, because with JSON, we do not yet know the structure of the data beforehand. For large datasets, not having a sorting key is bad! In practice, we will often want to extract at least some important and common fields from a JSON document into their own columns. For example, the timestamp:</p>\n<div><pre><code><span><span>CREATE TABLE</span> logs (</span>\n<span>\t<span>timestamp</span> DateTime,</span>\n<span>\tmessage JSON</span>\n<span>) ENGINE <span>=</span> MergeTree <span>ORDER</span> <span>BY</span> <span>timestamp</span></span>\n<span></span>\n<span></span>\n<span><span>INSERT INTO</span> logs</span>\n<span><span>SELECT</span> parseDateTimeBestEffort(JSONExtractString(json, <span>'timestamp'</span>)), json</span>\n<span><span>FROM</span> file(<span>'access.json.gz'</span>, JSONAsString)</span></code></pre></div>\n<p>Lastly, when displaying a JSON column ClickHouse only shows the field values by default (because internally, it is represented as a tuple). You can display the field names as well like this:</p>\n<div><pre><code><span>SELECT message FROM logs FORMAT JSONEachRow</span>\n<span>SETTINGS output_format_json_named_tuples_as_objects = 1</span></code></pre></div>\n<p>Give this new data type a try and let us know what you think!</p>\n<h2 id=\"reading-corner\"></h2>\n<p>What we’ve been reading:</p>\n<ol>\n<li><a target=\"_blank\" href=\"https://clickhouse.com/blog/building-a-paste-service-with-clickhouse/\">Building a Paste Service With ClickHouse</a>: Alexey explores building a Pastebin-style service using many ClickHouse anti-patterns (the post was published on April 1, but it’s only half in jest and the service actually works!).</li>\n<li><a target=\"_blank\" href=\"https://clickhouse.com/blog/stories-of-difference-inspiration-courage-and-empathy-international-womens-day-2022/\">International Women’s Day @ ClickHouse</a>: Read stories of the women that bring ClickHouse to you every month and some of their experiences as women in tech.</li>\n<li><a target=\"_blank\" href=\"https://clickhouse.com/blog/indexing-for-data-streams-benocs-telco\">Fast Indexing for Data Streams</a>: BENOCS is using ClickHouse to collect and visualize network traffic for large telcos worldwide.</li>\n<li><a target=\"_blank\" href=\"https://clickhouse.com/blog/clickhouse-22-3-lts-released/\">ClickHouse 22.3 release blog post</a> – learn more about our 22.3 release and what’s in it.</li>\n<li><a target=\"_blank\" href=\"https://clickhouse.com/docs/en/introduction/adopters/\">New ClickHouse Adopters</a>: Welcome <a target=\"_blank\" href=\"https://swetrix.com/\">Swetrix Analytics</a>.
