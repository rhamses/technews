You can do it with ClickHouse! There are a few options and they use some neat features in ClickHouse that you might not (yet) know.</p>\n<p><strong>Option 1:</strong></p>\n<div><pre><code><span><span>SELECT</span> <span>*</span> <span>FROM</span> hackernews <span>WHERE</span> formatRow(<span>'TSV'</span>, <span>*</span>) ILIKE <span>'%i love clickhouse%'</span></span></code></pre></div>\n<p>This query uses the <a target=\"_blank\" href=\"https://clickhouse.com/docs/en/sql-reference/functions/type-conversion-functions/#formatrow\">formatRow</a> function to concatenate all columns into a long tab-separated string and searches through it using <code>ILIKE</code>.</p>\n<p><strong>Option 2:</strong></p>\n<div><pre><code><span><span>SELECT</span> <span>*</span> <span>FROM</span> hackernews <span>WHERE</span> concat(<span>*</span> APPLY x <span>-</span><span>&gt;</span> concat(toString(x), <span>'&lt;&lt;&gt;&gt;'</span>)) ILIKE <span>'%i love clickhouse%'</span></span></code></pre></div>\n<p>In this query, we also concatenate all columns, but instead of using tabs as separators we can specify the separator ourselves, in this case <code>&lt;&lt;&gt;&gt;</code>. <a target=\"_blank\" href=\"https://clickhouse.com/docs/en/sql-reference/statements/select/#apply-modifier\">APPLY</a> is a wonderful modifier that allows us to invoke a function (in this case, a <a target=\"_blank\" href=\"https://clickhouse.com/docs/en/sql-reference/functions/#higher-order-functions\">higher-order lambda expression</a>) on any expression (all columns in this case, but we could have specified a subset of columns using the handily named <a target=\"_blank\" href=\"https://clickhouse.com/docs/en/sql-reference/statements/select/#columns-expression\">COLUMNS expression</a>).</p>\n<p><strong>Option 3:</strong></p>\n<div><pre><code><span><span>SELECT</span> <span>*</span> <span>FROM</span> hackernews <span>WHERE</span> (arrayExists(x <span>-</span><span>&gt;</span> positionCaseInsensitiveUTF8(x, <span>'i love clickhouse'</span>) <span>&gt;</span> <span>0</span>, <span>array</span>(<span>*</span> APPLY x <span>-</span><span>&gt;</span> toString(x))))</span></code></pre></div>\n<p>Have you noticed what can happen when using the first two options? Because all columns are simply concatenated into one big string it is possible to search across columns if one (knowingly or accidentally) searches for the column separator. The last query here eliminates the problem by gathering all columns into an array instead and using the <a target=\"_blank\" href=\"https://clickhouse.com/docs/en/sql-reference/functions/array-functions/#arrayexistsfunc-arr1\">arrayExists</a> function to check if there is any one element that contains the phrase we are searching for.</p>\n<p>When running any of these queries on the <a target=\"_blank\" href=\"https://github.com/ClickHouse/ClickHouse/issues/29693\">Hacker News dataset</a> they all find the comment “I love clickhouse: it’s simple yet flexible enough and free software.” Aw shucks, we love ClickHouse too!</p>\n<p>Have you written an interesting query recently that you think others could learn from? <a target=\"_blank\" href=\"https://twitter.com/clickhousedb\">Let us know on twitter</a>, we’d love to hear from you!</p>\n<h2 id=\"reading-corner\"></h2>\n<p>What we’ve been reading at the start of the year:</p>\n<ol>\n<li><a target=\"_blank\" href=\"https://clickhouse.com/blog/en/2022/clickhouse-v22.1-released/\">What’s New in ClickHouse 22.1</a> – our v22.1 release blog post, announcing automatic schema inference, parallel query processing on multiple replicas, a new diagnostic tool for your ClickHouse and more!</li>\n<li><a target=\"_blank\" href=\"https://clickhouse.com/blog/en/2022/a-mixer-aggregates-over-1-billion-unique-users-a-day-using-clickhouse/\">Admixer Aggregates Over 1 Billion Unique Users a Day using ClickHouse</a> – Adtech platform Admixer moved from MSSQL and Azure Table Storage to ClickHouse and is ingesting over 1M rows per second.</li>\n<li><a target=\"_blank\" href=\"https://vkontech.com/migrating-your-reporting-queries-from-a-general-purpose-db-mongodb-to-a-data-warehouse-clickhouse-performance-overview/\">Migrating Your Reporting Queries From MongoDB to ClickHouse</a> – Benchmarking MongoDB versus ClickHouse for analytics queries.
