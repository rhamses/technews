An alternative approach here might be to load the file into a table first before running the query on the file. The total load and query time thus exceeds 19 seconds.</p>\n<div><pre><code><span><span>CREATE TABLE</span> weather</span>\n<span>(</span>\n<span>\t`city` String,</span>\n<span>\t`temperature` <span>Decimal</span>(<span>8</span>, <span>1</span>)</span>\n<span>)</span>\n<span>ENGINE <span>=</span> Memory</span>\n<span></span>\n<span><span>INSERT INTO</span> weather <span>SELECT</span></span>\n<span>\tcity,</span>\n<span>\ttemperature</span>\n<span><span>FROM</span></span>\n<span>(</span>\n<span>\t<span>SELECT</span></span>\n<span>    \tsplitByChar(<span>';'</span>, line) <span>AS</span> vals,</span>\n<span>    \tvals[<span>1</span>] <span>AS</span> city,</span>\n<span>    \t<span>CAST</span>(vals[<span>2</span>], <span>'Decimal(8, 1)'</span>) <span>AS</span> temperature</span>\n<span>\t<span>FROM</span> file(<span>'measurements.txt'</span>, LineAsString)</span>\n<span>)</span>\n<span></span>\n<span><span>0</span> <span>rows</span> <span>in</span> set. In this case, a Materialized View <code>weather_mv</code> computes our statistics as the data is inserted. More specifically, our previous aggregation query executes on blocks of data as it is inserted with the results (effectively <a target=\"_blank\" href=\"https://clickhouse.com/docs/en/sql-reference/data-types/aggregatefunction\">aggregation states</a>) sent to a target table \"weather_results\" using the <a target=\"_blank\" href=\"https://clickhouse.com/docs/en/engines/table-engines/mergetree-family/aggregatingmergetree\">AggregatingMergeTree</a> table engine. A query on this table will utilize the fact the results have been precomputed, resulting in a significantly faster execution time.</p>\n<p>As an optimization, the <code>weather</code> table receiving our data can use the Null engine. This will cause the rows to be discarded, saving memory.</p>\n<div><pre><code><span><span>CREATE TABLE</span> weather</span>\n<span>(</span>\n<span>    `city` String,</span>\n<span>    `temperature` <span>Decimal</span>(<span>8</span>, <span>1</span>)</span>\n<span>)</span>\n<span>ENGINE <span>=</span> <span>Null</span></span>\n<span></span>\n<span><span>CREATE TABLE</span> weather_results(</span>\n<span>\tcity String,</span>\n<span>\tmax AggregateFunction(max, <span>Decimal</span>(<span>8</span>, <span>1</span>)),</span>\n<span>\tmin AggregateFunction(min, <span>Decimal</span>(<span>8</span>, <span>1</span>)),</span>\n<span>\tavg AggregateFunction(avg, <span>Decimal</span>(<span>8</span>, <span>1</span>))</span>\n<span>) ENGINE <span>=</span> AggregatingMergeTree <span>ORDER</span> <span>BY</span> tuple()</span>\n<span></span>\n<span><span>CREATE</span> MATERIALIZED <span>VIEW</span> weather_mv <span>TO</span> weather_results</span>\n<span><span>AS</span> <span>SELECT</span> city, maxState(temperature) <span>as</span> max, minState(temperature) <span>as</span> min, avgState(temperature) <span>as</span> avg</span>\n<span><span>FROM</span> weather</span>\n<span><span>GROUP</span> <span>BY</span> city</span>\n<span></span>\n<span><span>INSERT INTO</span> weather <span>SELECT</span></span>\n<span>\tcity,</span>\n<span>\ttemperature</span>\n<span><span>FROM</span></span>\n<span>(</span>\n<span>\t<span>SELECT</span></span>\n<span>    \tsplitByChar(<span>';'</span>, line) <span>AS</span> vals,</span>\n<span>    \tvals[<span>1</span>] <span>AS</span> city,</span>\n<span>    \t<span>CAST</span>(vals[<span>2</span>], <span>'Decimal(8, 1)'</span>) <span>AS</span> temperature</span>\n<span>\t<span>FROM</span> file(<span>'measurements.txt'</span>, LineAsString)</span>\n<span>)</span>\n<span></span>\n<span><span>0</span> <span>rows</span> <span>in</span> set.
