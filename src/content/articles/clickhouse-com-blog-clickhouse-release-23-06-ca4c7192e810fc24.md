As a column-oriented database, sorting data on insert is fundamental to query performance and one of the early concepts users encounter when needing to specify an <a target=\"_blank\" href=\"https://clickhouse.com/docs/en/sql-reference/statements/select/order-by\"><code>ORDER BY</code></a> clause when creating a table. This clause specifies a list of columns by which data will be sorted on disk, which should align with user access patterns to ensure optimal query performance. While these ordering keys are the first tool for every ClickHouse user to tune performance, it remains unrealistic to specify all columns here. Despite this, some columns are naturally sorted and aligned with these sorting keys.</p>\n<p>In 23.6, ClickHouse will now exploit any natural sorting patterns in the data to improve query performance. This is particularly in cases where a column is known to be monotonically increasing in most cases but is not part of the ordering key.</p>\n<h2 id=\"new-contributors\"></h2>\n<p>A special welcome to all the new contributors to 23.6!
