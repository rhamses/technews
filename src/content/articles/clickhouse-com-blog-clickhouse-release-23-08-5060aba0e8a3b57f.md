Historically, the orchestration of the latter relied on the user. While an initial data load could be performed using an <code>INSERT INTO SELECT</code> with the s3 function, subsequent incremental loads typically relied on the user building additional processes. These could be either a data pipeline, using a technology such as Kafka, or more simply, the scheduling of an <code>INSERT SELECT</code> e.g. using a cron job. The latter is surprisingly common and can be subtly difficult to ensure it is robust.</p>\n<p>In 23.8, we begin to drastically simplify incremental loads from S3 with the <a target=\"_blank\" href=\"https://clickhouse.com/docs/en/engines/table-engines/integrations/s3queue\"><code>S3Queue</code></a> table engine. This new table engine allows the streaming consumption of data from S3. As files are added to a bucket, ClickHouse will automatically process these files and insert them into a designated table. With this capability, users can set up simple incremental pipelines with no additional code.</p>\n<p>Consider the following simple example.
