contentHtml: "<article><div><p>Today, we’re proud to announce that <a target=\"_blank\" href=\"https://clickhouse.com/cloud/clickpipes\">ClickPipes</a> now supports AWS’s new way to provide private, unidirectional connectivity to individual data sources using AWS PrivateLink and VPC Lattice.</p>\n<p>Supporting this new PrivateLink feature coincides with our most recent accreditation status as a AWS PrivateLink Service Ready Partner. We went through a stringent validation process with the AWS team to demonstrate our technical capabilities, verification of our solution and security processes, so you can be sure the integration is robust.</p>\n<p>ClickPipes is our continuous data ingestion service designed specifically for ClickHouse Cloud. It connects your external data sources like <a target=\"_blank\" href=\"https://aws.amazon.com/msk/getting-started/\">Amazon MSK</a>, <a target=\"_blank\" href=\"https://aws.amazon.com/s3/getting-started/\">Amazon S3</a>, or <a target=\"_blank\" href=\"https://aws.amazon.com/kinesis/getting-started/\">Amazon Kinesis</a>, enabling you to set up robust and scalable data pipelines quickly and efficiently to get data into your ClickHouse service. Since its inception, ClickPipes has provided support for <a target=\"_blank\" href=\"https://docs.aws.amazon.com/vpc/latest/privatelink/what-is-privatelink.html\">AWS PrivateLink</a> to support our customers wanting to avoid their data and network traffic going over the public internet.</p>\n<p><span><img alt=\"1a_crossvpc.png\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2F1a_crossvpc_92f4eb1732.png&w=2048&q=75\"></span>\nAWS PrivateLink architecture with load balancer</p>\n<p>Cross-VPC resource access with AWS PrivateLink and VPC Lattice gives the added benefit of reducing the amount of resources needed as you no longer require a load-balancer (ALB/NLB) to take advantage of sharing your data to ClickPipes.</p>\n<p>This new capability leverages AWS PrivateLink VPC endpoints and VPC Lattice to share and access resources across VPCs and accounts.</p>\n<p><span><img alt=\"2_crossvpc.png\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2F2_crossvpc_a4d1da0342.png&w=2048&q=75\"></span>\nAWS PrivateLink architecture without load balancer</p>\n<p>A resource owner can share specific resources from their VPC, without exposing any other resources in that VPC to a resource consumer. A resource consumer can access shared resources in another VPC/account privately.</p>\n<p>With this capability, you can connect your individual resources across VPC and account boundaries, or even from on-premise networks* with the privacy and security benefits of AWS PrivateLink.</p>\n<p><span><img alt=\"3a_crossvpc.png\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2F3a_crossvpc_89d25b655c.png&w=2048&q=75\"></span>\nClickPipes using AWS PrivateLink and VPC Lattice for cross-VPC resource access</p>\n<p>In order to get started using AWS MSK shared through AWS PrivateLink and VPC Lattice, you will need to do the following steps:</p>\n<ol>\n<li>Create a Resource-Gateway to allow access into your VPC</li>\n<li>Provide a Resource-Configuration to specify which resource should be shared</li>\n<li>Share the Resource-Configuration with ClickHouse to use with ClickPipes</li>\n</ol>\n<h3 id=\"create-a-resource-gateway\"></h3>\n<p>In order to share resources that are within your VPC, you will need to create a Resource-Gateway. The following command will create the Resource-Gateway.</p>\n<div><pre><code><span>aws vpc-lattice create-resource-gateway \\ </span>\n<span>--vpc-identifier &lt;VPC_ID&gt; \\</span>\n<span>--subnet-ids &lt;SUBNET_IDS&gt; \\ </span>\n<span>--security-group-ids &lt;SG_IDs&gt; \\</span>\n<span>--name &lt;NAME&gt;</span></code></pre></div>\n<p>Before you can proceed, you will need to wait for the Resource-Gateway to enter into an “Active” state. You can check the state by running the following:</p>\n<div><pre><code><span>aws vpc-lattice get-resource-gateway \\</span>\n<span>--resource-gateway-identifier &lt;RESOURCE_GATEWAY_ID&gt;</span></code></pre></div>\n<h3 id=\"create-a-vpc-resource-configuration\"></h3>\n<p>To share your resource, you’ll need to create a Resource-Configuration that will be used by the Resource-Gateway.</p>\n<p>You can create a Resource-Configuration that either shares an IP-address or a domain-name that is publicly resolvable.</p>\n<p>This simple setup will focus on supplying a single Resource-Configuration to share, if you would like to configure Group/Child Resource-Configurations, please refer to our documentation.</p>\n<div><pre><code><span>aws vpc-lattice get-resource-gateway \\</span>\n<span>--resource-gateway-identifier &lt;RESOURCE_GATEWAY_ID&gt;</span></code></pre></div>\n<p>The output of the command will provide the “Resource-Configuration ARN”, you will use this in the next step and replace the &lt;VPC_RESOURCE_CONFIGURATION_ARN&gt; variable.</p>\n<p>Sharing your resource requires the Resource-Configuration to be shared with ClickPipes, this is facilitated through the Resource Access Manager (RAM).</p>\n<p>The following command will put the Resource-Configuration into the Resource-Share, enabling ClickHouse to access your resource when you have shared your Resource-Owner Account ID with us.</p>\n<div><pre><code><span>aws ram create-resource-share \\</span>\n<span>--principals 072088201116 \\</span>\n<span>--resource-arns \"&lt;VPC_RESOURCE_CONFIGURATION_ARN&gt;\" \\</span>\n<span>--name \"&lt;RESOURCE_SHARE_NAME&gt;\"</span></code></pre></div>\n<p>The ClickPipes team will require a resource owner account ID to be shared. You can find this within the <a target=\"_blank\" href=\"https://docs.aws.amazon.com/accounts/latest/reference/manage-acct-identifiers.html\">AWS console</a> or by running the following CLI command:</p>\n<div><pre><code><span>aws sts get-caller-identity \\</span>\n<span>--query Account \\</span>\n<span>--output text</span></code></pre></div>\n<p>If data source (e.g. Kafka broker) requires a private DNS setup , please share the host name(s) with ClickPipes team as part of your support request.</p>\n<h2 id=\"ready-to-get-set-up\"></h2>\n<p>We’re excited to get our users set up with cross-VPC resource access. If you would like to start utilizing this feature with ClickPipes, please raise a <a target=\"_blank\" href=\"https://console.clickhouse.cloud/support\">support ticket</a> through the ClickHouse Console with the Resource Owner Account ID.</p>\n<p>* In order to connect PrivateLink Resource Endpoints to an on-premise resource, a Direct Connect or VPN connection is required</p></div></article>"
