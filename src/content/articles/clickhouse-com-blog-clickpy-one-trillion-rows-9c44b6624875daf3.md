contentHtml: "<article><div><p><a target=\"_blank\" href=\"https://pypi.org/\">PyPi</a> (Python Package Index) is the software repository for the Python programming language. It sits at the center of the Python ecosystem, where various libraries are downloaded almost 2 billion times daily.</p>\n<p>Metadata related to those downloads can be accessed in BigQuery. This is fine for doing ad-hoc queries, but we wanted to create a user-facing service that lets users explore their favorite packages.</p>\n<p>Enter <a target=\"_blank\" href=\"https://clickpy.clickhouse.com/\">ClickPy</a>, a free service built on top of ClickHouse that lets you run real-time analytics on PyPi package downloads. They will be called <code>countries</code>, <code>projects,</code> and <code>pypi,</code> respectively.</p>\n<p><code>pypi</code> contains the most data since every download is one row, and we have a lot of rows! Therefore, we will create downstream tables for common query patterns and corresponding materialized views to populate those tables. The diagram below shows all the tables that we’ll create:</p>\n<p><span><img alt=\"ClickPy 1 Trillion Rows Banner (1).png\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2FClick_Py_1_Trillion_Rows_Banner_1_f5d4a623f9.png&w=2048&q=75\"></span></p>\n<p>ClickHouse also supports dictionaries, which are in-memory key-value pairs useful for reference data. We will create dictionaries for countries, mapping the country code to the country name, and another for projects, mapping the project name to the last update time.</p>\n<h2 id=\"ingesting-the-data\"></h2>\n<p>The underlying data for the projects and downloads is available in BigQuery. However, exporting the data takes several hours, so we exported the data into Google Cloud Storage buckets as Parquet files.
