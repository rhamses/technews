Hardware vendors constantly add new instructions to the instruction set of modern CPUs. And we often want to use the latest instructions for optimizations, and the most important are <a target=\"_blank\" href=\"https://en.wikipedia.org/wiki/Single_instruction,_multiple_data\">SIMD</a> instructions.
