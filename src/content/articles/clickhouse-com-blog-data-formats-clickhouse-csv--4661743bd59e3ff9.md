Since we believe loading data into your favorite OSS database should be as easy as possible, we have recently <a target=\"_blank\" href=\"https://clickhouse.com/docs/en/integrations/data-formats\">enhanced our docs</a> to include examples for the most popular formats. This also includes some useful hints and tricks for more experienced users.</p>\n<p>This post provides a brief overview of ClickHouse's extensive support for different formats and how to load your local files.</p>\n<h2 id=\"importing-and-exporting-data\"></h2>\n<p>ClickHouse supports most of the known text and binary data formats. This allows easy integration into almost any working data pipeline to leverage the benefits of ClickHouse.</p>\n<h3 id=\"standard-text-formats\"></h3>\n<p>CSV is one of the most popular formats to store data due to its simplicity. Importing and exporting CSV data is easy with the <a target=\"_blank\" href=\"https://clickhouse.com/docs/en/interfaces/formats/#csv\">CSV</a> format:</p>\n<div><pre><code><span>clickhouse-client -q <span>\"INSERT INTO some_table FORMAT CSV\"</span> &lt; data.csv</span></code></pre></div>\n<p>In many cases, CSV files are broken, poorly encoded, and have custom delimiters or even line separators. ClickHouse provides ways to handle any of these cases.</p>\n<p>To process CSVs with custom delimiters (<code>;</code> in our example), we have to set the following option:</p>\n<div><pre><code><span><span>SET</span> format_csv_delimiter <span>=</span> <span>';'</span>;</span></code></pre></div>\n<h3 id=\"importing-data-from-broken-or-custom-csv-files\"></h3>\n<p>In cases where the CSV file is encoded in a non-standard way or just invalid, we can use the <a target=\"_blank\" href=\"https://clickhouse.com/docs/en/sql-reference/formats/#format-customseparated\">CustomSeparated</a> format to customize escaping rules and delimiters:</p>\n<div><pre><code><span><span>SET</span> format_custom_field_delimiter <span>=</span> <span>'|'</span>;</span>\n<span><span>SET</span> format_custom_row_between_delimiter <span>=</span> <span>';'</span>;</span>\n<span><span>SET</span> format_custom_escaping_rule <span>=</span> <span>'JSON'</span>;</span></code></pre></div>\n<p>Here, we've used the JSON <a target=\"_blank\" href=\"https://clickhouse.com/docs/en/operations/settings/settings/#format_custom_escaping_rule\">escaping rule</a>, <code>|</code> as a custom value delimiter, and <code>;</code> as the line separator. After the settings are changed, we can continue with our import:</p>\n<div><pre><code><span><span>INSERT INTO</span> some_table <span>FROM</span> INFILE <span>'custom.csv'</span> FORMAT CustomSeparated</span></code></pre></div>\n<p>Another popular text data format is Tab Separated Values (TSV), which ClickHouse also supports with the <a target=\"_blank\" href=\"https://clickhouse.com/docs/en/interfaces/formats/#tabseparated\">TabSeparated</a> format:</p>\n<div><pre><code><span>clickhouse<span>-</span>client <span>-</span>q \"INSERT INTO some_table FORMAT TabSeparated\" <span>&lt;</span> </span>\n<span>data.tsv</span></code></pre></div>\n<p>Explore more of ClickHouse's capabilities for working with the family of CSV formats in our docs, including <a target=\"_blank\" href=\"https://clickhouse.com/docs/en/integrations/data-formats/csv-tsv/#skipping-lines-in-a-csv-file\">rows skipping</a>, controlling <a target=\"_blank\" href=\"https://clickhouse.com/docs/en/integrations/data-formats/csv-tsv#treating-null-values-in-csv-files\">Null values</a>, <a target=\"_blank\" href=\"https://clickhouse.com/docs/en/integrations/data-formats/csv-tsv#working-with-large-csv-files\">automatic decompression</a>, and more.</p>\n<h3 id=\"json-data\"></h3>\n<p>ClickHouse can work with almost any JSON data, be that an array of values, an object of objects, or separate JSON objects.</p>\n<p>For example, a logging app can write logs as a JSON object per line (known as <a target=\"_blank\" href=\"http://ndjson.org/\">NDJson</a>). This case can be addressed using the <a target=\"_blank\" href=\"https://clickhouse.com/docs/en/interfaces/formats/#jsoneachrow\">JSONEachRow</a> format in ClickHouse:</p>\n<div><pre><code><span>clickhouse-client - q <span>\"INSERT INTO sometable FORMAT JSONEachRow\"</span> &lt; </span>\n<span>access.log</span></code></pre></div>\n<p>Explore how JSON data of different forms can be <a target=\"_blank\" href=\"https://clickhouse.com/docs/en/integrations/data-formats/json#importing-json-data\">loaded to ClickHouse</a> as well as <a target=\"_blank\" href=\"https://clickhouse.com/docs/en/integrations/data-formats/json#exporting-json-data\">exported</a>. It is worth mentioning that ClickHouse also supports the <a target=\"_blank\" href=\"https://clickhouse.com/docs/en/integrations/data-formats/json#importing-and-exporting-bson\">BSON format</a> used by MongoDB.</p>\n<h2 id=\"regular-expressions-for-custom-text-formats\"></h2>\n<p>Besides standard formats like CSV or JSON, ClickHouse also supports data import based on <a target=\"_blank\" href=\"https://clickhouse.com/docs/en/integrations/data-formats/templates-regexp#importing-data-based-on-regular-expressions\">regular expressions</a>. In this case, the <a target=\"_blank\" href=\"https://clickhouse.com/docs/en/interfaces/formats/#data-format-regexp\"><code>Regexp</code></a> format should be used together with the <code>format_regexp</code> option containing regular expression with capture groups (treated as table columns):</p>\n<div><pre><code><span><span>INSERT INTO</span> some_log <span>FROM</span> INFILE <span>'custom.txt'</span></span>\n<span>SETTINGS</span>\n<span>  format_regexp <span>=</span> <span>'([0-9]+?) \\[(.+?)\\] \\- \"(.+)\"'</span></span>\n<span>FORMAT Regexp</span></code></pre></div>\n<p>This query can be used to load the following example file:</p>\n<div><pre><code><span>121201 [notice] - \"Started service\"</span>\n<span>121202 [error] - \"Configuration file not found\"</span>\n<span>122203 [warning] - \"Creating default configuration file\"</span></code></pre></div>\n<p>Another option to process custom text formats is to use a <a target=\"_blank\" href=\"https://clickhouse.com/docs/en/integrations/data-formats/templates-regexp#importing-based-on-a-template\">Template format</a>. The Template format is even more powerful in terms of exporting data because it allows rendering query results into high-level formats, like <a target=\"_blank\" href=\"https://clickhouse.com/docs/en/integrations/data-formats/templates-regexp#exporting-to-html-files\">HTML</a>.</p>\n<h2 id=\"native-and-binary-formats\"></h2>\n<p>ClickHouse has its own <a target=\"_blank\" href=\"https://clickhouse.com/docs/en/integrations/data-formats/binary-native#exporting-in-a-native-clickhouse-format\">native format</a> that can be used to import and export data. It's more efficient than text formats regarding processing speed and space usage. The Native format is helpful for transferring data between ClickHouse servers when they don't have a direct connection with each other. For example, to transfer data from a ClickHouse server to ClickHouse Cloud:</p>\n<div><pre><code><span>clickhouse-client -q <span>\"SELECT * FROM some_table FORMAT Native\"</span> | \\</span>\n<span>clickhouse-client --host some.aws.clickhouse.cloud --secure \\</span>\n<span>--port 9440 --password 12345 \\</span>\n<span>-q <span>\"INSERT INTO some_table FORMAT Native\"</span></span></code></pre></div>\n<p><a target=\"_blank\" href=\"https://clickhouse.com/docs/en/integrations/data-formats/binary-native#exporting-to-rowbinary\">Binary formats</a> are usually more efficient and safe than text formats but are limited in support. ClickHouse has the RowBinary format for general binary cases, and RawBLOB is used with (but is not limited to) files. Additionally, ClickHouse supports popular serialization formats like <a target=\"_blank\" href=\"https://clickhouse.com/docs/en/integrations/data-formats/binary-native#protocol-buffers\">Protocol Buffers</a>, <a target=\"_blank\" href=\"https://clickhouse.com/docs/en/integrations/data-formats/binary-native#capn-proto\">Cap’n Proto</a> and <a target=\"_blank\" href=\"https://clickhouse.com/docs/en/integrations/data-formats/binary-native#messagepack\">Message Pack</a>.</p>\n<h2 id=\"parquet-and-other-apache-formats\"></h2>\n<p>Apache has multiple data storage and serialization formats that are popular in Hadoop environments. </span>\n<span>file.parquet</span></code></pre></div>\n<p>Find out more about other supported Apache formats, such as <a target=\"_blank\"
