By doing this, we can rely on the power of ClickHouse to crunch numbers quickly, and reduce or even totally avoid the amount of code that we need to write. This also means that we can work with smaller in memory datasets on the client side and avoid the need for distributed computation.</p>\n<p>A good example of this is forecasting. ClickHouse implements two machine learning functions - Stochastic Linear Regression (stochasticLinearRegression) which can be used for fitting the model, and a function (evalMLMethod) which can be used for subsequent inference directly within the database.</p>\n<p>Of course there are more sophisticated forecasting models and more flexibility once you break out of SQL into a fully-fledged programming language, but this technique certainly has it's uses and performs well in our demonstration scenario here.</p>\n<h2 id=\"dataset\"></h2>\n<p>To demonstrate, we are going to use a simple flight departure dataset which contains a monthly <a target=\"_blank\" href=\"https://clickhouse.com/resources/engineering/what-is-time-series-database\">time series</a> of the number of passengers departing from different airports using various airlines.</p>\n<p>Our aim will be to take this data and use it forecast the same data into the future.</p>\n<p>We will aim to build a model using data from 2008 to 2015, and then test the performance of the model between 2015 and 2018.
