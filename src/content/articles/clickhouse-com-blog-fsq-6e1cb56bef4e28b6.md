the structure is the same as in the source. Additionally, I've created two materialized columns, <code>mercator_x</code> and <code>mercator_y</code> that map the lat/lon coordinates to the <a target=\"_blank\" href=\"https://en.wikipedia.org/wiki/Web_Mercator_projection\">Web Mercator</a> projection. The coordinates on the Mercator projection are represented by two UInt32 numbers for easier segmentation of the map into tiles. Additionally, I set up the order of the table by a <a target=\"_blank\" href=\"https://en.wikipedia.org/wiki/Space-filling_curve\">space-filling curve</a> on top of these numbers, and I created two <code>minmax</code> indices for faster search. ClickHouse has everything we need for real-time mapping applications!</p>\n<p>Then, I loaded the data with the following query:</p>\n<div><pre><code><span>INSERT INTO foursquare_mercator SELECT * FROM s3('s3://fsq-os-places-us-east-1/release/dt=2025-04-08/places/parquet/*')</span></code></pre></div>\n<p>The whole dataset is loaded in <strong>42 seconds</strong> and takes <strong>11 GB</strong>.</p>\n<h2 id=\"visualization\"></h2>\n<p>I only <a target=\"_blank\" href=\"https://github.com/ClickHouse/adsb.exposed/compare/main...foursquare\">slightly modified</a> the <a target=\"_blank\" href=\"https://adsb.exposed/\">adsb.exposed</a> tool, with 48 lines consisted mostly by replacing a table name and adding new example queries.</p>\n<p>When I opened the page, I was amazed at how beautiful it was!</p>\n<p><span><img alt=\"Screenshot_20250506_025216.png\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2FScreenshot_20250506_025216_949653b810.png&w=2048&q=75\"></span></p>\n<p><span><img alt=\"Screenshot_20250506_230749.png\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2FScreenshot_20250506_230749_b4396c9cc5.png&w=2048&q=75\"></span></p>\n<p>And it gives a lot of interesting info.
