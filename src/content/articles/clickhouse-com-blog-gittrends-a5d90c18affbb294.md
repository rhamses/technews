contentHtml: "<article><div><p>GitHub generates a constant stream of issues, pull requests, and comments. Those are known as GitHub events. Over time, these billions of events capture the complete lifecycle of technology: how frameworks, libraries, and tools rise and fade. But capturing that immense data stream and turning it into a real-time trends analyzer is a challenge.</p>\n<p><strong>GitTrends</strong> make this possible. It is a new open-source demo application that works like a <strong>specialized Google Trends for the tech world</strong>, letting you search and compare any topic, technology, or keyword trends across <strong>over 10 billion GitHub events in real time</strong>.</p>\n<p>It is now available at <a target=\"_blank\" href=\"https://gittrends.clickhouse.com/\">https://gittrends.clickhouse.com</a></p>\n<blockquote>\n<p>GitTrends is a public demo built to showcase ClickHouse's full-text search capabilities. It is fully functional, but may be missing some features or have the occasional bug.</p>\n</blockquote>\n<h2 id=\"how-can-you-use-gittrends\"></h2>\n<p>Type a search term into GitTrends and instantly see how many times it was mentioned across issues, pull requests, and comments in every GitHub repository. This gives you an overview of a technology's popularity over time, the repositories driving the conversation, the developers most actively talking about it, and the actual issues and pull requests where the term appears.</p>\n<p><span><img alt=\"gittrend-1.png\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2Fgittrend_1_f90a94c48d.png&w=2048&q=75\"></span></p>\n<p>But GitTrends gets really interesting when you start comparing.</p>\n<h3 id=\"compare-tech-adoption\"></h3>\n<p>Search and compare mention trends for any keywords, exactly like Google Trends but built on the world's most relevant data source for open-source technology. Compare <code>ClickHouse vs Druid</code> to see how two analytics databases have traded momentum over time, or track <code>Claude vs OpenAI</code> to watch the AI landscape shift in real developer conversations.</p>\n<p><span><img alt=\"gittrends-21.png\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2Fgittrends_21_d1284e2bdc.png&w=2048&q=75\"></span></p>\n<h3 id=\"identify-ecosystems\"></h3>\n<p>Identify the top repositories driving the conversation around any topic. Is ClickHouse discussed mostly in its own ecosystem, or is it bleeding into data engineering and observability projects? Is OpenAI mentioned across a broad range of repos while Claude is concentrated in a handful?</p>\n<p>Knowing where a technology lives tells you as much as knowing how popular it is.</p>\n<p><span><img alt=\"gittrends-31.png\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2Fgittrends_31_cca45cbdc2.png&w=2048&q=75\"></span></p>\n<h3 id=\"drill-into-the-source\"></h3>\n<p>Move from a high-level trend to the actual conversations behind it. Select any repository and explore its underlying activity: the most active contributors, and the most mentioned issues and PRs driving the trend.</p>\n<p><span><img alt=\"gittrends-41.png\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2Fgittrends_41_81773597ae.png&w=2048&q=75\"></span></p>\n<h2 id=\"full-text-search-at-scale\"></h2>\n<p>GitTrends is built around a simple idea: search any term in real time, across nearly 10 billion GitHub events with no data transformation. Rather than querying pre-computed answers, you index the raw text and search it directly at query time. That's the all promise behind the <a target=\"_blank\" href=\"https://clickhouse.com/blog/full-text-search-ga-release\">new full-text search feature</a> recently released in ClickHouse. <a target=\"_blank\" href=\"https://clickhouse.com/docs/engines/table-engines/mergetree-family/textindexes\">Simply build a text index on a text column</a> and use full-text search.</p>\n<p>What makes ClickHouse particularly powerful here is that full-text Search and aggregation live in the same engine. A single query can search raw text and aggregate results in one pass, with no joins across systems, no data movement, and no latency penalty. That combination is what makes the experience feel instant rather than just fast.</p>\n<p>The GitHub events dataset, nearly 10 billion rows of issues, pull requests, and comments, is a deliberate stress test. GitTrends still delivers fast search across all of it.</p>\n<p>To highlight the performance of the new full-text search index, GitTrends includes a live query performance comparison. For any search, you can toggle between using full-text Search, bloom filter and a full table scan and watch the difference play out in real time.&#160;</p>\n<p>It is the clearest demonstration of what the right index buys you at scale.</p>\n<h2 id=\"look-under-the-hood\"></h2>\n<p>GitTrends is fully open and built to be explored at every layer.</p>\n<h3 id=\"how-is-the-data-ingested\"></h3>\n<p>We have been ingesting the GitHub events dataset for some time and exposing it in our SQL Playground so anyone can explore it with SQL. We also documented several example queries and analyses on this <a target=\"_blank\" href=\"https://clickhouse.com/demos/explore-github-with-clickhouse-powered-real-time-analytics\">page</a>.</p>\n<p>The ingestion script used to load the data into ClickHouse is available <a target=\"_blank\" href=\"https://github.com/ClickHouse/sql.clickhouse.com/blob/main/load_scripts/github_events/ingest.sh\">here</a>.</p>\n<p>Note that GitHub introduced changes to the Events API payloads starting in October 2025. As a result, certain fields differ from earlier data, which can affect analyses and make trend detection across the full history less accurate. More details are available in the GitHub <a target=\"_blank\" href=\"https://github.blog/changelog/2025-08-08-upcoming-changes-to-github-events-api-payloads/\">changelog</a>.</p>\n<h3 id=\"what-sql-query-is-running-behind-each-chart\"></h3>\n<p>Every chart in GitTrends is backed by a real query.
