contentHtml: "<div><p>At ClickHouse, we’re working toward <a target=\"_blank\" href=\"https://clickhouse.com/blog/agent-facing-analytics\">our vision of agentic analytics</a> and building the <a target=\"_blank\" href=\"https://clickhouse.com/ai\">Agentic Data Stack</a>. The <a target=\"_blank\" href=\"https://github.com/clickhouse/clickhouse-mcp\">ClickHouse MCP server</a> is a key part of that vision, and allows ClickHouse to be integrated with the latest and greatest developer tools to bring the fastest analytics experience wherever developers work.</p>\n<p>In this post, I’ll show you how to integrate the ClickHouse MCP server with Google <a target=\"_blank\" href=\"https://antigravity.google/\">Antigravity</a>, an agentic development platform</p>\n<h2 id=\"user-content-adding_the_clickhouse_mcp_server_to_antigravity\"></h2>\n<p><a target=\"_blank\" href=\"https://antigravity.google/docs/mcp#connecting-custom-mcp-servers\">Antigravity supports MCP out of the box</a>, so adding the ClickHouse MCP server is straightforward.</p>\n<p>Within the Antigravity editor, <a target=\"_blank\" href=\"https://antigravity.google/docs/mcp#how-to-connect\">open the MCP Store panel within the \"...\" dropdown at the top of the editor's side panel</a>. Select ClickHouse from the list of servers and click Install. You will be redirected via OAuth in your browser to the ClickHouse sign in page to authenticate the connection.</p>\n<p><span><img alt=\"antigravity_mcp_apr2026_image1.png\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2Fantigravity_mcp_apr2026_image1_d75a9c1887.png&w=2048&q=75\"></span></p>\n<p>Once connected, <strong>the Antigravity agent gains read-only access to your organizations, services, databases, and tables according to your account permissions</strong>, allowing it to perform high-speed analytical queries on your behalf.</p>\n<h2 id=\"user-content-automatic_discovery\"></h2>\n<p>Once the MCP connection is active and authenticated via OAuth the agent will now have the ability to call tools supplied by the ClickHouse MCP server when prompted, allowing it to begin discovering the location and format of your data automatically.</p>\n<p><span><img alt=\"\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2Fantigravity_mcp_apr2026_image4_6a8a38eb97.png&w=2048&q=75\"></span></p>\n<p>You can use prompts like \"What tables are available?\" or \"Show me the schema for the UK properties price table.\" and the agent will use tools like <code>get_services_list</code> and <code>list_tables</code> to orient and ground itself in your data structure.</p>\n<p>In this example, we’re working with our  <code>uk_prices_1</code> example dataset, which has millions of UK property transactions. The agent identifies the relevant columns (<code>price</code>, <code>town</code>, <code>district</code>, <code>date</code>) and prepares to help us find meaningful trends.</p>\n<p><span><img alt=\"\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2Fantigravity_mcp_apr2026_image5_406c3233d4.png&w=2048&q=75\"></span></p>\n<h2 id=\"user-content-analyse_data_in_natural_language\"></h2>\n<p>The ClickHouse MCP server allows you to use natural language to query your data. The agent will handle translating natural language into functional ClickHouse SQL.</p>\n<p>When prompted with something like \"Analyze property price trends in London over the last decade and compare them to the national average.\", Antigravity converts that prompt into the correct SQL statement and executes it using the <code>run_select_query</code> tool.</p>\n<p>Because ClickHouse is built for speed, results of queries are fast, and you can have real-time conversations with your data.</p>\n<h2 id=\"user-content-generating_antigravity_artifacts\"></h2>\n<p>You’re not limited to just text. Through Artifacts, Antigravity can also generate custom visualizations for your data.</p>\n<p>For example, when we asked for a visual breakdown of the data, the agent generated a React-based interactive chart as an Artifact. The integrated browser renders the Artifact, so we can review it without leaving the IDE.</p>\n<p>Antigravity goes a step further than just showing us the Artifact it created: it tests it too. The agent uses the browser to interact with the chart (for example, clicking on tabs) and uses screenshots and screen recordings to watch what happens and validate that the Artifact is displaying and behaving correctly.</p>\n<p><span><img alt=\"\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2Fantigravity_mcp_apr2026_image3_10410c758b.png&w=2048&q=75\"></span></p>\n<h2 id=\"user-content-interactive_iteration_on_artifacts\"></h2>\n<p>Data analysis is rarely a one-step process.</p>\n<p>After Antigravity generated a visualisation, we noticed a peak in the pricing chart and got curious - what caused this peak? Is the trend consistent across property types? Antigravity’s <strong>Comments on Artifacts</strong> feature allows us to drag a box over the peak, and ask our question with the visual context of the chart.</p>\n<p>The agent immediately saw the context of our comment, queried the ClickHouse database again, answered our question and updated the Artifact to include the new breakdown.</p>\n<p>For a data analysis workflow, being able to iterate an Artifact by visually interacting with it is a pretty big deal. This kind of iteration has traditionally meant JIRA tickets, hand-offs between data engineers and business analysts, and a bunch of screenshots.</p>\n<p><span><img alt=\"\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2Fantigravity_mcp_apr2026_image2_ce259cda3a.png&w=2048&q=75\"></span></p>\n<h2 id=\"user-content-conclusion\"></h2>\n<p>The ClickHouse MCP server makes it possible to integrate ClickHouse with AI-native IDEs like Google Antigravity. Antigravity brings innovative features like commenting on Artifacts that bring workflow improvements that developers and data analysts have been dreaming about for years. Together, ClickHouse and Antigravity provide a compelling example of the future of agentic analytics.</p>\n<p>Are you using ClickHouse with Google Antigravity? We’d love to hear about your use cases! <a target=\"_blank\" href=\"https://clickhouse.com/slack\">Come chat with us in our Slack community.</a></p></div>"
