contentHtml: "<div><p>We’re releasing the official <a target=\"_blank\" href=\"https://github.com/ClickHouse/agent-skills\">ClickHouse Agent Skills</a>: a set of open-source, packaged skills encoded with ClickHouse best practices learned by our engineers and community.</p>\n<p>These skills provide your AI assistant with 28 prioritized rules for schema design, query optimization, and data ingestion. It helps your agent go from a general-purpose LLM to a ClickHouse power user.</p>\n<p><a target=\"_blank\" href=\"https://github.com/ClickHouse/agent-skills\">The repo is open and Apache licensed for everyone to contribute to</a>, so if you've got some hard-won lessons about how to best use ClickHouse, we'd love for you to share.</p></div><div><h2 id=\"get-started\"></h2>\n<p>You can add these skills to your local environment in seconds:</p>\n<div><pre><code><span>npx skills add clickhouse/agent-skills</span></code></pre></div>\n<p>The CLI will detect which agentic interfaces you have installed and drop the instructions in the right place.</p>\n<p>Agents that support skills should start to use them automatically when appropriate, but you can also manually invoke them (for example, in Claude Code, you can use <code>/clickhouse-best-practices</code>).</p>\n<h2 id=\"why-we-built-this\"></h2>\n<p>LLMs are a great accelerator, and we believe that they are only going to become more common in developer workflows as we build towards <a target=\"_blank\" href=\"https://clickhouse.com/blog/agent-facing-analytics\">agentic analytics</a>. But, they don't (yet?) always get specialised systems like ClickHouse exactly right.</p>\n<p>We’ve seen some developers hit walls when LLMs make functional, but less-than-perfect, choices:</p>\n<ul>\n<li>Choosing the wrong ORDER BY or data types.</li>\n<li>Writing JOINs that don't scale or failing to batch inserts.</li>\n<li>Missing out on Materialized Views or specialized indexes.</li>\n</ul>\n<p>These choices can lead to friction later down the line when you reach production, or need to scale. We want to support developers using AI, and while our docs contain a wealth of information on how to do these things correctly, LLMs don’t always find the right information at the right time.</p>\n<h2 id=\"what-s-in-the-box\"></h2>\n<p>We’ve built these skills using the <a target=\"_blank\" href=\"https://agentskills.io/\">Agent Skills</a> specification recently released by Anthropic. It’s a lightweight, agent-agnostic format that allows us to encode deep domain knowledge into a format that LLMs can invoke when they actually need it.</p>\n<p>The initial release focuses on the high-impact best practices that are relevant to almost all ClickHouse users:</p>\n<ul>\n<li><strong>Schema design</strong>\n<ul>\n<li>Primary Key selection</li>\n<li>Data Types</li>\n</ul>\n</li>\n<li><strong>Query performance</strong>\n<ul>\n<li>JOIN optimization</li>\n<li>Mutation avoidance</li>\n</ul>\n</li>\n<li><strong>Data ingestion</strong>\n<ul>\n<li>Insert batching</li>\n<li>Async inserts</li>\n</ul>\n</li>\n<li><strong>Advanced tools</strong>\n<ul>\n<li>Materialized Views</li>\n<li>Partitioning strategies</li>\n</ul>\n</li>\n</ul>\n<h2 id=\"what-s-next\"></h2>\n<p>This is just the start. We’re going to keep expanding this with deeper knowledge on cluster configurations, engine-specific optimizations, complex data pipeline patterns, and more.</p>\n<p>Check out the <a target=\"_blank\" href=\"https://github.com/ClickHouse/agent-skills\">repo</a> and <a target=\"_blank\" href=\"https://clickhouse.com/slack\">join us in Slack</a> to let us know what rules we should add next.</p></div>"
