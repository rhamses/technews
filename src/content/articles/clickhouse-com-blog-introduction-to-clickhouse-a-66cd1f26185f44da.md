During this webinar, we presented the plugin's history and the reasons behind the design choices and plans for the future.</p>\n<p>Like any good webinar, however, we wanted to present a demo of the technology itself. Coincidentally, we were presenting that webinar exactly 10 years since the first Git commit to Grafana. Coupled with some recent frustration over limited GitHub analytics, we decided to present an analysis of the Grafana repository.</p>\n<p>In this blog post, we review our findings and hopefully give our readers the tools to reproduce the same work on their projects.</p>\n<h2 id=\"a-source-of-frustration\"></h2>\n<p>Whenever looking at a new GitHub project, as engineers, we often turn to GitHub analytics - officially known as Pulse. At this point, our frustration typically begins, and we’re presented with some pretty underwhelming analytics.</p>\n<p><span><img alt=\"github_analytics_1.png\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2Fgithub_analytics_1_c6ebb0cf85.png&w=2048&q=75\"></span>\n<span><img alt=\"github_analytics_2.png\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2Fgithub_analytics_2_a148685719.png&w=2048&q=75\"></span></p>\n<p>Given the importance of the date, with it being 10 years since the first commit, we decided to see if we could do better. What better tools to solve the task than the world’s leading OSS OLAP database and data visualization tool?!</p>\n<h2 id=\"finding-the-data\"></h2>\n<p>For any good analysis, we need good data. Fortunately for us, the data we need is either public or can be generated.</p>\n<p>GitHub publishes the full event history of all public repositories through a wonderful project <a target=\"_blank\" href=\"https://www.gharchive.org/\">GH Archive</a>. This represents a fairly small dataset for ClickHouse, and we’ve already documented <a target=\"_blank\" href=\"https://ghe.clickhouse.tech/#how-this-dataset-is-created\">thoroughly how to load and analyze this</a>. With all pull requests, issues, stars, forks, watches &amp; comments for every repository on GitHub since the beginning of 2011, and over 5.5 billion events, it provides an excellent “background” dataset for our analysis. Note that this dataset is also available in <a target=\"_blank\" href=\"https://sql.clickhouse.com/?query_id=JAUTYJJXBOSATPJD9B624X\">play.clickhouse.com</a> for you to query for free. Alternatively, <a target=\"_blank\" href=\"https://ghe.clickhouse.tech/#download-the-dataset\">load this dataset </a>into ClickHouse yourself.</p>\n<p>While the above dataset provides us with an overview of GitHub Projects, it doesn’t provide commit histories. Admittedly, this would be a much larger dataset. However, using the <a target=\"_blank\" href=\"https://clickhouse.com/docs/en/getting-started/example-datasets/github#generating-the-data\">git-import </a>tool distributed with ClickHouse, we can easily generate the full commit history of a repository with a single command. This produces three files of increasing granularity: a file with a row for every commit, a file with a row per file change, and finally, a line-by-line change history.  We had already used this same tool to do an analysis on our own ClickHouse repository and documented the steps <a target=\"_blank\" href=\"https://clickhouse.com/docs/en/getting-started/example-datasets/github#downloading-and-inserting-the-data\">here</a>.</p>\n<p>While all of the datasets used in our demo are public and can be downloaded or generated, we’ve also assembled <a target=\"_blank\" href=\"https://gist.github.com/gingerwizard/1c03af6be54b56fe0f11871278555cfd\">some simple instructions</a> to make reproducing this demo a little easier. Our dashboard is also available in <a target=\"_blank\" href=\"https://grafana.com/grafana/dashboards/18065\">Grafana’s public catalog</a>.</p>\n<h2 id=\"building-the-visualizations\"></h2>\n<p>Armed with both datasets, building visualizations became straightforward. Our final dashboard aimed to use both datasets, with a list of possible questions already documented - <a target=\"_blank\" href=\"https://ghe.clickhouse.tech/#let-s-play-with-the-data\">here</a> and <a target=\"_blank\" href=\"https://clickhouse.com/docs/en/getting-started/example-datasets/github#queries\">here</a>. This left us simply needing to select those questions of interest and use the appropriate Grafana syntax to ensure time filters were respected before choosing a visualization. In the spirit of OSS, we also explored some of Grafana’s community visualizations, such as the <a target=\"_blank\" href=\"https://grafana.com/grafana/plugins/marcusolsson-treemap-panel/\">Treemap</a> and <a target=\"_blank\" href=\"https://grafana.com/grafana/plugins/magnesium-wordcloud-panel/\">Word Cloud</a> plugins. To visualize committers over time, for example, we simply need to inject the variables <code>$__timeFilter(time)</code> and <code>$__timeInterval(time)</code> to ensure the time filter is applied and the bucket sizes are appropriate. For us, we’re impressed that Grafana founder <a target=\"_blank\" href=\"https://github.com/torkelo\">Torkel</a> remains such an instrumental committer today as when the project was founded. Having spent a good part of the first 5yrs rewriting each other's code, <a target=\"_blank\" href=\"https://github.com/bergquist\">Carl Bergquist</a> and Torkel have clearly had a huge impact on what is a thriving community today. While the number of commits per day has steadily increased, what is apparent is the amount of work done by commits has increased dramatically. Key features such as alerting being added and a docker file being made available are by far the most popular issues. Finally, we were happy to see people committing to both repositories while noticing that community members starring both repositories (now over 6500) star Grafana first!
