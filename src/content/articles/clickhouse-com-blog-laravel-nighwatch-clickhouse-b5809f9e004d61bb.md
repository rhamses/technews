For Nightwatch's launch, Laravel anticipated instant adoption from its global community, with tens of thousands of applications sending events around the clock from day one.</p>\n<p>Laravel Nightwatch needed an architecture that could:</p>\n<ul>\n<li>Ingest millions of JSON events per second from customer applications reliably.</li>\n<li>Provide sub-second analytical queries for real-time dashboards.</li>\n<li>Scale horizontally to handle unpredictable traffic spikes.</li>\n<li>Deliver all of this in a cost-effective, low-maintenance manner.</li>\n</ul>\n<p>The challenge was to process data on a global scale and provide deep insights into application health without compromising on a straightforward setup experience for developers.</p>\n<h2 id=\"the-solution-a-decoupled-streaming-and-analytics-pipeline\"></h2>\n<p><span><img alt=\"blog-laravel-1.png\" src=\"https://aws.amazon.com/_next/image?url=%2Fuploads%2Fblog_laravel_1_2b8e4a05cc.png&w=2048&q=75\"></span></p>\n<p>Laravel Nightwatch implemented a dual-database,&#160;streaming-first architecture, shown in the preceding figure, that separates transactional and analytical workloads.</p>\n<ul>\n<li><strong>Transactional workloads</strong>&#160;–  user accounts, organization settings, billing, and similar workloads run on<a target=\"_blank\" href=\"https://aws.amazon.com/rds/\">&#160;Amazon RDS</a>&#160;for PostgreSQL.</li>\n<li><strong>Analytical workloads</strong>&#160;– telemetry events, metrics, query logs, and request traces are handled by ClickHouse Cloud.</li>\n</ul>\n<h3 id=\"key-components\"></h3>\n<p>The key components of the solution include the following:</p>\n<ol>\n<li><strong>Ingestion layer</strong>\n<ul>\n<li><a target=\"_blank\" href=\"https://aws.amazon.com/gateway\">Amazon API Gateway</a>&#160;receives telemetry from Laravel agents embedded in customer applications</li>\n<li><strong>Lambda</strong>&#160;validates and enriches events. Validated and enriched events are published to Amazon MSK, partitioned for scalability</li>\n</ul>\n</li>\n<li><strong>Streaming to analytics</strong>\n<ul>\n<li><a target=\"_blank\" href=\"https://clickhouse.com/cloud/clickpipes\">ClickPipes</a>&#160;in ClickHouse Cloud subscribe directly to MSK topics, reducing the need to build and manage extract, transform, and load (ETL) pipelines</li>\n<li>Materialized views in ClickHouse pre-aggregate and transform raw JSON into query-ready formats</li>\n</ul>\n</li>\n<li><strong>Dashboards and delivery</strong>\n<ul>\n<li>The Nightwatch dashboard, built with Laravel, Inertia, and React, runs on<a target=\"_blank\" href=\"https://docs.aws.amazon.com/AmazonECS/latest/developerguide/AWS_Fargate.html\">&#160;AWS Fargate for Amazon ECS</a></li>\n<li><a target=\"_blank\" href=\"https://aws.amazon.com/elasticache/redis/\">Amazon ElastiCache for Redis</a>&#160;accelerates session and cache lookups</li>\n<li>Cloudflare CDN provides low-latency delivery to global users</li>\n</ul>\n</li>\n</ol>\n<h2 id=\"why-amazon-msk-and-clickhouse-cloud\"></h2>\n<p>Nightwatch requires a durable, horizontally scalable, and low maintenance streaming backbone.</p>\n<p>With&#160;<a target=\"_blank\" href=\"https://docs.aws.amazon.com/msk/latest/developerguide/msk-broker-types-express.html\">Amazon MSK Express brokers</a>, we have achieved over 1 million events per second during load testing, benefiting from low-latency, elastic scaling, and simplified operations. MSK Express brokers require no storage sizing or provisioning, scale up to 20 times faster, and recover 90% quicker than standard Apache Kafka brokers—all while enforcing best-practice defaults and client quotas for reliable performance. Its seamless integration with other AWS services—such as Lambda,&#160;<a target=\"_blank\" href=\"https://aws.amazon.com/s3/\">Amazon Simple Storage Service (Amazon S3)</a>, and&#160;<a target=\"_blank\" href=\"https://aws.amazon.com/cloudwatch\">Amazon CloudWatch</a>—made it straightforward to build a resilient, end-to-end streaming architecture.</p>\n<p>To ingest and transform these events in real time, Nightwatch uses ClickHouse Cloud and its managed integration platform,&#160;<a target=\"_blank\" href=\"https://clickhouse.com/docs/integrations/clickpipes\">ClickPipes</a>. ClickHouse Cloud excels at analytical workloads by delivering up to 100 times faster query performance for analytics compared to traditional row-based databases. Its advanced compression algorithms provide up to 90% storage savings, significantly reducing infrastructure costs while maintaining high performance. With its columnar architecture and optimized execution engine, ClickHouse Cloud can query billions of rows in under 1 second, enabling Laravel Nightwatch to serve real-time dashboards and analytics at global scale.</p>\n<p>By integrating Amazon MSK and ClickHouse using ClickPipes, Laravel also reduced the operational burden of building and managing ETL pipelines, reducing latency and complexity.</p>\n<h2 id=\"overcoming-challenges\"></h2>\n<h3 id=\"testing-complexity\"></h3>\n<p>While synthetic benchmarking and test datasets yield useful results, a more realistic workload is required to rigorously test infrastructure and code before deployment to production.
