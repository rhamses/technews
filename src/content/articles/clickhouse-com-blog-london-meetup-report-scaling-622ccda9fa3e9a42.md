contentHtml: "<article><div>\n<p>On May 25th, 2023, at the ClickHouse meetup in London, Tim Glaser, co-founder and CTO of <a target=\"_blank\" href=\"https://posthog.com/\">PostHog</a>, introduced their new project <a target=\"_blank\" href=\"https://posthog.com/blog/introducing-housewatch\">HouseWatch</a> - an open-source suite of tools for monitoring and managing ClickHouse. During the presentation he also shared insights into PostHog's handling of huge amounts of analytics queries and their strategies for scaling, optimization, and administration.</p>\n<p>PostHog is an open-source solution that combines multiple analytics tools into one platform. It enables users to perform complex funnel queries, visualize trends, and filter product analytics data, providing valuable insights into user behavior.</p>\n<p>PostHog boasts a vibrant developer community with more than 10,000 GitHub stars. It has tracked over 50 billion events, primarily on their US cloud, and manages an impressive volume of data. Their events table alone handles around 62 terabytes of uncompressed data for just one column. The total volume of uncompressed data being queried is in the range of a couple of hundred terabytes.</p>\n<h2 id=\"features-of-posthog-session-replay-feature-flags-and-seamless-data-integration\"></h2>\n<p>PostHog offers several distinct features that simplify operations and provide key insights. With session replay, users can watch real-time interactions on their websites for deep analysis. Feature flags allow specific user groups to experience new features, aiding data-driven product decisions. Additionally, PostHog's advanced event pipeline supports seamless data transfer to different systems, integrating generated insights effectively.</p>\n<p><span><img alt=\"posthog_1.png\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2Fposthog_1_bce1040450.png&w=2048&q=75\"></span></p>\n<h2 id=\"enhanced-scalability-with-clickhouse\"></h2>\n<p>PostHog successfully scaled their platform by <a target=\"_blank\" href=\"https://posthog.com/blog/how-we-turned-clickhouse-into-our-eventmansion\">transitioning from Postgres to ClickHouse</a> and leveraging AWS servers, effectively catering to their growing usage needs. PostHog tackled slow queries and user data aggregation issues by introducing strategic optimizations.</p>\n<h3 id=\"challenge-1-optimizing-json-field-reading\"></h3>\n<p>One significant challenge encountered by PostHog was the performance impact of reading from JSON fields. Although ClickHouse handles this efficiently, queries involving billions of events for their largest customers became slow. To address this, PostHog introduced a <a target=\"_blank\" href=\"https://posthog.com/blog/clickhouse-materialized-columns\">materialized column to the events table</a>, identifying the most frequently used columns and materializing them. This optimization dramatically improved query performance and reduced processing time.</p>\n<p><span><img alt=\"posthog_2.png\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2Fposthog_2_b0575d359b.png&w=2048&q=75\"></span></p>\n<h3 id=\"challenge-2-aggregating-by-unique-users\"></h3>\n<p>PostHog faced a complex problem when it came to aggregating data by unique users. Due to mutable user IDs and the need to merge user data from different sources, traditional approaches proved inefficient. To overcome this challenge, PostHog implemented a pattern based on a person override table. Instead of modifying the event data directly, they store old and new person IDs along with versions in a separate table. This approach allows for efficient querying and aggregation by incorporating the correct person IDs when needed. More specifically,</p>\n<ol>\n<li>A \"person overrides\" table was created: This table is separate from the main event table. It stores the old person ID, the new person ID, and a version identifier (to know what the latest is).</li>\n<li>The person ID ingested with events is the one that is believed to be correct: This is correct in about 96% of cases. But if a merge happens (for instance, when someone logs in or when an anonymous user becomes a logged-in user), a row is added to the person overrides table.</li>\n<li>The person overrides table is used in queries: When running a query, they join in the person overrides table and use either the overridden person ID or the original person ID that was on the event.</li>\n<li>They periodically update the person IDs based on the override table: To prevent the person override table from becoming too large, they run a job that updates the person IDs based on the override table, rolling up all changes and maintaining fast query performance.</li>\n</ol>\n<p><span><img alt=\"posthog_3.png\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2Fposthog_3_d20847a2c5.png&w=2048&q=75\"></span></p>\n<p>The optimizations made by PostHog had a dramatic effect on performance. As Tim Glaser highlighted, \"Y Combinator's queries went from 18 seconds down to one second on average, and P95 queries went from 60 seconds to four seconds.\" This improvement in performance allows for more efficient data analysis, leading to faster insights and better decision-making.</p>\n<h3 id=\"additional-optimization-sampling-for-improved-performance\"></h3>\n<p>PostHog recognized the value of providing users with control over query performance. To address this, they introduced a sampling feature, allowing users to trade off accuracy for speed. By offering a button to adjust the sampling rate, users can expedite query execution and obtain quick results, especially during high-demand or overwhelming situations.</p>\n<h2 id=\"introducing-housewatch---streamlining-clickhouse-administration\"></h2>\n<p>PostHog launched <a target=\"_blank\" href=\"https://posthog.com/blog/introducing-housewatch\">HouseWatch</a>, a react app deployable via Docker, to provide enhanced visibility and control over ClickHouse infrastructures. This tool simplifies ClickHouse administration by offering extensive query monitoring and operations management features.</p>\n<p>HouseWatch enables real-time query monitoring, providing essential performance metrics. Users can quickly assess query performance and identify potential bottlenecks, improving their decision-making process.</p>\n<h3 id=\"monitoring-long-running-queries\"></h3>\n<p>HouseWatch enables users to identify and monitor long-running queries with ease. The tool offers a clear view of the top 10 queries with extended execution times. Users can quickly pinpoint the specific teams or parameters associated with these queries, allowing for focused optimization efforts and improved overall query performance.</p>\n<h3 id=\"schema-stats-and-disk-usage-analysis\"></h3>\n<p>With HouseWatch, users gain access to valuable schema statistics. The tool provides an overview of the largest tables within ClickHouse, facilitating efficient disk usage analysis. By drilling down into individual tables, users can identify the largest columns and take proactive measures to optimize storage and enhance performance.</p>\n<h3 id=\"simplified-operations-and-query-control\"></h3>\n<p>HouseWatch streamlines ClickHouse operations by providing essential management features. Users can terminate running queries seamlessly, eliminating the need for manual intervention. Additionally, HouseWatch includes a migration management system that allows users to create forwards and backward migrations, simplifying database schema updates and ensuring a seamless operational workflow.</p>\n<p><span><img alt=\"posthog_4.png\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2Fposthog_4_6be1ed1bad.png&w=2048&q=75\"></span></p>\n<p>PostHog's open-source product provides users with powerful tools for product analytics, session replay, feature flags, and experimentation. With optimizations and innovations like materialized columns and the person overrides table, PostHog has significantly improved query performance. The introduction of HouseWatch helps streamline ClickHouse administration, offering valuable insights, query control, and simplified operations. As Tim states, \"We're committed to revolutionizing data management and delivering exceptional value to ClickHouse users.\"</p>\n<h3 id=\"more-details\"></h3>\n<ul>\n<li>This talk was given at the <a target=\"_blank\" href=\"https://www.meetup.com/clickhouse-london-user-group/events/292892824/\">ClickHouse Meetup in London</a> on May 25, 2023</li>\n<li>The presentation materials are available <a target=\"_blank\" href=\"https://github.com/ClickHouse/clickhouse-presentations/blob/master/meetup75/Serving%205m%20analytics%20queries%20a%20month%20with%20ClickHouse%20-%20PostHog.pdf\">on GitHub</a></li>\n</ul></div></article>"
