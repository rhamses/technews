Suppose want to see the number of jobs queued or waiting over the last 10 days. If using ClickHouse Cloud you can even visualize the results of this query with SQL console:</p>\n<pre><p>\nSELECT\n    uniq(id) as num_jobs,\n    toStartOfHour(started_at) as hour\nFROM default.workflow_jobs\nWHERE has(labels, 'self-hosted') AND status IN ('in_progress', 'waiting')\n    AND started_at &gt; now() - INTERVAL 10 DAY\nGROUP BY hour\nORDER BY hour ASC\n</p>\n</pre>\n<p><a target=\"_blank\" href=\"https://clickhouse.com/uploads/jobs_queued_or_waiting_744bce346a.png\">\n<span><img alt=\"jobs_queued_or_waiting.png\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2Fjobs_queued_or_waiting_744bce346a.png&w=2048&q=75\"></span>\n</a></p><p>A more interesting query might be to show the total time jobs spend in the queue by the time of day. Here we include the average, max and 90th percentile:</p>\n<pre><p>\nSELECT max(time_spent) as max_time_spent, avg(time_spent) as avg_time_spent, quantile(0.9)(time_spent) as 90th_percentile, toStartOfHour(start_time) as hour FROM (\n    SELECT\n        max(workflow_jobs.completed_at) - min(workflow_jobs.started_at) as time_spent,\n        argMax(status,updated_at) as last_event,\n        id,\n        min(started_at) as start_time\n    FROM default.workflow_jobs\n    WHERE has(labels, 'self-hosted')\n        AND started_at &gt; now() - INTERVAL 10 DAY\n    GROUP BY id HAVING last_event = 'completed'\n) GROUP BY hour ORDER BY hour ASC\n</p>\n</pre>\n<p><a target=\"_blank\" href=\"https://clickhouse.com/uploads/time_in_queue_6571bb664d.png\">\n<span><img alt=\"time_in_queue.png\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2Ftime_in_queue_6571bb664d.png&w=2048&q=75\"></span>\n</a></p><p>Finally, with a little more complexity we can see the current ClickHouse queue size for self-managed GitHub Runners:</p>\n<pre><p>\nSELECT\n    last_status,\n    count() AS queue,\n    labels\nFROM\n(\n    SELECT\n        argMax(status, updated_at) AS last_status,\n        labels,\n        id,\n        html_url\n    FROM default.workflow_jobs\n    WHERE has(labels, 'self-hosted') AND (started_at &gt; (now() - toIntervalDay(2)))\n    GROUP BY ALL\n    HAVING last_status != 'completed'\n)\nGROUP BY ALL\nORDER BY\n    labels ASC,\n    last_status ASC\n</p>\n</pre>\n<p>The result will look like the following:</p>\n<p><span><img alt=\"play.png\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2Fplay_ea08eee183.png&w=2048&q=75\"></span></p>\n<h2 id=\"summary\"></h2>\n<p>In this post, we've shown how you can use ClickHouse and GitHub Webhooks to monitor the queues for the jobs of your GitHub Actions.</p></div></article>"
