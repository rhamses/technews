And tongue in cheek, just a little bit.</p>\n<p>If there is one new feature in ClickHouse 22.8 that you absolutely must try it’s the new DELETE query. Up to now, the only way to delete specific rows in ClickHouse was to use an <code>ALTER TABLE table DELETE WHERE cond</code> statement. It would asynchronously rewrite all data files containing rows matching the condition. Since data files in ClickHouse can by default be up to 150 GB this was very expensive and could lead to significant CPU and memory usage.</p>\n<p>The new DELETE query takes a different approach. Instead of physically deleting all data immediately it only marks the specified rows as deleted using a hidden column. The data is still there, but it is transparently filtered out of queries. Effectively, all queries are executed with an additional condition <code>WHERE _deleted = false</code>. Later, as ClickHouse merges files in the background it will drop any rows marked as deleted during the merge process.</p>\n<p>Let’s see how useful the new DELETE query can be.</p>\n<p>Just for fun, let’s create a table with a portfolio of stablecoins (cost is cost of purchase per coin on January 1, 2022, price is the value on 26 August 2022):</p>\n<div><pre><code><span><span>CREATE TABLE</span> mymoney engine <span>=</span> MergeTree <span>ORDER</span> <span>BY</span> coin <span>AS</span></span>\n<span><span>SELECT</span> <span>'USDC'</span> <span>AS</span> coin, <span>1000</span> <span>AS</span> amount, <span>1.0002</span> <span>AS</span> cost, <span>0.9999</span> <span>AS</span> price</span>\n<span><span>UNION</span> <span>ALL</span> <span>SELECT</span> <span>'USDT'</span>, <span>1000</span>, <span>1.0001</span>, <span>1.00</span></span>\n<span><span>UNION</span> <span>ALL</span> <span>SELECT</span> <span>'USTC'</span>, <span>1000</span>, <span>1.00</span>, <span>0.0275</span></span></code></pre></div>\n<p>And let’s calculate our portfolio return:</p>\n<div><pre><code><span>SELECT sum(amount * cost) cost, sum(amount * price) value,</span>\n<span>value - cost gain_loss, 1 - value / cost pct  FROM mymoney</span></code></pre></div>\n<p>We lost 32% of our money! What happened? Turns out TerraUSD (USTC) was not such a <a target=\"_blank\" href=\"https://www.investopedia.com/terrausd-crash-shows-risks-of-algorithmic-stablecoins-5272010\">“stable” stablecoin after all</a>.</p>\n<p>But no matter, the DELETE query will take care of this:</p>\n<div><pre><code><span><span>SET</span> allow_experimental_lightweight_delete <span>=</span> <span>1</span></span>\n<span><span>DELETE</span> <span>FROM</span> mymoney <span>WHERE</span> coin <span>=</span> <span>'USTC'</span></span></code></pre></div>\n<p>And now our portfolio return looks much better.
