contentHtml: "<article><div><p>We’re excited to announce that ClickHouse is now available as an official data source for Microsoft Power BI. Power BI is one of the leading business intelligence platforms in the world, and our users frequently ask how they can leverage it with ClickHouse.</p>\n<p>Working closely with Microsoft, the ClickHouse team built the Power BI Connector to make it easy for you to query the data in your ClickHouse instances, regardless of whether you use ClickHouse Cloud or self-manage your own instances.</p>\n<h2 id=\"clickhouse-connector-availability\"></h2>\n<p>As the de facto data visualization software for Microsoft users, our Power BI connector makes it super easy to create interactive dashboards and charts based on the data housed in ClickHouse. There are several flavors of Power BI that you can use to visualize your data:</p>\n<ul>\n<li>Power BI Desktop: a Windows desktop application</li>\n<li>Power BI Service: available within Azure as a SaaS</li>\n<li>Power BI Mobile: available on Windows, iOS and Android devices</li>\n</ul>\n<p><span><img alt=\"powerbi-1.png\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2Fpowerbi_1_1a9ef7d4f3.png&w=2048&q=75\"></span></p>\n<h2 id=\"ready-to-get-started\"></h2>\n<p>Before you can use the ClickHouse Power BI connector, you need to make sure you have the ClickHouse ODBC driver installed. You can get the latest version from the <a target=\"_blank\" href=\"https://github.com/ClickHouse/clickhouse-odbc\">official GitHub repository</a> and run the <code>.msi</code> installer. For more information on how to verify the installation, view our <a target=\"_blank\" href=\"https://clickhouse.com/docs/en/integrations/powerbi\">Power BI documentation</a>.</p>\n<p>Once the ODBC driver has been installed, you can now use the <code>Get Data</code> menu item, search for <code>ClickHouse,</code> and the connector will be installed to your Desktop application.</p>\n<p><span><img alt=\"powerbi-2.png\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2Fpowerbi_2_ee198c1b1d.png&w=2048&q=75\"></span></p>\n<p>Note: you will be prompted to enter your connection details, which you can do on the left-hand side in the ClickHouse Cloud UI. You’ll need to copy the following information:</p>\n<ul>\n<li>Host</li>\n<li>Port</li>\n<li>Database name</li>\n<li>Database username</li>\n<li>Password</li>\n</ul>\n<p><span><img alt=\"powerbi-3.png\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2Fpowerbi_3_837ce57201.png&w=2048&q=75\"></span></p>\n<p>We recommend using DirectQuery. This will enable you to query ClickHouse instead of import mode which will load the entire dataset into your application.</p>\n<p>To use Microsoft’s Power BI Service, you’ll need to create your report in Power BI Desktop and publish the report.</p>\n<h2 id=\"get-in-touch\"></h2>\n<p>We’re excited to hear what dashboards and visualizations you’ll be creating with Power BI. If you have any questions or want to provide future enhancement requests, please feel free to <a target=\"_blank\" href=\"https://github.com/ClickHouse/power-bi-clickhouse/issues/new/choose\">raise an issue on GitHub</a>.</p></div></article>"
