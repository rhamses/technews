contentHtml: "<div><h2 id=\"introduction\"></h2>\n<p>Building on the success of <a target=\"_blank\" href=\"https://clickhouse.com/blog/clickpipes-is-generally-available\">ClickPipes for Kafka</a>, we're thrilled to announce the expansion of our connectivity platform with new connectors for Amazon S3 and Google Cloud Storage (GCS), currently in beta.</p>\n<p><span><img alt=\"1.png\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2F1_19f50881f7.png&w=2048&q=75\"></span></p>\n<h2 id=\"large-bulk-data-loading\"></h2>\n<p>Loading billions (or <a target=\"_blank\" href=\"https://clickhouse.com/blog/clickhouse-1-trillion-row-challenge\">trillions</a>!) of rows from scratch into a ClickHouse service can pose certain challenges due to the time-consuming nature of the task. The longer the process takes, the greater the risk of encountering transient issues such as network glitches that could halt or disrupt the data loading. An interruption can also lead to leaving the destination tables in a partial state that can be tricky to recover from. The new ClickPipes object storage connectors for Amazon S3 and Google Cloud Storage (GCS) were designed to tackle these obstacles and ensure a smooth data loading process without interruptions, no matter how much data is ingested.</p>\n<p>The key behind the resiliency of these data loading tasks resides in the smart and efficient use of the ClickHouse destination service ingest capabilities, a tailored orchestration leveraging temporary staging tables that offer atomic units of data management for repeatability, a custom <a target=\"_blank\" href=\"https://clickhouse.com/docs/en/engines/table-engines/special/keeper-map\">KeeperMap</a> state that allow to track the progress and pause/resume the task, and the resilient ClickPipes underlying infrastructure. If you are curious, you can learn more about the core logic behind the feature in our post about <a target=\"_blank\" href=\"https://clickhouse.com/blog/supercharge-your-clickhouse-data-loads-part3#the-core-approach\">ClickLoad</a>, an open-source python script implementing a similar orchestration approach.</p>\n<p><span><img alt=\"2.png\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2F2_5647202141.png&w=2048&q=75\"></span></p>\n<h2 id=\"continuous-loading\"></h2>\n<p>In the beta phase, the ClickPipes connectors for S3 and GCS will offer the capability of bulk data loading. An ingest task will load all the files matched by a <a target=\"_blank\" href=\"https://clickhouse.com/docs/en/integrations/clickpipes#s3--gcs-clickpipe-limations\">pattern</a> from a specific remote bucket into the ClickHouse destination table. Note that ClickPipes will skip files larger than 1 GB for efficiency reasons, we recommend splitting larger files into 1 GB chunks.</p>\n<p><span><img alt=\"s3_CP.gif\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2Fs3_CP_ad92afc7ab.gif&w=2048&q=75\"></span></p>\n<p>Once all the data is successfully inserted in the destination table, the ClickPipe object storage connector will reach a “completed” state. In the GA release, we will enable the “continuous mode,” where the ClickPipes job will be running constantly, ingesting matching files that get added into the remote object storage bucket as they arrive. This will allow users to turn any object storage bucket into into a fully fledged staging area for ingesting data into ClickHouse Cloud.</p>\n<p><span><img alt=\"4.png\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2F4_7b53b840b3.png&w=2048&q=75\"></span></p>\n<p><span><img alt=\"5.png\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2F5_8095c9bfd9.png&w=2048&q=75\"></span></p>\n<h2 id=\"supported-formats-and-authentication\"></h2>\n<p>In this beta release, the object storage connectors support JSON, CSV, TSV, and Parquet formats (as well as their compressed counterparts). For authentication methods, ClickPipes supports public object storage buckets and private buckets with credentials-based authentication (AWS Access Key ID and Secret or Google HMAC keys). IAM role-based authentication is also available for Amazon S3 buckets.</p>\n<h2 id=\"give-it-a-spin-today\"></h2>\n<p>Starting today, you can access the new object storage beta connectors in your ClickPipes menu (under Data Sources &gt; ClickPipes). You can use it with your own S3 bucket or use the following test file hosted on our public bucket for a quick test (69 MB):</p>\n<div><pre><code><span>https://datasets-documentation.s3.eu-west-3.amazonaws.com/github/github-2022-flat.ndjson.gz</span></code></pre></div>\n<p><span><img alt=\"6.png\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2F6_07d27aaf60.png&w=2048&q=75\"></span></p>\n<p>The documentation and more details about how to get started can be found <a target=\"_blank\" href=\"https://clickhouse.com/docs/en/integrations/clickpipes\">here</a>.
