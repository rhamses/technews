It’s one of those standard tools you must know when you investigate problems using System, Application, or Security logs. Less well-known is that over the years, the classic model (EVT format) has evolved to a rich ‘winevtlog.h’ (EVTX format) that now has full API support with many advanced improvements. This provides support for application and service-specific log channels used by tools like ‘Sysmon’.</p>\n<p>Fluent Bit is a data collector that supports this format and can help us collect helpful logs to analyze and identify potential threats.</p>\n<h2 id=\"detecting-security-threats-with-sysmon-events\"></h2>\n<p>Besides the rich audit policies, most Security Engineers prefer using Sysmon to identify threats. <a target=\"_blank\" href=\"https://learn.microsoft.com/en-us/sysinternals/downloads/sysmon\">Sysmon</a>, developed by <a target=\"_blank\" href=\"https://learn.microsoft.com/en-us/sysinternals/\">SysInternals</a> (which is now part of Microsoft), delivers advanced kernel capabilities provided by a device driver and a running service. Once installed with a given configuration, it will start monitoring and logging system activities, such as process creation, network connections, registry manipulation, and more. Since it smoothly integrates as a Windows Event Log channel, we can easily transport these logs with Fluent Bit into ClickHouse.</p>\n<p>The most recent version can be downloaded <a target=\"_blank\" href=\"https://download.sysinternals.com/files/Sysmon.zip\">here</a>. Just extract the ZIP file in a directory, such as ‘<em>C:\\Tools\\Sysmon</em>’.</p>\n<p>After extraction, you can start the installation with default configuration settings.</p>\n<div><pre><code><span>sysmon.exe <span>-accepteula</span> <span>-i</span></span></code></pre></div>\n<h3 id=\"communities-bring-open-source-together\"></h3>\n<p>The default Sysmon configuration can be considered a foundation. Luckily for us, the community member and Security Expert ‘SwiftOnSecurity’ (Oh my god, not Taylor Swift ;) ) maintains a high-quality event tracing configuration that aligns with the <a target=\"_blank\" href=\"https://attack.mitre.org/\">MITRE ATT&amp;CK® matrix</a> techniques. Installation is easy - just download the latest release from <a target=\"_blank\" href=\"https://github.com/SwiftOnSecurity/sysmon-config\">github</a> and apply the configuration.</p>\n<div><pre><code><span>sysmon.exe <span>-c</span> sysmonconfig<span>-export</span>.xml</span></code></pre></div>\n<h2 id=\"collect-process-and-insert-with-fluent-bit\"></h2>\n<p>Awesome, we have everything set to collect, process, and distribute with Fluent Bit. Fluent Bit is a CNCF-Graduated project and a great lightweight tool based on a simple configuration file that easily helps us set up a data pipeline for processing all generated events. In this scenario, we will choose to set up Fluent Bit with a ZIP package, but we could also decide to use an installer or container image.</p>\n<p>Start with downloading the correct installation package, such as the <a target=\"_blank\" href=\"https://fluentbit.io/releases/2.0/fluent-bit-2.0.6-win64.zip\">released ZIP package</a>, and extract the archive.</p>\n<div><pre><code><span><span>Expand-Archive</span> .\\fluent<span>-bit-2</span>.<span>0.6</span><span>-win64</span>.zip C:\\Tools</span></code></pre></div>\n<p>After expanding the ZIP package, it’s time to extend the default pipeline configuration in <code>conf/fluent-bit.conf</code>, as shown below, to configure our <a target=\"_blank\" href=\"https://docs.fluentbit.io/manual/pipeline/inputs\">input</a>, <a target=\"_blank\" href=\"https://docs.fluentbit.io/manual/pipeline/filters\">filters</a>, and <a target=\"_blank\" href=\"https://docs.fluentbit.io/manual/pipeline/outputs\">output</a>.</p>\n<pre><div><p>\n[INPUT]\n    Name         winevtlog\n    Channels     Microsoft-Windows-Sysmon/Operational,Security\n    Interval_Sec 1\n    DB           winevtlog.sqlite\n[FILTER]\n    Name nest\n    Match *\n    Operation nest\n    Wildcard *\n    Nest_under log\n[OUTPUT]\n    name http\n    tls on\n    match *\n    host &lt;</p><!-- --><p>&gt;\n    port 8443\n    URI /?query=INSERT+INTO+&lt;</p><!-- --><p>&gt;.&lt;</p><!-- --><p>&gt;+FORMAT+JSONEachRow&amp;async_insert=1\n    format json_stream\n    json_date_key timestamp\n    json_date_format epoch\n    http_user &lt;&lt; For demo purposes you can use ‘default’ &gt;&gt;\n    http_passwd &lt;</p><!-- --><p>&gt;\n</p></div>\n</pre>\n<p>For details on the output configuration, specifically the URI parameter, we recommend reading our previous blogs on Fluent Bit <a target=\"_blank\" href=\"https://clickhouse.com/blog/nginx-logs-to-clickhouse-fluent-bit\">here</a> and <a target=\"_blank\" href=\"https://clickhouse.com/blog/kubernetes-logs-to-clickhouse-fluent-bit\">here</a>.</p>\n<p>Note the usage of the <code>async_insert=1</code> setting in the URI. Remember that for production scenarios, you should limit the JSON object type to fewer fields.
