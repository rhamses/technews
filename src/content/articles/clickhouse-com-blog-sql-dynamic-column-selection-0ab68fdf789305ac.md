<span>1</span>;</span></code></pre></div>\n<div><pre><code><span>┌─name──────────────────┬─type──────────┐</span>\n<span>│ VendorID              │ Int64         │</span>\n<span>│ tpep_pickup_datetime        │ Int64         │</span>\n<span>│ payment_type          │ Int64         │</span>\n<span>│ fare_amount           │ Float64       │</span>\n<span>│ extra                 │ Float64       │</span>\n<span>│ mta_tax               │ Float64       │</span>\n<span>│ tip_amount            │ Float64       │</span>\n<span>│ tolls_amount          │ Float64       │</span>\n<span>│ that contain _amount. Rather than having to type out those columns individually, we can use the COLUMNS clause to return the columns that match a regular expression. A query to return the first 10 rows for the amount columns would look like this:</p>\n<div><pre><code><span><span>FROM</span> trips </span>\n<span><span>SELECT</span> COLUMNS(<span>'.*_amount'</span>)</span>\n<span>LIMIT <span>10</span>;</span></code></pre></div>\n<div><pre><code><span>┌─fare_amount─┬─tip_amount─┬─tolls_amount─┬─total_amount─┐</span>\n<span>│           0 │          0 │            0 │            0 │</span>\n<span>│         120 │          0 │            0 │        120.3 │</span>\n<span>│          45 │       9.06 │            0 │        54.36 │</span>\n<span>│          75 │      15.06 │            0 │        90.36 │</span>\n<span>│          55 │      14.45 │            0 │        72.25 │</span>\n<span>│         4.5 │          0 │            0 │         6.55 │</span>\n<span>│          10 │          0 │            0 │         10.8 │</span>\n<span>│         115 │          5 │            0 │        120.3 │</span>\n<span>│          78 │      15.76 │            0 │        94.56 │</span>\n<span>│        19.5 │          0 │            0 │        21.55 │</span>\n<span>└─────────────┴────────────┴──────────────┴──────────────┘</span></code></pre></div>\n<p>Let’s say we also want to return columns that contain the terms fee or tax. We can update the regular expression to include those:</p>\n<div><pre><code><span><span>FROM</span> trips</span>\n<span><span>SELECT</span></span>\n<span>  COLUMNS(<span>'.*_amount|fee|tax'</span>)</span>\n<span><span>ORDER</span> <span>BY</span> rand() </span>\n<span>LIMIT <span>3</span></span>\n<span>FORMAT Vertical;</span></code></pre></div>\n<div><pre><code><span>Row 1:</span>\n<span>──────</span>\n<span>fare_amount:  9.3</span>\n<span>mta_tax:      0.5</span>\n<span>tip_amount:   0</span>\n<span>tolls_amount: 0</span>\n<span>total_amount: 13.3</span>\n<span>airport_fee:  0</span>\n<span></span>\n<span>Row 2:</span>\n<span>──────</span>\n<span>fare_amount:  10</span>\n<span>mta_tax:      0.5</span>\n<span>tip_amount:   2</span>\n<span>tolls_amount: 0</span>\n<span>total_amount: 16</span>\n<span>airport_fee:  0</span>\n<span></span>\n<span>Row 3:</span>\n<span>──────</span>\n<span>fare_amount:  18.4</span>\n<span>mta_tax:      0.5</span>\n<span>tip_amount:   1</span>\n<span>tolls_amount: 0</span>\n<span>total_amount: 23.4</span>\n<span>airport_fee:  0</span></code></pre></div>\n<h2 id=\"apply-functions-to-all-columns\"></h2>\n<p>We can also use the <code>APPLY</code> function to apply functions across every column. For example, if we wanted to find the maximum value of each of those columns, we could run the following query:</p>\n<div><pre><code><span><span>FROM</span> trips </span>\n<span><span>SELECT</span> </span>\n<span>  COLUMNS(<span>'.*_amount|fee|tax'</span>)</span>\n<span>  APPLY(max)</span>\n<span>FORMAT Vertical;</span></code></pre></div>\n<div><pre><code><span>Row 1:</span>\n<span>──────</span>\n<span>max(fare_amount):  1160.1</span>\n<span>max(mta_tax):      53.16</span>\n<span>max(tip_amount):   380.8</span>\n<span>max(tolls_amount): 196.99</span>\n<span>max(total_amount): 1169.4</span>\n<span>max(airport_fee):  1.25</span></code></pre></div>\n<p>Or maybe, we’d like to see the average instead:</p>\n<div><pre><code><span><span>FROM</span> trips </span>\n<span><span>SELECT</span> </span>\n<span>  COLUMNS(<span>'.*_amount|fee|tax'</span>)</span>\n<span>  APPLY(avg)</span>\n<span>FORMAT Vertical;</span></code></pre></div>\n<div><pre><code><span>Row 1:</span>\n<span>──────</span>\n<span>avg(fare_amount):  18.36706861234277</span>\n<span>avg(mta_tax):      0.48828997712900174</span>\n<span>avg(tip_amount):   3.3679406710521764</span>\n<span>avg(tolls_amount): 0.5184906575852216</span>\n<span>avg(total_amount): 27.020383107155837</span>\n<span>avg(airport_fee):  0.10489592293640923</span></code></pre></div>\n<p>Those values contain a lot of decimal places, but luckily we can fix that by chaining functions. In this case, we’ll apply the avg function, followed by the round function:</p>\n<div><pre><code><span><span>FROM</span> trips </span>\n<span><span>SELECT</span> </span>\n<span>  COLUMNS(<span>'.*_amount|fee|tax'</span>)</span>\n<span>  APPLY(avg)</span>\n<span>  APPLY(round)</span>\n<span>FORMAT Vertical;</span></code></pre></div>\n<div><pre><code><span>Row 1:</span>\n<span>──────</span>\n<span>round(avg(fare_amount)):  18</span>\n<span>round(avg(mta_tax)):      0</span>\n<span>round(avg(tip_amount)):   3</span>\n<span>round(avg(tolls_amount)): 1</span>\n<span>round(avg(total_amount)): 27</span>\n<span>round(avg(airport_fee)):  0</span></code></pre></div>\n<p>But that rounds the averages to whole numbers. If we want to round to, say, 2 decimal places, we can do that as well. As well as taking in functions, the APPLY function takes in a lambda, which gives us the flexibility to have the round function round our average values to 2 decimal places:</p>\n<div><pre><code><span><span>FROM</span> trips </span>\n<span><span>SELECT</span> </span>\n<span>  COLUMNS(<span>'.*_amount|fee|tax'</span>)</span>\n<span>  APPLY(avg)</span>\n<span>  APPLY(col <span>-</span><span>&gt;</span> round(col, <span>2</span>))</span>\n<span>FORMAT Vertical;</span></code></pre></div>\n<div><pre><code><span>Row 1:</span>\n<span>──────</span>\n<span>round(avg(fare_amount), 2):  18.37</span>\n<span>round(avg(mta_tax), 2):      0.49</span>\n<span>round(avg(tip_amount), 2):   3.37</span>\n<span>round(avg(tolls_amount), 2): 0.52</span>\n<span>round(avg(total_amount), 2): 27.02</span>\n<span>round(avg(airport_fee), 2):  0.1</span></code></pre></div>\n<h2 id=\"replacing-columns\"></h2>\n<p>So far so good. But let’s say we want to adjust one of the values, while leaving the other ones as they are. For example, maybe we want to double the total amount and divide the MTA tax by 1.1. We can do that by using the REPLACE clause, which will replace a column while leaving the other ones as they are.</p>\n<div><pre><code><span><span>FROM</span> trips </span>\n<span><span>SELECT</span> </span>\n<span>  COLUMNS(<span>'.*_amount|fee|tax'</span>)</span>\n<span>  REPLACE(</span>\n<span>    total_amount<span>*</span><span>2</span> <span>AS</span> total_amount,</span>\n<span>    mta_tax<span>/</span><span>1.1</span> <span>AS</span> mta_tax</span>\n<span>  ) </span>\n<span>  APPLY(avg)</span>\n<span>  APPLY(col <span>-</span><span>&gt;</span> round(col, <span>2</span>))</span>\n<span>FORMAT Vertical;</span></code></pre></div>\n<div><pre><code><span>Row 1:</span>\n<span>──────</span>\n<span>round(avg(fare_amount), 2):               18.37</span>\n<span>round(divide(avg(mta_tax), 1.1), 2):      0.44</span>\n<span>round(avg(tip_amount), 2):                3.37</span>\n<span>round(avg(tolls_amount), 2):              0.52</span>\n<span>round(multiply(avg(total_amount), 2), 2): 54.04</span>\n<span>round(avg(airport_fee), 2):               0.1</span></code></pre></div>\n<p>We can see that those two columns have both been replaced and the other columns are as they were in the previous query.\nExcluding columns</p>\n<p>We can also choose to exclude a field by using the EXCEPT clause. For example, to remove the tolls_amount column, we would write the following query:</p>\n<div><pre><code><span><span>FROM</span> trips </span>\n<span><span>SELECT</span> </span>\n<span>  COLUMNS(<span>'.*_amount|fee|tax'</span>) <span>EXCEPT</span>(tolls_amount)</span>\n<span>  REPLACE(</span>\n<span>    total_amount<span>*</span><span>2</span> <span>AS</span> total_amount,</span>\n<span>    mta_tax<span>/</span><span>1.1</span> <span>AS</span> mta_tax</span>\n<span>  ) </span>\n<span>  APPLY(avg)</span>\n<span>  APPLY(col <span>-</span><span>&gt;</span> round(col, <span>2</span>))</span>\n<span>FORMAT Vertical;</span></code></pre></div>\n<div><pre><code><span>Row 1:</span>\n<span>──────</span>\n<span>round(avg(fare_amount), 2):               18.37</span>\n<span>round(divide(avg(mta_tax), 1.1), 2):      0.44</span>\n<span>round(avg(tip_amount), 2):                3.37</span>\n<span>round(multiply(avg(total_amount), 2), 2): 54.04</span>\n<span>round(avg(airport_fee), 2):               0.1</span></code></pre></div>\n<p><code>tolls_amount</code> has now been removed and the other columns remain.</p>\n<h2 id=\"in-conclusion\"></h2>\n<p>Hopefully you’ve seen that even with a dataset that didn’t have that many columns, ClickHouse’s dynamic column selection functionality saves us a bunch of typing in our SQL queries.</p>\n<p>Give these clauses a try on your own data and let us know how you get on!</p></div></article>"
