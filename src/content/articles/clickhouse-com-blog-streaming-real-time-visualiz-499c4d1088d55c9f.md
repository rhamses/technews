It offers interactive and customizable visualizations, such as heat maps, line charts, and tree maps. Like ClickHouse, Perspective is built with performance in mind. Its core is written in Rust and C++ and compiled into WebAssembly. With its support for both Python and JavaScript, it can be integrated into both backend analytics pipelines and web-based interfaces.</p>\n<p>While Perspective complements ClickHouse perfectly for standard visualization needs, we were particularly interested in its ability to handle streaming data, maintaining a constant memory overhead by only retaining the latest N rows. We, therefore, use a polling approach to fetch the latest rows over HTTP. Testing showed that while our query executes in less than 10ms even on the full 11 billion row dataset, the HTTP round trip time to a ClickHouse instance is optimistically (same region) 20-30ms. This is continuously executed, retrieving rows as quickly as ClickHouse can serve them.</p>\n<p><span><img alt=\"sliding_window.png\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2Fsliding_window_a19e99b1cf.png&w=2048&q=75\"></span></p>\n<p>The simplified diagram above assumes that each query execution takes exactly 50ms.
