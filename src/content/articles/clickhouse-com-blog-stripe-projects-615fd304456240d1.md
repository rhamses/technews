contentHtml: "<div><p>ClickHouse is now available in <a target=\"_blank\" href=\"https://projects.dev/\">Stripe Projects</a>, the new Stripe CLI workflow that lets developers and AI agents provision real infrastructure without leaving the command line.</p>\n<p>Starting today, one command provisions a ClickHouse or Postgres service on ClickHouse Cloud, returns working credentials to your environment, and hands off to <a target=\"_blank\" href=\"https://clickhouse.com/blog/introducing-clickhousectl-official-cli-for-clickhouse-local-and-cloud\"><code>clickhousectl</code></a>, a new ClickHouse CLI built for agents, so the agent can keep building.</p>\n<h2 id=\"user-content-why-we-built-this\"></h2>\n<p>Agents cannot create accounts, click through setup flows, or paste credentials into a config file. We built this integration so that spinning up a ClickHouse or Postgres service on ClickHouse Cloud is something an agent can do completely, with real credentials landing in the environment without any UI interaction.</p>\n<p>Stripe Projects is the CLI workflow that puts it all together. Run <code>stripe projects init my-app</code>, select the services you need, and Stripe Projects provisions real resources in your own provider accounts, syncs credentials to your <code>.env</code>, and keeps everything auditable from the terminal. Credentials land in your environment without any manual steps, and the workflow is the same whether a human or an agent is running it.</p>\n<p>This is a developer preview. We want feedback from teams building agent-assisted workflows or just trying to cut the time from new repo to running app.</p>\n<h2 id=\"user-content-what-can-you-provision\"></h2>\n<p>ClickHouse Cloud offers two services through Stripe Projects:</p>\n<p><strong>ClickHouse</strong> is the real-time analytics database. ClickHouse is known for: high-ingest, high-concurrency, billions of rows in milliseconds. If your app needs to query event streams, power user-facing analytics, or run aggregations at scale, this is the right service.</p>\n<p><strong>Postgres (public beta)</strong> is a fully managed Postgres service on ClickHouse Cloud, built on local NVMe storage for microsecond latency and up to 10x faster performance on I/O-heavy workloads. For teams that need a transactional store alongside their analytics layer, both services are provisioned through the same CLI workflow, land in the same account, and share credentials.</p>\n<h2 id=\"user-content-how-credentials-flow-to-the-agent\"></h2>\n<p>Once provisioning completes, credentials are written directly to your <code>.env</code> file in an agent-readable format. From there, the agent picks them up and continues all operations through <code>clickhousectl</code>, the ClickHouse CLI, without any manual credential handling or context switching.</p>\n<blockquote>\n<p>Note: clickhousectl &gt;v0.3.0 is required.</p>\n</blockquote>\n<h2 id=\"user-content-try-it\"></h2>\n<p>ClickHouse is in the Stripe Projects developer preview today.</p>\n<div><pre><code><span><span># Create a project</span></span>\n<span>stripe projects init my-app</span>\n<span></span>\n<span><span># Add a ClickHouse service</span></span>\n<span>stripe projects add clickhouse/clickhouse</span>\n<span></span>\n<span><span># Or add a managed Postgres service (public beta)</span></span>\n<span>stripe projects add clickhouse/postgres</span></code></pre></div></div><div><p>Install the Stripe CLI, run <code>stripe projects init my-app</code>, and add whichever service fits your stack. Credentials sync to <code>.env</code> automatically. From there, <code>clickhousectl</code> takes over: set up data ingestion with ClickPipes, query your service, and keep building without leaving the terminal.</p>\n<p>To learn more, visit <a target=\"_blank\" href=\"https://clickhouse.com/cloud\">clickhouse.com/cloud</a> or the <a target=\"_blank\" href=\"https://docs.stripe.com/projects\">Stripe Projects documentation</a>.</p></div>"
