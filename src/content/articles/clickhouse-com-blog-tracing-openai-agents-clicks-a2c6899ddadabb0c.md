By default, it publishes traces to OpenAI's tracing product, but we can hook in our own custom exporter to capture and analyze the data ourselves.</p>\n<p>The OpenAI agents tracing SDK treats traces and spans as separate entities. Here's how they define each:</p>\n<p>Traces represent a single end-to-end operation of a \"workflow\". They're composed of Spans. Traces have the following properties:</p>\n<ul>\n<li><code>workflow_name</code>: This is the logical workflow or app. For example, \"Code generation\" or \"Customer service\".</li>\n<li><code>trace_id</code>: A unique ID for the trace. Automatically generated if you don't pass one. Must have the format trace_&lt;32_alphanumeric&gt;.</li>\n<li><code>group_id</code>: Optional group ID, to link multiple traces from the same conversation. For example, you might use a chat thread ID.</li>\n<li><code>disabled</code>: If True, the trace will not be recorded.</li>\n<li><code>metadata</code>: Optional metadata for the trace.</li>\n</ul>\n<p>Spans represent operations that have a start and end time. Spans have:</p>\n<ul>\n<li><code>started_at</code> and ended_at timestamps.</li>\n<li><code>trace_id</code>, to represent the trace they belong to</li>\n<li><code>parent_id</code>, which points to the parent Span of this Span (if any)</li>\n<li><code>span_data</code>, which is information about the Span. For example, AgentSpanData contains information about the Agent, GenerationSpanData includes information on the LLM generation, and so on.</li>\n</ul>\n<p>Let’s build a basic exporter that prints out spans and traces to the terminal:</p>\n<div><pre><code><span><span>from</span> agents.tracing.processors <span>import</span> TracingExporter</span>\n<span></span>\n<span><span>class</span> <span>ClickHouseExporter</span>(<span>TracingExporter</span>):    </span>\n<span>    <span>def</span> <span>export</span>(<span>self, items: <span>list</span></span>) -&gt; <span>None</span>:</span>\n<span>        <span>for</span> item <span>in</span> items:</span>\n<span>            <span>print</span>(item.export())</span></code></pre></div>\n<p>Next, we’ll add the following code to the top of our <code>main</code> function to add <code>ClickHouseExporter</code> as the exporter for a <code>BatchTraceProcessor</code>:</p>\n<div><pre><code><span><span>from</span> agents.tracing.processors <span>import</span> BatchTraceProcessor</span>\n<span></span>\n<span>exporter = ClickHouseExporter()</span>\n<span>add_trace_processor(BatchTraceProcessor(exporter=exporter, max_batch_size=<span>200</span>))</span></code></pre></div>\n<p>Now, let’s rerun our script.
