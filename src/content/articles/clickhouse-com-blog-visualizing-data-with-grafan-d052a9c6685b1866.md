Users should be able to reproduce all examples using the <code>explorer</code> user (no password required).</p>\n<h2 id=\"grafana\"></h2>\n<p>Since originating as a fork of Kibana in 2014, Grafana has grown to be one of the most popular visualization techniques for time series data. The code has long diverged from its Kibana roots, extending its support for datastores, adding new visualizations, and expanding beyond a simple dashboarding tool. While applicable to BI use cases, it predominately focuses on serving the Observability use case, with excellent support for dedicated views for logs and traces.</p>\n<p>At ClickHouse, we continue to work closely with the Grafana team to invest in the official OSS ClickHouse plugin, allowing users to visualize data in real-time effortlessly. We recently released <a target=\"_blank\" href=\"https://clickhouse.com/blog/clickhouse-grafana-plugin-2.0\">version 2.x of the Grafana plugin for ClickHouse</a>, which included long-awaited features like JSON and HTTP support. In our examples, we utilize <a target=\"_blank\" href=\"https://grafana.com/auth/sign-in/\">Grafana Cloud</a>, which provides a generous free tier more than sufficient for querying data in our <a target=\"_blank\" href=\"https://clickhouse.cloud/signUp\">ClickHouse Cloud</a> service. The instructions for installing the official ClickHouse plugin can be found <a target=\"_blank\" href=\"https://clickhouse.com/docs/en/connect-a-ui/grafana-and-clickhouse\">here</a>. These should be identical for self-managed instances.</p>\n<p>To connect Grafana to ClickHouse a user is simply required to create a ClickHouse Datasource - effectively an instantiation of the plugin. Users can create multiple data sources: each potentially connecting to a different ClickHouse service or possibly providing access to the same instance with different credentials. We illustrate this process below:</p>\n<p><a target=\"_blank\" href=\"https://clickhouse.com/uploads/grafana_1_datasource_81c6357583.gif\">\n         <span><img alt=\"grafana-1-datasource.gif\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2Fgrafana_1_datasource_81c6357583.gif&w=2048&q=75\"></span>\n</a>\n<br>\nVisualizing data in Grafana requires us to create a dashboard. From here, the user can add a visualization panel and specify that this should use our ClickHouse data source.\n<br><br>\n<a target=\"_blank\" href=\"https://clickhouse.com/uploads/grafana_2_create_visual_2_f2a043d353.gif\">\n         <span><img alt=\"grafana-2-create-visual-2.gif\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2Fgrafana_2_create_visual_2_f2a043d353.gif&w=2048&q=75\"></span>\n</a>\n<br>\nWhen creating a visual, the user is required to be familiar with SQL concepts. However, a visual query builder assists with constructing ClickHouse SQL for most chart types. With Granfana focusing on time-series data, most charts require the user to define a DateTime/Date column along with a numerical value.\n</p><p>In the example below, we use the <a target=\"_blank\" href=\"https://clickhouse.com/blog/getting-data-into-clickhouse-part-1\">hacker news dataset from an earlier post</a>, to create a simple bar chart showing ClickHouse activity over time. Notice how we initially use the query builder to get started, before editing the SQL directly to capture posts per month.</p>\n<p><a target=\"_blank\" href=\"https://clickhouse.com/uploads/grafana_3_simple_bar_2_26cea715dd.gif\">\n         <span><img alt=\"grafana-3-simple-bar-2.gif\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2Fgrafana_3_simple_bar_2_26cea715dd.gif&w=2048&q=75\"></span>\n</a></p><pre><p>\nSELECT count() as `posts per month`, toStartOfMonth(time) as month FROM default.hackernews WHERE type IN ('comment', 'story') AND (text ILIKE '%ClickHouse%' OR title ILIKE '%ClickHouse%') GROUP BY month ORDER BY month LIMIT 1000\n</p> <a target=\"_blank\" href=\"https://sql.clickhouse.com/?query_id=JYYNJM7UWYX5RIWU7GPGTJ\">✎</a>\n</pre>\n<p>Multi-line charts, i.e., those with more than one series, require a string column in addition to the standard Date/DateTime and numeric columns. This string column thus defines the series key. Below we utilize the forex dataset from our <a target=\"_blank\" href=\"https://clickhouse.com/blog/getting-data-into-clickhouse-part-3-s3\">previous post</a>, to show the price of various currency pairs where the USD is the base.  Note we use a SQL query here with the filter <code>$__timeFilter</code>, which automatically injects our selected time range into the query as a filter - thus allowing us to drill down. We use the <a target=\"_blank\" href=\"https://clickhouse.com/docs/en/sql-reference/aggregate-functions/reference/argmax/\">argMax</a> function to get the close price each day. Finally, we use <code>SETTINGS max_result_rows = 10000</code> to allow us to get a larger dataset from <a target=\"_blank\" href=\"https://play.clickhouse.com/play?user=play\">play.clickhouse.com</a>.</p>\n<p><a target=\"_blank\" href=\"https://clickhouse.com/uploads/grafana_4_multi_line_2_e8daf9fcd9.gif\">\n         <span><img alt=\"grafana-4-multi-line-2.gif\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2Fgrafana_4_multi_line_2_e8daf9fcd9.gif&w=2048&q=75\"></span>\n</a></p><pre><p>\nSELECT toStartOfDay(datetime) as time, quote, argMax(bid,datetime) as close\nFROM blogs.forex\nWHERE (base ='EUR') AND quote IN ('GBP', 'USD', 'NZD', 'CAD') AND $__timeFilter(datetime)\nGROUP BY time, quote\nORDER BY time ASC, quote ASC\nSETTINGS max_result_rows=10000\n</p> <a target=\"_blank\" href=\"https://sql.clickhouse.com/?query_id=G5QCEZE3VY4CDVFE7MSIAE\">✎</a>\n</pre>\n<p>A little more work is required for less standard visualizations, such as heatmap and candlestick. Candlestick visualizations require a value for each time period indicating the open, close (using <a target=\"_blank\" href=\"https://clickhouse.com/docs/en/sql-reference/aggregate-functions/reference/argmin\">argMin</a>), low, and high values. This naturally fits our forex dataset, allowing us to visualize how prices change over time.</p>\n<p><a target=\"_blank\" href=\"https://clickhouse.com/uploads/grafana_5_candle_stick_2_1ebaee5f4b.gif\">\n         <span><img alt=\"grafana-5-candle_stick-2.gif\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2Fgrafana_5_candle_stick_2_1ebaee5f4b.gif&w=2048&q=75\"></span>\n</a></p><pre><p>\nSELECT toStartOfDay(datetime) as day, argMin(ask, datetime) as open, argMax(ask,datetime) as close, max(ask) as high, min(ask) as low\nFROM blogs.forex\nWHERE (base ='EUR') AND quote ='USD' AND $__timeFilter(datetime)\nGROUP BY day\nORDER BY day ASC\nSETTINGS max_result_rows=10000\n</p> <a target=\"_blank\" href=\"https://sql.clickhouse.com/?query_id=NJPUOAHZYRPELRF6DY2XFT\">✎</a>\n</pre>\n<p>Heatmaps in Grafana require us to bucket our geo data and provide a numerical value to control the color scale. Our weather dataset, from a <a target=\"_blank\" href=\"https://clickhouse.com/blog/real-world-data-noaa-climate-data\">previous post</a>, provides us with a simple means to demonstrate this. We use the ClickHouse <a target=\"_blank\" href=\"https://clickhouse.com/docs/en/sql-reference/functions/geo/geohash/#geohashencode\">geoHashEncode</a> function to aggregate on our <a target=\"_blank\" href=\"https://clickhouse.com/docs/en/sql-reference/data-types/geo/#point\">Point</a> field, finding the max temperature recorded for each grid. These can then be plotted using the GeoMap visualization as a heatmap to show the hottest areas of the United States and Mexico. Note the geographic restriction via the polygon dictionary - a filter optimization explored <a target=\"_blank\" href=\"https://clickhouse.com/blog/real-world-data-noaa-climate-data\">here</a>.</p>\n<p><a target=\"_blank\" href=\"https://clickhouse.com/uploads/grafana_6_map_4673cb2d47.gif\">\n         <span><img alt=\"grafana-6-map.gif\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2Fgrafana_6_map_4673cb2d47.gif&w=2048&q=75\"></span>\n</a></p><pre><p>\nSELECT geoHash, geohashDecode(geoHash) as lon_lat, max(tempMax)/10 as max_temp\nFROM blogs.noaa\nWHERE date &gt; '1970-01-01' and dictGet(blogs.country_polygons, 'name', location) IN ('United States of America', 'Mexico')\nGROUP BY geohashEncode(location.1, location.2, 3) as geoHash SETTINGS max_result_rows = 100000\n</p> <a target=\"_blank\" href=\"https://sql.clickhouse.com/?query_id=NHQIA2R29W9QCV8QL9EPNA\">✎</a>\n</pre>\n<p>The above examples focus on datasets from our previous posts. Grafana, however, is typically used for the Observability use case. While a post dedicated to using Grafana with Observability data is justified (coming soon!), here we demonstrate the use of the <a target=\"_blank\" href=\"https://sql.clickhouse.com/?query_id=PT6BDKJPNWWYVOSFHJ2N9H\">JSON log data available in play.clickhouse.com</a> to build a simple view in Grafana’s log explorer. We offset this data to the last 24 hrs in order to simplify the visualization. Note we also create a level field from the status code to ensure our logs are categorized and color-coded.</p>\n<p><a target=\"_blank\" href=\"https://clickhouse.com/uploads/grafana_7_logs_2_666a64f353.gif\">\n         <span><img alt=\"grafana-7-logs-2.gif\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2Fgrafana_7_logs_2_666a64f353.gif&w=2048&q=75\"></span>\n</a></p><pre><p>\nSELECT\n    now() - (toDateTime('1998-05-08 13:44:46') - timestamp) AS log_time,\n    multiIf(message.status &gt; 500, 'critical', message.status &gt; 400, 'error', message.status &gt; 300, 'warning', 'info') AS level,\n    message.request.method AS method,\n    message.status AS status,\n    message.size AS size,\n    message.request AS log\nFROM blogs.http_logs\nORDER BY timestamp DESC\nLIMIT 10000\n</p> <a target=\"_blank\" href=\"https://sql.clickhouse.com/?query_id=24AZ83BWSK7DYB24TDJHZD\">✎</a>\n</pre>\n<h2 id=\"conclusion\"></h2>\n<p>In this post, we have shown some simple visualization techniques using the Grafana plugin.
