Queries can be constructed by simply dragging and dropping fields - a feature likely to appeal to business users. Focusing on fast data exploration, the breadth of visuals and customizability is less than previous tools we’ve demonstrated, with the benefit of a cleaner and simpler interface and workflow.</p>\n<p>Downloading the Metabase jar offers the simplest getting-started experience. This requires you to have a Java Runtime Environment (JRE) installed on your system. Ensure you download the <a target=\"_blank\" href=\"https://github.com/enqueue/metabase-clickhouse-driver/releases\">ClickHouse driver</a> (jar file), placing this in a “/plugins” subdirectory. Starting Metabase is then trivial:</p>\n<div><pre><code><span>java -jar metabase.jar</span></code></pre></div>\n<p>The app can take a few minutes to start. The console should redirect you to <a target=\"_blank\" href=\"http://localhost:3000/\">http://localhost:3000</a> once Metabase is ready.</p>\n<p>Select ClickHouse as your database during setup and assign a name to the data source. Note the usage of the HTTP port.</p>\n<p><a target=\"_blank\" href=\"https://clickhouse.com/uploads/metabase_1_datasource_v2_3cc6f654ae.gif\">\n         <span><img alt=\"metabase-1-datasource-v2.gif\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2Fmetabase_1_datasource_v2_3cc6f654ae.gif&w=2048&q=75\"></span>\n</a></p><p>Metabase offers an exploration feature useful for obtaining a quick overview of a particular dataset. The overview statistics such as field cardinality and value changes over time. Below we explore the forex dataset, from an <a target=\"_blank\" href=\"https://clickhouse.com/blog/getting-data-into-clickhouse-part-3-s3\">earlier post</a>, to obtain an overview of the main base and quote columns.</p>\n<p><a target=\"_blank\" href=\"https://clickhouse.com/uploads/metabase_explore_1b683eb74e.gif\">\n         <span><img alt=\"metabase-explore.gif\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2Fmetabase_explore_1b683eb74e.gif&w=2048&q=75\"></span>\n</a>\n<br>\nUsers of Metabase create analytics that can be based on either traditional SQL queries or a “question”. Questions are built with a guided query builder where the user selects a database, table, filter, and summarization field. The summarization can also be split into groups - effectively using a GROUP BY. This intuitive approach allows users to build simple visualizations quickly.\n</p><p>Below we use the question feature to view the average price for the EUR currency pairs USD, AUD, CAD, CHF, GPB, and NZD from our <a target=\"_blank\" href=\"https://clickhouse.com/blog/getting-data-into-clickhouse-part-3-s3\">forex dataset</a>. Note we assume the bid price represents the average price of the currency pair.</p>\n<p><a target=\"_blank\" href=\"https://clickhouse.com/uploads/metabase_2_simple_viz_v2_0f1b8f08a4.gif\">\n         <span><img alt=\"metabase-2-simple-viz-v2.gif\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2Fmetabase_2_simple_viz_v2_0f1b8f08a4.gif&w=2048&q=75\"></span>\n</a>\n<br>\nThis “question” approach is particularly suited to most simple visualization requirements. For more complex visualizations, Metabase offers a SQL editor.  The user simply has to ensure results are returned in a structure appropriate to visualize - similar to the Grafana approach. With no client-side transformation logic, all manipulation is deferred to the query itself. With an extensive range of analytical functions, this suits ClickHouse and is typically encouraged even for the largest datasets.\n</p><p>Below we demonstrate using this SQL editor to show the world’s coldest countries, according to our <a target=\"_blank\" href=\"https://clickhouse.com/blog/real-world-data-noaa-climate-data\">NOAA dataset</a>, overlaid on a regional map.</p>\n<p><a target=\"_blank\" href=\"https://clickhouse.com/uploads/metabase_3_country_map_6ad50aa039.gif\">\n         <span><img alt=\"metabase-3-country-map.gif\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2Fmetabase_3_country_map_6ad50aa039.gif&w=2048&q=75\"></span>\n</a></p><pre><p>\nSELECT\n    code,\n    min(tempMin) / 10 AS min_temp\nFROM blogs.noaa\nWHERE date &gt; '1970-01-01'\nGROUP BY substring(station_id, 1, 2) AS code\nLIMIT 1000\n</p> <a target=\"_blank\" href=\"https://sql.clickhouse.com/?query_id=HNQECUKC2F4GGRKHXWRTGS\">✎</a>\n</pre>\n<p>As well as region maps, Metabase includes a Grid map. While currently quite simple, this can be useful for plotting points where the color intensity is determined by a metric. We use this capability to plot weather events in the United States where the wind gust speed was greater than 100 kph or approx. 30 MPS (our units of wind gust speed are tenths of meters per second), and significant volumes of rain were involved over the period of a week, i.e., more than 2cm of rain on average per day. We restrict this to the period of July to October, which loosely describes the conditions and time of year for hurricanes. We finally plot the top 2 highest events per year with respect to wind speed and filter out events of high elevation (&gt;500m) -  as bad weather tends to be a common occurrence on mountain peaks!  Note the use of the function <a target=\"_blank\" href=\"https://clickhouse.com/docs/en/sql-reference/functions/geo/geohash/#geohashencode\">geohashEncode</a> to capture significant events over a wide area, rather than potentially single anomalous stations, as well as the <a target=\"_blank\" href=\"https://clickhouse.com/docs/en/sql-reference/functions/ext-dict-functions/#dictget-dictgetordefault-dictgetornull\">dictGet</a> function to restrict our analysis to the United States.</p>\n<p><a target=\"_blank\" href=\"https://clickhouse.com/uploads/metabase_hurricanes_48f2f78e1b.gif\">\n         <span><img alt=\"metabase-hurricanes.gif\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2Fmetabase_hurricanes_48f2f78e1b.gif&w=2048&q=75\"></span>\n</a></p><p>As expected, we capture <a target=\"_blank\" href=\"https://en.wikipedia.org/wiki/List_of_United_States_hurricanes\">hurricanes impacting the east coast</a> - including <a target=\"_blank\" href=\"https://en.wikipedia.org/wiki/Hurricane_Katrina\">Katrina in 2005</a>.</p>\n<pre><p>\nSELECT\n    week,\n    toYear(week) AS year,\n    lat, lon,\n    avg_precipitation,\n    max_wind_speed * 10\nFROM\n(\n    SELECT\n        geoHash,\n        week,\n        geohashDecode(geoHash) AS lonlat,\n        lonlat.1 AS lon,\n        lonlat.2 AS lat,\n        max(maxWindSpeed) AS max_wind_speed,\n        avg(precipitation)/10 AS avg_precipitation\n    FROM blogs.noaa\n    WHERE (dictGet(blogs.country_polygons, 'name', location) IN ('United States of America')) AND (elevation &lt; 500) AND toMonth(date) BETWEEN 6 AND 10\n    GROUP BY\n        geohashEncode(location.1, location.2, 4) AS geoHash,\n        toStartOfWeek(date) AS week\n    HAVING max_wind_speed &gt; 300  AND avg_precipitation &gt; 20\n    ORDER BY\n        max_wind_speed DESC\n)\nORDER BY\n    year ASC,\n    max_wind_speed DESC\nLIMIT 2 BY year\n</p> <a target=\"_blank\" href=\"https://sql.clickhouse.com/?query_id=T7DVXL4IRQSYDZXUZEMYOL\">✎</a>\n</pre>\n<p>The waterfall visualization conveys similar information to the <a target=\"_blank\" href=\"https://clickhouse.com/blog/visualizing-data-with-grafana\">Grafana candlestick</a> shown in our earlier post - a popular technique for forex datasets. Below we reuse a query from <a target=\"_blank\" href=\"https://clickhouse.com/blog/getting-data-into-clickhouse-part-3-s3\">our earlier forex post</a> to plot the GBP/EUR currency pair change - using a <a target=\"_blank\" href=\"https://clickhouse.com/docs/en/sql-reference/functions/time-window-functions/\">window function</a> over the daily close price. As shown, Metabase also preserves the notion of dashboards to collate multiple visualizations.</p>\n<p><a target=\"_blank\" href=\"https://clickhouse.com/uploads/meatabase_4_waterfall_83c2b7e296.gif\">\n         <span><img alt=\"metabase-4-waterfall.gif\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2Fmeatabase_4_waterfall_83c2b7e296.gif&w=2048&q=75\"></span>\n</a></p><pre><p>\nSELECT\n    base,\n    quote,\n    day,\n    close,\n    close - any(close) OVER (PARTITION BY base, quote ORDER BY base ASC, quote ASC, day ASC ROWS BETWEEN 1 PRECEDING AND CURRENT ROW) AS change\nFROM\n(\n    SELECT\n        base,\n        quote,\n        day,\n        argMax(ask, datetime) AS close\n    FROM blogs.forex\n    WHERE (quote = 'GBP') AND (base = 'EUR')\n    GROUP BY\n        base,\n        quote,\n        toStartOfDay(datetime) AS day\n    ORDER BY\n        base ASC,\n        quote ASC,\n        day ASC\n)\nORDER BY day ASC\n</p> <a target=\"_blank\" href=\"https://sql.clickhouse.com/?query_id=BXNF4KPUROV9QRCS5FAGMD\">✎</a>\n</pre>\n<p>Similar to Grafana and Superset, Metabase supports combo charts to allow multiple axes to be plotted. For example purposes, we use the <a target=\"_blank\" href=\"https://clickhouse.com/docs/en/getting-started/example-datasets/uk-price-paid\">UK house price dataset</a> used throughout our docs. We plot the average house price and sales per month since 1995, differentiating between <a target=\"_blank\" href=\"https://www.moneyhelper.org.uk/en/homes/buying-a-home/leasehold-vs-freehold-whats-the-difference\">leasehold and freehold</a> transactions.</p>\n<p><a target=\"_blank\" href=\"https://clickhouse.com/uploads/metabase_5_prices_cd9d9a76dc.gif\">\n         <span><img alt=\"metabase-5-prices.gif\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2Fmetabase_5_prices_cd9d9a76dc.gif&w=2048&q=75\"></span>\n</a></p><pre><p>\nSELECT\n    month,\n    countIf(duration = 'leasehold') AS `Leasehold Sold`,\n    countIf(duration = 'freehold') AS `Freehold Sold`,\n    avgIf(price, duration = 'freehold') AS `Average Freehold Price`,\n    avgIf(price, duration = 'leasehold') AS `Average Leasehold Price`\nFROM uk_price_paid\nGROUP BY toStartOfMonth(date) AS month\nORDER BY month ASC\n</p> <a target=\"_blank\" href=\"https://sql.clickhouse.com/?query_id=5DVCXJZPH77BQJKREMEG8Z\">✎</a>\n</pre>\n<p>Returning to our NOAA dataset, we were curious as to where might be perfect holiday destination based on climatic conditions. Our rudimentary criteria - good temperature range, little rain, non-excessive elevation, and absence of extreme weather events, might be a little contrived, but this allows us to demonstrate the funnel visualization and usage of the <a target=\"_blank\" href=\"https://clickhouse.com/docs/en/sql-reference/functions/array-functions/#arrayjoinarr\">arrayJoin</a> and <a target=\"_blank\" href=\"https://clickhouse.com/docs/en/sql-reference/aggregate-functions/combinators/#-if\">If combinator</a> functions for transforming column names to values. We compute our conditions over geo hash regions and months of the year, thereby not just considering a single station recording.</p>\n<p><a target=\"_blank\" href=\"https://clickhouse.com/uploads/metabase_6_funnel_bf9903a805.gif\">\n         <span><img alt=\"metabase-6-funnel.gif\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2Fmetabase_6_funnel_bf9903a805.gif&w=2048&q=75\"></span>\n</a></p><pre><p>\nSELECT\n    values.1 AS labels,\n    values.2 AS count\nFROM\n(\n    SELECT arrayJoin([('not_too_cold', countIf(min_temp &gt; 0)), ('not_too_cold_or_cold', countIf((min_temp &gt; 0) AND (max_temp &lt; 40))), ('ideal_temp', countIf((max_temp &lt; 40) AND (min_temp &gt; 0) AND (avg_temp &gt; 10))), ('ideal_temp_min_rain', countIf((max_temp &lt; 40) AND (min_temp &gt; 0) AND (avg_temp &gt; 10) AND (sum_precipitation &lt; 100))), ('ideal_temp_min_rain_not_high', countIf((max_temp &lt; 40) AND (min_temp &gt; 0) AND (avg_temp &gt; 10) AND (sum_precipitation &lt; 100) AND (avg_elevation &lt; 1000)))]) AS values\n    FROM\n    (\n        SELECT\n            geoHash,\n            month,\n            avg(percentDailySun) AS avg_daily_sun,\n            geohashDecode(geoHash) AS lonlat,\n            lonlat.1 AS lat,\n            lonlat.2 AS lon,\n            avg(tempAvg) / 10 AS avg_temp,\n            max(tempMax) / 10 AS max_temp,\n            min(tempMin) / 10 AS min_temp,\n            sum(precipitation) AS sum_precipitation,\n            avg(elevation) AS avg_elevation\n        FROM blogs.noaa\n        WHERE date &gt; '1970-01-01'\n        GROUP BY\n            geohashEncode(location.1, location.2, 4) AS geoHash,\n            toMonth(date) AS month\n    )\n)\n</p> <a target=\"_blank\" href=\"https://sql.clickhouse.com/?query_id=9MFVCCCQDPMXAB6TMG6LQZ\">✎</a>\n</pre>\n<p>For those curious about the optimal locations, the Pin map allows us to interpret the coordinates quickly. This requires us to move our most restrictive condition to a HAVING clause.</p>\n<p><a target=\"_blank\" href=\"https://clickhouse.com/uploads/metabase_pin_map_e070ffb4d8.gif\">\n         <span><img alt=\"metabase-pin-map.gif\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2Fmetabase_pin_map_e070ffb4d8.gif&w=2048&q=75\"></span>\n</a></p><pre><p>\nSELECT\n    geoHash,\n    month,\n    avg(percentDailySun) AS avg_daily_sun,\n    geohashDecode(geoHash) AS lonlat,\n    lonlat.1 AS lon,\n    lonlat.2 AS lat,\n    avg(tempAvg) / 10 AS avg_temp,\n    max(tempMax) / 10 AS max_temp,\n    min(tempMin) / 10 AS min_temp,\n    sum(precipitation) AS sum_precipitation,\n    avg(elevation) AS avg_elevation\nFROM blogs.noaa\nWHERE date &gt; '1970-01-01'\nGROUP BY\n    geohashEncode(location.1, location.2, 4) AS geoHash,\n    toMonth(date) AS month\nHAVING (max_temp &lt; 40) AND (min_temp &gt; 0) AND (avg_temp &gt; 10) AND (sum_precipitation &lt; 100) AND (avg_elevation &lt; 1000)\n</p> <a target=\"_blank\" href=\"https://sql.clickhouse.com/?query_id=DN1SAY1IIIEAWRPF4JHFCG\">✎</a>\n</pre>\n<p>We’ll leave it to the reader to explore these locations and report if they do make ideal holiday destinations.</p>\n<h2 id=\"summary\"></h2>\n<p>In this post, we’ve demonstrated how Metabase offers a great getting-started experience for users not familiar with SQL by providing a simple but effective way to build visualizations for BI via the questions feature. This contrasts with the other tools in this blog series which address other needs. Grafana has a clear strength with respect to time series data and its evolving flexibility in use cases such as geo analysis, requiring users to be comfortable in SQL. Superset meanwhile optimizes for data analysts and BI use cases with an excellent SQL editor and the ability to save any query as a reusable “dataset”, resulting in a highly effective way of building visualizations.
