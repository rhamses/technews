With a focus on SQL-based data stores, users are expected to be comfortable writing queries but with assistance from an IDE-like editor. Retaining the concept of dashboards, data analysts and more technical BI users are presented with a rich BI experience and a wide range of visualization types, including tree maps and box plots.</p>\n<p>One of Superset's key strengths is its extensibility, allowing developers to create custom visualizations and plugins to meet specific organizational needs. Additionally, Superset supports a variety of data sources, including traditional relational databases, NoSQL databases, and cloud-native data warehouses, making it a versatile choice for organizations with diverse data ecosystems. The platform also emphasizes security and governance, providing features like role-based access control and data source management to ensure data integrity and compliance with organizational policies.</p>\n<h2 id=\"getting-started-with-superset-and-clickhouse\"></h2>\n<p><code>docker-compose</code> represents the <a target=\"_blank\" href=\"https://superset.apache.org/docs/installation/installing-superset-using-docker-compose\">simplest getting started experience</a> for new users of Superset.</p>\n<p>First clone the Superset repository:</p>\n<div><pre><code><span>git <span>clone</span> --depth=1  https://github.com/apache/superset.git</span>\n<span><span>cd</span> superset</span></code></pre></div>\n<p>Prior to running any docker-compose commands, ensure the official ClickHouse driver will be installed by adding “clickhouse-connect” to the requirements file as shown below. We also add a map box key to enable geo visualizations.</p>\n<div><pre><code><span><span>echo</span> <span>\"clickhouse-connect\"</span> &gt;&gt; ./docker/requirements-local.txt</span>\n<span><span>echo</span> <span>\"MAPBOX_API_KEY=\"</span> &gt;&gt; docker/.env-non-dev</span></code></pre></div>\n<p>Next, let's launch Superset</p>\n<div><pre><code><span><span>export</span> TAG=3.1.1</span>\n<span>docker compose -f docker-compose-image-tag.yml up</span></code></pre></div>\n<p>Finally, we're going to create our Superset admin and initialize Superset's database:</p>\n<div><pre><code><span>SUPERSET_ID=$(docker ps -aqf <span>\"name=superset_app\"</span>)</span></code></pre></div>\n<div><pre><code><span>docker <span>exec</span> -it <span>${SUPERSET_ID}</span> superset fab create-admin \\</span>\n<span>  --username admin --firstname Superset --lastname Admin \\</span>\n<span>  --email admin@superset.com --password admin</span>\n<span>docker <span>exec</span> -it <span>${SUPERSET_ID}</span>  superset db upgrade</span>\n<span>docker <span>exec</span> -it <span>${SUPERSET_ID}</span>  superset init</span></code></pre></div>\n<p>You can access Superset via <a target=\"_blank\" href=\"http://localhost:8088/\">http://localhost:8088</a> and log in using the credentials <code>admin/admin</code>.</p>\n<h2 id=\"adding-database-connection\"></h2>\n<p>Once we've logged in, we're going to create a database connection. Here we limit to data from the 2020s and assume the reader has created the dataset in Superset using the previous example. Note we use <code>1/avg(ask-bid)</code> as an estimation of market activity in a currency pair. This computes the inverse of the spread (see our <a target=\"_blank\" href=\"https://clickhouse.com/blog/getting-data-into-clickhouse-part-3-s3\">earlier post</a> for the definition), for which a lower value indicates greater liquidity and trading volumes.</p>\n<p><a target=\"_blank\" href=\"https://clickhouse.com/uploads/superset_treemap_2_6b919aba01.gif\">\n         <span><img alt=\"superset-treemap-2.gif\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2Fsuperset_treemap_2_6b919aba01.gif&w=2048&q=75\"></span>\n</a></p><h2 id=\"creating-a-superset-dataset-from-a-sql-query\"></h2>\n<p>We can perform a similar analysis of the <code>GBP/EUR</code> but visualize it as a calendar to see those days during which the largest change in price occurred during 2016 - unsurprisingly, the day of the <a target=\"_blank\" href=\"https://en.wikipedia.org/wiki/2016_United_Kingdom_European_Union_membership_referendum\">Brexit referendum</a>. This requires us to use the SQL IDE, where the results of a query can be saved as a dataset. This powerful feature allows us to capture more complex logic. This specific query is from our <a target=\"_blank\" href=\"https://clickhouse.com/blog/getting-data-into-clickhouse-part-3-s3\">earlier forex post</a> and requires a window function to compute the daily change.</p>\n<pre><p>\nSELECT\n    base,\n    quote,\n    day,\n    close,\n    close - any(close) OVER (PARTITION BY base, quote ORDER BY base ASC, quote ASC, day ASC ROWS BETWEEN 1 PRECEDING AND CURRENT ROW) AS change\nFROM\n(\n    SELECT\n        base,\n        quote,\n        day,\n        argMax(ask, datetime) AS close\n    FROM blogs.forex\n    WHERE (quote = 'GBP') AND (base = 'EUR') AND (datetime &gt; '2016-01-01 00:00:00.000') AND (datetime &lt; '2017-01-01 00:00:00.000')\n    GROUP BY\n        base,\n        quote,\n        toStartOfDay(datetime) AS day\n    ORDER BY\n        base ASC,\n        quote ASC,\n        day ASC\n)\nORDER BY\n    base ASC,\n    quote ASC,\n    day ASC\n</p> <a target=\"_blank\" href=\"https://sql.clickhouse.com/?query_id=BXNF4KPUROV9QRCS5FAGMD\">✎</a>\n</pre>\n<p><a target=\"_blank\" href=\"https://clickhouse.com/uploads/superset_calendar_d424f56ed6.gif\">\n         <span><img alt=\"superset-calendar.gif\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2Fsuperset_calendar_d424f56ed6.gif&w=2048&q=75\"></span>\n</a></p><p>Although we haven’t explored the <a target=\"_blank\" href=\"https://clickhouse.com/docs/en/getting-started/example-datasets/uk-price-paid\">UK house price</a> dataset in our blog series, this is often used for example purposes throughout our docs. By using a list of <a target=\"_blank\" href=\"https://gist.github.com/gingerwizard/07044995d259c5f82582da4d6f9cf3f8\">regional codes</a> for the UK (ISO 3166-2) we can identify regions that have seen the largest percentage change in median house prices in the last 20 years. The query here uses some nice aggregate functions, joining our codes and prices, and yet still runs in less than 0.2 secs in our public play environment. The UK has undergone changes in regional codes over the last 25 years, so some houses have no valid value in the current codes - however, this compromises less than one-tenth of a percent and is not meaningful to our analysis.</p>\n<pre><p>\nSELECT\n   code,\n   (anyIf(med_2020, med_2020 &gt; 0) - anyIf(med_2000, med_2000 &gt; 0)) / anyIf(med_2000, med_2000 &gt; 0) AS percent_change\nFROM\n(\n   SELECT\n       code,\n       medianIf(price, year = 2000) AS med_2000,\n       medianIf(price, year = 2020) AS med_2020\n   FROM\n   (\n       SELECT\n           date,\n           price,\n           locality,\n           town,\n           district,\n           county,\n           code\n       FROM uk_price_paid\n       LEFT JOIN blogs.uk_codes AS codes ON (uk_price_paid.county = codes.name) OR (uk_price_paid.district = codes.name) OR (uk_price_paid.town = codes.name) OR (uk_price_paid.locality = codes.name) OR (replaceAll(uk_price_paid.district, 'CITY OF ', '') = codes.name)\n   )\n   WHERE (code != '') AND ((toYear(date) = 2000) OR (toYear(date) = 2020))\n   GROUP BY\n       code,\n       toYear(date) AS year\n   ORDER BY code ASC\n)\nGROUP BY code\nORDER BY percent_change DESC\n</p> <a target=\"_blank\" href=\"https://sql.clickhouse.com/?query_id=W2VWYX9FLEK9MPXFEVM9UR\">✎</a>\n</pre>\n<p>Using the country map we can in turn visualize this.</p>\n<p><a target=\"_blank\" href=\"https://clickhouse.com/uploads/superset_country_map_d2e2b52147.gif\">\n         <span><img alt=\"superset-country-map.gif\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2Fsuperset_country_map_d2e2b52147.gif&w=2048&q=75\"></span>\n</a></p><p>Superset offers a box plot visualization, effective for showing the distributions of a metric across multiple groups. This allows us to show how precipitation varies per country using the weather dataset explored in a <a target=\"_blank\" href=\"https://clickhouse.com/blog/real-world-data-noaa-climate-data\">previous post</a>. For this, we need a simple mapping of <a target=\"_blank\" href=\"https://raw.githubusercontent.com/mysociety/gaze/master/data/fips-10-4-to-iso-country-codes.csv\">fips 10-4 codes</a> to country names. Recall that the first 2 digits of the station id for the weather dataset represent a fips country code. Our mapping is this then loaded into a ClickHouse Complex Key Hashed dictionary, using our table as a source, for use in the following query via the <a target=\"_blank\" href=\"https://clickhouse.com/docs/en/sql-reference/functions/ext-dict-functions/#dictget-dictgetordefault-dictgetornull\">dictGet</a> function.</p>\n<pre><p>\nCREATE TABLE blogs.country_codes (\n   `name` LowCardinality(String),\n   `code` LowCardinality(String)\n) ENGINE = MergeTree ORDER BY code\nINSERT INTO blogs.country_codes SELECT Name as name, `FIPS 10-4` as code FROM url('https://raw.githubusercontent.com/mysociety/gaze/master/data/fips-10-4-to-iso-country-codes.csv', 'CSVWithNames')\nCREATE DICTIONARY blogs.country_iso_codes\n(\n   `code` String,\n   `name` String\n)\nPRIMARY KEY code\nSOURCE(CLICKHOUSE(TABLE 'country_codes' DATABASE 'blogs'))\nLIFETIME(MIN 0 MAX 0)\nLAYOUT(COMPLEX_KEY_HASHED())\n</p> \n</pre>\n<p>Below we show the dataset being created from a query that computes the average precipitation per year by country. We limit the countries to those in the EU by their <a target=\"_blank\" href=\"https://en.wikipedia.org/wiki/List_of_FIPS_country_codes\">FIPS code</a>.  This can, in turn, be used to create our box plot.</p>\n<p><a target=\"_blank\" href=\"https://clickhouse.com/uploads/superset_box_plot_8b14bbb1cc.gif\">\n         <span><img alt=\"superset-box-plot.gif\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2Fsuperset_box_plot_8b14bbb1cc.gif&w=2048&q=75\"></span>\n</a></p><pre><p>\nSELECT year,\n       avg(`precipitation`) AS `avg_precipitation`,\n       dictGet(`blogs`.`country_iso_codes`, 'name', code) as country\nFROM `blogs`.`noaa_v2`\nWHERE date &gt; '1970-01-01' AND code IN ('AL', 'AN', 'AU', 'BE', 'BO', 'CY', 'DA', 'EI', 'EZ', 'EN', 'FI', 'FR', 'GG', 'GI', 'GK', 'GM',\n'GR', 'HR', 'HU', 'IC', 'IM', 'IT', 'JE', 'LG', 'LH', 'LO', 'LS', 'LU', 'MD', 'MK', 'MN', 'MT', 'NL', 'NO', 'PL', 'PO', 'RO', 'SI', 'SM',\n'SP', 'SW', 'SZ', 'TU', 'UK', 'UP', 'VT')\nGROUP BY toStartOfYear(`date`) AS `year`,\n         substring(station_id, 1, 2) as code\nHAVING avg_precipitation &gt; 0         \nORDER BY country, year ASC\nLIMIT 100000\n</p> <a target=\"_blank\" href=\"https://sql.clickhouse.com/?query_id=EDQSLZ32CKBUWT1QQJ6TWM\">✎</a>\n</pre>\n<p>As well as offering your usual numerical analysis charts, Superset allows some simple text analysis with a word cloud. Focusing on the Hacker News dataset from our <a target=\"_blank\" href=\"https://clickhouse.com/blog/getting-data-into-clickhouse-part-1\">earlier post</a>, we can use the <a target=\"_blank\" href=\"https://clickhouse.com/docs/en/sql-reference/functions/splitting-merging-functions/#alphatokenss\">tokenization</a> and <a target=\"_blank\" href=\"https://clickhouse.com/docs/en/sql-reference/functions/array-functions\">array functions</a> to identify the top N 2-term phrases (shingles).</p>\n<pre><p>\nWITH stop_words AS\n   (\n       SELECT token\n       FROM blogs.stop_words\n   )\nSELECT\n   phrase,\n   count() AS c\nFROM\n(\n   SELECT\n       arrayJoin(shingles) AS shingle,\n       concat(shingle.1, ' ', shingle.2) AS phrase\n   FROM\n   (\n       SELECT\n           tokens,\n           arrayFilter(t -&gt; (NOT ((t.2) IS NULL)), arrayZip(tokens, arrayPushBack(arrayPopFront(tokens), NULL))) AS shingles\n       FROM\n       (\n           SELECT arrayFilter(t -&gt; ((t NOT IN (stop_words)) AND (length(t) &gt; 2)), alphaTokens(title)) AS tokens\n           FROM default.hackernews\n           WHERE (type IN ('story', 'comment'))\n       )\n       WHERE length(tokens) &gt; 0\n   )\n)\nGROUP BY phrase\nORDER BY c DESC\nLIMIT 20\n</p> <a target=\"_blank\" href=\"https://sql.clickhouse.com/?query_id=PW9DCFW8AWGRHYHHQ7TODQ\">✎</a>\n</pre>\n<p>Note how we exclude phrases containing stop words.
