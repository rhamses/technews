As well as supporting the full breadth of <a target=\"_blank\" href=\"https://clickhouse.com/docs/en/sql-reference/functions\">ClickHouse functions</a>, JSON is also one of the many <a target=\"_blank\" href=\"https://clickhouse.com/docs/en/sql-reference/formats/\">supported file formats</a>. The benchmark compares several command-line tools with a focus on querying large files that fit into the disk of a standard machine but might not fit into memory.   A 10GB subset of the <a target=\"_blank\" href=\"http://deepyeti.ucsd.edu/jianmo/amazon\">Amazon book reviews dataset</a> was used as the test dataset. The original list of tools used in the benchmark was SPySQL, jq, trdsql, Miller, OctoSQL, spqrk-sql, Pandas, and DSQ. The benchmark itself focused on 3 challenges:</p>\n<ul>\n<li>Map: a new column is calculated for all rows (batch input and output are large). This represents a common ETL-like task required for data cleansing and enrichment.</li>\n<li>Aggregation/Reduce: the average of all rows of a column is calculated (only the input is large). Useful to users who need a quick analytical answer and want to avoid the steps of loading the data into a data store such as ClickHouse.</li>\n<li>Subset/Filter: the first 100 values of a column matching filter criteria are returned (only a part of the input needs to be processed). The objective of this test is to assess the tool's ability to sample files quickly and represents a task users often perform before iterating on a query.</li>\n</ul>\n<p>The first set of results for this benchmark showed SPySQL as the fastest tool for querying large JSON files:</p>\n<p><span><img alt=\"initial_results.png\" src=\"https://clickhouse.com/_next/image?url=%2Fuploads%2Finitial_results_cb29f85d92.png&w=2048&q=75\"></span></p>\n<p>But Daniel was unaware of the clickhouse-local. To assist with this task, ClickHouse recently introduced two cool features that make it easy and straightforward to process JSON files and reproduce this benchmark: support for semi-structured data storage and automatic schema inference.  The latter feature allows ClickHouse to infer the types of columns from the data itself so that the user is not required to specify the structure of JSON files and the type of each field: simplifying the syntax and accelerating the getting started experience.</p>\n<p>After contacting  Daniel, he promptly added clickhouse-local to his benchmarks and updated the results. To his surprise, clickhouse-local was faster than all previous tools. One of the developers of OctoSQL (written in Go) also asked to update the benchmark in accordance with the latest improvements with good results.
