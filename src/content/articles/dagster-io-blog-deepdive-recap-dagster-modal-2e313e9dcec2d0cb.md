In many teams, the challenge comes when trying to manage this infrastructure without getting slammed with complex configurations, like writing Kubernetes YAML or managing GPU operators.</p><p>In our most recent Dagster Deep Dive, led by Colton Padden (Developer Advocate at Dagster) and Charles Frye (AI Engineer at Modal), we jumped into how using <a target=\"_blank\" href=\"https://dagster.io/\">Dagster</a> and <a target=\"_blank\" href=\"https://modal.com/\">Modal</a> together help automate and streamline these processes so that they become more developer-friendly and scalable.</p><p>In case you missed it (or just want to watch it over again), I’ve embedded the video below.</p><figure><p></p><figcaption>Orchestrating Flexible Compute for ML with Dagster and Modal (A Dagster Deep Dive)</figcaption></figure><p>‍</p><h2>Highlights</h2><p>The deep dive covered different ways of using Dagster and Modal for machine learning workflows. Here’s a rundown of the main points Colton and Charles discussed:</p><h3>Orchestration with Dagster</h3><p>Colton began the demo by talking about Dagster’s ability to orchestrate ML pipelines. He highlighted key Dagster features like <a target=\"_blank\" href=\"https://docs.dagster.io/guides/build/assets/defining-assets\">asset-based workflows</a> for managing data dependencies, <a target=\"_blank\" href=\"https://docs.dagster.io/guides/build/partitions-and-backfills\">partitioned assets</a> for handling time-series data, and <a target=\"_blank\" href=\"https://docs.dagster.io/guides/automate/sensors\">sensors</a> for triggering runs based on external events, such as a new episode of a podcast.</p><p>Colton finished up this segment by talking about how Dagster could integrate with different compute environments through <a target=\"_blank\" href=\"https://github.com/dagster-io/dagster/discussions/16319\">Dagster Pipes</a>.</p><h3>Scalable Infrastructure with Modal</h3><p>Charles followed up by showing Modal’s scaling capabilities and explaining how it can easily parallelize workloads. He demonstrated this by splitting podcast audio and transcribing multiple segments simultaneously. &#160;The code and file structure for the podcast summary demo. &#160;</figcaption></figure><p>The demo ultimately and effectively showed the combined strength of Dagster’s orchestration and Modal’s scalable computing power.</p><h2>Takeaways</h2><p>Here’s the TL:DR of all of the insights from the deep dive.</p><ul><li>Dagster’s orchestration and Modal’s scalable infrastructure give you a strong solution for machine learning pipelines, particularly for tasks needing parallelism like audio transcription and large-scale data processing.</li><li>Modal offers flexibility without complexity, giving you a way to scale GPU workloads without needing to deal with complex Kubernetes configurations so you can focus on development.</li><li>Being able to rerun specific assets or pipelines through Dagster’s UI while relying on Modal’s support for parallel workloads lets you handle production-ready machine learning systems.</li><li>Dagster’s developer-friendly features (partitions, sensors, and cursors) let you orchestrate and simplify pipelines for engineers, especially when dealing with data sources like RSS feeds</li></ul><h2>Conclusion</h2><p>With Dagster and Modal, teams can streamline and optimize their machine learning pipelines while reducing infrastructure complexity.
