contentHtml: "<div><p>dbt™ has become an industry standard for structuring SQL transformations within a warehouse. But teams using dbt still struggle with orchestration: scheduling their dbt models and running them in step with the other data assets in their data platforms.</p><p>We first presented <a target=\"_blank\" href=\"https://dagster.io/integrations/dagster-dbt\">Dagster’s dbt integration</a> in October 2020. Since then, Dagster + dbt usage has ramped up, and now over half of Dagster users <a href=\"https://docs.dagster.io/integrations/libraries/dbt/using-dbt-with-dagster/load-dbt-models\" target=\"_blank\">run dbt models</a> as part of their data pipelines. In Dagster’s latest release – 1.4 – we’ve put a heavy focus on Dagster’s dbt integration, making it both more flexible and easier to get started. &#160;With the latest improvements, we believe Dagster is far and away the best way to orchestrate dbt.</p><p>This isn’t because Dagster has more features than the alternatives, although it has a wide set of capabilities. It’s because <strong>Dagster’s core design principles go really well together with dbt</strong>. The similarities between the way that Dagster thinks about data pipelines and the way that dbt thinks about data pipelines means that Dagster can orchestrate dbt much more faithfully than other general-purpose orchestrators like Airflow.</p><p>At the same time, Dagster is able to compensate for dbt’s biggest limitations. dbt is rarely used in a vacuum: the data transformed using dbt needs to come from somewhere and go somewhere. When a data platform needs more than just dbt, Dagster is a better fit than dbt-specific orchestrators, like the job scheduling system inside dbt Cloud.</p><h2>Why Dagster is the best way to orchestrate dbt</h2><p>Looking to migrate off dbt Cloud? &#160;Check out the step-by-step migration guide.</p><p><a target=\"_blank\" href=\"https://dagster.io/vs/dagster-vs-dbt-cloud\"> &#160; &#160; &#160; &#160; &#160; &#160; &#160; &#160;Check out the migration guide &#160; &#160; &#160; &#160; &#160; &#160;</a>. &#160; &#160;</p><h4>Dagster and dbt share a mental model</h4><p>One of the elements of dbt that makes it so intuitive and powerful is that it centers on data assets. When you build a data pipeline using dbt, each model you define is one of the tables or intermediate datasets that make up your pipeline.</p><p>From the very beginning, you’re thinking about the data products that your pipeline is there to support. <a target=\"_blank\" href=\"https://dagster.io/glossary/data-lineage\">Data lineage</a> comes automatically because the references between your tables are part of how you define your data pipeline.</p><p>Like dbt, Dagster puts data assets at the center. Dagster pipelines are graphs of connected data assets.</p><p>This means that Dagster can understand a dbt project at a really deep level. When you use Dagster’s dbt integration to load your dbt project into Dagster, you get a faithful representation of your dbt models and the connections between them, inside Dagster.</p><p>Unlike other orchestrators, Dagster doesn’t need to run each dbt model in a separate task, which incurs a lot of overhead. Dagster can execute a full dbt project (or project sub-selection) with a single invocation of the dbt CLI, but still provide observability at the level of individual models.</p><p>Automatically load your models as Dagster assets<br>by importing your dbt project in Dagster Cloud.</p><p><a href=\"https://dagster.cloud/signup?next=/prod/getting-started%3Ftab%3Dimport_dbt_core_project%26serverless%3D1\" target=\"_blank\"> &#160; &#160; &#160; &#160; &#160; &#160; &#160; &#160;Check out Dagster Cloud &#160; &#160; &#160; &#160; &#160; &#160;</a></p><h4>Work beyond dbt: cross-technology, cross-team collaboration</h4><p>Beyond understanding and enhancing your dbt work, Dagster provides the framework needed by teams working with dbt as part of a larger data platform.</p><p>A Dagster data asset can be a dbt model, but can equally be:</p><ul><li>A table ingested using a tool like Fivetran, Stitch, or Airbyte</li><li>A machine learning model</li><li>A dataset of images</li><li>A file</li></ul><p>You can compute Dagster assets using any Python code, running on any platform.</p><p>This means that you can build Dagster pipelines that connect the models in your dbt project to these other kinds of data assets, allowing you to orchestrate and track lineage across your entire organization.</p><p>For example, you might have a machine learning team that trains models using data that’s transformed using dbt. &#160;Dagster makes it easy to kick off ML training and <a target=\"_blank\" href=\"https://dagster.io/glossary/schema-inference\">inference</a> based on changes to dbt models, and it can render the lineage between the ML models and the dbt models they depend on. &#160;Dagster was built from the start for organization-wide collaboration and execution at the enterprise scale. &#160;It has a set of abstractions that make it easy to scope what you’re doing to the parts of the pipeline that you own, but zoom out to the entire asset graph spanning multiple data teams when you need to.</p><h4>A full orchestration feature set</h4><p>Dagster provides a greater depth of orchestration features when compared to dbt-specific tools like dbt Cloud. &#160;Orchestration has been Dagster’s primary job since its inception, and over that time, it’s grown to handle a very long tail of orchestration needs. trigger dbt model runs, so you're not limited to cron-based scheduling. You can check for source data freshness, incorporate business calendars, or apply any custom logic your use case requires.</p><h3>Can Dagster orchestrate more than just dbt?</h3><p>Yes. Dagster assets can represent dbt models, ingestion tools like Fivetran or Airbyte, machine learning models, files, and any other data asset computed with Python. This lets you build pipelines that connect dbt to the rest of your data platform.</p><h3>When does dbt Cloud fall short as an orchestration solution?</h3><p>dbt Cloud works for small analytics engineering teams with basic scheduling needs, but it lacks full-featured orchestration: no source-aware scheduling, no native asset observability, and limited alerting. Dagster has native partitioning support, allowing you to update data incrementally without dropping and recreating entire tables, while maintaining a clear record of each asset's status.</p><h3>Is Dagster open source?</h3><p>Yes.
