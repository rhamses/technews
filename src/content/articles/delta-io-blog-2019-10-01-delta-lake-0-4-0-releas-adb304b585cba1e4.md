The key features in this release are:</p>\n<ul>\n<li><strong>Python APIs for DML and utility operations (<a target=\"_blank\" href=\"https://github.com/delta-io/delta/issues/89\">#89</a>)</strong> - You can now use Python APIs to update/delete/merge data in Delta Lake tables and to run utility operations (i.e., vacuum, history) on them. These are great for building complex workloads in Python, e.g.,&#160;<a target=\"_blank\" href=\"https://docs.delta.io/0.4.0/delta-update.html#slowly-changing-data-scd-type-2-operation-into-delta-tables\">Slowly Changing Dimension (SCD)</a>&#160;operations, merging&#160;<a target=\"_blank\" href=\"https://docs.delta.io/0.4.0/delta-update.html#write-change-data-into-a-delta-table\">change data</a>&#160;for replication, and&#160;<a target=\"_blank\" href=\"https://docs.delta.io/0.4.0/delta-update.html#upsert-from-streaming-queries-using-foreachbatch\">upserts from streaming queries</a>. See the&#160;<a target=\"_blank\" href=\"https://docs.delta.io/0.4.0/delta-update.html\">documentation</a>&#160;for more details.</li>\n<li><strong>Convert-to-Delta (<a target=\"_blank\" href=\"https://github.com/delta-io/delta/issues/78\">#78</a>)</strong> - You can now convert a Parquet table in place to a Delta Lake table without rewriting any of the data. This is great for converting very large Parquet tables which would be costly to rewrite as a Delta table. Furthermore, this process is reversible - you can convert a Parquet table to Delta Lake table, operate on it (e.g., delete or merge), and easily convert it back to a Parquet table. See the&#160;<a target=\"_blank\" href=\"https://docs.delta.io/0.4.0/delta-utility.html#convert-to-delta\">documentation</a>&#160;for more details.</li>\n<li><strong>SQL for utility operations</strong> - You can now use SQL to run utility operations vacuum and history. See the&#160;<a target=\"_blank\" href=\"https://docs.delta.io/0.4.0/delta-utility.html#enable-sql-commands-within-apache-spark\">documentation</a>&#160;for more details on how to configure Spark to execute these Delta-specific SQL commands.</li>\n</ul>\n<p>To try out Delta Lake 0.4.0, please follow the&#160;<a target=\"_blank\" href=\"https://delta.io/learn/getting-started\">Getting Started guide</a>.</p>\n<p>Visit the&#160;<a target=\"_blank\" href=\"https://github.com/delta-io/delta/releases/tag/v0.4.0\">release notes</a> to learn more about the release.</p>  </div>        </div>"
