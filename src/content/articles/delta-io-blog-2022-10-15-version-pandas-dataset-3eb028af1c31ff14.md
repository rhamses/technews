contentHtml: "<div>  <p>This post shows how you can easily version your datasets with pandas and the incredible benefits this provides. Versioned data lets you time travel, undo mistakes, and append data to existing datasets in a safe manner. It also lets you run your models on the same dataset over different points in time to see how the new data has impacted your model accuracy.</p>\n<p>All the computations in this post are in <a target=\"_blank\" href=\"https://github.com/MrPowers/delta-examples/blob/master/notebooks/pandas/pandas-versioned-dataset.ipynb\">this Jupyter Notebook</a>, so you can run this code on your machine and follow along.</p>\n<h2 id=\"install-delta-lake-and-pandas\">Install Delta Lake and pandas</h2>\n<p>You can install Delta Lake with <code>pip install deltalake</code> and install pandas with <code>pip install pandas</code>.</p>\n<p><code>deltalake</code> is the Python interface for the <a target=\"_blank\" href=\"https://github.com/delta-io/delta-rs/\">delta-rs</a> project. delta-rs is written in Rust, but you can use it just like any other Python library via the Python bindings.</p>\n<p>Delta Lake was originally built for Spark, but the <code>deltalake</code> implementation does not have a Spark dependency. <code>delta-spark</code> depends on Spark, <code>deltalake</code> does not.</p>\n<h2 id=\"create-a-versioned-delta-lake-with-pandas\">Create a versioned Delta Lake with pandas</h2>\n<p>You can easily write out a pandas DataFrame to a Delta table.</p>\n<p>Start by importing pandas and creating the pandas DataFrame. You can run this command in a Jupter notebook or your command line:</p>\n<pre><code><span><span>import pandas as pd</span></span>\n<span><span></span></span>\n<span><span>df = pd.DataFrame({\"x\": [1, 2, 3]})</span></span></code></pre>\n<p>Now write out the pandas DataFrame to a Delta table. You need to create the directory where the Delta table will be written.</p>\n<pre><code><span><span>import os</span></span>\n<span><span>from deltalake.writer import write_deltalake</span></span>\n<span><span></span></span>\n<span><span>os.makedirs(\"tmp/some_delta_lake\", exist_ok=True)</span></span>\n<span><span>write_deltalake(\"tmp/some_delta_lake\", df)</span></span></code></pre>\n<p>Delta Lake stores the data in a Parquet file and keeps a transaction log that records the data operations performed on the table. The transaction log allows for versioned data and time travel.</p>\n<p>Read in the Delta table to another pandas DataFrame to make sure it’s easily accessible:</p>\n<pre><code><span><span>from deltalake import DeltaTable</span></span>\n<span><span></span></span>\n<span><span>dt = DeltaTable(\"tmp/some_delta_lake\")</span></span>\n<span><span>dt.to_pandas()</span></span>\n<span><span></span></span>\n<span><span>      x</span></span>\n<span><span>0     1</span></span>\n<span><span>1     2</span></span>\n<span><span>2     3</span></span></code></pre>\n<p>Now let’s use pandas to add some more data to the Delta table.</p>\n<h2 id=\"append-to-a-versioned-dataset-with-pandas\">Append to a versioned dataset with pandas</h2>\n<p>Create another pandas DataFrame and append it to the Delta table.</p>\n<pre><code><span><span>df2 = pd.DataFrame({\"x\": [9, 8, 10]})</span></span>\n<span><span></span></span>\n<span><span>write_deltalake(\"tmp/some_delta_lake\", df2, mode=\"append\")</span></span></code></pre>\n<p>Read the Delta table contents to make sure the data was correctly appended:</p>\n<pre><code><span><span>DeltaTable(\"tmp/some_delta_lake\").to_pandas()</span></span>\n<span><span></span></span>\n<span><span>      x</span></span>\n<span><span>0     1</span></span>\n<span><span>1     2</span></span>\n<span><span>2     3</span></span>\n<span><span>3     9</span></span>\n<span><span>4     8</span></span>\n<span><span>5     10</span></span></code></pre>\n<p>Our Delta table has two versions now. Version 0 contains the initial data and Version 1 includes the data that was appended.</p>\n<p><img src=\"https://delta.io/_astro/image1.CREzVHrJ_Z1Y9N8p.webp\"></p>\n<p>When you append data to a CSV or Parquet data lake, you’re always stuck reading the latest version of the dataset. Delta Lake gives you the amazing flexibility to be able to read prior versions of the data. Let’s see how to read Version 0 of the dataset.</p>\n<h2 id=\"time-travel-versioned-data-with-pandas\">Time travel versioned data with pandas</h2>\n<p>Here’s how to time travel to Version 0 of the dataset with pandas:</p>\n<pre><code><span><span>dt = DeltaTable(\"tmp/some_delta_lake\", version=0)</span></span>\n<span><span></span></span>\n<span><span>dt.to_pandas()</span></span>\n<span><span></span></span>\n<span><span>      x</span></span>\n<span><span>0     1</span></span>\n<span><span>1     2</span></span>\n<span><span>2     3</span></span></code></pre>\n<p>If you don’t specify the version, then you’ll read the latest version of the Delta table by default:</p>\n<pre><code><span><span>DeltaTable(\"tmp/some_delta_lake\").to_pandas()</span></span>\n<span><span></span></span>\n<span><span>      x</span></span>\n<span><span>0     1</span></span>\n<span><span>1     2</span></span>\n<span><span>2     3</span></span>\n<span><span>3     9</span></span>\n<span><span>4     8</span></span>\n<span><span>5     10</span></span></code></pre>\n<p>Let’s perform another transaction that will overwrite the contents of the Delta table with a new DataFrame.</p>\n<pre><code><span><span>df3 = pd.DataFrame({\"x\": [55, 66, 77]})</span></span>\n<span><span></span></span>\n<span><span>write_deltalake(\"tmp/some_delta_lake\", df3, mode=\"overwrite\")</span></span></code></pre>\n<p>Here are the different versions of the Delta table after the overwrite operation:</p>\n<p><img src=\"https://delta.io/_astro/image2.CPhJRH-r_16bQLG.webp\"></p>\n<p>Read in the latest version of the Delta table to confirm it has been updated:</p>\n<pre><code><span><span>DeltaTable(\"tmp/some_delta_lake\").to_pandas()</span></span>\n<span><span></span></span>\n<span><span>      x</span></span>\n<span><span>0     55</span></span>\n<span><span>1     66</span></span>\n<span><span>2     77</span></span></code></pre>\n<p>Now read in Version 0 of the dataset to confirm it’s still accessible:</p>\n<pre><code><span><span>DeltaTable(\"tmp/some_delta_lake\", version=0).to_pandas()</span></span>\n<span><span></span></span>\n<span><span>      x</span></span>\n<span><span>0     1</span></span>\n<span><span>1     2</span></span>\n<span><span>2     3</span></span></code></pre>\n<p>Also read in Version 1 of the dataset to confirm it’s still accessible:</p>\n<pre><code><span><span>DeltaTable(\"tmp/some_delta_lake\", version=1).to_pandas()</span></span>\n<span><span></span></span>\n<span><span>      x</span></span>\n<span><span>0     1</span></span>\n<span><span>1     2</span></span>\n<span><span>2     3</span></span>\n<span><span>3     9</span></span>\n<span><span>4     8</span></span>\n<span><span>5     10</span></span></code></pre>\n<p>All versions of the dataset remain accessible, even after overwrite operations. Accessing legacy versions of your data is impossible if you’re using CSV or Parquet data lakes.</p>\n<h2 id=\"schema-enforcement-prevents-bad-appends\">Schema enforcement prevents bad appends</h2>\n<p>Another advantage of Delta Lake is that it prevents you from appending data to a Delta table with a schema that doesn’t match the existing data. Parquet, CSV, and JSON data lakes, on the other hand, are easily corruptible because they let you append data with any schema.</p>\n<p>The Delta table we’ve been using thus far has a single <code>x</code> column. Let’s create another DataFrame with a single <code>y</code> column and see what happens when we try to append it to our existing Delta table.</p>\n<pre><code><span><span>df4 = pd.DataFrame({\"y\": [111, 222]})</span></span>\n<span><span></span></span>\n<span><span>write_deltalake(\"tmp/some_delta_lake\", df4, mode=\"append\")</span></span></code></pre>\n<p>Here’s the error you’ll get:</p>\n<pre><code><span><span>ValueError: Schema of data does not match table schema</span></span>\n<span><span>Table schema:</span></span>\n<span><span>y: int64</span></span>\n<span><span>-- schema metadata --</span></span>\n<span><span>pandas: '{\"index_columns\": [{\"kind\": \"range\", \"name\": null, \"start\": 0, \"' + 357</span></span>\n<span><span>Data Schema:</span></span>\n<span><span>x: int64</span></span></code></pre>\n<p>Delta Lake is doing you a huge favor here. It’s preventing you from corrupting your data lake.</p>\n<h2 id=\"interoperable-versioned-dataset\">Interoperable versioned dataset</h2>\n<p>Delta Lakes are interoperable with a variety of other technologies. You can read/write to Delta tables with Apache Flink, Apache Hive, Apache Kafka, PrestoDB, Apache Spark, Trino, and programming languages like Rust, Python, Scala, Java, and more.</p>\n<p>Here are some examples of how to use pandas and Delta Lake in your production ETL pipeline:</p>\n<ul>\n<li>You may use pandas and deltalake to build a data ingestion platform that incrementally updates a dataset every hour. This dataset may be too large to be queried by pandas, so perhaps you’ll query the data with Trino.</li>\n<li>Or you may do the opposite. Maybe you have a large dataset that can be aggregated and cleaned with Spark. If the Spark aggregation shrinks the data sufficiently, you can let downstream users query it with deltalake and pandas. This workflow is great for data scientists that are more comfortable with pandas.</li>\n</ul>\n<p>Delta Lake is a great way to build ETL pipelines with multiple technologies.</p>\n<h2 id=\"conclusion\">Conclusion</h2>\n<p>This post showed you how to create a versioned dataset with pandas and Delta Lake. It demonstrates how you can easily time travel between different versions of your data with pandas.</p>\n<p>You also saw how Delta Lake provides schema enforcement which prevents you from writing data with an incompatible schema to the Delta table. This prevents you from corrupting your dataset.</p>\n<p>Future blog posts will discuss even more advantages Delta Lake provides pandas programmers. Delta Lake offers many advantages, often at no cost, compared to file formats like CSV, Parquet, and JSON. Many pandas users can switch to Delta Lake and immediately start enjoying some significant data quality and performance benefits right away.</p>  </div>"
