contentHtml: "<div>  <h2 id=\"delta-lake-40-the-future-of-open-data-lakehouses\">Delta Lake 4.0: The Future of Open Data Lakehouses</h2>\n<p>We’re thrilled to announce the release of Delta Lake 4.0, a milestone release packed with powerful new features, performance optimizations, and foundational enhancements for the future of open data lakehouses. With new catalog integration, enhanced support for semi-structured data, smarter change tracking, and improved performance, this release delivers practical solutions to everyday data challenges.</p>\n<p>Let’s dive into the highlights!</p>\n<p>Delta Lake 4.0 is the result of a true community effort, with contributions from an incredible group of contributors from around the world. More than 70 individuals came together to deliver the features in this release.</p>\n<p>A big thank you to everyone who contributed code, ideas, feedback, and support. Your passion and commitment drive the Delta Lake project forward and help make the open data lakehouse vision a reality for organizations everywhere.</p>\n<p><img alt=\"Delta Lake 4.0 Features\" src=\"https://delta.io/_astro/delta-lake-4.0-features.Budau-mX_Z1dccGk.webp\"></p>\n<h2 id=\"spark-integration-laying-the-groundwork-for-the-future\">Spark Integration: Laying the Groundwork for the Future</h2>\n<h2 id=\"catalog-managed-tables-preview\">Catalog-Managed Tables (Preview)</h2>\n<p>Delta Lake 4.0 introduces catalog-managed tables as a preview feature—a major shift that enables seamless integration with catalogs. While Delta Lake continues to support its popular “filesystem-managed” tables, catalog-managed tables are the foundation for a whole new set of possibilities.</p>\n<p>Expect more advanced features like enhanced observability, foreign key constraints, and multi-table / multi-statement transactions built on this foundation in future releases!</p>\n<h2 id=\"delta-connect-extending-spark-connect\">Delta Connect: Extending Spark Connect</h2>\n<p>Delta Lake 4.0 brings Delta Connect: an extension that enables Delta-specific operations over the Spark Connect wire protocol. This means:</p>\n<ul>\n<li>Delta APIs everywhere: Access Delta Lake features from any Spark Connect client, including Python variants.</li>\n<li>Future-proofing: Server and client can evolve independently, making upgrades and integrations smoother than ever.</li>\n</ul>\n<h2 id=\"variant-data-type-embracing-semi-structured-data\">Variant Data Type: Embracing Semi-Structured Data</h2>\n<p>The new variant data type is a game-changer for anyone dealing with semi-structured data (think JSON payloads with evolving schemas):</p>\n<ul>\n<li>Schema-on-read: No need to define a rigid schema up front. Extract structured data at query time.</li>\n<li>Efficient storage: Store dynamic payloads efficiently, with high-performance encoding.</li>\n<li>Shredded Variants (Preview): Extract specific columns from variant data and collect statistics for faster queries and file skipping.</li>\n</ul>\n<p>This is a highly anticipated feature, developed with broad community support across many projects. Contributors from Apache Parquet, Apache Arrow, Apache Iceberg, Delta Lake, Apache Spark, and many more are coming together to deliver these features across the data ecosystem.</p>\n<h2 id=\"drop-feature-streamlined-table-evolution\">Drop Feature: Streamlined Table Evolution</h2>\n<p>Previously, removing a feature from a Delta table required truncating the entire history—a major pain point. With Delta Lake 4.0, dropping features retains table history, making it easier to evolve your tables and enable compatibility with more clients.</p>\n<h2 id=\"kernel-enhancements-performance-and-advanced-table-features\">Kernel Enhancements: Performance and Advanced Table Features</h2>\n<h2 id=\"version-checksums-faster-more-reliable-table-reads\">Version Checksums: Faster, More Reliable Table Reads</h2>\n<p>The Java kernel now supports reading and writing version checksums—think of them as mini-checkpoints for your Delta logs. Benefits include:\nAccelerated log parsing: Quickly access the most current protocol and metadata.\nDetailed metrics: File counts, table size, and data distribution histograms for stronger consistency and easier debugging.</p>\n<h2 id=\"log-compaction-read--write-support\">Log Compaction: Read &amp; Write Support</h2>\n<p>Kernel now supports reading and writing log compaction files, further optimizing table scan performance and reducing overhead for large tables.</p>\n<h2 id=\"advanced-table-feature-support\">Advanced Table Feature Support</h2>\n<p>This release contains some major improvements to the internal table features framework, which governs how table features are enabled in Delta Kernel. As part of this change, engines using Delta kernel can now write to tables with the deletionVectors, v2Checkpoint, and timestampNtz features enabled.</p>\n<p>On top of this, two foundational new table features are now supported.</p>\n<ul>\n<li>Row Tracking allows tracking individual rows across inserts, updates, and deletes and enables highly efficient implementations for Change Data Feeds</li>\n<li>Clustered Tables support enables Kernel to define and update the clustering columns on a table, making clustering information available for Delta clustering implementations.</li>\n</ul>\n<h2 id=\"file-statistics-enhanced-file-skipping\">File Statistics: Enhanced File Skipping</h2>\n<p>Improved support for writing file statistics means even more effective file skipping—speeding up queries and reducing resource usage.</p>\n<h2 id=\"looking-ahead\">Looking Ahead</h2>\n<p>Delta Lake 4.0 is a leap forward, setting the stage for even more powerful data warehouse features, greater flexibility, and blazing-fast performance. We’re excited to see what you build with it!</p>\n<h2 id=\"ready-to-get-started\">Ready to get started?</h2>\n<p>Check out the Delta Lake 4.0 documentation and join the conversation in our community forums.</p>  </div>"

We’re thrilled to announce the release of Delta Lake 4.0, a milestone release packed with powerful new features, performance optimizations, and foundational enhancements for the future of open data lakehouses. With new catalog integration, enhanced support for semi-structured data, smarter change tracking, and improved performance, this release delivers practical solutions to everyday data challenges.
