The table feature formerly called\n<span>catalogOwned-preview</span> is now named <span>catalogManaged</span>\nand the associated Unity Catalog table ID property has been updated to match (from\n<span>ucTableId</span> to <span>catalogManaged.unityCatalog.tableId</span>).</p>\n<p>This brings several benefits:</p>\n<ul>\n<li><strong>Clearer semantics</strong>: The new name better reflects what the feature does: enabling the catalog to manage table storage and commits.</li>\n<li><strong>Commit validation</strong>: the catalog now controls commit visibility and prevents invalid operations (e.g. commits that violate foreign key constraints) and enforces access controls.</li>\n<li><strong>Better Unity Catalog alignment</strong>: Property names now follow Unity Catalog naming conventions, enhancing integration.</li>\n<li><strong>Production readiness</strong>: The removal of <span>-preview</span> from the feature name signals stability and readiness for broader use.</li>\n</ul>\n<blockquote>\n<p>If you’ve already been exploring catalog-managed tables, you’ll need to update your table properties to use the new naming\nconventions to continue using this experimental feature.</p>\n</blockquote>\n<h2 id=\"oauth-authentication-for-unity-catalog\">OAuth Authentication for Unity Catalog</h2>\n<p>🔥 <strong>You can now authenticate to Unity Catalog using OAuth, with automatic token acquisition and refresh.\nNo more static tokens required.</strong></p>\n<p>Delta Lake 4.0.1 adds OAuth-based authentication for <a target=\"_blank\" href=\"https://github.com/unitycatalog/unitycatalog/releases/tag/v0.3.1\">Unity Catalog (0.3.1)</a>\nthrough a new catalog-scoped <span>auth.*</span> configuration.
