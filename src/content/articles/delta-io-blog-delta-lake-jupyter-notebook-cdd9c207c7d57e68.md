contentHtml: "<div>  <p>This post shows you how to use Delta Lake in Jupyter Notebooks.</p>\n<p>Jupyter notebooks are a great tool for data analysis in Python. They are easy to use and give you an intuitive, interactive interface to process and visualize your data.</p>\n<p>Many Python data professionals use Delta Lake from a Jupyter Notebook. This is a great setup for running exploratory data analysis, for collaborating across teams and organizations, and for tasks that require interactive code execution.</p>\n<p>This post will show you how you can use Delta Lake from a Jupyter Notebook.</p>\n<p><img src=\"https://delta.io/_astro/image1.CVJovtUe_1MFrKx.webp\"></p>\n<h2 id=\"delta-lake-from-a-jupyter-notebook\">Delta Lake from a Jupyter Notebook</h2>\n<p>There are 2 ways to use Delta Lake from a Jupyter Notebook:</p>\n<ol>\n<li>Use <a target=\"_blank\" href=\"https://pypi.org/project/delta-spark/\">delta-spark</a> with PySpark</li>\n<li>Use Python deltalake (aka <a target=\"_blank\" href=\"https://pypi.org/project/deltalake/\">delta-rs</a>) with other query engines like pandas or polars</li>\n</ol>\n<p>Use delta-spark if you are using the Spark query engine. If you are not using Spark yet, you may still want to use delta-spark if you have large enough workloads that would benefit from Spark’s distributed computing.</p>\n<p>Use delta-rs if you are more familiar with Python data processing engines like pandas, polars, Dask, Daft and Datafusion.</p>\n<p>Let’s dive into using Delta Lake from a Jupyter Notebook with Spark.</p>\n<h2 id=\"delta-lake-from-a-jupyter-notebook-with-spark\">Delta Lake from a Jupyter Notebook with Spark</h2>\n<p>You can use Delta Lake from a Jupyter notebook with PySpark.</p>\n<p>Here is a toy example that shows how you can write and read a Delta Lake table with PySpark.</p>\n<pre><code><span><span># create a dataframe</span></span>\n<span><span>data = [</span></span>\n<span><span>    {'first_name': 'bob', 'age': 47},</span></span>\n<span><span>    {'first_name': 'li', 'age': 23},</span></span>\n<span><span>    {'first_name': 'leah', 'age': 51}</span></span>\n<span><span>]</span></span>\n<span><span></span></span>\n<span><span>df = spark.createDataFrame(data=data)</span></span>\n<span><span></span></span>\n<span><span># write data to delta table</span></span>\n<span><span>df.write.format(\"delta\").save(\"/tmp/spark-delta-table\")</span></span>\n<span><span></span></span>\n<span><span># read delta table</span></span>\n<span><span>df = spark.read.format(\"delta\").load(\"/tmp/spark-delta-table\")</span></span>\n<span><span>df.show()</span></span>\n<span><span></span></span>\n<span><span>+------------+---------------+</span></span>\n<span><span>|         age|     first_name|</span></span>\n<span><span>+------------+---------------+</span></span>\n<span><span>|[47, 23, 51]|[bob, li, leah]|</span></span>\n<span><span>|    [33, 68]|   [suh, anais]|</span></span>\n<span><span>|    [33, 68]|   [suh, anais]|</span></span>\n<span><span>+------------+---------------+</span></span></code></pre>\n<p>When using Delta Lake with PySpark, you need to make sure that you are using compatible versions. This is a common pain point for users, but it is easily solved.</p>\n<p>There are 3 ways to make sure you have the right Delta Lake and PySpark versions:</p>\n<ol>\n<li>Create a virtual environment that pins the right versions, e.g. with conda.</li>\n<li>Use the official <a target=\"_blank\" href=\"https://github.com/delta-io/delta-docker\">Delta Lake Docker image</a>.</li>\n<li>Consult the <a target=\"_blank\" href=\"https://docs.delta.io/latest/releases.html\">compatibility matrix</a> and install the right versions manually.</li>\n</ol>\n<h3 id=\"virtual-environment\">Virtual Environment</h3>\n<p>The easiest way to ensure you have the right versions of Delta-spark and PySpark is to create a virtual Python environment with Conda. <a target=\"_blank\" href=\"https://docs.conda.io/projects/conda/en/stable/#\">Conda</a> is a package manager for Python.</p>\n<p>To create a conda environment with the latest compatible versions of PySpark and delta-spark, follow the steps below:</p>\n<ol>\n<li>\n<p>Create a .yml file with the following contents and name it <code>pyspark-350-delta-320.yml</code>:</p>\n<pre><code><span><span>name: pyspark-350-delta-320</span></span>\n<span><span>channels:</span></span>\n<span><span> - conda-forge</span></span>\n<span><span> - defaults</span></span>\n<span><span>dependencies:</span></span>\n<span><span> - python=3.11</span></span>\n<span><span> - ipykernel</span></span>\n<span><span> - jupyterlab</span></span>\n<span><span> - jupyterlab_code_formatter</span></span>\n<span><span> - isort</span></span>\n<span><span> - black</span></span>\n<span><span> - pyspark=3.5.0</span></span>\n<span><span> - pip</span></span>\n<span><span> - pip:</span></span>\n<span><span>   - delta-spark==3.2.0</span></span></code></pre>\n<p><em>Note: This creates an environment with the latest PySpark and Delta-spark versions. You can create environments with older compatible versions using the .yml files in the <a target=\"_blank\" href=\"https://github.com/delta-io/delta-examples/tree/master/envs\">Delta Examples repository</a>.</em></p>\n</li>\n<li>\n<p>Make sure you have <a target=\"_blank\" href=\"https://conda.io/projects/conda/en/latest/user-guide/install/index.html\">installed Conda</a>.</p>\n</li>\n<li>\n<p>Open a terminal window and create a new conda virtual environment from the .yml file using the following:</p>\n<p><code>conda env create -f pyspark-350-delta-310.yml</code></p>\n</li>\n<li>\n<p>Activate the environment to use it:</p>\n<p><code>conda activate pyspark-350-delta-310.yml</code></p>\n</li>\n<li>\n<p>Launch a Jupyter notebook by running <code>jupyter lab</code> from the command line. You can select an existing notebook or launch a new one from <code>File &gt; New &gt; Notebook</code>.</p>\n</li>\n<li>\n<p>Use Delta Lake with PySpark</p>\n</li>\n</ol>\n<p>Let’s work through a simple example of using Delta Lake with PySpark in a Jupyter notebook.</p>\n<p>Start by importing PySpark and Delta Lake and initializing your Spark session:</p>\n<pre><code><span><span>```</span></span>\n<span><span>import pyspark</span></span>\n<span><span>from delta import *</span></span>\n<span><span></span></span>\n<span><span>builder = (</span></span>\n<span><span>    pyspark.sql.SparkSession.builder.appName(\"MyApp\")</span></span>\n<span><span>    .config(\"spark.sql.extensions\", \"org.apache.spark.sql.delta.catalog.DeltaCatalog\",</span></span>\n<span><span>    )</span></span>\n<span><span>)</span></span>\n<span><span></span></span>\n<span><span>spark = configure_spark_with_delta_pip(builder).getOrCreate()</span></span>\n<span><span>```</span></span></code></pre>\n<p>Next, let’s create some toy data to work with:</p>\n<pre><code><span><span>```</span></span>\n<span><span>data = [</span></span>\n<span><span>    {\"first_name\": \"bob\", \"age\": 47},</span></span>\n<span><span>    {\"first_name\": \"li\", \"age\": 23},</span></span>\n<span><span>    {\"first_name\": \"leah\", \"age\": 51},</span></span>\n<span><span>]</span></span>\n<span><span></span></span>\n<span><span>df = spark.createDataFrame(data=data)</span></span>\n<span><span>```</span></span></code></pre>\n<p>And write this DataFrame out to a Delta Lake table on disk:</p>\n<pre><code><span><span>`df.write.format(\"delta\").save(\"/tmp/spark-delta-table\")`</span></span></code></pre>\n<p>You can read this Delta table back into your Spark session like this:</p>\n<pre><code><span><span>```</span></span>\n<span><span>df = You will need to have <a target=\"_blank\" href=\"https://docs.docker.com/get-docker/\">Docker installed</a> on your machine.</p>\n<p>To use Delta Lake from a Jupyter Notebook with this Docker image, follow the steps below to build a Docker Image with Apache Spark and Delta Lake installed:</p>\n<ol>\n<li>\n<p>Clone the <a target=\"_blank\" href=\"https://github.com/delta-io/delta-docker\">delta-docker</a> repo to your machine</p>\n</li>\n<li>\n<p>Navigate to the cloned folder</p>\n</li>\n<li>\n<p>Open a terminal window</p>\n</li>\n<li>\n<p>Execute the following from the cloned repo folder:</p>\n<p><code>docker build -t delta_quickstart -f Dockerfile_delta_quickstart</code></p>\n</li>\n<li>\n<p>Run a container from the image with a JuypterLab entry point</p>\n<p><code>docker run --name delta_quickstart --rm -it -p 8888-8889:8888-8889 delta_quickstart</code></p>\n</li>\n</ol>\n<p>Alternatively, you can also download the image from DockerHub at Delta Lake DockerHub:</p>\n<ol>\n<li><code>docker pull deltaio/delta-docker:latest</code> for the standard Linux docker</li>\n<li><code>docker pull deltaio/delta-docker:latest_arm64</code> for running this optimally on your Mac M1</li>\n</ol>\n<h3 id=\"manual-implementation\">Manual Implementation</h3>\n<p>The final option to run Delta Lake with PySpark is to check the <a target=\"_blank\" href=\"https://docs.delta.io/latest/releases.html\">Compatibility Matrix</a> in the Delta Lake documentation. You can then manually install compatible PySpark and Delta Lake versions, for example using pip.</p>\n<p>This method is fine for quick testing. It is not recommended for production environments that require robust reliability and reproducible notebooks.</p>\n<h3 id=\"disabling-logging-output\">Disabling Logging Output</h3>\n<p>By default, running PySpark in Jupyter Notebooks can output logging information that is displayed as red lines. This is due to a change in <a target=\"_blank\" href=\"https://github.com/ipython/ipykernel/releases/tag/6.0.0\">ipykernel 6.0.0</a> which forwards low-level output to your notebook display.\nThe logging data is purely informational and does not mean anything is wrong with your code.</p>\n<p>This can look like something this:</p>\n<p><img src=\"https://delta.io/_astro/image2.CPcZ6Mnc_Z1GWGR1.webp\"></p>\n<p>You can disable this logging with the <a target=\"_blank\" href=\"https://ipython.readthedocs.io/en/stable/config/options/kernel.html#configtrait-IPKernelApp.capture_fd_output\">capture fd output</a> flag in your iPython profile config.</p>\n<p>To do so:</p>\n<ol>\n<li>Run <code>ipython profile create</code> from a terminal window</li>\n<li>Add the following line to your <code>~/.ipython/profile_default/ipython_config.py</code> file:\n<code>c.IPKernelApp.capture_fd_output = False</code></li>\n<li>Important: Clear your browser cache</li>\n<li>Restart your notebook kernel if you already had it running</li>\n</ol>\n<p>Your cell outputs should now look like this:</p>\n<p><img src=\"https://delta.io/_astro/image3.gybWtnTG_Z1nhV7l.webp\"></p>\n<h2 id=\"delta-lake-from-a-jupyter-notebook-with-delta-rs\">Delta Lake from a Jupyter Notebook with delta-rs</h2>\n<p>You don’t need to know Spark to use Delta Lake. You can also use Delta Lake from many other Python or SQL query engines, including:</p>\n<ul>\n<li>pandas</li>\n<li>polars</li>\n<li>Dask</li>\n<li>Daft</li>\n<li>Datafusion</li>\n<li>DuckDB</li>\n</ul>\n<p>Use <a target=\"_blank\" href=\"https://delta-io.github.io/delta-rs/\">delta-rs</a> to run analyses with these query engines on Delta Lake tables.</p>\n<p>There are no compatibility issues with running delta-rs. To get started, simply <code>pip install deltalake</code> along with your favorite query engine.</p>\n<h3 id=\"delta-lake-from-a-jupyter-notebook-with-pandas\">Delta Lake from a Jupyter Notebook with pandas</h3>\n<p>Let’s look at an example with <code>pandas</code>.</p>\n<p>Open a new notebook and run:</p>\n<pre><code><span><span>`!pip install deltalake 68]}</span></span>\n<span><span>```</span></span></code></pre>\n<p>Create a DataFrame with the first dictionary and write it to a Delta Lake table:</p>\n<pre><code><span><span>```</span></span>\n<span><span>df = pd.DataFrame.from_dict(data)</span></span>\n<span><span>write_deltalake(\"tmp/pandas-table\", 51</span></span>\n<span><span>```</span></span></code></pre>\n<p><img src=\"https://delta.io/_astro/image4.DSqXhb_7_Og30I.webp\"></p>\n<p>Refer to the <a target=\"_blank\" <a target=\"_blank\" href=\"https://delta-io.github.io/delta-rs/integrations/delta-lake-polars/\">polars</a>, <a target=\"_blank\"
