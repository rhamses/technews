You have two (or more) datasets and you need to merge data points from one dataset into another: you need to update an existing row and insert a new one.</p>\n<p>The <code>MERGE</code> statement in Delta Lake is designed to handle upserts. It lets you combine <strong>insert</strong>, <strong>update</strong>, and <strong>delete</strong> actions within a single query.</p>\n<p>The basic syntax for a Delta Lake <code>MERGE</code> operation is as follows:</p>\n<pre><code><span><span>target_table.alias(</span><span>\"target\"</span><span>) \\</span></span>\n<span><span>    .merge(source_table.alias(</span><span>\"source\"</span><span>), </span><span>\"condition\"</span><span>) \\</span></span>\n<span><span>    .whenMatchedUpdate(</span><span>set</span><span>=</span><span>{</span><span>\"target_column\"</span><span>: </span><span>\"source_column\"</span><span>}) \\</span></span>\n<span><span>    .whenNotMatchedInsert(</span><span>values</span><span>=</span><span>{</span><span>\"target_column\"</span><span>: </span><span>\"source_column\"</span><span>}) \\</span></span>\n<span><span>    .execute()</span></span></code></pre>\n<p>Here’s a breakdown:</p>\n<ul>\n<li><code>target_table</code> is the table where you want to perform the upsert.</li>\n<li><code>source_table</code> is the table with the new data.</li>\n<li><code>condition</code> specifies how the two tables are joined, often using a unique identifier.</li>\n<li><code>whenMatchedUpdate</code> allows you to update rows in <code>target_table</code> that match rows in <code>source_table</code>.</li>\n<li><code>whenNotMatchedInsert</code> lets you insert rows into <code>target_table</code> that don’t have matches in <code>source_table</code>.</li>\n</ul>\n<p>Now let’s look at a real code example.</p>\n<h3 id=\"example-upsert-data-in-delta-lake\">Example: Upsert Data in Delta Lake</h3>\n<p>Let’s say you have a <code>customer</code> Delta table with records that you need to keep updated based on incoming data in a <code>new_data</code> DataFrame.</p>\n<h4 id=\"1-define-your-target-delta-table\">1.
