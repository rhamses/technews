href=\"https://huggingface.co/blog/lerobot-release-v050#hardware-more-robots-than-ever\">\n\t\t<span></span>\n\t</a>\n\t<span>\n\t\tHardware: More Robots Than Ever\n\t</span>\n</h2>\n<p>LeRobot v0.5.0 dramatically expands the roster of supported hardware — from arms and mobile robots to a full humanoid.</p>\n<h3>\n\t<a target=\"_blank\" href=\"https://huggingface.co/blog/lerobot-release-v050#unitree-g1-humanoid\">\n\t\t<span></span>\n\t</a>\n\t<span>\n\t\tUnitree G1 Humanoid\n\t</span>\n</h3>\n<p>The biggest hardware addition in this release: <strong>full Unitree G1 humanoid support</strong>. This is LeRobot's first humanoid integration, and it's comprehensive:</p>\n<ul>\n<li><strong>Locomotion</strong>: Walk, navigate, and move through environments.</li>\n<li><strong>Manipulation</strong>: Perform dexterous object manipulation tasks.</li>\n<li><strong>Teleoperation</strong>: Control the G1 remotely with an intuitive teleoperation interface.</li>\n<li><strong>Whole-Body Control (WBC)</strong>: Coordinate locomotion and manipulation simultaneously for complex, real-world tasks.</li>\n</ul>\n<p>The G1 integration represents a major step toward general-purpose robotics within LeRobot — moving beyond tabletop arms into full-body embodied AI. Try it out yourself by following the <a target=\"_blank\" href=\"https://huggingface.co/docs/lerobot/unitree_g1\">documentation</a>.</p>\n<p><a target=\"_blank\" href=\"https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/lerobot-blog/release-v0.5.0/unitree_bosswalk.JPG\"><img src=\"https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/lerobot-blog/release-v0.5.0/unitree_bosswalk.JPG\" alt=\"unitree-boss\"></a></p>\n<h3>\n\t<a target=\"_blank\" href=\"https://huggingface.co/blog/lerobot-release-v050#openarm--openarm-mini\">\n\t\t<span></span>\n\t</a>\n\t<span>\n\t\tOpenArm &amp; OpenArm Mini\n\t</span>\n</h3>\n<p>We've added support for the <a target=\"_blank\" href=\"https://openarm.dev/\"><strong>OpenArm</strong></a> robot and its companion <strong>OpenArm Mini</strong> teleoperator. OpenArm is a capable robot arm with full LeRobot integration, and the Mini serves as its natural teleoperation device. Both support <strong>bi-manual configurations</strong>, enabling dual-arm setups for more complex manipulation tasks. Check it out in the <a target=\"_blank\" href=\"https://huggingface.co/docs/lerobot/openarm\">documentation</a>.</p>\n<h3>\n\t<a target=\"_blank\" href=\"https://huggingface.co/blog/lerobot-release-v050#more-robots\">\n\t\t<span></span>\n\t</a>\n\t<span>\n\t\tMore Robots\n\t</span>\n</h3>\n<p>The hardware ecosystem keeps growing:</p>\n<ul>\n<li><a target=\"_blank\" href=\"https://shop.frodobots.com/products/miniplus\"><strong>Earth Rover</strong></a>: Our first mobile robot integration, bringing LeRobot to outdoor navigation and ground-level robotics.</li>\n<li><a target=\"_blank\" href=\"https://ai.robotis.com/omx/hardware_omx.html\"><strong>OMX Robot</strong></a>: A new robot arm with configurable gripper settings and calibration support.</li>\n<li><strong>SO-100/SO-101 Consolidation</strong>: We've unified the SO-100 and SO-101 implementations into a single, cleaner codebase — including bi-manual setups. Less code duplication, easier maintenance, same great robots.</li>\n</ul>\n<h3>\n\t<a target=\"_blank\" href=\"https://huggingface.co/blog/lerobot-release-v050#can-bus-motors\">\n\t\t<span></span>\n\t</a>\n\t<span>\n\t\tCAN Bus Motors\n\t</span>\n</h3>\n<p>New motor controller support via CAN (Controller Area Network) bus opens the door to higher-performance actuators:</p>\n<ul>\n<li><a target=\"_blank\" href=\"https://github.com/RobStride/Product_Information\"><strong>RobStride</strong></a>: A CAN-based motor controller for high-torque applications.</li>\n<li><strong>Damiao</strong>: Another CAN bus motor controller, expanding the range of compatible hardware.</li>\n</ul>\n<p>These additions mean LeRobot can now drive a wider variety of professional-grade actuators beyond the existing Dynamixel and Feetech ecosystem.</p>\n<h2>\n\t<a target=\"_blank\" href=\"https://huggingface.co/blog/lerobot-release-v050#policies-a-growing-model-zoo\">\n\t\t<span></span>\n\t</a>\n\t<span>\n\t\tPolicies: A Growing Model Zoo\n\t</span>\n</h2>\n<p>This release brings six new policies and techniques into LeRobot, pushing the boundaries of what's possible with open-source robot learning.</p>\n<h3>\n\t<a target=\"_blank\" href=\"https://huggingface.co/blog/lerobot-release-v050#pi0-fast-autoregressive-vlas\">\n\t\t<span></span>\n\t</a>\n\t<span>\n\t\tPi0-FAST: Autoregressive VLAs\n\t</span>\n</h3>\n<p><strong>Pi0-FAST</strong> brings autoregressive Vision-Language-Action models to <a target=\"_blank\" href=\"https://huggingface.co/docs/lerobot/pi0fast\">LeRobot with FAST (Frequency-space Action Sequence Tokenization)</a>. Unlike the flow-matching approach of Pi0, Pi0-FAST uses an autoregressive action expert (based on Gemma 300M) that generates discretized action tokens, enabling:</p>\n<ul>\n<li><strong>FAST tokenization</strong>: Actions are tokenized for autoregressive decoding, with a dedicated <a target=\"_blank\" href=\"https://huggingface.co/lerobot/fast-action-tokenizer\">FAST action tokenizer</a>.</li>\n<li><strong>Flexible decoding</strong>: Configurable temperature and max decoding steps for balancing speed and quality.</li>\n<li><strong>RTC-compatible</strong>: Works with Real-Time Chunking (see <a target=\"_blank\" href=\"https://huggingface.co/blog/lerobot-release-v050#real-time-chunking-rtc\">next section</a>) for responsive inference.</li>\n</ul>\n<pre><code>lerobot-train \\\n  --policy.type=pi0_fast \\\n  --dataset.repo_id=lerobot/aloha_sim_insertion_human \\\n  --policy.device=cuda\n</code></pre>\n<h3>\n\t<a target=\"_blank\" href=\"https://huggingface.co/blog/lerobot-release-v050#real-time-chunking-rtc\">\n\t\t<span></span>\n\t</a>\n\t<span>\n\t\tReal-Time Chunking (RTC)\n\t</span>\n</h3>\n<p><strong>Real-Time Chunking</strong> is an inference-time technique from <a target=\"_blank\" href=\"https://www.pi.website/\">Physical Intelligence</a> that makes flow-matching policies dramatically more responsive. Instead of waiting for a full action chunk to finish before replanning, RTC continuously blends new predictions with in-progress actions, producing smoother and more reactive behavior.</p>\n<p>RTC is not a standalone policy — it's an enhancement that plugs into existing flow-matching policies (Pi0 family, SmolVLA &amp; Diffusion). Configure it via <code>--policy.rtc_config.enabled=true</code>.</p>\n<p>This is a game-changer for real-world deployment where latency matters. Read the <a target=\"_blank\" href=\"https://huggingface.co/papers/2506.07339\">original paper</a> for the technical details and our <a target=\"_blank\" href=\"https://huggingface.co/docs/lerobot/rtc\">documentation</a>.</p>\n<h3>\n\t<a target=\"_blank\" href=\"https://huggingface.co/blog/lerobot-release-v050#wall-x\">\n\t\t<span></span>\n\t</a>\n\t<span>\n\t\tWall-X\n\t</span>\n</h3>\n<p><strong>Wall-X</strong> is a new VLA policy built on <a target=\"_blank\" href=\"https://huggingface.co/collections/Qwen/qwen25-vl\"><strong>Qwen2.5-VL</strong></a> with flow-matching action prediction. It combines the strong vision-language understanding of Qwen2.5-VL with a flow-matching head for cross-embodiment robotic control.</p>\n<pre><code>pip install lerobot[wall_x]\nlerobot-train \\\n  --policy.type=wall_x \\\n  --dataset.repo_id=lerobot/aloha_sim_insertion_human\n</code></pre>\n<h3>\n\t<a target=\"_blank\" href=\"https://huggingface.co/blog/lerobot-release-v050#x-vla\">\n\t\t<span></span>\n\t</a>\n\t<span>\n\t\tX-VLA\n\t</span>\n</h3>\n<p><strong>X-VLA</strong> brings a <strong>Florence2-based</strong> VLA to LeRobot. Built on Microsoft's Florence-2 vision-language model, X-VLA offers an alternative backbone for VLA policies, expanding the diversity of foundation models available for robot learning. Check out the <a target=\"_blank\" href=\"https://huggingface.co/docs/lerobot/xvla\">training guide</a> for setup instructions and the <a target=\"_blank\" href=\"https://huggingface.co/lerobot/xvla-base\">base model</a>.</p>\n<pre><code>pip install lerobot[xvla]\nlerobot-train \\\n  --policy.type=xvla \\\n  --dataset.repo_id=lerobot/bimanual-so100-handover-cube\n</code></pre>\n<h3>\n\t<a target=\"_blank\" href=\"https://huggingface.co/blog/lerobot-release-v050#sarm\">\n\t\t<span></span>\n\t</a>\n\t<span>\n\t\tSARM\n\t</span>\n</h3>\n<p><strong>SARM (Stage-Aware Reward Modeling)</strong> tackles one of the hardest problems in robot learning: long-horizon tasks. Instead of using a single global linear progress signal over the whole episode, it models progress in a stage-aware manner by predicting both the task stage and the progress within that stage. This makes it much easier to train policies for complex, multi-step manipulation tasks. Start experimenting with it by following the <a target=\"_blank\" href=\"https://huggingface.co/docs/lerobot/sarm\">documentation</a>.</p>\n<p><a target=\"_blank\" href=\"https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/lerobot-blog/release-v0.5.0/sarm_community.gif\"><img src=\"https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/lerobot-blog/release-v0.5.0/sarm_community.gif\" alt=\"sarm-community\"></a></p>\n<h3>\n\t<a target=\"_blank\" href=\"https://huggingface.co/blog/lerobot-release-v050#peft-support\">\n\t\t<span></span>\n\t</a>\n\t<span>\n\t\tPEFT Support\n\t</span>\n</h3>\n<p>You can now <strong>fine-tune large VLAs using LoRA</strong> (and other PEFT methods) without modifying the core training pipeline. PEFT configuration lives at the policy level, making it straightforward to adapt massive foundation models to your specific robot and task with a fraction of the compute. Learn more reading the <a target=\"_blank\" href=\"https://huggingface.co/docs/lerobot/peft_training\">documentation</a>.</p>\n<pre><code>lerobot-train \\\n  --policy.type=pi0 \\\n  --policy.peft_config.use_peft=<span>true</span> \\\n  --dataset.repo_id=lerobot/aloha_sim_insertion_human\n</code></pre>\n<h2>\n\t<a target=\"_blank\" href=\"https://huggingface.co/blog/lerobot-release-v050#datasets-faster-recording-faster-training\">\n\t\t<span></span>\n\t</a>\n\t<span>\n\t\tDatasets: Faster Recording, Faster Training\n\t</span>\n</h2>\n<p>The dataset pipeline gets major performance improvements in this release, making both data collection and training significantly faster.</p>\n<h3>\n\t<a target=\"_blank\" href=\"https://huggingface.co/blog/lerobot-release-v050#streaming-video-encoding\">\n\t\t<span></span>\n\t</a>\n\t<span>\n\t\tStreaming Video Encoding\n\t</span>\n</h3>\n<p>Previously, recording a dataset meant waiting after each episode for video encoding to finish. <strong>No more.</strong> With streaming video encoding, frames are encoded in real-time as they're captured — meaning <strong>zero wait time between episodes</strong>. Just finish one episode and immediately start the next.</p>\n<p>Streaming encoding also supports <strong>hardware encoder auto-detection</strong>, so if your system has a GPU-accelerated video encoder, LeRobot will use it automatically:</p>\n<pre><code>dataset = LeRobotDataset.create(\n    repo_id=<span>\"my/dataset\"</span>,\n    fps=<span>30</span>,\n    video_backend=<span>\"auto\"</span>,       <span># Auto-detect best HW encoder</span>\n    streaming_encoding=<span>True</span>,    <span># Encode in real-time</span>\n)\n</code></pre>\n<blockquote>\n<p>Streaming encoding performance can vary significantly depending on your hardware and recording setup (number of cameras, resolution, etc.). Make sure to review the <a target=\"_blank\" href=\"https://huggingface.co/docs/lerobot/streaming_video_encoding\">streaming video encoding documentation</a> before enabling it.</p>\n</blockquote>\n<h3>\n\t<a target=\"_blank\" href=\"https://huggingface.co/blog/lerobot-release-v050#10x-faster-image-training-3x-faster-encoding\">\n\t\t<span></span>\n\t</a>\n\t<span>\n\t\t10x Faster Image Training, 3x Faster Encoding\n\t</span>\n</h3>\n<p>Under the hood, we've fixed key data access bottlenecks and overhauled image processing:</p>\n<ul>\n<li><strong>10x faster image training</strong>: Improved image transform support and fixed data access bottlenecks that were silently slowing down training.</li>\n<li><strong>3x faster encoding</strong>: Parallel encoding is now the default across all platforms, with dynamic compression levels that adapt to your dataset type (video vs. image), when not using streaming.</li>\n<li><strong>Better CPU utilization</strong>: More efficient resource usage during recording and dataset creation.</li>\n</ul>\n<h3>\n\t<a target=\"_blank\" href=\"https://huggingface.co/blog/lerobot-release-v050#new-dataset-tools\">\n\t\t<span></span>\n\t</a>\n\t<span>\n\t\tNew Dataset Tools\n\t</span>\n</h3>\n<p>The dataset editing toolkit continues to grow:</p>\n<ul>\n<li><strong>Subtask support</strong>: Annotate and query subtasks within episodes for hierarchical task learning.</li>\n<li><strong>Image-to-video conversion</strong>: Convert existing image-based datasets to video format for better storage efficiency, with support for multiple episodes per video file.</li>\n<li><strong>More editing operations</strong>: New <code>info</code> operation for inspecting datasets, task modification tools, and numerous fixes to existing operations (splitting, merging, feature editing).</li>\n<li><strong>Expose more options</strong>: Configurable video codecs, tolerance settings, and metadata buffer sizes for fine-grained control over dataset
