</div><!--]--></div><!----> <!--[-1--><!--]--> <!---->\n<div></div><!--]--><!--]--><p>Anthropic is limiting access to Claude models in open agent platforms for Pro/Max subscribers.  Don’t worry though, there are great open models on Hugging Face to keep your agents running! Most of the time, at a fraction of the cost. </p>\n<p>If you've been cut off and your OpenClaw, Pi, or Open Code agents need resuscitation, you can move them to open models in two ways:</p>\n<ol>\n<li>Use an open model served through Hugging Face Inference Providers.  </li>\n<li>Run a fully local open model on your own hardware.</li>\n</ol>\n<p>The hosted route is the fastest way back to a capable agent. The local route is the right fit if you want privacy, zero API costs, and full control.</p>\n<p>To do so, just tell your claude code, your cursor or your favorite agent: <em>help me move my OpenClaw agents to Hugging Face models</em>, and link this page.</p>\n<h2>\n\t<a target=\"_blank\" href=\"https://huggingface.co/blog/liberate-your-openclaw#hugging-face-inference-providers\">\n\t\t<span></span>\n\t</a>\n\t<span>\n\t\tHugging Face Inference Providers\n\t</span>\n</h2>\n<p>Hugging Face inference providers is an open platform that routes to providers of open source models. It’s the right choice if you want the best models or you don’t have the necessary hardware.</p>\n<p>First, you’ll need to create a token <a target=\"_blank\" href=\"https://huggingface.co/settings/tokens\">here</a>. Then you can add that token to <code>openclaw</code> like so:</p>\n<pre><code>openclaw onboard --auth-choice huggingface-api-key\n</code></pre>\n<p>Paste your Hugging Face token when prompted, and you’ll be asked to select a model.</p>\n<p>We’d recommend <a target=\"_blank\" href=\"https://huggingface.co/zai-org/GLM-5\">GLM-5</a> because of its excellent <a target=\"_blank\" href=\"https://huggingface.co/datasets/harborframework/terminal-bench-2.0\">Terminal Bench</a> scores, but there are thousands to chose from <a target=\"_blank\" href=\"https://huggingface.co/inference/models\">here</a>.</p>\n<p>You can update your Hugging Face model at any time entering its <code>repo_id</code> in the OpenClaw config:</p>\n<pre><code>{\n  agents: {\n    defaults: {\n      model: {\n        primary: \"huggingface/zai-org/GLM-5:fastest\"\n      }\n    }\n  }\n}\n</code></pre>\n<p>Note: HF PRO subscribers get $2 free credits each month which applies to Inference Providers usage, learn more <a target=\"_blank\" href=\"https://huggingface.co/pro\">here</a>.</p>\n<h2>\n\t<a target=\"_blank\" href=\"https://huggingface.co/blog/liberate-your-openclaw#local-setup\">\n\t\t<span></span>\n\t</a>\n\t<span>\n\t\tLocal Setup\n\t</span>\n</h2>\n<p>Running models locally gives you full privacy, zero API costs, and the ability to experiment without rate limits. </p>\n<p>Install Llama.cpp, a fully open source library for low resource inference.</p>\n<pre><code><span># </span><span>on mac or linux</span>\nbrew install llama.cpp\n<span></span>\n<span># </span><span>on windows</span>\nwinget install llama.cpp\n</code></pre>\n<p>Start a local server with a built-in web UI:</p>\n<pre><code>llama-server -hf unsloth/Qwen3.5-35B-A3B-GGUF:UD-Q4_K_XL\n</code></pre>\n<p>Here, we’re using Qwen3.5-35B-A3B, which works great with 32GB of RAM. If you have different requirements, please check out the hardware compatibility <a target=\"_blank\" href=\"https://huggingface.co/unsloth/Qwen3.5-35B-A3B-GGUF\">for the model you're interested in</a>. <a target=\"_blank\" href=\"https://huggingface.co/models?pipeline_tag=text-generation&library=gguf&sort=trending\">There are thousands to choose from</a>.</p>\n<p>If you load the GGUF in llama.cpp, use an OpenClaw config like this:</p>\n<pre><code>openclaw onboard --non-interactive \\                                                                                   \n   --auth-choice custom-api-key \\                                                                                         \n   --custom-base-url \"http://127.0.0.1:8080/v1\" \\                                                                         \n   --custom-model-id \"unsloth-qwen3.5-35b-a3b-gguf\" \\                                                                     \n   --custom-api-key \"llama.cpp\" \\                                                                                         \n   --secret-input-mode plaintext \\                                                                                        \n   --custom-compatibility openai\n</code></pre>\n<p>Verify the server is running and the model is loaded:</p>\n<pre><code>curl http://127.0.0.1:8080/v1/models\n</code></pre>\n<h2>\n\t<a target=\"_blank\" href=\"https://huggingface.co/blog/liberate-your-openclaw#which-path-should-you-choose\">\n\t\t<span></span>\n\t</a>\n\t<span>\n\t\tWhich path should you choose?\n\t</span>\n</h2>\n<p>Use Hugging Face Inference Providers if you want the quickest path back to a capable OpenClaw agent. Use <code>llama.cpp</code> if you want privacy, full local control, and no API bill.</p>\n<p>Either way, you do not need a closed hosted model to get OpenClaw back on its feet! </p>\n<!----></div>"
