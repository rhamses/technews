It supports tool calling and multi-step workflows while staying small and fast enough for everyday hardware, from laptops to phones. This enables developers to deploy agents everywhere, keep data private on the device, and scale usage without a cloud inference bill.</p>\n<ul>\n<li><strong>Best-in-class agent:</strong> Competitive with models 4x larger on tool use, instruction following, and multi-step agentic tasks.  </li>\n<li><strong>Agentic reinforcement learning:</strong> Trained inside the most popular agentic harnesses to improve compatibility.  </li>\n<li><strong>Efficient inference</strong>: 220 tok/s on an Apple M5 Max and 113 tok/s on an AMD Ryzen CPU, in under 2.5 GB of memory.</li>\n</ul>\n<p><a target=\"_blank\" href=\"https://cdn-uploads.huggingface.co/production/uploads/644249b08443bce4c9890a0f/DaHxE_1x4xMB_5c-P0AXF.png\"><img src=\"https://cdn-uploads.huggingface.co/production/uploads/644249b08443bce4c9890a0f/DaHxE_1x4xMB_5c-P0AXF.png\" alt=\"lfm2_5_2_6b_evaluations\"></a></p>\n<h2>\n\t<a target=\"_blank\" href=\"https://huggingface.co/blog/LiquidAI/lfm2-5-2-6b#how-we-built-a-reliable-agentic-model-for-edge-devices\">\n\t</a>\n\t<span>\n\t\tHow we built a reliable agentic model for edge devices\n\t</span>\n</h2>\n<p>LFM2.5-2.6B is pre-trained on ~34T tokens, with a mid-training phase that extends the context window to 128K. Post-training then turns the base model into an agent in four stages:</p>\n<ol>\n<li><strong>Supervised fine-tuning (SFT):</strong> two rounds of SFT, weighted heavily toward agentic data like tool use, web search, and harness trajectories.  </li>\n<li><strong>Teacher specialization:</strong> train one specialist teacher per domain (math, code, tool use, and more).  </li>\n<li><strong>Multi-domain on-policy distillation (MOPD):</strong> distill the specialist teachers into a single student.  </li>\n<li><strong>Agentic Reinforcement Learning (Agentic RL):</strong> run multi-turn RL inside real agent harnesses, where the model learns to work across different tools, system prompts, and multi-turn task environments.</li>\n</ol>\n<p><a target=\"_blank\" href=\"https://cdn-uploads.huggingface.co/production/uploads/644249b08443bce4c9890a0f/jg-qhMYLMPi6PAslhT9S_.png\"><img src=\"https://cdn-uploads.huggingface.co/production/uploads/644249b08443bce4c9890a0f/jg-qhMYLMPi6PAslhT9S_.png\" alt=\"LFM2.5-2.6B-Training-Recipe\"></a></p>\n<p>The Agentic RL pipeline separates model optimization, inference, and environment execution into distinct components. The <strong>Training Engine</strong> optimizes the model, while the <strong>Rollout Engine</strong> generates actions using the latest policy. The <strong>RL framework</strong> orchestrates the training loop by launching rollouts, collecting trajectories and rewards, and updating the model.</p>\n<p>Actions are executed within a <strong>Sandbox Service</strong>, where the <strong>Blackbox Harness</strong> hosts the agent (e.g., OpenClaw or Hermes Agent) and coordinates interactions with the task environment.
