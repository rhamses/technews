href=\"https://huggingface.co/blog/multimodal-sentence-transformers#what-are-multimodal-models\">\n\t</a>\n\t<span>\n\t\tWhat are Multimodal Models?\n\t</span>\n</h2>\n<p>Traditional embedding models convert text into <a target=\"_blank\" href=\"https://huggingface.co/blog/matryoshka#understanding-embeddings\">fixed-size vectors</a>. Multimodal embedding models extend this by mapping inputs from different modalities (text, images, audio, or video) into a shared embedding space. This means you can compare a text query against image documents (or vice versa) using the same similarity functions you're already familiar with.</p>\n<p>Similarly, traditional reranker (Cross Encoder) models compute relevance scores between pairs of texts. Multimodal rerankers can score pairs where one or both elements are images, combined text-image documents, or other modalities.</p>\n<p>For example, you can compare a text query against image documents, find video clips matching a description, or build RAG pipelines that work across modalities.</p>\n<h2>\n\t<a target=\"_blank\" href=\"https://huggingface.co/blog/multimodal-sentence-transformers#installation\">\n\t</a>\n\t<span>\n\t\tInstallation\n\t</span>\n</h2>\n<p>Multimodal models require some extra dependencies. Install the extras for the modalities you need (see <a target=\"_blank\" href=\"https://sbert.net/docs/installation.html\">Installation</a> for more details):</p>\n<pre><code><span># For image support</span>\npip install -U <span>\"sentence-transformers[image]\"</span>\n<span># For audio support</span>\npip install -U <span>\"sentence-transformers[audio]\"</span>\n<span># For video support</span>\npip install -U <span>\"sentence-transformers[video]\"</span>\n<span># Mix and match as needed</span>\npip install -U <span>\"sentence-transformers[image,video,train]\"</span>\n</code></pre>\n<blockquote>\n<p>VLM-based models like Qwen3-VL-2B require a GPU with at least ~8 GB of VRAM. For the 8B variants, expect ~20 GB. If you don't have a local GPU, consider using a cloud GPU service or Google Colab. On CPU, these models will be extremely slow; text-only or CLIP models are better suited for CPU inference.</p>\n</blockquote>\n<h2>\n\t<a target=\"_blank\" href=\"https://huggingface.co/blog/multimodal-sentence-transformers#multimodal-embedding-models\">\n\t</a>\n\t<span>\n\t\tMultimodal Embedding Models\n\t</span>\n</h2>\n<h3>\n\t<a target=\"_blank\" href=\"https://huggingface.co/blog/multimodal-sentence-transformers#loading-a-model\">\n\t</a>\n\t<span>\n\t\tLoading a Model\n\t</span>\n</h3>\n<p>Loading a multimodal embedding model works exactly like loading a text-only model:</p>\n<pre><code><span>from</span> sentence_transformers <span>import</span> SentenceTransformer\nmodel = SentenceTransformer(<span>\"Qwen/Qwen3-VL-Embedding-2B\"</span>)\n</code></pre>\n<blockquote>\n<p>Some models might require a <code>revision</code> argument for now if the integration pull requests for the model is still pending. Once they're merged, you'll be able to load them without specifying a revision, like above.</p>\n</blockquote>\n<p>The model automatically detects which modalities it supports, so there's nothing extra to configure. See <a target=\"_blank\" href=\"https://huggingface.co/blog/multimodal-sentence-transformers#processor-and-model-kwargs\">Processor and Model kwargs</a> if you want to control things like image resolution or model precision.</p>\n<h3>\n\t<a target=\"_blank\" href=\"https://huggingface.co/blog/multimodal-sentence-transformers#encoding-images\">\n\t</a>\n\t<span>\n\t\tEncoding Images\n\t</span>\n</h3>\n<p>With a multimodal model loaded, <a target=\"_blank\" href=\"https://sbert.net/docs/package_reference/sentence_transformer/SentenceTransformer.html#sentence_transformers.SentenceTransformer.encode\"><code>model.encode()</code></a> accepts images alongside text. Images can be provided as URLs, local file paths, or PIL Image objects (see <a target=\"_blank\" href=\"https://huggingface.co/blog/multimodal-sentence-transformers#supported-input-types\">Supported Input Types</a> for all accepted formats):</p>\n<pre><code><span>from</span> sentence_transformers <span>import</span> SentenceTransformer\nmodel = SentenceTransformer(<span>\"Qwen/Qwen3-VL-Embedding-2B\"</span>)\n<span># Encode images from URLs</span>\nimg_embeddings = model.encode([\n    <span>\"https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/transformers/tasks/car.jpg\"</span>,\n    <span>\"https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/bee.jpg\"</span>,\n])\n<span>print</span>(img_embeddings.shape)\n<span># (2, 2048)</span>\n</code></pre>\n<h3>\n\t<a target=\"_blank\" href=\"https://huggingface.co/blog/multimodal-sentence-transformers#cross-modal-similarity\">\n\t</a>\n\t<span>\n\t\tCross-Modal Similarity\n\t</span>\n</h3>\n<p>You can compute similarities between text embeddings and image embeddings, since the model maps both into the same space:</p>\n<pre><code><span>from</span> sentence_transformers <span>import</span> SentenceTransformer\nmodel = SentenceTransformer(<span>\"Qwen/Qwen3-VL-Embedding-2B\"</span>)\n<span># Encode images</span>\nimg_embeddings = model.encode([\n    <span>\"https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/transformers/tasks/car.jpg\"</span>,\n    <span>\"https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/bee.jpg\"</span>,\n])\n<span># Encode text queries (one matching + one hard negative per image)</span>\ntext_embeddings = model.encode([\n    <span>\"A green car parked in front of a yellow building\"</span>,\n    <span>\"A red car driving on a highway\"</span>,\n    <span>\"A bee on a pink flower\"</span>,\n    <span>\"A wasp on a wooden table\"</span>,\n])\n<span># Compute cross-modal similarities</span>\nsimilarities = model.similarity(text_embeddings, img_embeddings)\n<span>print</span>(similarities)\n<span># tensor([[0.5115, 0.1078],</span>\n<span>#         [0.1999, 0.1108],</span>\n<span>#         [0.1255, 0.6749],</span>\n<span>#         [0.1283, 0.2704]])</span>\n</code></pre>\n<p>As expected, \"A green car parked in front of a yellow building\" is most similar to the car image (0.51), and \"A bee on a pink flower\" is most similar to the bee image (0.67). The hard negatives (\"A red car driving on a highway\", \"A wasp on a wooden table\") correctly receive lower scores.</p>\n<p>You might notice that even the best matching scores (0.51, 0.67) aren't very close to 1.0. This is due to the <a target=\"_blank\" href=\"https://arxiv.org/abs/2203.02053\">modality gap</a>: embeddings from different modalities tend to cluster in separate regions of the space. Cross-modal similarities are typically lower than within-modal ones (e.g., text-to-text), but the relative ordering is preserved, so retrieval still works well.</p>\n<h3>\n\t<a target=\"_blank\" href=\"https://huggingface.co/blog/multimodal-sentence-transformers#encoding-queries-and-documents\">\n\t</a>\n\t<span>\n\t\tEncoding Queries and Documents\n\t</span>\n</h3>\n<p>For retrieval tasks, <a target=\"_blank\" href=\"https://sbert.net/docs/package_reference/sentence_transformer/SentenceTransformer.html#sentence_transformers.SentenceTransformer.encode_query\"><code>encode_query()</code></a> and <a target=\"_blank\" href=\"https://sbert.net/docs/package_reference/sentence_transformer/SentenceTransformer.html#sentence_transformers.SentenceTransformer.encode_document\"><code>encode_document()</code></a> are the recommended methods. Many retrieval models prepend different instruction prompts depending on whether the input is a query or a document, similar to how chat models might apply different system prompts depending on the goal. Model authors can specify their prompts in the model config, and <code>encode_query()</code> / <code>encode_document()</code> automatically load and apply the correct one:</p>\n<ul>\n<li><code>encode_query()</code> uses the model's <code>\"query\"</code> prompt (if available) and sets <code>task=\"query\"</code>.</li>\n<li><code>encode_document()</code> uses the first available prompt from <code>\"document\"</code>, <code>\"passage\"</code>, or <code>\"corpus\"</code>, and sets <code>task=\"document\"</code>.</li>\n</ul>\n<p>Under the hood, both are thin wrappers around <code>encode()</code>, they just handle prompt selection for you. Here's what cross-modal retrieval looks like:</p>\n<pre><code><span>from</span> sentence_transformers <span>import</span> SentenceTransformer\nmodel = SentenceTransformer(<span>\"Qwen/Qwen3-VL-Embedding-2B\"</span>)\n<span># Encode text queries with the query prompt</span>\nquery_embeddings = model.encode_query([\n    <span>\"Find me a photo of a vehicle parked near a building\"</span>,\n    <span>\"Show me an image of a pollinating insect\"</span>,\n])\n<span># Encode document screenshots with the document prompt</span>\ndoc_embeddings = model.encode_document([\n    <span>\"https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/transformers/tasks/car.jpg\"</span>,\n    <span>\"https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/bee.jpg\"</span>,\n])\n<span># Compute similarities</span>\nsimilarities = model.similarity(query_embeddings, doc_embeddings)\n<span>print</span>(similarities)\n<span># tensor([[0.3907, 0.1490],</span>\n<span>#         [0.1235, 0.4872]])</span>\n</code></pre>\n<p>These methods accept the same input types as <code>encode()</code> (images, URLs, multimodal dicts, etc.) and pass through the same parameters. For models without specialized query/document prompts, they behave identically to <code>encode()</code>.</p>\n<h2>\n\t<a target=\"_blank\" href=\"https://huggingface.co/blog/multimodal-sentence-transformers#multimodal-reranker-models\">\n\t</a>\n\t<span>\n\t\tMultimodal Reranker Models\n\t</span>\n</h2>\n<p>Multimodal reranker (CrossEncoder) models score the relevance between pairs of inputs, where each element can be text, an image, audio, video, or a combination. They tend to outperform embedding models in terms of quality, but are slower since they process each pair individually. The currently available pretrained multimodal rerankers focus on text and image inputs, but the architecture supports any modality that the underlying model can handle.</p>\n<h3>\n\t<a target=\"_blank\" href=\"https://huggingface.co/blog/multimodal-sentence-transformers#ranking-mixed-modality-documents\">\n\t</a>\n\t<span>\n\t\tRanking Mixed-Modality Documents\n\t</span>\n</h3>\n<p>The <a target=\"_blank\" href=\"https://sbert.net/docs/package_reference/cross_encoder/cross_encoder.html#sentence_transformers.cross_encoder.CrossEncoder.rank\"><code>rank()</code></a> method scores and ranks a list of documents against a query, supporting mixed modalities:</p>\n<pre><code><span>from</span> sentence_transformers <span>import</span> CrossEncoder\nmodel = CrossEncoder(<span>\"Qwen/Qwen3-VL-Reranker-2B\"</span>)\nquery = <span>\"A green car parked in front of a yellow building\"</span>\ndocuments = [\n    <span># Image documents (URL or local file path)</span>\n    <span>\"https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/transformers/tasks/car.jpg\"</span>,\n    <span>\"https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/bee.jpg\"</span>,\n    <span># Text document</span>\n    <span>\"A vintage Volkswagen Beetle painted in bright green sits in a driveway.\"</span>,\n    <span># Combined text + image document</span>\n    {\n        <span>\"text\"</span>: <span>\"A car in a European city\"</span>,\n        <span>\"image\"</span>: <span>\"https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/transformers/tasks/car.jpg\"</span>,\n    },\n]\nrankings = model.rank(query, documents)\n<span>for</span> rank <span>in</span> rankings:\n    <span>print</span>(<span>f\"<span>{rank[<span>'score'</span>]:<span>.4</span>f}</span>\\t(document <span>{rank[<span>'corpus_id'</span>]}</span>)\"</span>)\n<span>\"\"\"</span>\n<span>0.9375  (document 0)</span>\n<span>0.5000  (document 3)</span>\n<span>-1.2500 (document 2)</span>\n<span>-2.4375 (document 1)</span>\n<span>\"\"\"</span>\n</code></pre>\n<p>The reranker correctly identifies the car image (document 0) as the most relevant result, followed by the combined text+image document about a car in a European city (document 3). The bee image (document 1) scores lowest.\nKeep in mind that the <a target=\"_blank\" href=\"https://arxiv.org/abs/2203.02053\">modality gap</a> can influence absolute scores: text-image pair scores may occupy a different range than text-text or image-image pair scores.</p>\n<p>You can also check which modalities a reranker supports using <a target=\"_blank\" href=\"https://sbert.net/docs/package_reference/cross_encoder/cross_encoder.html#sentence_transformers.cross_encoder.CrossEncoder.modalities\"><code>modalities</code></a> and <a target=\"_blank\" href=\"https://sbert.net/docs/package_reference/cross_encoder/cross_encoder.html#sentence_transformers.cross_encoder.CrossEncoder.supports\"><code>supports()</code></a>, just like with embedding models:</p>\n<pre><code><span>print</span>(model.modalities)\n<span># ['text', 'image', 'video', 'message']</span>\n<span>print</span>(model.supports(<span>\"image\"</span>))\n<span># True</span>\n<span># Check if the model supports a specific pair of modalities</span>\n<span>print</span>(model.supports((<span>\"image\"</span>, <span>\"text\"</span>)))\n<span># True</span>\n</code></pre>\n<h3>\n\t<a target=\"_blank\" href=\"https://huggingface.co/blog/multimodal-sentence-transformers#predicting-pair-scores\">\n\t</a>\n\t<span>\n\t\tPredicting Pair Scores\n\t</span>\n</h3>\n<p>You can also use <a target=\"_blank\" href=\"https://sbert.net/docs/package_reference/cross_encoder/cross_encoder.html#sentence_transformers.cross_encoder.CrossEncoder.predict\"><code>predict()</code></a> to get raw relevance scores for specific pairs of inputs:</p>\n<pre><code><span>from</span> sentence_transformers <span>import</span> CrossEncoder\nmodel = CrossEncoder(<span>\"jinaai/jina-reranker-m0\"</span>, trust_remote_code=<span>True</span>)\nscores = model.predict([\n    (<span>\"A green car\"</span>, <span>\"https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/transformers/tasks/car.jpg\"</span>),\n    (<span>\"A bee on a flower\"</span>, <span>\"https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/bee.jpg\"</span>),\n    (<span>\"A green car\"</span>, <span>\"https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/bee.jpg\"</span>),\n])\n<span>print</span>(scores)\n<span># [0.9389156  0.96922314 0.46063158]</span>\n</code></pre>\n<h2>\n\t<a target=\"_blank\" href=\"https://huggingface.co/blog/multimodal-sentence-transformers#retrieve-and-rerank\">\n\t</a>\n\t<span>\n\t\tRetrieve and Rerank\n\t</span>\n</h2>\n<p>A common pattern is to use an embedding model for fast initial retrieval, then refine the top results with a reranker:</p>\n<pre><code><span>from</span> sentence_transformers <span>import</span> SentenceTransformer, CrossEncoder\n<span># Step 1: Retrieve with an embedding model</span>\nembedder = SentenceTransformer(<span>\"Qwen/Qwen3-VL-Embedding-2B\"</span>)\nquery = <span>\"revenue growth chart\"</span>\nquery_embedding = embedder.encode_query(query)\n<span># Pre-compute corpus embeddings (do this once, then store them)</span>\ndocument_screenshots = [\n    <span>\"path/to/doc1.png\"</span>,\n    <span>\"path/to/doc2.png\"</span>,\n    <span># ... potentially millions of document screenshots</span>\n]\ncorpus_embeddings = embedder.encode_document(document_screenshots, show_progress_bar=<span>True</span>)\n<span># Simple cosine similarity retrieval, viable as long as embeddings fit in memory</span>\nsimilarities = embedder.similarity(query_embedding, corpus_embeddings)\ntop_k_indices = similarities.argsort(descending=<span>True</span>)[<span>0</span>][:<span>10</span>]\n<span># Step 2: Rerank the top-k results with a reranker model</span>\nreranker = CrossEncoder(<span>\"nvidia/llama-nemotron-rerank-vl-1b-v2\"</span>, trust_remote_code=<span>True</span>)\ntop_k_documents = [document_screenshots[i] <span>for</span> i <span>in</span> top_k_indices]\nrankings = reranker.rank(query, top_k_documents)\n<span>for</span> rank <span>in</span> rankings:\n    <span>print</span>(<span>f\"<span>{rank[<span>'score'</span>]:<span>.4</span>f}</span>\\t<span>{top_k_documents[rank[<span>'corpus_id'</span>]]}</span>\"</span>)\n</code></pre>\n<p>Since the corpus embeddings are pre-computed, the initial retrieval is fast even over millions of documents. The reranker then provides more accurate scoring over the smaller candidate set.</p>\n<h2>\n\t<a target=\"_blank\" href=\"https://huggingface.co/blog/multimodal-sentence-transformers#input-formats-and-configuration\">\n\t</a>\n\t<span>\n\t\tInput Formats and Configuration\n\t</span>\n</h2>\n<h3>\n\t<a target=\"_blank\" href=\"https://huggingface.co/blog/multimodal-sentence-transformers#supported-input-types\">\n\t</a>\n\t<span>\n\t\tSupported Input Types\n\t</span>\n</h3>\n<p>Multimodal models accept a variety of input formats. href=\"https://huggingface.co/blog/multimodal-sentence-transformers#checking-modality-support\">\n\t</a>\n\t<span>\n\t\tChecking Modality Support\n\t</span>\n</h3>\n<p>You can check which modalities a model supports using the <a target=\"_blank\" href=\"https://sbert.net/docs/package_reference/sentence_transformer/SentenceTransformer.html#sentence_transformers.SentenceTransformer.modalities\"><code>modalities</code></a> property and <a target=\"_blank\" href=\"https://sbert.net/docs/package_reference/sentence_transformer/SentenceTransformer.html#sentence_transformers.SentenceTransformer.supports\"><code>supports()</code></a> method:</p>\n<pre><code><span>from</span> sentence_transformers <span>import</span> SentenceTransformer\nmodel = SentenceTransformer(<span>\"Qwen/Qwen3-VL-Embedding-2B\"</span>)\n<span># List all supported modalities</span>\n<span>print</span>(model.modalities)\n<span># ['text', 'image', 'video', 'message']</span>\n<span># Check for a specific modality</span>\n<span>print</span>(model.supports(<span>\"image\"</span>))\n<span># True</span>\n<span>print</span>(model.supports(<span>\"audio\"</span>))\n<span># False</span>\n</code></pre>\n<p>The <code>\"message\"</code> modality indicates that the model accepts chat-style message inputs with interleaved content. In practice, you rarely need to use this directly. When you pass strings, URLs, or multimodal dicts, the model converts them to the appropriate message format internally. Sentence Transformers supports two message formats:</p>\n<ul>\n<li><strong>Structured</strong> (most VLMs, e.g. Qwen3-VL): Content is a list of typed dicts, e.g. <code>[{\"type\": \"text\", \"text\": \"...\"}, {\"type\": \"image\", \"image\": ...}]</code></li>\n<li><strong>Flat</strong> (e.g. Deepseek-V3): Content is a direct value, e.g. <code>\"some text\"</code></li>\n</ul>\n<p>The format is auto-detected from the model's chat template.</p>\n<p>Since all inputs get converted into the same message format internally, you can mix input types in a single <a target=\"_blank\" href=\"https://sbert.net/docs/package_reference/sentence_transformer/SentenceTransformer.html#sentence_transformers.SentenceTransformer.encode\"><code>encode()</code></a> call:</p>\n<pre><code>embeddings = model.encode([\n    <span># A text input</span>\n    <span>\"A green car parked in front of a yellow building\"</span>,\n    <span># An image input (URL)</span>\n    <span>\"https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/transformers/tasks/car.jpg\"</span>,\n    <span># A combined text + image input</span>\n    {\n        <span>\"text\"</span>: <span>\"A car in a European city\"</span>,\n        <span>\"image\"</span>: <span>\"https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/transformers/tasks/car.jpg\"</span>,\n    },\n])\n</code></pre>\n<details>\n<summary>Click here if you need to pass raw message inputs</summary>\n<p>If a model doesn't follow either format and you need full control, you can pass raw message dicts with <code>role</code> and <code>content</code> keys directly:</p>\n<pre><code>embeddings = model.encode([\n    [\n        {\n            <span>\"role\"</span>: <span>\"user\"</span>,\n            <span>\"content\"</span>: [\n                {<span>\"type\"</span>: <span>\"image\"</span>, <span>\"image\"</span>: <span>\"https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/transformers/tasks/car.jpg\"</span>},\n                {<span>\"type\"</span>: <span>\"text\"</span>, <span>\"text\"</span>: <span>\"Describe this vehicle.\"</span>},\n            ],\n        }\n    ],\n])\n</code></pre>\n<p>This bypasses the automatic format conversion and passes the messages directly to the processor's <code>apply_chat_template()</code>.</p>\n</details>\n<h3>\n\t<a target=\"_blank\" href=\"https://huggingface.co/blog/multimodal-sentence-transformers#processor-and-model-kwargs\">\n\t</a>\n\t<span>\n\t\tProcessor and Model kwargs\n\t</span>\n</h3>\n<p>You may want to control image resolution bounds or model precision. Use <code>processor_kwargs</code> and <code>model_kwargs</code> when loading the model:</p>\n<pre><code>model = SentenceTransformer(\n    <span>\"Qwen/Qwen3-VL-Embedding-2B\"</span>,\n    model_kwargs={<span>\"attn_implementation\"</span>: <span>\"flash_attention_2\"</span>, <span>\"torch_dtype\"</span>: <span>\"bfloat16\"</span>},\n    processor_kwargs={<span>\"min_pixels\"</span>: <span>28</span> * <span>28</span>, <span>\"max_pixels\"</span>: <span>600</span> * <span>600</span>},\n)\n</code></pre>\n<ul>\n<li><code>processor_kwargs</code> controls how inputs are preprocessed (e.g., image resolution bounds). Higher <code>max_pixels</code> means higher quality but more memory and compute. These are passed directly to <code>AutoProcessor.from_pretrained(...)</code>.</li>\n<li><code>model_kwargs</code> controls how the underlying model is loaded (e.g., precision, attention implementation). These are passed directly to the appropriate <code>AutoModel.from_pretrained(...)</code> call (e.g., <code>AutoModel</code>, <code>AutoModelForCausalLM</code>, <code>AutoModelForSequenceClassification</code>, etc., depending on the configuration of the model modules).</li>\n</ul>\n<p>See the <a target=\"_blank\" href=\"https://sbert.net/docs/package_reference/sentence_transformer/SentenceTransformer.html#sentence_transformers.SentenceTransformer\">SentenceTransformer</a> API Reference documentation for more details on these kwargs.</p>\n<blockquote>\n<p>In Sentence Transformers v5.4, <code>tokenizer_kwargs</code> has been renamed to <code>processor_kwargs</code> to reflect that multimodal models use processors rather than just tokenizers. The old name is still accepted but deprecated.</p>\n</blockquote>\n<h2>\n\t<a target=\"_blank\"
