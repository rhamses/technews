This process searches for known patterns that can be optimised. After any patterns have been identified, it uses ast (abstract syntax tree) to manipulate the source code and rewrite some of the operations in place.</p>\n<p><strong>What can we achieve with this?</strong></p>\n<ul>\n<li>Fused operations that are many-to-one mapped to (ultra) optimized vLLM kernels, such as the ones used for Expert Parallelization (EP) in Mixture-of-Experts (MoE) models.</li>\n<li>The main other fused operations are vLLM's <code>MergedColumnParallelLinear</code> and <code>QKVParallelLinear</code>. These blocks allow us to infer parallel plans for TP (tensor-parallel). PP (pipeline-parallel) plans can also be inferred if the decoder block list is easily identifiable.</li>\n<li>The manipulated models are still fully (torch) compilable, being passed through <code>torch.compile</code> and CUDA Graphs, just the same as a dedicated vLLM model implementation.</li>\n<li>Unlike vLLM model implementations, Transformers model implementations can be used in <strong>training</strong>. So you can use the same model code for training/evals/RL rollouts.</li>\n</ul>\n<p>As shown above, this results in native vLLM inference speed for compatible models, without having to write a single line of code to optimize the model for inference.</p>\n<blockquote>\n<p>We are in the process of writing a detailed blog post to dive deep inside these optimized inference methods and explain in detail how we manipulate the model to adapt to them.</p>\n</blockquote>\n<h2>\n\t<a target=\"_blank\" href=\"https://huggingface.co/blog/native-speed-vllm-transformers-backend#resources\">\n\t</a>\n\t<span>\n\t\tResources\n\t</span>\n</h2>\n<ul>\n<li><a target=\"_blank\" href=\"https://huggingface.co/blog/transformers-model-definition#a-model-definition-library\">Transformers model definition</a></li>\n<li><a target=\"_blank\" href=\"https://vllm.ai/blog/2025-04-11-transformers-backend\">Transformers modeling backend in vLLM</a></li>\n<li><a target=\"_blank\" href=\"https://vllm.ai/blog/2025-12-17-large-scale-serving\">Large scale serving</a></li>\n<li><a target=\"_blank\" href=\"https://docs.pytorch.org/docs/2.12/fx.html\">Torch FX</a></li>\n<li><a target=\"_blank\" href=\"https://docs.python.org/3/library/ast.html\">Abstract syntax tree</a></li>\n</ul>\n<!----></div>"
