Developers can select the backend through the <code>engine</code> parameter and pass backend-specific options through <code>engine_config</code>.</p>\n<p>In practice, this means:</p>\n<ul>\n<li>The pipelines behind these tasks are managed by PaddleOCR, so developers do not need to manually call each internal component.</li>\n<li>Transformers becomes one of the supported inference backends for running supported PaddleOCR models.</li>\n<li>Developers can configure backend-related options such as <code>dtype</code>, device placement, and attention implementation through <code>engine_config</code>.</li>\n</ul>\n<p>A simple way to understand the stack:</p>\n<div>\n\t<table>\n\t\t<thead><tr>\n<th>Layer</th>\n<th>What it means</th>\n<th>Examples</th>\n</tr>\n\t\t</thead><tbody><tr>\n<td><strong>Application layer</strong></td>\n<td>Applications that use OCR and document parsing outputs</td>\n<td>RAG, agents, Document AI...</td>\n</tr>\n<tr>\n<td><strong>Model layer</strong></td>\n<td>OCR and document parsing capabilities</td>\n<td>PP-OCRv5, PaddleOCR-VL 1.5...</td>\n</tr>\n<tr>\n<td><strong>Inference backend layer</strong></td>\n<td>Runtime used to run supported models</td>\n<td>Paddle static graph, Paddle dynamic graph, Transformers</td>\n</tr>\n</tbody>\n\t</table>\n</div>\n<p>This release is mainly about the inference backend layer: PaddleOCR continues to provide OCR and document parsing capabilities, while Transformers gives supported PaddleOCR models another backend option that fits naturally into Hugging Face-centered environments.
