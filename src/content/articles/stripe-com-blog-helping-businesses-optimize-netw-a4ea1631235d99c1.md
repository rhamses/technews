contentHtml: "<section>\n    <p>Visa recently launched the <a target=\"_blank\" href=\"https://support.stripe.com/questions/understand-the-visa-digital-commerce-authentication-program-%28dcap%29-on-stripe\">Digital Commerce Authentication Program (DCAP)</a>, a new global framework designed to reduce fraud and increase authorization rates for card-not-present transactions. The program rewards businesses in the US for sharing richer transaction data with issuers during authentication, such as device ID, billing address, IP address, and customer email. Qualifying transactions receive a net interchange reduction of five basis points.</p><p>New network programs create opportunity, but they also introduce complexity. Businesses need to understand which transactions qualify, ensure their integration passes the required data, and determine whether participating will improve their end-to-end transaction economics or have unintended consequences, such as hurting authorization rates.</p><p>To participate in DCAP, businesses need to share required cardholder data with issuers via frictionless authentication in their checkout. This might introduce latency and uncertainty around how issuers interpret these newer signals.&#160;</p><p>We moved quickly to help Stripe businesses take advantage of DCAP and capture interchange savings while protecting authorization rates. Here’s what we did.&#160;</p><h3>Optimizing DCAP savings without sacrificing conversion</h3><p>Before rolling out DCAP, we worked with Visa to run readiness testing and identify the right implementation approach. This collaborative testing underscored the need for transaction-level intelligence.</p><p>With <a target=\"_blank\" href=\"https://stripe.com/authorization-boost\">Stripe Authorization Boost</a>, we intelligently select which transactions should go through <a target=\"_blank\" href=\"https://docs.stripe.com/payments/3d-secure/strong-customer-authentication-exemptions#data-only\">Data Only 3DS</a>, which sends additional risk data from the card network to the issuer for authorization. Rather than applying static rules, Authorization Boost evaluates cost savings, conversion impact, and fraud risk at the individual transaction level to determine when to apply Data Only 3DS. This allows businesses to capture DCAP savings while limiting the impact to the customer experience and optimizing authorization rates.</p><p>Since April 18, we’ve helped Stripe businesses capture $18.4 million in annualized network cost savings from DCAP. By helping businesses collect and pass the required data, we saw an 8x increase in the number of DCAP-eligible transactions. We’re continuing to work with Visa to optimize eligibility, so more transactions can benefit from DCAP.</p><h2>Automatically benefit from DCAP optimizations&#160;</h2><p>If you use Authorization Boost and are collecting the required data points, you’re already automatically benefiting from DCAP optimizations. For businesses using <a target=\"_blank\" href=\"https://docs.stripe.com/payments/3d-secure/standalone-3d-secure\">standalone 3DS</a>, you can participate by setting <strong>flow_preference[type]</strong> to <code>data_share</code> on authentication requests and ensuring required fields are populated.</p><p>Learn more about how <a target=\"_blank\" href=\"https://docs.stripe.com/payments/analytics/optimization\">Authorization Boost</a> can help optimize your payments performance.</p>\n  </section>"
