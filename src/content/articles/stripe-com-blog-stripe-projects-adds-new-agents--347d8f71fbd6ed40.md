And yet, many of the steps adjacent to writing code—such as provisioning infrastructure, managing credentials, setting up accounts, and connecting services together—are still too hard for agents to do on their own.&#160;</p><p>We’re expanding <a target=\"_blank\" href=\"https://projects.dev/\">Stripe Projects</a>, which lets you provision and manage services from the CLI, to solve this with new agent integrations, additional providers, and new developer controls.&#160;</p><p>Here’s what’s new with Projects.</p><h2>Hermes, Factory Droids, and Warp agents can provision infrastructure directly</h2><p>Stripe Projects is now available as a skill—a set of structured instructions that give agents the context to act—in <a target=\"_blank\" href=\"https://hermes-agent.nousresearch.com/\">Hermes</a>, an open-source, self-improving AI agent from Nous Research. Stripe Projects handles infrastructure provisioning and management, while Hermes carries context across sessions. This means that if you’re building a complex product over days or weeks, your agent is a persistent collaborator—returning to a project the same way a developer would. </p><figure>\n  <div>\n  <picture>\n        <source srcset=\"https://images.stripeassets.com/fzn2n1nzq965/3cBn2JGUW48c3vW16XVHSO/b86389a61ceda91eba7dd78324a2b2b2/projects-social.png?w=1620&q=80&fm=webp\" type=\"image/webp\">\n      <img alt=\"Blog > Projects > Hermes\" src=\"https://images.stripeassets.com/fzn2n1nzq965/3cBn2JGUW48c3vW16XVHSO/b86389a61ceda91eba7dd78324a2b2b2/projects-social.png?w=1620&q=80\">\n    </picture>\n</div>\n</figure><p><a target=\"_blank\" href=\"https://factory.ai/\">Factory Droids</a> and <a target=\"_blank\" href=\"https://www.warp.dev/integrations/stripe\">Warp</a>, model-agnostic coding agents, have also integrated with Projects. Developers can now access the embedded Projects CLI directly in their preferred agent workflows.</p><h2>Agents can provision and build with 16 new providers</h2><p>Stripe Projects now connects to 16 new providers for a total of <a target=\"_blank\" href=\"https://projects.dev/providers\">49 providers</a>. New providers include Metronome, a Stripe product, for usage-based billing, Wix for public-facing storefronts, and ClickHouse for LLM observability. This allows agents to spin up a live AI-powered product, bill users, and monitor model cost, latency, and quality from the first call—without a human clicking through a dashboard.</p><h2>Developers can access new controls for agents to safely build</h2><p>Agents provisioning infrastructure need many of the same guardrails as agents making purchases, such as scoped credentials, spend thresholds, and enforced environment boundaries. We’re shipping three updates to give you that control, plus the ability for platforms to natively distribute services for its users.</p><p><strong>See multiple providers’ spend in one place.</strong> Stripe Projects now gives you a unified view across all providers by current and historical <a target=\"_blank\" href=\"https://docs.stripe.com/projects#view-your-spend\">cost per project</a>, so you can understand what a project costs to run.&#160;</p><p><strong>Set spend limits per provider.</strong> You can now <a target=\"_blank\" href=\"https://docs.stripe.com/projects#set-a-spend-limit\">set custom spending caps per service</a>, such as tighter limits on an AI model provider, or higher limits for production hosting and database layer. Per-provider limits let you tailor the guardrails for each service, helping prevent an agent from burning through your entire budget on a single provider.&#160;</p><p><strong>Keep builds contained with named environments. </strong>You can now create <a target=\"_blank\" href=\"https://docs.stripe.com/projects#manage-multiple-environments\">isolated credentials</a> for&#160; development, staging, production, or any custom environment, as well as share resources across environments when you need consistency. Agents default to the development environment, so even if an agent goes off-script, it won’t access or impact your production environment.&#160;</p><p><strong>Natively provision services on your platform.</strong> With delegated authority and white-labeling support, <a target=\"_blank\" href=\"https://docs.stripe.com/projects/platform-integration\">platforms can now mint scoped credentials</a> and set up infrastructure on your developers’ behalf, so developers can go from writing code to running it without leaving your environment.</p><h3>What’s next</h3><p>We’ll continue to expand Projects to cover the full lifecycle of agent-built software, from first provision to ongoing operations and security. We plan to add deeper security primitives for agents that act autonomously and a data layer, so providers can meter and bill for the software agents that build on top of their services.</p><p>Learn more about <a target=\"_blank\" href=\"https://docs.stripe.com/projects\">Stripe Projects</a> or, if you’re ready to build, ask your agent to: <em>use Stripe Projects to add a Prisma database.</em>\n</p>\n  </section>"
