contentHtml: "<article><div>\n<p>ChatGPT is no longer just a chat app. OpenAI recently launched the <a target=\"_blank\" href=\"https://developers.openai.com/apps-sdk/\">Apps SDK</a>, which turns ChatGPT into a platform where developers can build interactive applications. These apps run inside ChatGPT and can display custom interfaces, connect to databases, and perform real actions.</p>\n<p>In this guide, you will learn how to build a ChatGPT app that connects to your Supabase database. You will use <a target=\"_blank\" href=\"https://mcp-use.com/\">mcp-use</a>, an open source SDK that makes it easy to deploy MCP servers on Supabase Edge Functions. By the end, you will have an app that lets ChatGPT users explore your database schema, view table data, and run SQL queries, all through interactive widgets.</p>\n<p>ChatGPT apps extend what ChatGPT can do. Instead of just answering questions, ChatGPT can now show interactive interfaces and connect to external services.</p>\n<p>Every ChatGPT app has two parts:</p>\n<ul>\n<li><strong>MCP server.</strong> This is your backend. It defines the tools and capabilities your app provides. When a user asks ChatGPT to do something, ChatGPT calls your MCP server to get the data or perform the action.</li>\n<li><strong>Web component.</strong> This is your frontend. It renders inside ChatGPT as an iframe. Your MCP server can return UI metadata that tells ChatGPT which component to display and what data to pass to it.</li>\n</ul>\n<p>The MCP server and web component work together. ChatGPT acts as the bridge. When a user asks a question, ChatGPT figures out which tool to call. Your MCP server runs the tool and returns both data and UI instructions. ChatGPT then renders your component with the data.</p>\n<p>This architecture is powerful because it separates what your app can do from how it looks. Your MCP server handles all the logic. Your components handle all the display. ChatGPT handles the conversation.</p>\n<p>mcp-use is an open source TypeScript SDK for building MCP servers. It solves a specific problem: the official MCP SDK uses Express, which depends on Node.js features that do not work in edge environments like Supabase Edge Functions.</p>\n<p>mcp-use uses Hono instead of Express. Hono is a lightweight web framework designed for edge runtimes. This means your MCP server can run on Supabase Edge Functions, Cloudflare Workers, and other serverless platforms.</p>\n<p>Here is what mcp-use gives you:</p>\n<ul>\n<li><strong>Edge runtime support.</strong> Works on Deno, Cloudflare Workers, and Supabase Edge Functions.</li>\n<li><strong>OpenAI Apps SDK integration.</strong> Built-in support for ChatGPT app widgets and UI components.</li>\n<li><strong>Supabase Auth integration.</strong> Native support for authenticating users with Supabase Auth.</li>\n<li><strong>Full MCP compliance.</strong> Scores 100/100 on the official MCP conformance tests.</li>\n</ul>\n<p>Supabase Edge Functions are a good fit for MCP servers for several reasons.</p>\n<ul>\n<li><strong>Everything in one place.</strong> Your database, authentication, and server code all live in the same Supabase project. Your MCP server can query your database directly. It can check user permissions using Supabase Auth. There is no need to manage separate services or configure connections between them.</li>\n<li><strong>Fast cold starts.</strong> Edge Functions run on Deno and start quickly. When ChatGPT calls your MCP server, users do not wait for a container to spin up.</li>\n<li><strong>Built-in authentication.</strong> Supabase Auth works out of the box with mcp-use. You can require users to log in before using your app. You can check their roles and permissions. You can scope data access to specific users.</li>\n<li><strong>Simple deployment.</strong> A single command deploys your MCP server. Supabase handles scaling, HTTPS, and infrastructure.</li>\n</ul>\n<p>You will build a ChatGPT app that explores Supabase databases. The app provides four tools:</p>\n<ul>\n<li><strong>List tables.</strong> Shows all tables in your database with an interactive schema explorer widget.</li>\n<li><strong>Show table.</strong> Displays data from a specific table with sorting and filtering.</li>\n<li><strong>Execute SQL.</strong> Runs read-only SQL queries and shows results with syntax highlighting.</li>\n<li><strong>Supabase status.</strong> Shows the current status of Supabase services and recent incidents.</li>\n</ul>\n<p>Each tool returns both data and a React widget. ChatGPT users see interactive interfaces, not just text responses.</p>\n<p>This guide provides the key points for building a ChatGPT app. For the full implementation, please visit or clone the
