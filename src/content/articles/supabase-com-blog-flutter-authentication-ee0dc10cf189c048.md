In this article, we will take a look at how we can implement authentication using Google sign-in to secure our application using the <a target=\"_blank\" href=\"https://supabase.com/docs/reference/dart/introduction\">Supabase SDK for Flutter</a>.</p>\n<p>We will also dive into the deep ends of Open ID Connect sign-in to better understand how third-party sign-ins are being performed. You can check out the code of the sample in this article <a target=\"_blank\" href=\"https://github.com/supabase/supabase/tree/master/examples/auth/flutter-native-google-auth\">here</a>.</p>\n<p>This article assumes you are comfortable with writing a basic application in Flutter. Open ID Connect, or OIDC is a protocol built on top of OAuth 2.0 that allows third-party applications to request the users to provide some personal information, such as name or profile image, in the form of an identity token along with an access token. This identity token can then be verified and decoded by the application to obtain that personal information.</p>\n<p>Supabase auth provides <code>signInWithIdToken</code> method where we can sign in a user using their ID token obtained from third-party auth providers such as Google. Upon signing a user with the <code>signInWithIdToken</code> method, Supabase automatically populates the content of the ID token in the Supabase user metadata for easy access to the information. We will be utilizing this feature in this example to display the user profile upon the user signing in.</p>\n<p>In today’s example, our app will make a request to Google, obtain the identity token, and we will use it to sign the user in as well as obtain basic user information.</p>\n<p>We will build a simple app with a login screen and a home screen. The user is first presented with the login screen, and only after they sign in, can they proceed to the home screen. The login screen presents a login button that will kick off a third-party authentication flow to complete the sign-in. The profile screen displays user information such as the profile image or their full name.</p>\n<p>Let’s start by creating a fresh Flutter project.</p>\n<div><p><code><br><div><p><span>_<!-- -->10</span></p><p><span>flutter create myauthapp</span></p></div><br></code></p></div>\n<p>then we can install the dependencies.
