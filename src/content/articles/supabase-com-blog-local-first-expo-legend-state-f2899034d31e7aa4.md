Legend-State has four primary goals:</p>\n<ol>\n<li>As easy as possible to use.</li>\n<li>The fastest React state library.</li>\n<li>Fine-grained reactivity for minimal renders.</li>\n<li>Powerful sync and persistence (with Supabase support built in!)</li>\n</ol>\n<p>And, to put the cherry on top, it works with Expo and React Native (via <a target=\"_blank\" href=\"https://github.com/react-native-async-storage/async-storage?tab=readme-ov-file#react-native-async-storage\">React Native Async Storage</a>). This makes it a perfect match for building local-first mobile and web apps.</p>\n<p>In local-first software, \"the availability of another computer should never prevent you from working\" (<a target=\"_blank\" href=\"https://www.youtube.com/watch?v=NMq0vncHJvU\">via Martin Kleppmann</a>). When you are offline, you can still read and write directly from/to a database on your device. You can trust the software to work offline, and you know that when you are connected to the internet, your data will be seamlessly synced and available on any of your devices running the app. When you're online, this architecture is well suited for \"multiplayer\" apps, as <a target=\"_blank\" href=\"https://www.figma.com/blog/how-figmas-multiplayer-technology-works/\">popularized by Figma</a>.</p>\n<p>To dig deeper into what local-first is and how it works, refer to the <a target=\"_blank\" href=\"https://docs.expo.dev/guides/local-first/\">Expo docs</a>.</p>\n<p>A primary goal of Legend-State is to make automatic persisting and syncing both easy and very robust, as it's meant to be used to power all storage and sync of complex apps.</p>\n<p>Any changes made while offline are persisted between sessions to be retried whenever connected. To do this, the sync system subscribes to changes on an observable, then on change goes through a multi-step flow to ensure that changes are persisted and synced.</p>\n<ol>\n<li>Save the pending changes to local persistence.</li>\n<li>Save the changes to local persistence.</li>\n<li>Save the changes to remote persistence.</li>\n<li>On remote save, set any needed changes (like updated_at) back into the observable and local persistence.</li>\n<li>Clear the pending changes in local persistence.</li>\n</ol>\n<p>To set up a new React Native project you can use the <code>create-expo-app</code> utility.
