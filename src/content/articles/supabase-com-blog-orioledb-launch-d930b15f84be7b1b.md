contentHtml: "<article><div>\n<p>Today, we're releasing the Public Alpha of <a target=\"_blank\" href=\"https://www.orioledb.com/\">OrioleDB</a> on the Supabase platform.</p>\n<h3 id=\"whats-orioledb\">What’s OrioleDB?<a target=\"_blank\" href=\"https://supabase.com/blog/orioledb-launch#whats-orioledb\">#</a></h3>\n<p>OrioleDB is a <strong>storage extension</strong> which uses Postgres' pluggable storage system. It’s designed to be a drop-in replacement for Postgres’ default Heap storage.</p>\n<p>You can read more about OrioleDB <a target=\"_blank\" href=\"https://www.orioledb.com/blog/orioledb-beta7-benchmarks\">here</a> and learn why you might choose it over the default Postgres storage engine.</p>\n<h3 id=\"limitations\">Limitations<a target=\"_blank\" href=\"https://supabase.com/blog/orioledb-launch#limitations\">#</a></h3>\n<p>This initial release is a Public Alpha and you should <em>not</em> use it for Production workloads. The release comes with several limitations:</p>\n<ul>\n<li>The release is restricted to Free organizations. You will not be able to upgrade OrioleDB projects to larger instance sizes. If you want to run OrioleDB on a larger instance we suggest following the <a target=\"_blank\" href=\"https://www.orioledb.com/docs/usage/getting-started\">Getting Started</a> guide on OrioleDB’s official website.</li>\n<li>Index support is restricted to the Postgres default B-Tree index type. Other indexs like GIN/GiST/BRIN/Hash, and pgvector's HNSW/IVFFlat are not supported.</li>\n</ul>\n<h3 id=\"should-you-use-it-today\">Should you use it today?<a target=\"_blank\" href=\"https://supabase.com/blog/orioledb-launch#should-you-use-it-today\">#</a></h3>\n<p>At this stage, the goal of adding OrioleDB to the platform is to make it easier for testers to give feedback. If you’re running Production workloads, stick to the standard options available.</p>\n<h3 id=\"getting-started-and-more-info\">Getting started and more info<a target=\"_blank\" href=\"https://supabase.com/blog/orioledb-launch#getting-started-and-more-info\">#</a></h3>\n<p>To get started today, go to <a target=\"_blank\" href=\"http://database.new/\">database.new</a> and choose “Postgres with OrioleDB” under the \"Advanced Configuration\" section when launching a new database.</p>\n<!-- -->\n<p>If you want to learn more about OrioleDB and their vision for the future, check out the <a target=\"_blank\" href=\"https://www.orioledb.com/blog/orioledb-beta7-benchmarks\">blog post the OrioleDB team released today</a>.</p></div></article>"
