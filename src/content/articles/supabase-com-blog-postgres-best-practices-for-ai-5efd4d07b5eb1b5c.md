Think of them as documentation written for machines. Instead of hoping an agent learned the right patterns from its training data, you give it explicit rules to follow. The agent reads the skill when it needs guidance and applies the rules to its work.</p>\n<p>The format was developed by <a target=\"_blank\" href=\"https://github.com/anthropics/skills\">Anthropic</a> and released as an open standard. It has since been adopted across the industry. Vercel used it to publish <a target=\"_blank\" href=\"https://vercel.com/blog/introducing-react-best-practices\">react-best-practices</a>, packaging ten years of React and Next.js optimization knowledge into 40 rules that agents can reference. Cloudflare released <a target=\"_blank\" href=\"https://github.com/cloudflare/skills\">skills for Workers, Pages, D1, R2, and 40 other services</a>. We're applying the same approach to Postgres.</p>\n<p>When you install the skill, your agent gains access to all 30 rules. It can reference them when writing queries, reviewing code, or suggesting schema changes. The agent treats the rules as authoritative guidance rather than generating advice from its training data.</p>\n<p>Supabase runs Postgres for hundreds of thousands of projects. We see the same mistakes repeatedly:</p>\n<ul>\n<li>Missing indexes on foreign keys</li>\n<li>Queries that bypass RLS by accident</li>\n<li>Migrations that lock tables in production</li>\n<li>Connection pool exhaustion from poorly managed clients</li>\n<li>Full table scans hidden behind ORMs</li>\n</ul>\n<p>Our support team, database advisors, and documentation already contain this knowledge. We packaged it into a format that agents can use directly.</p>\n<p>If you've used the <a target=\"_blank\" href=\"https://supabase.com/docs/guides/getting-started/mcp\">Supabase MCP server</a>, you know it lets AI agents connect directly to your Supabase project. Agents can create tables, run queries, manage schemas, and configure settings through natural language.</p>\n<p>The MCP server gives agents the <em>ability</em> to work with your database. These best practices teach them to do it <em>correctly</em>.</p>\n<p>Think of it this way: the MCP server is the steering wheel, and the best practices are the driving lessons. An agent with MCP access can execute any query you ask for. An agent with both MCP access and these rules will warn you before creating an index that locks your table, suggest RLS policies before you ship insecure code, and structure queries to avoid performance problems.</p>\n<p>They work well together. The MCP server handles the connection and execution. The best practices handle the judgment.</p>\n<p>The rules in this repo came from our internal knowledge base, but we know the community has insights we've missed.</p>\n<p>If you've hit a Postgres gotcha that agents should know about, open a PR. Each rule needs:</p>\n<ul>\n<li>A clear title</li>\n<li>A priority level (critical, high, medium, low)</li>\n<li>An explanation of why it matters</li>\n<li>Good and bad code examples</li>\n</ul>\n<p>The <code>CONTRIBUTING.md</code> file has the full template.</p>\n<p>The repo is live at <a target=\"_blank\" href=\"https://github.com/supabase/agent-skills\">github.com/supabase/agent-skills</a>.</p>\n<p>To install a skill, you can use <a target=\"_blank\" href=\"https://www.npmjs.com/package/skills\">Vercel’s skills npm package</a> to interactively install this skill on your agent.</p>\n<div><p><code><br><div><p><span>_<!-- -->10</span></p><p><span>npx skills add supabase/agent-skills</span></p></div><br></code></p></div>\n<p>If you’re using Claude Code, you can also install this skill as a plugin.</p>\n<div><p><code><br><div><p><span>_<!-- -->10</span></p><p><span>/plugin marketplace add supabase/agent-skills</span></p></div><div><p><span>_<!-- -->10</span></p><p><span>/plugin install postgres-best-practices@supabase-agent-skills</span></p></div><br></code></p></div>\n<p>Try it on your next Postgres project, and let us know what rules are missing.</p></div></article>"
