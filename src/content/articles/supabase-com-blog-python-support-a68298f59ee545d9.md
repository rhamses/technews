This demand for the most part has been serviced by the open source community itself, which currently maintains <a target=\"_blank\" href=\"https://github.com/supabase-community/#client-libraries\">dozens of libraries</a>.</p>\n<p>When folks make requests to the hosted Supabase service we're able to build up a good picture of how broadly some of these libraries are used, and when a particular library achieves broad adoption it makes sense for us to add official support for it. Examples of libraries that have made the leap from community supported to officially supported include <a target=\"_blank\" href=\"https://github.com/supabase/supabase-flutter\">supabase-flutter</a> and <a target=\"_blank\" href=\"https://github.com/supabase/supabase-swift/\">supabase-swift</a>.</p>\n<p>There has always been incredible community support for the Python client libraries, over the last year and a half however we've seen a huge surge in adoption.
