An index is like the index at the back of a book. Instead of reading every page to find a topic, you look it up in the index and jump straight to the right page. Postgres works the same way. Without an index, Postgres reads every row in a table to find matching data. This is called a sequential scan. With an index, Postgres looks up which rows match and jumps directly to them. The difference can be dramatic: a query that takes 30 seconds without an index might take 30 milliseconds with one.</p>\n<p>Run <code>EXPLAIN ANALYZE</code> on slow queries to see if Postgres is using indexes or doing sequential scans. Analytical queries do the opposite. They scan millions of rows, aggregate data, and compute statistics.
