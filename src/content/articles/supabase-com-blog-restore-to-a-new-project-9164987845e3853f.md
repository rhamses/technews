contentHtml: "<article><div><p>Today we’re adding <a target=\"_blank\" href=\"https://supabase.com/docs/guides/platform/clone-project\">Restore to a New Project</a>.</p>\n<p>You can use this new tool to copy data easily from an existing Supabase project to a new one. <strong>Restore to a New Project</strong> integrates seamlessly with daily physical backups and Point-in-Time Recovery (PITR) to provide flexible restoration options.</p>\n<p>When physical backups are enabled, Supabase triggers daily backups of project data. You can use this backup to restore to a new Supabase project. The new project should match the original project attributes:</p>\n<ul>\n<li>Size of compute instance.</li>\n<li>Disk settings; volume type, size, IOPS, and throughput.</li>\n<li>SSL enforcement configuration.</li>\n<li>Network restrictions.</li>\n<li>Cloud region.</li>\n</ul>\n<p>After launching your restored project, the rest of the process is automated. The length of time for a new project to provision will depend on the size of the source dataset.</p>\n<p>The new project will be available in the Supabase Dashboard as soon as the copy process has completed. This project will behave as any other Supabase project and is completely independent of the source.</p>\n<h3 id=\"point-in-time-recovery\">Point-in-Time Recovery<a target=\"_blank\" href=\"https://supabase.com/blog/restore-to-a-new-project#point-in-time-recovery\">#</a></h3>\n<p>In addition to daily backups it is possible to restore from a project with PITR enabled. This allows for very fine granularity when selecting the desired point to restore from. The process is very similar as with daily backup with the exception of being asked to select a specific time.</p>\n<p>To ensure maximum flexibility a source project can be <em>copied</em> as many times as required, making the tool perfect for testing, development environments etc. However, please note that cloning from an already cloned project is not currently supported (this is in the works).</p>\n<p>The Restore to a New Project feature can be found on the Supabase dashboard under <a target=\"_blank\" href=\"https://supabase.com/dashboard/project/_/database/backups/restore-to-new-project\">database backups</a>.</p>\n</div></article>"
