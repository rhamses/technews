You can provide context manually (e.g. an RLS Policy) or automatically based on whichever page you're visiting in the Dashboard (e.g. the specific table you're working on).</p>\n<p>The result is a single panel that's persistent across the entire Dashboard. It sits alongside your workspace and can be called upon when needed (<code>cmd+i</code>!). It automatically retrieves context for your prompt and can be provided with extra context similar to other AI tools like Cursor and GitHub Copilot.</p>\n<p>Let's take a look at new abilities in this release.</p>\n<h3 id=\"schema-design\">Schema design<a target=\"_blank\" href=\"https://supabase.com/blog/supabase-ai-assistant-v2#schema-design\">#</a></h3>\n<p>If you are creating something new, the Assistant can guide or inspire you. It will show you how to structure your database and generate all the SQL queries to set it up.</p>\n<!-- -->\n<h3 id=\"writing-sql\">Writing SQL<a target=\"_blank\" href=\"https://supabase.com/blog/supabase-ai-assistant-v2#writing-sql\">#</a></h3>\n<p>Like our previous Assistant, the new Assistant will help you write queries based on your schema. This version has better contextual understanding and can provide more accurate suggestions.</p>\n<h3 id=\"debug-your-queries\">Debug your queries<a target=\"_blank\" href=\"https://supabase.com/blog/supabase-ai-assistant-v2#debug-your-queries\">#</a></h3>\n<p>Writing SQL can be tough. You can use the new Assistant to debug database errors directly through the SQL Editor or within the Assistant panel.</p>\n<!-- -->\n<h3 id=\"discover-data-insights\">Discover data insights<a target=\"_blank\" href=\"https://supabase.com/blog/supabase-ai-assistant-v2#discover-data-insights\">#</a></h3>\n<p>The new Assistant can run queries directly. This can be a useful (and fun) way to query your data through natural language. Basic select queries run automatically, and results are displayed within the conversation in tabular form or chart form. The chart axis are picked intuitively by the Assistant. No data is sent to the underlying LLM, only your schema structure. This is a helpful tool for folks who are not comfortable with SQL but are still interested in analyzing data insights.</p>\n<!-- -->\n<h3 id=\"sql-to-rest\">SQL to REST<a target=\"_blank\" href=\"https://supabase.com/blog/supabase-ai-assistant-v2#sql-to-rest\">#</a></h3>\n<p>Once your database is set up, you probably want to connect to it directly or with one of our client libraries. If you're using our <code>supabase-js</code> library, we've added a helpful tool to convert an SQL query to supabase-js client code. Simply ask the Assistant to convert a query, and it will respond with either a complete snippet for you to copy or a combination of function + RPC call. This is powered by the <a target=\"_blank\" href=\"https://supabase.com/docs/guides/api/sql-to-rest\">sql-to-rest</a> tool.</p>\n<!-- -->\n<h3 id=\"rls-policies-protect-your-database\">RLS Policies: Protect your database<a target=\"_blank\" href=\"https://supabase.com/blog/supabase-ai-assistant-v2#rls-policies-protect-your-database\">#</a></h3>\n<p>Use the Assistant to suggest, create or modify RLS Policies. Simply explain the desired behavior and the Assistant will generate a new Policy using the context of your database schema and existing policies. To edit an existing policy, click “edit with Assistant” within your Policy list. The Assistant will be provided the appropriate context for you to start prompting.</p>\n<!-- -->\n<h3 id=\"postgres-functions-and-triggers\">Postgres Functions and Triggers<a target=\"_blank\" href=\"https://supabase.com/blog/supabase-ai-assistant-v2#postgres-functions-and-triggers\">#</a></h3>\n<p>Suggest, create or update functions and triggers in a similar way to policies. Just describe what you want or select “Edit with Assistant” from your Function or Trigger list.</p>\n<!-- -->\n<p>This release gives us a foundation to build off and incorporate into other parts of your database journey. Where are you struggling the most when using Postgres? How might the Assistant help you? Send us your thoughts, ideas, concerns via the feedback form in the Dashboard.</p>\n<p>Supabase Assistant v2 is available today.\nGo to a Project and hit <code>cmd + i</code>, or alternatively click the Assistant icon in the top right toolbar.</p></div></article>"
