Let's dig into some of the features of the Auth system.</p>\n<p>Supabase Auth provides all the backend services you need to authenticate and authorize your users.</p>\n<h3 id=\"user-management\">User management<a target=\"_blank\" href=\"https://supabase.com/blog/supabase-auth#user-management\">#</a></h3>\n<p>Supabase makes it simple to onboard your users with our new <code>supabase.auth.signUp()</code> and <code>supabase.auth.signIn()</code> <a target=\"_blank\" href=\"https://supabase.com/docs/guides/auth\">functions</a>.</p>\n<video width=\"99%\" loop muted controls><source src=\"https://xguihxuzqibwxjnimxev.supabase.co/storage/v1/object/public/videos/docs/auth-zoom2.mp4\" type=\"video/mp4\"></video>\n<h3 id=\"row-level-security\">Row Level Security<a target=\"_blank\" href=\"https://supabase.com/blog/supabase-auth#row-level-security\">#</a></h3>\n<p>Authentication only gets you so far. When you need granular authorization rules, nothing beats PostgreSQL's <a target=\"_blank\" href=\"https://www.postgresql.org/docs/current/ddl-rowsecurity.html\">Row Level Security</a>. Supabase makes it simple to turn RLS on and off.</p>\n<video width=\"99%\" loop muted controls><source src=\"https://xguihxuzqibwxjnimxev.supabase.co/storage/v1/object/public/videos/docs/rls-zoom2.mp4\" type=\"video/mp4\"></video>\n<h3 id=\"policies\">Policies<a target=\"_blank\" href=\"https://supabase.com/blog/supabase-auth#policies\">#</a></h3>\n<p><a target=\"_blank\" href=\"https://www.postgresql.org/docs/current/sql-createpolicy.html\">Policies</a> are PostgreSQL's rule engine. They are incredibly powerful and flexible, allowing you to write complex SQL rules which fit your unique business needs.</p>\n<video width=\"99%\" loop muted controls><source src=\"https://xguihxuzqibwxjnimxev.supabase.co/storage/v1/object/public/videos/docs/policies-zoom2.mp4\" type=\"video/mp4\"></video>\n<p>With policies, your database becomes the rules engine. Instead of repetitively filtering your queries, like this ...</p>\n<div><p><code><br><div><p><span>_<!-- -->10</span></p><p><span>const loggedInUserId = 'd0714948'</span></p></div><div><p><span>_<!-- -->10</span></p><p><span>let user = await supabase.from('users').select('user_id, name').eq('user_id', loggedInUserId)\\n</span></p></div><div><p><span>_<!-- -->10</span></p><p><span>// Returns { id: 'd0714948', name: 'Jane'</span></p></div><br></code></p></div>\n<p>... you can simply define a rule on your database table, <code>(select auth.uid()) = user_id</code>, and your request will return the rows which pass the rule, even when you remove the filter from your middleware:</p>\n<div><p><code><br><div><p><span>_<!-- -->10</span></p><p><span>let user = await supabase.from('users').select('user_id, name')\\n</span></p></div><div><p><span>_<!-- -->10</span></p><p><span>// Still returns { id: 'd0714948', name: 'Jane' }</span></p></div><br></code></p></div>\n<h3 id=\"open-source\">Open source<a target=\"_blank\" href=\"https://supabase.com/blog/supabase-auth#open-source\">#</a></h3>\n<p>Building an open source Firebase alternative is difficult task, made possible by an amazing suite of OSS tools that have forged the way for Supabase. We spent many weeks building Auth POC's with existing OSS tools. Notable mentions go to RedHat's <a target=\"_blank\" href=\"https://www.keycloak.org/\">KeyCloak</a>, and Ory's <a target=\"_blank\" href=\"https://github.com/ory/kratos\">Kratos</a>.</p>\n<p>Ultimately we landed on a system which utilises three amazing open source products:</p>\n<ul>\n<li>Authorization: <a target=\"_blank\" href=\"https://www.postgresql.org/\">PostgreSQL</a> and <a target=\"_blank\" href=\"http://postgrest.org/en/v7.0.0/auth.html\">PostgREST</a>.</li>\n<li>Authentication: Netlify's <a target=\"_blank\" href=\"https://github.com/netlify/gotrue\">GoTrue</a> server, which we forked and will continue to contribute to.</li>\n</ul>\n<h3 id=\"next-steps\">Next steps<a target=\"_blank\" href=\"https://supabase.com/blog/supabase-auth#next-steps\">#</a></h3>\n<p>Supabase has a culture of shipping early and often.
