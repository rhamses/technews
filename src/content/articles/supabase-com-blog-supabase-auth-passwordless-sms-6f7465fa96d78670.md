You can write native PostgreSQL Row Level Security policies to\ndetermine which data your users should (or should not) have access to. It can even be used in conjunction with other Supabase features,\nsuch as <a target=\"_blank\" href=\"https://supabase.com/storage\">Storage</a>, to control access for specific files and buckets.</p>\n<p>Today we're announcing some major new features for our <a target=\"_blank\" href=\"https://github.com/supabase/gotrue\">fork</a> of Netlify's <a target=\"_blank\" href=\"https://github.com/netlify/gotrue\">GoTrue</a> Auth server.</p>\n<p>Your users can now log in using their mobile with SMS-based OTPs (one-time password).</p>\n<h3 id=\"passwordless-sms-login\">Passwordless SMS login<a target=\"_blank\" href=\"https://supabase.com/blog/supabase-auth-passwordless-sms-login#passwordless-sms-login\">#</a></h3>\n<p>Users can log in using a passwordless SMS based OTP with <code>supabase-js</code>, or directly with the Auth API.</p>\n<p>After logging in, the user will receive a six-digit One Time Password. The OTP can be easily verified.</p>\n<h3 id=\"sms-login-with-passwords\">SMS login with passwords<a target=\"_blank\" href=\"https://supabase.com/blog/supabase-auth-passwordless-sms-login#sms-login-with-passwords\">#</a></h3>\n<p>Phone Auth can be used in conjunction with a password. We've also laid the groundwork for mobile Multi-Factor\nAuth and will be offering that as an option soon.</p>\n<p>The community has contributed tons of OAuth providers, and today we're announcing two more.</p>\n<p>Shoutout to <a target=\"_blank\" href=\"https://github.com/ph1p\">@ph1p</a> who contributed <a target=\"_blank\" href=\"https://supabase.com/docs/guides/auth/auth-twitch\">Twitch</a> as our latest OAuth provider!\nThe Supabase team added <a target=\"_blank\" href=\"https://supabase.com/docs/guides/auth/social-login/auth-discord\">Discord</a> last month, bringing the total OAuth Providers to ten.</p>\n<p>You can request more providers on our <a target=\"_blank\" href=\"https://github.com/supabase/gotrue\">Auth repo</a> and Pull Requests are, of course, always welcome.</p>\n<p>To make life easy for developers, the Supabase hosted platform manages all Auth-related emails, including confirmation,\nrecovery, invite, and passwordless \"magic-link\" emails. The templates are customizable and we even offer the ability to bring your own SMTP provider.</p>\n<p>Some of our power users require a little more flexibility however.
