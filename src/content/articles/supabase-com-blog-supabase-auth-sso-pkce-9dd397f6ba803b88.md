The authorization code is returned as a query parameter so it's accessible on the server. During the PKCE flow:</p>\n<ol>\n<li>The <em>code challenge</em> is sent to Supabase Auth, which returns an <em>authorization code.</em></li>\n<li>The client sends the <em>authorization code</em> together with the <em>code verifier</em> to obtain the user's session.</li>\n<li>Supabase Auth checks if the <em>code verifier</em> matches the <em>code challenge</em> sent earlier by computing the hash.
