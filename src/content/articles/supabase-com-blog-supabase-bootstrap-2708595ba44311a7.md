contentHtml: "<article><div>\n<p>Supabase <code>bootstrap</code> is the fastest to spin up a new hosted Supabase project from existing starter templates:</p>\n<div><p><code><br><div><p><span>_<!-- -->10</span></p><p><span>npx supabase bootstrap</span></p></div><br></code></p></div>\n<p>This brings a “shadcn”-like experience to Supabase, creating a project locally and launching a remote database ready for deployment.</p>\n<p>From any local directory, run <code>supabase bootstrap</code> and you will be prompted to choose a starter template. And the best thing is, you don't even need to install the CLI to get started! As long as you have <code>npm</code> or <code>bun</code> installed, you're ready to go!</p>\n<ul>\n<li>CLI: <code>supabase bootstrap</code></li>\n<li>NPM: <code>npx supabase@latest bootstrap</code></li>\n<li>Bun: <code>bunx</code> <code>supabase@latest bootstrap</code></li>\n</ul>\n<p>The list of starter templates is published on GitHub as <a target=\"_blank\" href=\"https://github.com/supabase-community/supabase-samples/blob/main/samples.json\">samples.json</a>. Whenever we (and in the future the community) add a new starter, it will automatically become available to all Supabase users.</p>\n<p>The template repository typically includes the full frontend code, following the file structure below:</p>\n<ul>\n<li>A <code>supabase</code> directory with <code>config.toml</code> and <code>migrations</code> files (if any).</li>\n<li>A <code>.env.example</code> file that defines a list of environment variables for CLI to populate project credentials. We currently support the same list of credentials as our <a target=\"_blank\" href=\"https://vercel.com/integrations/supabase\">Vercel integration</a>. If a <code>.env</code> file doesn't exist, the CLI will create it for you.</li>\n</ul>\n<h3 id=\"local-development\">Local development<a target=\"_blank\" href=\"https://supabase.com/blog/supabase-bootstrap#local-development\">#</a></h3>\n<p>After selecting a starter, the Supabase CLI downloads all files from the template repository to your chosen local directory.</p>\n<p>This model is very similar to the popular <a target=\"_blank\" href=\"https://ui.shadcn.com/\">shadcn</a> workflow. After files are creating in your local repo, you can modify them and check them into source control.</p>\n<h3 id=\"deploying-to-production\">Deploying to production<a target=\"_blank\" href=\"https://supabase.com/blog/supabase-bootstrap#deploying-to-production\">#</a></h3>\n<p>During the <code>supabase bootstrap</code> process, a new project will be created on the Supabase platform and linked to your local environment. This command will run you through the account creation flow if you don't already have one.</p>\n<p>Once the linking is completed, you will be prompted to push any template migration files to your new hosted project. These migration files will setup your remote database with the necessary schemas to support the starter application.</p>\n<p>After pushing the migrations, your project credentials will be exported to a <code>.env</code> file for you to connect from any frontend or backend code. The default environment variables include:</p>\n<ul>\n<li><code>POSTGRES_URL</code></li>\n<li><code>SUPABASE_URL</code></li>\n<li><code>SUPABASE_ANON_KEY</code></li>\n<li><code>SUPABASE_SERVICE_ROLE_KEY</code></li>\n</ul>\n<p>Other custom variables from <code>.env.example</code> file defined by your chosen template will also be merged to your local <code>.env</code> file.</p>\n<p>Finally, the CLI will suggest a <code>start</code> command to launch your application locally. Starting the local app will use credentials defined in <code>.env</code> file to connect to your new hosted project.</p>\n<p>And that's it, with a single command, you can get a new project up and running end to end.</p>\n<p>Supabase Bootstrap makes it even easier to get started with Supabase, mobile app tools, and web development frameworks like Next.js, Expo React Native, Flutter, Swift iOS.</p>\n<p>We have many many more templates coming soon, and we'll be opening it up to community contributions. Stay tuned!</p>\n<p>Visit the <a target=\"_blank\" href=\"https://supabase.com/docs/guides/cli/getting-started\">Supabase CLI docs</a> to get started with <code>supabase bootstrap</code>.</p></div></article>"
