contentHtml: "<article><div>\n<p>Today we are moving the Supabase CLI v1 out of beta. The Supabase CLI is capable of managing database migrations and generating TypeScript types. Follow these <a target=\"_blank\" href=\"https://supabase.com/docs/guides/cli\">install instructions</a> to get started.</p>\n<p>In addition, we are releasing a Management API (in beta). The Management API is a REST API that allows you to manage organizations, projects, Edge Functions, and more. You can read the <a target=\"_blank\" href=\"https://supabase.com/docs/reference/api\">API docs</a> or interact with the Management API from the Supabase CLI v1.</p>\n<p>(Note: The Management API was previously called the Admin API.)</p>\n<p></p>\n<p><small><i>Watch the CLI team announcing the new features.</i></small></p>\n<p>If you've used <a target=\"_blank\" href=\"https://supabase.com/blog/supabase-edge-functions#quickstart\">Supabase Edge Functions</a>, you've used the Supabase CLI. We're extending it to let you manage organizations and projects.</p>\n<div><p><code><br><div><p><span>_<!-- -->10</span></p><p><span>supabase login</span></p></div><div><p><span>_<!-- -->10</span></p><p><span>supabase orgs list</span></p></div><div><p><span>_<!-- -->10</span></p><p><span>supabase projects create my-project --org-id cool-green-pqdr0qc --db-password ******** --region us-east-1</span></p></div><br></code></p></div>\n<p>Once your new Supabase project is created, use the CLI to link it locally to begin development.</p>\n<div><p><code><br><div><p><span>_<!-- -->10</span></p><p><span>supabase link --project-ref &lt;project-id&gt;</span></p></div><br></code></p></div>\n<p>View the <a target=\"_blank\" href=\"https://supabase.com/docs/reference/cli\">Supabase CLI docs</a> for the full list of available commands.</p>\n<p>You asked for more database migration support, and we listened. We've made improvements to manually-written migrations and auto generated schema diffs.</p>\n<h3 id=\"schema-diff-ing\">Schema diff-ing<a target=\"_blank\" href=\"https://supabase.com/blog/supabase-cli-v1-and-admin-api-beta#schema-diff-ing\">#</a></h3>\n<p>Previously we supported schema diff-ing using PgAdmin. We found that the tool did not account for default privileges when generating role grants. This leads to verbose statements when diff-ing complex schema changes.</p>\n<p>To improve the usability of <code>db diff</code> command, we are introducing another tool, <a target=\"_blank\" href=\"https://github.com/djrobstep/migra\">migra</a>, via the <code>--use-migra</code> experimental flag. We found that <code>migra</code> runs faster and produces more concise DDL statements. While the generated scripts are <a target=\"_blank\" href=\"https://supabase.com/blog/supabase-cli#migrations\">not perfect</a>, we hope this tool helps you iterate quicker on your migration scripts. Over time (and with your feedback) we hope to improve schema-diffing to cover all edge-cases.</p>\n<div><p><code><br><div><p><span>_<!-- -->10</span></p><p><span>$ supabase db diff --use-migra --file file_name</span></p></div><div><p><span>_<!-- -->10</span></p><p><span># Creates a DDL script: supabase/migrations/&lt;datetime_string&gt;_file_name.sql</span></p></div><br></code></p></div>\n<p>Running the above command diffs the <code>public</code> schema of your local development database against a fresh shadow database. You may specify other schema by passing in the <code>--schema</code> flag multiple times or as a comma separate list. More details in our <a target=\"_blank\" href=\"https://supabase.com/docs/guides/cli/cicd-workflow#creating-a-new-migration\">migration guide</a>.</p>\n<p>In the long-term we hope to consolidate on a single diff-ing tool which is perfect, but diff-ing is hard so we would need your help and feedback to improve tooling.</p>\n<h3 id=\"manual-migrations\">Manual migrations<a target=\"_blank\" href=\"https://supabase.com/blog/supabase-cli-v1-and-admin-api-beta#manual-migrations\">#</a></h3>\n<p>You can test manual migrations locally without data loss using local branching. Run the following commands to clone your local database to a new branch.</p>\n<div><p><code><br><div><p><span>_<!-- -->10</span></p><p><span>supabase db branch new my_branch</span></p></div><div><p><span>_<!-- -->10</span></p><p><span>supabase db branch switch my_branch</span></p></div><br></code></p></div>\n<p>Now you can run any DDL statements from Studio UI's SQL Editor. To undo the changes, simply switch back and delete the new branch.</p>\n<div><p><code><br><div><p><span>_<!-- -->10</span></p><p><span>supabase db branch switch main</span></p></div><div><p><span>_<!-- -->10</span></p><p><span>supabase db branch delete my_branch</span></p></div><br></code></p></div>\n<p>Automating migrations and tests on your CI / CD pipeline gives developers more confidence that each PR contains a working migration script. CLI v1 focuses on both local and <a target=\"_blank\" href=\"https://github.com/supabase/setup-cli\">GitHub Actions</a> support for the following workflows.</p>\n<p>Test all migrations on a fresh local database:</p>\n<div><p><code><br><div><p><span>_<!-- -->10</span></p><p><span>supabase init</span></p></div><div><p><span>_<!-- -->10</span></p><p><span>supabase start</span></p></div><br></code></p></div>\n<p>Release schema changes to staging and production:</p>\n<div><p><code><br><div><p><span>_<!-- -->10</span></p><p><span>$ supabase link --project-ref $PROJECT_ID</span></p></div><div><p><span>_<!-- -->10</span></p><p><span>$ supabase db push</span></p></div><br></code></p></div>\n<p>We created an <a target=\"_blank\" href=\"https://github.com/supabase/supabase-action-example\">example project</a> showing how to set up GitHub Actions to test and migrate with Supabase CLI v1.</p>\n<p>You can now generate TypeScript types using the CLI:</p>\n<div><p><code><br><div><p><span>_<!-- -->10</span></p><p><span># in a project set up with the CLI:</span></p></div><div><p><span>_<!-- -->10</span></p><p><span>supabase gen types typescript --local</span></p></div><div><p><span>_<!-- -->10</span></p><p><span>supabase gen types typescript --db-url $SUPABASE_DB_URL</span></p></div><br></code></p></div>\n<p>Of course, the types aren't very useful on its own, you need some way to consume it. For that, stay tuned for tomorrow! 😉</p>\n<p>The CLI is the first consumer of our new Management API. Over the next few weeks, we'll be adding the endpoints needed to programmatically manage your Supabase projects and organizations. This is ideal for CI/CD workflows and spinning up test environments.</p>\n<p>Here's an example of deploying a new project from the command line (generate your access token from the <a target=\"_blank\" href=\"https://supabase.com/dashboard/account/tokens\">Supabase Dashboard</a>).</p>\n<div><p><code><br><div><p><span>_<!-- -->10</span></p><p><span>curl 'https://api.supabase.com/v1/projects' \\</span></p></div><div><p><span>_<!-- -->10</span></p><p><span>  -H 'Authorization: Bearer &lt;[your-access-token](https://supabase.com/dashboard/account/tokens)&gt;' \\</span></p></div><div><p><span>_<!-- -->10</span></p><p><span>  -H \"Content-Type: application/json\" \\</span></p></div><div><p><span>_<!-- -->10</span></p><p><span>  -d '{\"name\": \"my-project\", \"organization_id\": \"cool-green-pqdr0qc\", \"region\": \"us-east-1\", \"plan\": \"free\", \"db_pass\": \"********\"}'</span></p></div><br></code></p></div>\n<p>The response JSON will match the example below:</p>\n<div><p><code><br><div><p><span>_<!-- -->10</span></p><p><span>{</span></p></div><div><p><span>_<!-- -->10</span></p><p><span>  \"id\": \"abcdefghijklmnopqrst\",</span></p></div><div><p><span>_<!-- -->10</span></p><p><span>  \"organization_id\": \"cool-green-pqdr0qc\",</span></p></div><div><p><span>_<!-- -->10</span></p><p><span>  \"name\": \"hello\",</span></p></div><div><p><span>_<!-- -->10</span></p><p><span>  \"region\": \"us-east-1\",</span></p></div><div><p><span>_<!-- -->10</span></p><p><span>  \"created_at\": \"2022-08-12T17:37:11.88819Z\"</span></p></div><div><p><span>_<!-- -->10</span></p><p><span>}</span></p></div><br></code></p></div>\n<p>Check out the <a target=\"_blank\" href=\"https://supabase.com/docs/reference/api\">API docs</a> to browse all the functionality added so far.</p>\n<p>The new API also opens the door to a whole new suite of integrations, including Zapier, Terraform, Pulumi etc. We're looking forward to seeing how the dev community interacts with these new public endpoints.
