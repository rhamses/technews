contentHtml: "<article><div>\n<p>We're launching <a target=\"_blank\" href=\"https://supabase.sh/\">supabase.sh</a>, a public SSH server that gives AI coding agents direct bash access to Supabase documentation. It's free and available now as a public experiment:</p>\n<div><p><code><br><div><p><span>_<!-- -->10</span></p><p><span>ssh supabase.sh</span></p></div><br></code></p></div>\n<p>Coding agents don't know what they don't know. Without access to the latest docs, they guess - and often recommend non-existent APIs, run incorrect CLI commands, or skip steps like enabling RLS. What's the best way to get up-to-date docs in front of them?</p>\n<p>If you watch a coding agent work through a codebase, you'll see the same tools over and over: <code>grep</code>, <code>find</code>, <code>ls</code>, <code>cat</code>. These models are trained heavily on bash and they treat the file system as their primary interface for exploration.</p>\n<p><a target=\"_blank\" href=\"https://supabase.sh/\">supabase.sh</a> gives them that same interface for our documentation. Every doc page is a markdown file in a virtual file system at <code>/supabase/docs</code>. Agents can search across topics, list pages, and read any page as needed. The same workflow they use for code applies to docs.</p>\n<p>Add recommended Supabase instructions to your project's <code>AGENTS.md</code> or <code>CLAUDE.md</code>:</p>\n<div><p><code><br><div><p><span>_<!-- -->10</span></p><p><span>ssh supabase.sh agents &gt;&gt; AGENTS.md</span></p></div><br></code></p></div>\n<p>Or let your agent set it up for you:</p>\n<div><p><code><br><div><p><span>_<!-- -->10</span></p><p><span>ssh supabase.sh setup | claude</span></p></div><br></code></p></div>\n<p>The snippet tells your agent to check the docs before working with Supabase, keeping it grounded in current docs without hallucinating.</p>\n<p><a target=\"_blank\" href=\"https://supabase.sh/\">supabase.sh</a> runs on <a target=\"_blank\" href=\"https://github.com/vercel-labs/just-bash\">just-bash</a>, an open-source Bash emulator from Vercel written in TypeScript. Commands run inside a sandboxed JavaScript runtime over a virtual file system, which means we can keep it public and unauthenticated without running an actual shell on the server.</p>\n<p>This isn't the first time someone has built a public app over SSH. The <a target=\"_blank\" href=\"https://charm.sh/\">Charm</a> team explored this idea with their <a target=\"_blank\" href=\"https://github.com/charmbracelet/wish\">Wish</a> library, and there are some well-known SSH experiments worth trying (<code>ssh terminal.shop</code> is a good one).</p>\n<p>We applied the same pattern to documentation - the files served over SSH are the same markdown source that powers <a target=\"_blank\" href=\"https://supabase.com/docs\">supabase.com/docs</a>. It's the same content, just through a bash shell instead of a browser.</p>\n<p>The <a target=\"_blank\" href=\"https://supabase.com/docs/guides/getting-started/mcp\">Supabase MCP server</a> already ships a <code>search_docs</code> tool - hybrid keyword and semantic search over our docs. It works, but the agent has to know what to ask for up front. It can't browse, skim, or stumble onto something useful by itself.</p>\n<p>Bash gives agents the ability to explore without a predefined query. They can list all pages on a topic, search across multiple files at once, and read parts of a page before deciding whether it's relevant. Search is more opaque - the agent asks a question and gets back results without the ability to explore or navigate. With bash, it can <code>grep</code> across docs, <code>cat</code> specific files, and use <code>head</code> and <code>tail</code> to skim without bloating its context window.</p>\n<p><a target=\"_blank\" href=\"https://supabase.sh/\">supabase.sh</a> is live now. Try it from any terminal:</p>\n<div><p><code><br><div><p><span>_<!-- -->10</span></p><p><span>ssh supabase.sh</span></p></div><br></code></p></div>\n<p>To add Supabase context to your project:</p>\n<div><p><code><br><div><p><span>_<!-- -->10</span></p><p><span>ssh supabase.sh agents &gt;&gt; AGENTS.md</span></p></div><br></code></p></div>\n<p>It's open source - find the code at <a target=\"_blank\" href=\"https://github.com/supabase-community/supabase-ssh\">github.com/supabase-community/supabase-ssh</a>.</p>\n<p>This is an early experiment - let us know what you think. If you run into something or something's missing, <a target=\"_blank\" href=\"https://github.com/supabase-community/supabase-ssh/issues/new/choose\">open an issue on GitHub</a> or find us on <a target=\"_blank\" href=\"https://x.com/supabase\">X</a>.</p></div></article>"
