contentHtml: "<article><div>\n<p>Supabase is part of the <a target=\"_blank\" href=\"https://projects.dev/\">Stripe Projects</a> developer preview. Stripe Projects is a new workflow in the Stripe CLI that lets developers and AI agents provision real services and get working credentials from a single command. With Supabase in the catalog, one command provisions a Postgres database along with the rest of Supabase (Auth, Storage, Edge Functions, and Realtime) without ever opening a dashboard.</p>\n<p>AI Agents need a fast way to provision infrastructure, with deterministic steps and real credentials. They cannot click through a browser or guess at setup docs.</p>\n<p>Stripe Projects offers a standard provisioning workflow for AI Agents and humans. One command handles account setup, resource provisioning, and credential delivery. Credentials land in your environment in a format that both humans and agents can use. Your Supabase account and dashboard stay yours and are always accessible.</p>\n<p>We worked closely with Stripe as a co-design partner on the integration spec. That means provisioning a Supabase project through Stripe Projects is deterministic and repeatable. Whether you run it yourself or an agent runs it for you, the steps are the same.</p>\n<p>Install the Stripe CLI, then run:</p>\n<div><p><code><br><div><p><span>_<!-- -->10</span></p><p><span>stripe plugin install projects</span></p></div><div><p><span>_<!-- -->10</span></p><p><span>stripe projects init my-app</span></p></div><div><p><span>_<!-- -->10</span></p><p><span>stripe projects add supabase/project</span></p></div><div><p><span>_<!-- -->10</span></p><p><span>stripe projects env --sync</span></p></div><br></code></p></div>\n<p>That's it. A new Supabase project is created in your account with a full Postgres database ready to connect. To open the Supabase dashboard directly:</p>\n<div><p><code><br><div><p><span>_<!-- -->10</span></p><p><span>stripe projects open supabase</span></p></div><br></code></p></div>\n<p>If you already have a Supabase account, the flow will prompt you to link it instead of creating a new one.</p>\n<p><strong>A complete Supabase project</strong></p>\n<p>Every project includes a Postgres database, Auth, Storage, Edge Functions, and Realtime. <a target=\"_blank\" href=\"https://supabase.com/docs/guides/database/overview\">Learn more in the docs</a>.</p>\n<p><strong>Credentials in your environment</strong></p>\n<p>After provisioning, <code>stripe projects env --sync</code> writes your project credentials to a local <code>.env</code> file. They are also stored in your Stripe Project so agents can access them directly.</p>\n<p><strong>Your account, your data</strong></p>\n<p>The database lives in your own Supabase account. You keep full access to the Supabase dashboard, your connection strings, and your data. Nothing is proxied or white-labeled.</p>\n<p><strong>Credential rotation</strong></p>\n<p>You can rotate your database credentials at any time:</p>\n<div><p><code><br><div><p><span>_<!-- -->10</span></p><p><span>stripe projects rotate supabase/project</span></p></div><br></code></p></div>\n<p>This updates the stored secrets in your Stripe Project automatically.</p>\n<p>This is a developer preview. Install the Stripe CLI, then run:</p>\n<div><p><code><br><div><p><span>_<!-- -->10</span></p><p><span>stripe projects init my-app</span></p></div><div><p><span>_<!-- -->10</span></p><p><span>stripe projects add supabase/project</span></p></div><br></code></p></div>\n<p><a target=\"_blank\" href=\"https://docs.stripe.com/stripe-cli/install\">Install the Stripe CLI</a></p>\n<p><a target=\"_blank\" href=\"https://docs.stripe.com/stripe-projects\">Stripe Projects docs</a></p>\n<p>We want to hear from you. If you run into issues or have feedback, <a target=\"_blank\" href=\"https://discord.supabase.com/\">reach out on Discord</a> or open an issue on <a target=\"_blank\" href=\"https://github.com/supabase/supabase/issues\">GitHub</a>.</p>\n<p></p></div></article>"
