JSR supports publishing TypeScript source code, auto-generating documentation and type definition files, provenance attestation for more security, and can be used with npm-like package managers. Since its launch, over 250 new packages are being published each week.</p>\n<p>We're thrilled to announce that our <a target=\"_blank\" href=\"https://jsr.io/@supabase/supabase-js\">JavaScript client library</a> is now available on JSR.</p>\n<p>As many of you know, our JavaScript library, <code>supabase-js</code>, is composed of <a target=\"_blank\" href=\"https://github.com/supabase-community#client-libraries\">many sub-clients</a> that let you query your Supabase <a target=\"_blank\" href=\"https://supabase.com/database\">database</a>, subscribe to <a target=\"_blank\" href=\"https://supabase.com/realtime\">real-time events</a>, upload and download <a target=\"_blank\" href=\"https://supabase.com/storage\">files</a>, manage <a target=\"_blank\" href=\"https://supabase.com/auth\">auth</a>, invoke Deno powered <a target=\"_blank\" href=\"https://supabase.com/edge-functions\">Edge Functions</a>, and <a target=\"_blank\" href=\"https://supabase.com/vector\">more</a>. It's fully isomorphic and can be used across any environment that speaks JavaScript and HTTPS, such as browsers, servers, and <a target=\"_blank\" href=\"https://deno.com/blog/the-future-of-web-is-on-the-edge\">the edge</a>!</p>\n<p>Using supabase-js via JSR offers an excellent developer experience, with first class TypeScript support, auto-generated documentation accessible in your code editor, and more.</p>\n<p>You can get started with Supabase using the <code>deno add</code> command:</p>\n<div><p><code><br><div><p><span>_<!-- -->10</span></p><p><span>deno add @supabase/supabase-js</span></p></div><br></code></p></div>\n<p>Or using npm:</p>\n<div><p><code><br><div><p><span>_<!-- -->10</span></p><p><span>npx jsr add
