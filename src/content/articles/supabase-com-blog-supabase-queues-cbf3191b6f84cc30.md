contentHtml: "<article><div>\n<p>Today we're releasing <a target=\"_blank\" href=\"https://supabase.com/modules/queues\">Supabase Queues</a>, for durable background task processing.</p>\n<p>Supabase Queues is a Postgres-native, durable Message Queue with guaranteed delivery, improving the scalability and resiliency of your applications. It's designed to work seamlessly with the entire Supabase platform.</p>\n<p></p>\n<ol>\n<li><strong>Postgres Native</strong>: Built on top of the open source <code>pgmq</code> database extension, create and manage Queues with any Postgres tooling.</li>\n<li><strong>Granular Authorization</strong>: Control client-side consumer access to Queues with API permissions and Row Level Security (RLS) policies.</li>\n<li><strong>Guaranteed Message Delivery</strong>: Messages added to Queues are guaranteed to be delivered to your consumers.</li>\n<li><strong>Exactly Once Message Delivery</strong>: A Message is delivered exactly once to a consumer within a customizable visibility window.</li>\n<li><strong>Queue Management and Monitoring</strong>: Create, manage, and monitor Queues and Messages in the Supabase Dashboard.</li>\n<li><strong>Message Durability and Archival</strong>: Messages are stored in Postgres and you can choose to archive them for analytical or auditing purposes.</li>\n</ol>\n<p>A Queue is used to manage and process tasks asynchronously. Typically, you use a Queue for long-running tasks to ensure that your application is robust.</p>\n<p><strong>For example, sending emails:</strong></p>\n<p>Let's say you want to send a welcome email to a user after they register on your website. Instead of sending the email immediately within the registration process - which could slow down the user's experience - you can place the “email task” into a Queue.A separate email service can then process this task, sending the email without affecting the registration flow. Even better: if the email bounces then the task could \"reappear\" in the Queue to get processed again.</p>\n<p>In this scenario, Queues have improved your application's <em>performance</em> and <em>resilience</em>. Other cases include:</p>\n<ul>\n<li><strong>Process tasks asynchronously</strong>: offload time-consuming operations, like sending emails, processing images, and generating embeddings.</li>\n<li><strong>Communication between services:</strong> decouple your services by passing messages through a central queue.</li>\n<li><strong>Load Balancing</strong>: Distribute tasks evenly across multiple workers.</li>\n</ul>\n<p>Queues can be created in the Dashboard or using SQL / database migrations.</p>\n<h3 id=\"types-of-queues\">Types of Queues<a target=\"_blank\" href=\"https://supabase.com/blog/supabase-queues#types-of-queues\">#</a></h3>\n<p>There are several types of queues available:</p>\n<!-- -->\n<p><strong>Basic Queues</strong>: Simple, reliable queues with core functionality, ideal for most use cases. Messages are stored and processed within Postgres using standard transactional guarantees.</p>\n<p><strong>Unlogged Queues</strong>: Optimized for performance, unlogged queues avoid writing messages to disk, making them faster but less durable in case of a database crash. Suitable for transient or less critical workloads.</p>\n<p><strong>Partitioned Queues</strong> (coming soon): Designed for high throughput and scalability, partitioned queues distribute messages across multiple partitions, enabling parallel processing and more efficient load handling.</p>\n<h3 id=\"queues-with-postgres-row-level-security\">Queues with Postgres Row-Level Security<a target=\"_blank\" href=\"https://supabase.com/blog/supabase-queues#queues-with-postgres-row-level-security\">#</a></h3>\n<p>Supabase Queues are compatible with Postgres Row-Level Security (RLS), providing fine-grained access control to Messages. RLS Policies restrict which users or roles can insert, select, update, or delete messages in specific queues.</p>\n<p>Once your Queue is configured you can begin adding Messages.</p>\n<!-- -->\n<h3 id=\"from-the-dashboard\">From the Dashboard<a target=\"_blank\" href=\"https://supabase.com/blog/supabase-queues#from-the-dashboard\">#</a></h3>\n<p>Let's create a new Basic Queue and add a Message.</p>\n<!-- -->\n<!-- -->\n<!-- -->\n<h3 id=\"from-the-server\">From the server<a target=\"_blank\" href=\"https://supabase.com/blog/supabase-queues#from-the-server\">#</a></h3>\n<p>If you're <a target=\"_blank\" href=\"https://supabase.com/docs/guides/database/connecting-to-postgres\">connecting</a> to your Postgres database from a server, you can add messages using SQL from any Postgres client:</p>\n<div><p><code><br><div><p><span>_<!-- -->10</span></p><p><span>select * from pgmq.send(</span></p></div><div><p><span>_<!-- -->10</span></p><p><span>  queue_name  =&gt;
