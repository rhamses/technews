So for the past few months, we've doubled-down on the Vercel x Supabase experience. Here are a few of the newest improvements.</p>\n<p>Our new <a target=\"_blank\" href=\"https://vercel.com/integrations/supabase\">Vercel Integration</a> streamlines the process of creating, deploying, and maintaining web applications.</p>\n<h3 id=\"monorepo-support\">Monorepo support<a target=\"_blank\" href=\"https://supabase.com/blog/using-supabase-with-vercel#monorepo-support\">#</a></h3>\n<p>You can now <a target=\"_blank\" href=\"https://app.supabase.com/org/_/integrations\">link multiple</a> Vercel projects to a single Supabase project:</p>\n<!-- -->\n<p>Previously we mapped each Vercel project to a single Supabase project. With this release, we're introducing the concept of project 'Connections'. Supabase projects can have an unlimited number of Vercel Connections. This is especially useful for monorepos using <a target=\"_blank\" href=\"https://turbo.build/\">Turborepo</a>.</p>\n<h3 id=\"automatically-managed-supabase-config\">Automatically managed Supabase config<a target=\"_blank\" href=\"https://supabase.com/blog/using-supabase-with-vercel#automatically-managed-supabase-config\">#</a></h3>\n<p>We've improved the way we manage your Supabase environment variables.</p>\n<!-- -->\n<p>Supabase keeps each of your Vercel Projects updated with Environment Variables, managing your secrets (like <code>service-role-key</code>) and public variables (like <code>supabase-url</code>).</p>\n<p>Importantly, Supabase now updates the Auth Redirect URIs to match your main Vercel project domain and any preview deployment URLs. We listen to your Vercel deployment webhooks and adjust your redirects accordingly.</p>\n<h3 id=\"starter-kits\">Starter kits<a target=\"_blank\" href=\"https://supabase.com/blog/using-supabase-with-vercel#starter-kits\">#</a></h3>\n<p>Don't have a project to work on yet? Not a problem, Supabase has a range of Starter kits. With the click of a button you can you have an full-stack application running in less than a minute.</p>\n<p>You can find a Vercel Starter kit by looking for Vercel's blue \"Deploy Button\". Clicking on any one of these buttons will:</p>\n<ol>\n<li>Take you to Vercel to clone the repository to your own GitHub account/organization</li>\n<li>Auto install the Supabase Integration (if not already done so).</li>\n<li>Then we make things really easy: Supabase checks for any migrations in the Starter kit, and if so, we'll run them in your new Supabase project.</li>\n</ol>\n<p>After Vercel has deployed the app, it works without any additional configuration. Starter kits include everything from table schemas, authentication, and sample data from the <code>seed.sql</code> file.</p>\n<h3 id=\"database-branching\">Database Branching<a target=\"_blank\" href=\"https://supabase.com/blog/using-supabase-with-vercel#database-branching\">#</a></h3>\n<p>We announced Database Branching on <a target=\"_blank\" href=\"https://supabase.com/blog/supabase-local-dev#branching-and-preview-environments\">Tuesday</a>. We've designed this to work perfectly with Vercel's Preview Deployments.</p>\n<!-- -->\n<p>For now, Branching in Supabase is limited to development partners. We'll be rolling it out to everyone over the coming months. If you're interested in testing the new features, <a target=\"_blank\" href=\"https://forms.supabase.com/branching-request\">sign up for early access</a>.</p>\n<p>The new App Router in Next.js adds a lot of exciting features, like React Suspense and Streaming. This means Supabase Auth needs to be configured to store session data in cookies - available in the browser and on the server - rather than Local Storage. We've simplified this process for you with our new <a target=\"_blank\" href=\"https://supabase.com/docs/guides/auth/auth-helpers/nextjs\">Next.js Auth Helpers package</a>.</p>\n<p>This configures cookie-based Auth, making the user's session available throughout the entire Next.js App Router stack:</p>\n<ul>\n<li><a target=\"_blank\" href=\"https://supabase.com/docs/guides/auth/auth-helpers/nextjs#client-components\">Client Components</a> — <code>createClientComponentClient</code></li>\n<li><a target=\"_blank\" href=\"https://supabase.com/docs/guides/auth/auth-helpers/nextjs#server-components\">Server Components</a> — <code>createServerComponentClient</code></li>\n<li><a target=\"_blank\" href=\"https://supabase.com/docs/guides/auth/auth-helpers/nextjs#server-actions\">Server Actions</a> — <code>createServerActionClient</code></li>\n<li><a target=\"_blank\" href=\"https://supabase.com/docs/guides/auth/auth-helpers/nextjs#route-handlers\">Route Handlers</a> — <code>createRouteHandlerClient</code></li>\n<li><a target=\"_blank\" href=\"https://supabase.com/docs/guides/auth/auth-helpers/nextjs#middleware\">Middleware</a> — <code>createMiddlewareClient</code></li>\n</ul>\n<p><a target=\"_blank\" href=\"https://nextjs.org/docs/pages/api-reference/create-next-app\">create-next-app</a> is one of the easiest way to get started with Next.js.</p>\n<p>We've created a new template for <code>create-next-app</code> scaffolding Supabase projects:</p>\n<div><p><code><br><div><p><span>_<!-- -->10</span></p><p><span>npx create-next-app -e with-supabase</span></p></div><br></code></p></div>\n<p>This creates a new Next.js app configured with:</p>\n<ul>\n<li>Server-side cookie-based Auth</li>\n<li>TypeScript</li>\n<li>Tailwind CSS</li>\n</ul>\n<p>This is the perfect starting point for any application built with Next.js and Supabase!
