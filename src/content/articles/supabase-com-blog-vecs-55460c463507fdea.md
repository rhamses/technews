contentHtml: "<article><div>\n<p><a target=\"_blank\" href=\"https://github.com/supabase/vecs\">Vecs</a> is a new Python library for managing embeddings in your Postgres database with the pgvector extension.</p>\n<p>It handles:</p>\n<ul>\n<li>Creating and indexing tables</li>\n<li>Querying vectors by cosine distance, l2 distance, and max inner dot product</li>\n<li>Filtering based on user-defined metadata</li>\n</ul>\n<p>Our goal for <code>vecs</code> is to provide an interface that lets Postgres + pgvector look and feel like a dedicated vector store. It works with any Postgres database (or platform) that <a target=\"_blank\" href=\"https://github.com/pgvector/pgvector/issues/54\">supports pgvector</a>.\nIt was designed with ease-of-use, interactivity, and exploratory data analysis in mind, but works equally well as a search workhorse.</p>\n<p>If you're interested in the nuts and bolts of what's going on, it's trivial to drop into the SQL layer and see what's happening.\nAlternatively, folks who don't want to know what's happening in the database, don't need to care.</p>\n<p><code>Vecs</code> makes it easy to create a collection (table) and insert a few records - just 5 lines of code.</p>\n<h3 id=\"connecting\">Connecting<a target=\"_blank\" href=\"https://supabase.com/blog/vecs#connecting\">#</a></h3>\n<div><p><code><br><div><p><span>_<!-- -->10</span></p><p><span>import vecs</span></p></div><div><p><span>_<!-- -->10</span></p></div><div><p><span>_<!-- -->10</span></p><p><span>DB_CONNECTION = \"postgresql://&lt;user&gt;:&lt;password&gt;@&lt;host&gt;:&lt;port&gt;/&lt;db_name&gt;\"</span></p></div><div><p><span>_<!-- -->10</span></p></div><div><p><span>_<!-- -->10</span></p><p><span># create vector store client</span></p></div><div><p><span>_<!-- -->10</span></p><p><span>vx = vecs.create_client(DB_CONNECTION)</span></p></div><div><p><span>_<!-- -->10</span></p></div><div><p><span>_<!-- -->10</span></p><p><span># create a collection of vectors with 3 dimensions</span></p></div><div><p><span>_<!-- -->10</span></p><p><span>docs = vx.get_or_create_collection(name=\"docs\", dimension=3)</span></p></div><br></code></p></div>\n<p>The <code>get_or_create_collection</code> call sets up a table in the Postgres database specified by <code>DB_CONNECTION</code> in a schema named <code>vecs</code> with the user defined name <code>docs</code>.</p>\n<p>Or, more specifically:</p>\n<div><p><code><br><div><p><span>_<!-- -->10</span></p><p><span>create table vecs.docs -->10</span></p><p><span>);</span></p></div><br></code></p></div>\n<h3 id=\"insertupdate\">Insert/Update<a target=\"_blank\" href=\"https://supabase.com/blog/vecs#insertupdate\">#</a></h3>\n<p>We can -->10</span></p><p><span>        (</span></p></div><div><p><span>_<!-- -->10</span></p><p><span>          \"vec0\",           # the records user defined identifier</span></p></div><div><p><span>_<!-- -->10</span></p><p><span>          [0.1, 0.2, 0.3],  # the vector. A list or np.array</span></p></div><div><p><span>_<!-- -->10</span></p><p><span>          {\"year\": 1973}    # associated metadata</span></p></div><div><p><span>_<!-- -->10</span></p><p><span>        )</span></p></div><div><p><span>_<!-- -->10</span></p><p><span>    ]</span></p></div><div><p><span>_<!-- -->10</span></p><p><span>)</span></p></div><br></code></p></div>\n<p>which will add the records to our table if the <code>id</code> <code>\"vec0\"</code> does not exist, or updates the existing record if it does exist.</p>\n<h3 id=\"query\">Query<a target=\"_blank\" inserting\ndata.</p>\n<div><p><code><br><div><p><span>_<!-- -->10</span></p><p><span>docs.index()</span></p></div><br></code></p></div>\n<p>Where <code>index</code> optionally takes an argument for  .eq('url', '/hello-world')</span></p></div><br></code></p></div>\n<p>For more deployment options, including enterprise scalable architecture, check out the <a target=\"_blank\"
