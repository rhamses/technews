Thanks to<a target=\"_blank\" href=\"https://www.quarkslab.com/\"> Quarkslab</a> and the<a target=\"_blank\" href=\"https://www.cncf.io/\"> Cloud Native Computing Foundation</a> (CNCF), Cortex received custom review and documentation for current and future security development.</p>\n<p><strong>Audit Process</strong>:</p>\n<p>In early spring of 2026, two auditors from Quarkslab reviewed the overall security posture of Cortex using whitebox code review methods. First, they undertook a period of discovery, followed by studying the previously created threat model and alignment with project maintainers. Once an understanding of the project and its threat vectors was reached, the audit shifted to a period of code review with static analysis and finally dynamic testing. The focus of this work was around the security health of the tenant boundary and cluster operations. That means interrogating the confidentiality, integrity, and availability of those two functions.&#160;</p>\n<p><strong>Audit Results</strong>:</p>\n<ul>\n<li>7 Findings with Security Impact\n<ul>\n<li>6 Medium</li>\n<li>1 Low</li>\n</ul>\n</li>\n<li>Custom Project Documentation</li>\n<li>Fix Recommendations</li>\n<li>Recommendations for Future Security Development</li>\n</ul>\n<p>The report documents the positive impressions of the auditors as well as insights into the project’s strengths and overall risk areas.
