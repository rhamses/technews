It improves the accuracy, relevance, and trustworthiness of LLM outputs without requiring model retraining.</span></p><p><span>RAG also enhances text generation by incorporating information from private or proprietary data sources. This technique combines a retrieval model that searches large data sets or knowledge bases with a generation model like an LLM to produce readable text responses.</span></p></div><div><p></p><h2 id=\"application-architecture\">Application architecture</h2><p></p></div><div><figure><img src=\"https://static-www.elastic.co/v3/assets/bltefdd0b53724fa2ce/blt08fd47f6f39775f4/6745e600a1696b008379fde8/hybridgeospatial.png\" alt=\"hybrid geospatial rag \"></figure></div><div><p><span>This reference architecture explains how to build a sample conversational AI assistant for the real estate industry using Elasticsearch, AWS Location Service, AWS Data Exchange, and Amazon Bedrock.</span></p><ul><li><p><span><strong>Step 1:</strong></span><span> The user submits a query about properties in an area — “Find me townhomes with a swimming pool within 2 miles of 33 Union Sq, Cupertino, CA.”</span></p></li><li><p><span><strong>Step 2:</strong></span><span> The conversational AI assistant application calls the REST API through the Amazon API Gateway.</span></p></li><li><p><span><strong>Step 3: </strong></span><span>The REST API makes a call to the AWS Lambda function forwarding the user prompt.</span></p></li><li><p><span><strong>Step 4, 5:</strong></span><span> The AWS Lambda function calls Anthropic Claude 3 Sonnet through Amazon Bedrock for extracting entities like address, distance, and type of property.
