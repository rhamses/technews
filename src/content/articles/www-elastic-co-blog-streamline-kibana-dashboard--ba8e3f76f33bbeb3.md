This feature is available in technical preview in Kibana 8.11.</span></p><p><span>There are occasions in which you may want to create multiple thematically related dashboards and link them to each other. This is a better way to </span><a target=\"_blank\" href=\"https://www.elastic.co/blog/designing-intuitive-kibana-dashboards-as-a-non-designer\"><span>organize your visualizations</span></a><span> that will result in smaller, more usable and more performant dashboards. For example, users could not carry over their context such as filters and queries when navigating from dashboard to dashboard, which slowed down their analysis. Moreover, when importing or copying a new dashboard to a space, the links in the Markdown panel would not work because they were referencing a different space.&#160;</span></p><p><span>The Links panel will fix all these issues by providing a streamlined way to organize and navigate your dashboards.</span></p></div><div><p></p><h2 id=\"get-started-with-the-links-panel\">Get started with the Links panel</h2><p></p><p><span>In this post, we will show how to create a Links panel to link four different dashboards provided by default when you install the Elastic Agent. These dashboards contain different metrics collected by the Elastic Agent, and users will usually need to navigate from one to the other.</span></p></div><figure><img src=\"https://play.vidyard.com/kHjDktSPHxhbC5hFpAyhzj.jpg\" alt=\"Video thumbnail\"></figure><div><p><span>Start by opening one of the dashboards you want to link (make sure you have edit permissions) and follow these easy steps:</span></p><p><span>1. Click the </span><span><strong>Add panel</strong></span><span> button and click again on the </span><span><strong>Links</strong></span><span> option.</span></p></div><div><figure><img src=\"https://static-www.elastic.co/v3/assets/bltefdd0b53724fa2ce/bltc5c3af4741c5fa06/654dcd89bfc7b3040a8b2a06/1-elastic-blog.png\" alt=\"1 - links\"></figure></div><p><span>2. A flyout will be displayed where you can decide whether you want your links to be listed vertically or horizontally. We are selecting </span><span><strong>vertical</strong></span><span> for this example (a horizontal layout example is provided in the first gif in this post). Then click on the </span><span><strong>Add link</strong></span><span> button.</span></p><div><figure><img src=\"https://static-www.elastic.co/v3/assets/bltefdd0b53724fa2ce/blt0623ae51187bcc0e/654dcd93258798040ab5c3a5/2-elastic-blog.png\" alt=\"2 - layout\"></figure></div><p><span>3. You can select to add a link to dashboards or to any other URLs. Select the dashboard labeled as </span><span><strong>Current</strong></span><span> to add a link to the open dashboard.</span></p><div><figure><img src=\"https://static-www.elastic.co/v3/assets/bltefdd0b53724fa2ce/bltcf3be9edd06c4049/654dcd9da238d9040aeca066/3-elastic-blog.png\" alt=\"3 - current\"></figure></div><p><span>4. Add any custom text to display in your panel if you don’t want to use the original dashboard name and click </span><span><strong>Add link</strong></span><span>.</span></p><div><figure><img src=\"https://static-www.elastic.co/v3/assets/bltefdd0b53724fa2ce/blt56134121794aea13/654dcda5121719040ad2172e/4-elastic-blog.png\" alt=\"4 - text overview\"></figure></div><p><span>5. Keep doing the same for all the dashboards. Rearrange them by dragging and dropping them in this list.</span></p><div><figure><img src=\"https://static-www.elastic.co/v3/assets/bltefdd0b53724fa2ce/blt65cdc969e91b42fc/654dcdaec29c46040aaeefc0/5-elastic-blog.png\" alt=\"5 - create links panel\"></figure></div><p><span>6. This will allow you to reuse this panel in other dashboards later on. Since we need to add the same panel to our four dashboards, it will be faster and easier to manage if we reuse the same panel rather than creating multiple different panels. That way any edits to the panel will be automatically reflected in all dashboards. However, if you don’t need this, you can disable this option by turning off the toggle. You will always be able to make the decision later by using the save to library option from the panel menu.</span></p><div><figure><img src=\"https://static-www.elastic.co/v3/assets/bltefdd0b53724fa2ce/blt7b24d50546edb5ba/654dcdb61d4362040ac501fc/6-elastic-blog.png\" alt=\"6 - Save to library\"></figure></div><p><span>7. After clicking </span><span><strong>Save</strong></span><span>, the following window will be displayed asking you to set a name for your Links panel and save it to the library.</span></p><div><figure><img src=\"https://static-www.elastic.co/v3/assets/bltefdd0b53724fa2ce/bltafa96dce0a5f9719/654dcdbe590422040af0eaad/7-elastic-blog.png\" alt=\"7. -save links panel to library\"></figure></div><p><span>8. You can now see your Links panel in the dashboard where you can resize it and move it around. The panel title set in the previous step is displayed by default, but you can hide it by clicking on it and turning off the </span><span><strong>Show title</strong></span><span> toggle.</span></p><div><figure><img src=\"https://static-www.elastic.co/v3/assets/bltefdd0b53724fa2ce/blt37d69d906228f571/654dcdc6f3aa15040a459068/8-elastic-blog.png\" alt=\"8. -elastic agent links panel\"></figure></div><div><figure><img src=\"https://static-www.elastic.co/v3/assets/bltefdd0b53724fa2ce/bltd25b77f83542695f/654dcdcfa238d9040aeca06a/9-elastic-blog.png\" alt=\"9 - show title\"></figure></div><p><span>9. We now have our Links panel in the dashboard!</span></p><div><figure><img src=\"https://static-www.elastic.co/v3/assets/bltefdd0b53724fa2ce/blt90c4bcffb6743f1d/654dcdd6111f09040a46ee91/10-elastic-blog.png\" alt=\"10 - overview dropdown\"></figure></div><div><p><span>Next, we need to add this Links panel to the rest of the dashboards. Since we added the Links panel to the library (see steps 6 and 7), you will be able to search for it and simply add it to the other dashboards.</span></p><p><span>10. Navigate to one of the other dashboards where you want to add the Links panel and click on the </span><span><strong>Add from library</strong></span><span> button.</span></p></div><div><figure><img src=\"https://static-www.elastic.co/v3/assets/bltefdd0b53724fa2ce/bltf77bac1bbbdec3c8/654dcdde45c7f1040abcb66a/11-elastic-blog.png\" alt=\"11 - add from library\"></figure></div><p><span>11. Search for the Links panel name and click on it — it will automatically be added to the dashboard with the same width and height as the one you set in the previous dashboard.</span></p><div><figure><img src=\"https://static-www.elastic.co/v3/assets/bltefdd0b53724fa2ce/blt29d7ae1af58dcd2b/654dcde773289a040a26df13/12-elastic-blog.png\" alt=\"12 - add from library dashboard\"></figure></div><div><figure><img src=\"https://static-www.elastic.co/v3/assets/bltefdd0b53724fa2ce/blt46462dbeed4b4474/654dce04d013f8040ae54520/13-elastic-blog.png\" alt=\"13 - add from library dashboard-2\"></figure></div><div><p><span>12.
