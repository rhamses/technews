contentHtml: "<div><p>If you've been following the Open Semantic Interchange (OSI) project, the open specification for semantic layer and ontology, there's an important update. The project has been accepted into the Apache Incubator. Along with this transition the name is changing to Apache Ossie (Incubating).</p><p>The spec, the community, and the mission haven't changed, but the name, governance home, and long-term trajectory have.</p><h2 id=\"why-the-new-name\">Why the new name?</h2><p>When work on this initiative was started, it was called the Open Semantic Interchange. This quickly got shortened to OSI, which became the GitHub repo name. Unfortunately this has caused some confusion along the way as the acronym OSI is used frequently to refer to Open Source Initiative.</p><p>Now although it might be fun to say OSI OSI (Open Source Initiative Open Semantic Interchange), the community decided it was best to rename the project. Through discussion the community decided on Ossie, and with acceptance into the Apache incubator, it is now Apache Ossie (Incubating). In addition to the rename, a mascot has been chosen, a kangaroo. The Ossie Kangaroo is dedicated to carrying semantic metadata in its pouch from platform to platform. That is, it’s making your data hop.</p><p>In short:</p><ul><li>The project is Apache Ossie (Incubating)</li><li>Any reference to \"OSI\" in the project are historical (and will slowly be removed)</li><li>There is a kangaroo logo</li></ul><p>If you've been building on Open Semantic Interchange, nothing breaks. The name changed, but the spec didn't.</p><h2 id=\"what-is-ossie\">What is Ossie?</h2><p>Ossie is an open specification for both semantic layer and ontology. It defines a vendor-neutral format for expressing business metrics, dimensions, relationships, as well as broader business concepts and rules. It allows any tool or platform in your semantic layer stack to produce and consume semantic definitions without loss of meaning.</p><p>The problem it solves is important: it ensures that a given business concept (say, \"Monthly Active Users\") can be defined, interpreted, and resolved consistently across an organization's CRM, data warehouse, and BI tools. When a human analyst or an AI agent runs a query, they shouldn't have to guess which definition is correct. Ossie provides the shared, machine-readable format that encodes not just the data but the intent and business meaning behind it.</p><h2 id=\"why-the-apache-software-foundation-asf\">Why the Apache Software Foundation (ASF)?</h2><p>Incubating Ossie with the Apache Software Foundation ensures that it remains an open standard with no single controlling entity. The goal of Ossie is to provide industry-wide standardization of semantic data, and to that end ensuring that it has a vendor neutral ground to operate in is imperative.</p><p>Under incubation, Ossie operates with public mailing lists, GitHub-based development, a formal discussion-and-vote process for spec changes, and committership earned through contribution rather than employer affiliation. Note that as part of this transition, all mailing lists referring to Open Semantic Interchange will be retired; community members should use the ASF-provided project resources that are linked below instead.</p><p>Ossie didn't start as a single-company project, it has been a community effort. Since the repository opened in November 2025:</p><ul><li>More than 100 commits and 35 merged pull requests have landed from contributors at Snowflake, Salesforce, Databricks, dbt Labs, RelationalAI, GoodData, and Honeydew</li><li>The participating coalition has grown from 17 launch partners to <a target=\"_blank\" title=\"more than 50 organizations\" href=\"https://www.snowflake.com/en/blog/open-semantic-interchanges-specs-finalized/\">more than 50 organizations</a></li><li>Three working groups (Metric Language, Catalog, and Ontology) operate with dedicated leads, meetings and public channels</li><li>Implementations including the Ossie-to-dbt Semantic Layer converters and an Apache Polaris™ converter are already merged</li></ul><h2 id=\"whats-next\">What's next</h2><p>dbt Labs was one of the founding organizations behind Open Semantic Interchange, and we'll continue as an active contributor to the project as it grows under ASF governance.</p><p>As with any Apache project, the community will decide the direction together. That said, there are a few areas we're excited about and hope to work with the community to contribute proposals for:</p><ul><li>Deepening the spec's expressiveness to accommodate what real enterprise models demand, including an expression language spec, advanced metric logic, windowing functions and complex relationships</li><li>Building converters for additional platforms and frameworks so that adopting Ossie doesn't require ripping out what you already have</li><li>A standardized semantic query specification that any engine can support</li><li>Integration with Apache Polaris so that semantic models are discoverable directly from the catalog</li></ul><p>None of this is predetermined. It will go through the same open discussion-and-vote process as everything else in the project.</p><h2 id=\"get-involved\">Get involved</h2><p>Ossie is transitioning to ASF infrastructure as part of incubation. Watch for updates on the new <a target=\"_blank\" title=\"project website\" href=\"http://ossie.apache.org/\">project website</a>, join the <a target=\"_blank\" title=\"development mailing list\" href=\"mailto:dev@ossie.apache.org\">development mailing list</a>, collaborate on <a target=\"_blank\" title=\"GitHub\" href=\"https://github.com/apache/ossie\">GitHub</a> and join the <a target=\"_blank\" title=\"Ossie Slack workspace\" href=\"https://join.slack.com/t/apache-ossie/shared_invite/zt-42i1xkgy8-7YQtKEDq7v~mceFmdiLhkA\">Ossie Slack workspace</a>.</p><p>Whether you're building an AI agent, BI tool, or a query engine that needs to understand business context, Ossie is the community working to make sure you don't have to tackle semantic interoperability alone.</p></div>"
