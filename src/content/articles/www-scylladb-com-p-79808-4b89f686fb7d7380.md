contentHtml: "<div>\r\n                        <p><strong>Connect your AI agents to ScyllaDB using the new ScyllaDB integration in MCP Toolbox for Databases</strong></p>\n<p>ScyllaDB is now a supported database source in <a target=\"_blank\" href=\"https://github.com/googleapis/mcp-toolbox/releases/tag/v1.5.0\">MCP Toolbox for Databases</a> (as of v1.5.0). This means that your agents and applications can query your ScyllaDB clusters using the same framework they use to connect to Postgres, MySQL, BigQuery, and dozens of other databases.</p>\n<p>This post walks through what was added, how to set it up, and how to connect it to your agent or framework of choice.</p>\n<p></p>\n<h2>What is MCP Toolbox for Databases?</h2>\n<p><a target=\"_blank\" href=\"https://github.com/googleapis/mcp-toolbox\">MCP Toolbox for Databases</a> is an open source <a target=\"_blank\" href=\"https://modelcontextprotocol.io/\">Model Context Protocol (MCP)</a> server that Google built to connect AI agents and applications directly to databases. It supports 40+ databases, including PostgreSQL, MySQL, MongoDB, Redis, Spanner, BigQuery, and now ScyllaDB.</p>\n<p>It serves two purposes:</p>\n<ul>\n<li><strong>As a ready-to-use MCP server:</strong> You can instantly plug your IDE assistant (Claude Code, Gemini CLI, Codex, and others) into your database. That lets your team ask questions in plain English, explore schemas, and generate data-aware code without writing boilerplate.</li>\n<li><strong>As a custom tools framework:</strong> You can define safe, structured CQL tools for your production AI agents using a simple YAML config. Toolbox handles all the connection pooling, authentication, and observability out of the box.</li>\n</ul>\n<p>Toolbox has client SDKs for <a target=\"_blank\" href=\"https://pypi.org/project/toolbox-core/\">Python</a>, <a target=\"_blank\" href=\"https://www.npmjs.com/package/@toolbox-sdk/core\">JavaScript/TypeScript</a>, <a target=\"_blank\" href=\"https://pkg.go.dev/github.com/googleapis/mcp-toolbox-sdk-go\">Go</a>, and <a target=\"_blank\" href=\"https://mvnrepository.com/artifact/com.google.cloud.mcp/mcp-toolbox-sdk-java\">Java</a>.</p>\n<h2>The ScyllaDB Integration</h2>\n<p>The integration adds two new resource types to MCP Toolbox:</p>\n<ul>\n<li><strong>scylladb source:</strong> Connects Toolbox to a ScyllaDB cluster over the <a target=\"_blank\" href=\"https://docs.scylladb.com/stable/cql/\">CQL protocol</a>. It’s built on the <a target=\"_blank\" href=\"https://github.com/scylladb/gocql\">ScyllaDB Go driver</a>.</li>\n<li><strong>scylladb-cql tool:</strong> Executes a pre-defined CQL statement against a ScyllaDB source, with support for parameterized queries and template parameters.</li>\n</ul>\n<p>Both self-hosted ScyllaDB clusters and <a target=\"_blank\" href=\"https://cloud.scylladb.com/\">ScyllaDB Cloud</a> are supported.</p>\n<h2>Installing and Running MCP Toolbox</h2>\n<p>Toolbox ships as a single binary. The quickest way to install it on Linux (AMD64):</p>\n<pre><code>curl -L https://github.com/googleapis/mcp-toolbox/releases/latest/download/toolbox_linux_amd64 -o toolbox\r\nchmod +x toolbox</code></pre>\n<p>For other installation options, <a target=\"_blank\" href=\"https://mcp-toolbox.dev/documentation/introduction/#install-toolbox\">see the docs</a>.</p>\n<p>Once installed, start it with your configuration file:</p>\n<pre><code>./toolbox --config tools.yaml</code></pre>\n<h2>Connecting MCP Toolbox to ScyllaDB</h2>\n<p>The scylladb source is defined in <code>tools.yaml</code>. Here’s a minimal self-hosted configuration:</p>\n<pre><code>kind: source\r\nname: my-scylladb-source\r\ntype: scylladb\r\nhosts:\r\n  - 127.0.0.1\r\nkeyspace: my_keyspace\r\nusername: ${SCYLLA_USER}\r\npassword: ${SCYLLA_PASSWORD}</code></pre>\n<h3>Connecting to ScyllaDB Cloud</h3>\n<p>For <a target=\"_blank\" href=\"https://cloud.scylladb.com/\">ScyllaDB Cloud</a>, set <code>localDC</code> to the datacenter name shown on the Connect tab of your cluster. This enables DC-aware, token-aware load balancing:</p>\n<pre><code>kind: source\r\nname: my-scylladb-cloud-source\r\ntype: scylladb\r\nhosts:\r\n  - node-0.your-cluster.us-east-1.cloud.scylladb.com\r\n  - ...\r\nkeyspace: my_keyspace\r\nusername: ${SCYLLA_USER}\r\npassword: ${SCYLLA_PASSWORD}\r\nlocalDC: AWS_US_EAST_1</code></pre>\n<hr>\n<h2>Defining CQL Tools for Your AI Agent</h2>\n<p>Here is a simple lookup tool definition:</p>\n<pre><code>kind: tool\r\nname: search_users_by_email\r\ntype: scylladb-cql\r\nsource: my-scylladb-source\r\nstatement: |\r\n  SELECT user_id, email, first_name, last_name, created_at\r\n  FROM users\r\n  WHERE email = ?\r\nparameters:\r\n  - name: email\r\n    type: string</code></pre>\n<p>The <code>?</code> placeholder is replaced at runtime, preventing CQL injection. For dynamic table names, use <code>templateParameters</code> with Go template syntax.</p>\n<h2>Connecting to Your AI Client or Framework</h2>\n<h3>MCP Clients (Claude Code, Gemini CLI, etc.)</h3>\n<pre><code>{\r\n  \"mcpServers\": {\r\n    \"toolbox\": {\r\n      \"type\": \"http\",\r\n      \"url\": \"http://127.0.0.1:5000/mcp\"\r\n    }\r\n  }\r\n}</code></pre>\n<h3>Python Applications</h3>\n<pre><code>from toolbox_core import ToolboxClient\nasync with ToolboxClient(\"http://127.0.0.1:5000\") as client:\r\n    tools = await client.load_toolset(\"user_tools\")</code></pre>\n<h2>To get started:</h2>\n<ul>\n<li><a target=\"_blank\" href=\"https://mcp-toolbox.dev/integrations/scylladb/source/\">ScyllaDB integration docs</a></li>\n<li><a target=\"_blank\" href=\"https://github.com/googleapis/mcp-toolbox\">MCP Toolbox on GitHub</a></li>\n<li><a target=\"_blank\" href=\"https://cloud.scylladb.com/\">ScyllaDB Cloud</a></li>\n<li><a target=\"_blank\" href=\"https://university.scylladb.com/\">ScyllaDB University</a></li>\n</ul>\n                    </div>"
